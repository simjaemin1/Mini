
⚠ 클라우드 상자(코어 2 · 8 GB)는 무거운 판 동시 2 까지(T1345 회부 5) · 판 하나 365날 ≈ 2시간 · 둘째 해는 전쟁으로 하루 40 ~ 110초(두 해 판은 이 상자에서 못 돈다 — 회부).
판 폴더 이름(`판표.json` · `덧붙임셋.json` 의 `dir`): `판/x/*` = 한 번에 돈 판 · main `311d0773a` + T1380 · `판/s/*`(덧붙임 셋 · T1373 위) · `판/b/*`(④ 몸 세계) · `판/t/*`(T1302) = 마디 판(`--every 30` · `T1345_SEG=1 T1380_SEG=1`) · 가지 끝(land1085 + T1380). 마디 판 다시 하기: 위 줄에 `--every 30` 과 env `T1345_SEG=1 T1380_SEG=1` · 끊기면 `node scripts/t1308-long-run.js --resume <폴더>`.
