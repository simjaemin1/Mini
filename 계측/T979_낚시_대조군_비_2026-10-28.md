## 0. 하늘의 비는 벽시계 날의 해시다

* 하네스 존은 `ENABLE_VILLAGES=0` 이라 날씨 날 = `zoneGameDay()` = ⌊벽시계 ÷ 24분⌋(`server/zone.js _rawGameDay`).

## 2. ⑦ 도 같은 어긋남에 기대 있었다(종전 하네스)

B(바람 켬 · 비 켬) ↔ C(비 끔 · **`windOff`**) — `windOff` 는 풀 층을 "종전대로 선명한 텍스처"로 바꾼다(`00-const.js:1173`). 그래서 `diff(B, C)` 대부분이 찌가 아니라 풀이었다.

| 판(종전) | 상자 안 차 | 찌 둘레 40px(찌 화면 자리 (544,445)) | 나머지 |
|---|---|---|---|
| 마른 날(밀기 +2분) | 5,783 | 678 | **5,105** (88%) |
| 약한 비 | 5,929 | 660 | **5,269** |
| 굵은 비 | 6,330 | 236 | **6,094** |

무게중심도 (735,393) — 찌(544,445)가 아니라 오른쪽 풀밭이다. "변화가 내 앞 물 위에 있다(중앙에서 < 300px)"는 화면 가운데에서 재므로 풀밭 무게중심도 통과했다.

## 3. 고친 하네스 — 비·바람 끄기를 얼린 직후(대조군 앞)로 옮김

## 4. 시계 밀기 프리로드(레포 밖 · 관찰용)

```js
// T979_SHIFT_MS 만큼 Date 를 민다 — central · zone · 하네스 + (playwright 를 감싸) 하네스가 띄우는 페이지
const S = +process.env.T979_SHIFT_MS || 0;
if (S) {
  const RD = Date, rnow = RD.now.bind(RD);
  class D extends RD { constructor(...a) { if (a.length === 0) super(rnow() + S); else super(...a); } static now() { return rnow() + S; } }
  global.Date = D;
  // (페이지 갈래: require('playwright') 를 감싸 newPage 마다 addInitScript 로 같은 D 를 심는다)
}
```

쓰는 법: `T979_SHIFT_MS=<ms> NODE_OPTIONS="-r shift.js" node scripts/e2e-fishing.js` — 목표 날 한가운데로 가는 ms = (날 + 0.3) × 1,440,000 − 지금.
