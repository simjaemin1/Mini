# 1020 양팔의 닫힌 첫 400날

진행 중인 같은 두 730날 세계에서 확정된 첫 40마디만 읽었다. 독립 400날 실행이나 730날 완료가 아니다. 365날과 400날 물자 스냅샷도 포함한다. 양팔 80마디의 실제 존 종료 코드·가상 시계 오류가 모두 0이며 켬의 몸/인구 최솟비는 1, 연결 누락 주민은 0이다.

몸 상한 Infinity·하루 24분·10날 정본 체크포인트·고정 제품 소스는 유지했다. 두 차례 환경 중단 뒤 채택한 마디만 CPU 평균에 한 번씩 넣었다. 버린 미완성 마디 CPU 관측 하한은 두 infra-recovery 폴더에 따로 있으며 전체 비용의 정확한 합은 알 수 없다. 끔의 기존 마을별 인구/몸 수 동기화는 유지한다.

`archive-*-integrity400.json`은 실행 원자료와 압축 복사본의 경제·모든 마을 필드를 각각 400/400날 비교한 보존 무결성 검사다. 고침 전/후 의미 보존 지문 범위를 400날로 늘리는 검사가 아니며, 그 범위는 별도 100/100날이다.

이탈은 `t1075Emigrate`가 수락한 마을 이주 횟수다. 완공 0은 당일 몸 완공 증가가 없는 마을 수이며 끔 팔에는 해당하지 않는다. 400날 켬 당일 완공 0은 48마을, 직전 10날 내내 완공 0은 46마을이다. 빈 마을은 켬 0·끔 1이다. `bodyStarve`·`debtDeaths` 원시 계수는 서로 더해 고유 사망자 수로 해석하지 않는다.

보존에 사용한 오프라인 도구는 `archive-prefix.py`다. 기존 판만 읽으며 새 세계를 띄우지 않는다. 같은 라이브 판이 남아 있을 때 별도 출력 경로로 재현할 수 있다.

```sh
python3 계측/T1411_2026-11-21/pair-1020-400/archive-prefix.py --through 400 --out /tmp/t1411/recheck-pair400 --reuse 계측/T1411_2026-11-21/pair-1020-300
```
