# 1020 양팔의 첫 100날 접두부

진행 중인 두 730날 판의 닫힌 첫 10마디만 읽었다. 독립 100날 판이나 730날 완료가 아니다. `summary.json`·CSV는 이 접두부만의 집계다. 원본 ON 자료는 `../feature-100/ON-1020`, OFF 자료는 이 폴더의 `OFF-1020`에 있다. source-progress는 복사 시점의 실제 감독 상태이며 closed-prefix는 포함한 마디를 명시한다. 100날 지점이 지난 뒤에도 같은 세계가 계속 돈다. 양팔 몸 상한은 없지만 OFF의 종전 몸 동기화는 마을당 하루 ±2명이고 ON은 T1302가 1:1을 강제하므로, 순간의 몸 수를 인구와 무조건 같다고 쓰지 않는다.
