사용자가 “지금은?”이라고 물었을 때 환경은 starting이었다. ready 후 실제 세계·감독·백업·집계 프로세스 및 제품 종료 코드 파일이 모두 없음을 확인했다. 마지막 일일 기록은 켬551날(25일05:37)·끔561날(05:42)이었다. 중단 직전 제공자 상태나 중단 원인은 직접 관측하지 못했다. 현재 환경 진단은 running/connected·failure=null이다. 이 값으로 과거 원인을 판단하지 않는다.

미완성 자료와 이진 체크포인트를 먼저 별도 보존하고 SHA256을 확인했다(interruption.json, preserve-before-resume.py). 켬550날·끔560날부터 기존 명령으로 이어갔다. 실제 존 두 개와 정본 러너 두 개의 환경은 launch-verification.json에 있다. Node22.23.0/ABI127·고정 제품/계측기·하루24분·몸 상한 없음 조건을 유지했다. 런처의 Infinity 표기는 정본 자식 환경에서 변수를 제거해 제품 기본값 Infinity를 사용하는 기존 방식이다(server/villages.js:216). 첫 확인 스크립트는 존에도 문자 Infinity를 요구하여 실패했고, 기존 정본의 정규화와 제품 기본값을 확인한 뒤 실제 값을 기록했다. 제품이나 실험 환경은 바꾸지 않았다.
