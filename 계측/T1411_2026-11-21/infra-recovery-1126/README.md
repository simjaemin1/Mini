# 일곱 번째 중단 뒤 복구 · 한국 시각2026-11-26

질문 시 환경은 starting이었다. ready 뒤 실제 세계·감독·백업·최종 집계 대기 프로세스와 제품 종료 코드 파일이 모두 없었다. 마지막 관측은 켬626날·끔635날이다. 중단 직전 제공자 상태나 원인은 이번 턴에서 직접 관측하지 못했다. 현재 진단은 running/connected·failure=null이며 이 값으로 과거 원인을 판단하지 않는다.

미완성 마디와 이진 체크포인트를 먼저 별도로 보존하고 SHA256을 확인했다(interruption.json, preserve-before-resume.py). 확정 켬620날·끔630날부터 저장된 기존 명령으로 재개했다. Node22.23.0·SQLite ABI127·고정 제품/계측기·몸 상한 없음·하루24분 조건을 유지한다. 실제 존 둘·정본 러너 둘의 지정 필드와 PID는 launch-verification.json에 있다. 런처의 Infinity 표기는 정본 자식 환경에서 변수를 없애 기존 제품 기본값Infinity를 쓰는 방식이다.
