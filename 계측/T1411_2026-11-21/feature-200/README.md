# ON/1020 판의 닫힌 첫 200날

진행 중인 같은 730날 판에서 닫힌 첫 20마디만 읽었다. 독립 200날 실행이나 730날 완료가 아니다. 모든 경제·마을 필드의 원본/후보 지문 일치는 별도 100날 대조이며 여기서 200날 일치로 늘려 부르지 않는다. OFF/1020이 200날에 닿기 전에는 200날 끔비를 만들지 않는다. 실제 source-progress·닫힌 마디 목록·원자료를 함께 보존한다.

`archive-integrity200.json`은 같은 후보 판의 보존 전 파일과 압축 보존본 200날의 경제·마을 필드를 맞댄 보존 무결성 검사다. 첫 20마디 실제 존 종료와 가상 시계 오류도 각각 0을 확인했다.
