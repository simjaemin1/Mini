# V8 덩이 표의 범위

`native-age-groups.csv`의 시간은 표본 사이 경과 시간이다. OS CPU가 아니다. 포함 시간은 부모·자식이 겹친다.

초기 표의 `spatial_index`는 `rebuildSpatialIndex`·`_rebuildSpatialInc`·`_sweepOne`을 합친 **공간 색인+주기 쓸기**다. 이름을 유지하고 두 구성 항목을 추가했다.

- `spatial_build`: 공간 색인 두 함수만.
- `body_periodic`: `_sweepOne`. 이 몸통은 계단·낙하·허기 등 게이지·HP 회복·게이지 전송을 부른다.

따라서 `spatial_index`와 그 두 하위 항목을 더하지 않는다. 원본 91~100날 자기 표본초/날은 색인만 7.338, 주기 쓸기 3.926, 합 11.264다. 포함 표본초/날은 각각 7.893·8.036이며, 이는 두 몸통이 부른 하위 함수도 포함한다.

`observer_self`는 기존 관찰기 파일의 자기 시간이고, `census`는 별도 v3 시간대 관찰기의 자기 시간이다. census의 포함 시간에는 원래 onGameTick 실행도 걸리므로 관찰 오버헤드라고 부르지 않는다.

첫 1~30날과 91~100날은 같은 나이의 전후 비교가 아니다. 나이에 따른 비용 변화를 보는 원본 진단이다. 후보 전후는 양쪽의 같은 91~100날 자료로 비교한다.
