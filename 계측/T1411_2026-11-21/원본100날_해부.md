# 원본 100날 나이의 해부

main `1aa63e637` 원본의 닫힌 90날 체크포인트를 재생한 91~100날이다. 앞 90날은 공유하며 독립 100날 반복이 아니다. 원본과 신규 재생 10날의 경제·모든 마을 필드 지문이 같고 전체 비교는 100/100이다.

네이티브 프로파일 1개·표본 1,204,444개·표본 가중치 경과 시간 1,366.628초. **아래 값은 OS CPU가 아닌 자기 표본 경과초/게임날**이다. 포함 시간은 겹치므로 더하지 않는다. 91~100날에는 v3 시간대 관찰기가 추가되며 자기 시간도 별도로 보인다.

| 덩이 | 원본 첫 1~30날 | 원본 91~100날 |
|---|---:|---:|
| 걸음 준비·뒷일 | 8.737 | 19.444 |
| 공간 색인·쓸기 | 5.568 | 11.264 |
| 몸 판단·이동 콜백 | 5.932 | 13.399 |
| 몸 분리 | 2.498 | 5.215 |
| 길·답압 | 3.723 | 6.600 |

| 영토 선택·크루 | 0.722 | 1.319 |

| _t561Fit | 0.000 | 0.000 |
| 추가 시간대 관찰기 자기 시간 | 0.000 | 0.093 |

100날 나이의 함수별 자기 시간 꼭대기는 메인 프레임·_wwPre·_wwPreOne이다. 영토 견적·선택/크루의 합은 2.379 표본 경과초/날이고, 같은 프로파일 전체는 136.663 표본 경과초/날이다. 공유 길찾기에는 교역 경로·공통 AI 경로도 포함된다. _t561Fit은 이 판에서 큰 덩이가 아니다.

실제 원본 비프로파일의 100날 누적 OS CPU는 99.012초/날, 100날 당일은 128.897초다. 해당 CPU와 위 V8 경과 표본을 같은 단위로 합산하지 않는다. 고친 후보의 같은 91~100날도 후보 자신의 90날 체크포인트에서 재생했고, 비프로파일 후보와 전체 지문 100/100(새 재생 10날)이 같다. 전후 표는 `native-matched-91-100.csv`, 해석은 보고서의 “같은 91~100날 네이티브 전후”를 따른다. 견적·선택 자기 시간은 줄었으나 같은 비프로파일 100날 누적 CPU의 전체 개선은 확인하지 못했다.

100날 시간대 표본 24개: 실제 주민 몸 평균 1,212.25, 일과 창 안 평균 832.25(최대 1,212), 취침 라벨 610.33, 그 밖의 기록된 라벨 601.92, 미기록 0, 속도칸 0 아님 327.75. 일과 창과 행동 라벨은 서로 다른 분류다. 장부 경계의 일과 창 안은 0이다. 구간 길이는 23.99994 게임 시간이며 관찰은 표본 평균이다.

원표: `base-native-91-100/native-profile.json`, `native-age-groups.csv`, `base-awake-91-100/awake-summary.json`. 압축된 해당 마디·네이티브 프로파일·실제 종료 자료는 `base-native-91-100/raw/`에 있다.

공간 색인·쓸기 합계는 색인만 7.338 자기 표본초/날과 생존·계단 등의 주기 쓸기 3.926으로 나뉜다. CSV의 `spatial_build`·`body_periodic`이며 기존 합계 `spatial_index`에 다시 더하지 않는다. 덩이 정의는 `native-age-groups.README.md`를 따른다.

## 첫날과 100날의 실제 CPU

| 원본 날짜 | 인구·주민 몸 | 비프로파일 OS CPU 초/날 |
|---|---:|---:|
| 1 | 408 | 141.055 |
| 2 | 408 | 33.265 |
| 30 | 819 | 84.119 |
| 60 | 982 | 93.968 |
| 100 | 1219 | 128.897 |

첫날은 초기 교역 경로 구축을 포함해 100날보다도 비싸다. 첫날의 CPU를 정상 하루의 출발값으로 삼아 단조 증가를 주장하지 않는다. 주민 몸은 408→1,219로 늘고, 기동 다음 날 CPU 33.265초와 100날 128.897초는 증가했지만 한 시드의 서로 다른 나이 관측이다. 앞의 네이티브 표는 첫날 단독이 아니라 1~30날 평균과 91~100날 평균의 비교다.
