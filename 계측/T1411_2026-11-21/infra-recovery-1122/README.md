# 환경 중단과 체크포인트 복구 증거

한국 시각 2026-11-22 재연결 후 보존했다. 플랫폼에서 stopped/offline을 확인했으며 제품 종료 코드 파일은 없었다. 켬 250날·끔 210날의 확정 이진 체크포인트와 미완성 마디를 구분했다. 끔 마지막 관측 장부는 218날이다. `interruption.json`에 체크포인트·부분 파일 SHA-256과 관측된 소모 CPU 하한을 남겼다.

`replay-check.json`: 복구 뒤 같은 끔 211~218날을 재생하면서 t1274 일일 장부·t1302 일일 몸 관찰·t1411 일일 census의 보존 전/후 필드를 각각 8/8날 맞췄다. CPU·프로세스 CPU 누계·uptime 세 필드만 제외하며 census의 가상 시각은 포함한다. 이는 같은 판의 중단 구간 재생 검사다. 기존 원본/후보 전체 마을 필드 지문 100/100의 범위를 늘리는 자료나 독립 세계가 아니다.

재현 명령:

```sh
python3 scripts/t1411-recovery-check.py --evidence 계측/T1411_2026-11-21/infra-recovery-1122 --runs /tmp/t1411/worlds --out /tmp/t1411/recovery-check.json
```

진행 중 읽기에는 `--allow-incomplete`를 줄 수 있다. 결과의 complete와 matchedDays를 함께 읽는다. 일일 인구를 1 바꾼 오프라인 사본은 실제 비교에서 실패했고 CPU 시간만 바꾼 사본은 허용됐다. 실제 세계나 보존 원자료는 그 검사에서 수정하지 않았다. 환경 중단 직전의 미완성 기동 CPU와 마지막 미완성 날의 CPU는 측정되지 않아 정확한 총 복구 소모를 만들지 않는다.
