# 평형 저장본 목록 (T1420)

저장본 파일은 **레포에 넣지 않는다**(족보 911 — 맥 디스크). 여기에는 만드는 한 줄 · 지문 · 크기 · 만드는 시간만 적는다.
캐시 자리 = `${TMPDIR:-/tmp}/durango-eq-cache/<코드 지문>/` — 코드 지문 = `sim/` · `server/` · `data/` 파일 바이트 + `scripts/lib-lab-dist.js` 의 sha1 16자(`node -e 'console.log(require("./scripts/lib-eq-lab").codeSig())'`).
코드 지문이 다르면 `eq-run` 이 "낡음"이라 말하고 다시 만든다(옛 것을 조용히 쓰지 않는다). 같은 지문이면 아래 sha 와 바이트가 같아야 한다(결정론).

## 만드는 한 줄

```
# 랩(t17 자) — 저장본만
node scripts/eq-run.js --seed 1020 --from make:800 --days 1        # 캐시에 없으면 800날을 돌려 만든다(시딩 캐시 있으면 약 7분)
# 랩 — 여러 날을 한 판에서(관측 · 지문과 같이)
T1420_EQ=1 T1420_SAVE_AT=400,800 LAB_SEEDCACHE=<시딩 캐시> node scripts/t17-metrics.js 1600 1020
# 서버(끔 세계 = 서버 판 자 조건 · t1308 마디 자)
node scripts/eq-run.js --server --seed 1020 --from make:800 --days 1
```
