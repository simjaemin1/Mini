# 공개 자료 — 직접 확인한 위치와 재현 방법

## S10 HGC-TA

원문 위치는 저자 저장소 README의 `Datasets`와 `0_datapreparation.R`의 `DATA DESCRIPTION` 절, 각 `Society_Author.csv`의 헤더 및 행이다. `provenance.json`에 정확한 커밋과 입력 SHA-256을 기록했다. 논문 PDF의 쪽·방법·Table S1은 이번 환경에서 직접 열지 못했다. README는 공개12현장 파일과 별도 요청이 필요한 Tsimane 자료를 구분하며, 후자가 없으면 논문 모형 결과와 일치하지 않는다고 명시한다. 요청 메일은 보내지 않았고 논문 모형도 실행하지 않았다.

`hgc_descriptive.csv`는 공개 현장 파일만 읽은 기술 집계다. 원문을 대신한 모델 재현이 아니다.

1. CSV를 직접 읽는다. `NA`·빈 값·비유한 수는 결측이다.
2. 실제 나이가 알려지고 `3≤floor(Age)≤20`, 양수의 알려진 `offset`을 가진 행을 범위로 삼는다. 이는 R의 floor 연령 처리와 맞춘 범위이며 성인 표본이 아니다.
3. 범주별로 그 범주가 알려진 행만 분자·분모에 함께 포함한다. 결측 범주를0으로 만들지 않는다.
4. `percent = 100 × sum(category) / sum(offset)`를 파일별·범주별 계산한다. 각 분모·입력 행 수·알려진 범주 행 수·고유 ID 수를 함께 보관한다.
5. `food_production`, `household`, `childcare`, `play`는 각각 원문 변수다. food_production을 밭일, household를 오직 곡식 가공, play를 쉼으로 재명명하지 않는다. 파일마다 연령·조사법·연도·관측 구간이 달라 사회 간 원시 비율의 우열을 판정하지 않는다.
6. 반복 관측과 동시 활동이 있으므로 네 비율을 독립·배타적 비중이라고 보지 않는다. 잔여를 쉼이라 부르지 않는다. 원자료 행의 개인 ID/좌표 등은 이 저장소에 복사하지 않고 집계만 기록했다.

계산은 제품 시험이 아니라 공개 CSV의 문서용 기술 집계다. 통계적 유의성·공표 모형·연령 보정 추정치·성인 평균은 산출하지 않았다.

## S11 D-PLACE SCCS

직접 읽은 위치: `cldf/variables.csv`의 SCCS116(식물성 식품 준비),121(요리),123(땔감 채집),125(물 긷기),127(잣기),128(직조); `cldf/codes.csv`의 해당 코드; `cldf/data.csv`의 Var_ID별 값이다. 여섯 변수 각각186행·186사회를 확인했다. 각 코드의 행 수를 세고 결측·작업 없음·성별 미상도 별도로 남겼다.

이 변수들은 누가 하는가에 관한 범주다. 코드1~5의 숫자 차이를 시간 차이로 보거나, 코드를 실제 근로 비율로 바꾸지 않는다. 직접 확인한 코드북의 서지는 Murdock & Provost (1973), Ethnology12(2),203–225를 가리키지만, 이 쪽 범위는 코드북에 적힌 서지이며 원 논문의 특정 표를 직접 확인한 것은 아니다. 파생 자료의 저장소 커밋·라이선스·원 출처 서지를 함께 보존한다(README: Murdock & White1969; 자료 CC-BY-NC-4.0).

## 이 두 자료가 현재 채우지 못하는 것

성인 밭일/곡식 가공/쉼 비율, 조·기장·벼의 h/kg, 가구의 연료kg·물L·왕복 시간, 섬유별 h/kg·h/m², 도토리/밤의 kg/ha·우리기 사람-시간은 두 자료로 확정할 수 없다. 그래서 requested_metrics.csv의24지표는 미확인으로 유지한다.
