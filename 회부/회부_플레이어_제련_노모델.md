## 지금 상태

- **물리는 다 있다** — `server/era.js`:
  - `furnaceTemp(setup)` : 노 종류 × 연료(장작 900℃ 상한 / 목탄) × 풀무(+150) → 도달 온도
  - `smeltOutcome(metal, setup)` : 환원온도·융점·끓는점만으로 none / solid(단조만) / melt 판정
  - `smeltYield(metal, setup)` : 온도 여유 × 지식(시대가 모르면 ×0.05)
  - 실측: 청동기 최고 설비로 철 수율 **3.4%** → 시대 오픈 후 같은 설비 67.8% → 괴련로 88.1%
- **플레이어 흐름에는 제련 단계가 없다** — 채광 → 선광(`sort_ore`)하면 **금속이 바로 나온다**.
  NPC 는 수율 0.33 제련을 거치는데 플레이어는 공짜다(제련 규약 불일치 — 예전부터 이월된 그 항목).

## 정할 것

1. **노(爐)는 무엇인가** — 설치물인가(마을 대장간처럼 셀에 짓는다), 아이템인가(도가니를 들고 다닌다),
   마을 시설 이용인가(NPC 대장간에 수수료를 내고 빌린다). 셋 다 고증 근거가 있다.
2. **제련 UI** — 주조(3금속 슬라이더)처럼 배합 화면을 재활용할지, "원석 넣고 기다린다"로 단순화할지.
3. **목탄 사슬** — 숯가마(나무→목탄)도 설치물인가. 철 1에 목탄 몇 배로 할지(고증은 수 배).
   `charcoal` 재화는 specialty 에 이미 있다.
4. **실패 연출** — 철의 전부-아니면-전무(슬래그 덩어리)를 어떻게 보여줄지.
5. **운철** — 지표 발견물 스폰을 어디에·얼마나 드물게. `METEORIC = {iron .93, nickel .07}` 은 준비돼 있다.

## 내 의견

노는 **설치물**(플레이어 집 건설과 같은 계약), UI 는 기존 주조 화면 재활용, 목탄은 숯가마 설치물,
운철은 자잘 광맥과 같은 급의 초희귀 지표 오브젝트. 다만 전부 UX 라 확정은 재민 몫.
