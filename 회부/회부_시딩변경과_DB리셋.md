# 회부 — 시딩을 아무리 고쳐도 **라이브에는 안 먹는다** (DB 리셋 없이는)

> 2026-08-02 배치 E19. **실측으로 확인**했다. 리셋 자체는 금지 규칙이라 손대지 않고 회부만 한다.

---

## 실측

새 DB 로 `zone.js` 를 띄우면(ENABLE_VILLAGES 기본 켜짐):

```
[hanbando] 🏘️ 마을 시딩 시작 — 후보 51 → 선별 19 (VILLAGE_MAX=20)
[hanbando] 🏘️ [임업2] 시딩: 중심 셀(…) 집 2 논 … land(F1.15/W1.5/S1.45/O0.37/우드2.44)
… 18곳 시딩 …
[hanbando] 🌏 zone server up on :39311
=== ALIVE 269s · 예외 0
```

**같은 DB 로 다시 띄우면:**

```
[hanbando] 🏴 [도적] 복원: 소굴 3곳 …
[hanbando] 🌏 zone server up on :39312
시딩 로그 0줄
```

⇒ **시딩은 DB 가 비어 있을 때 딱 한 번 돈다.** 그 뒤로는 전부 복원 경로다.

## 그래서 지금 라이브(hanbando, Vultr /opt/Mini)는

`world-hanbando.db` 가 이미 있다. 그러므로 라이브 세계의 마을 20곳은 **옛 시딩(타입 prior)**
으로 뽑힌 자리이고, 초기 부존도 **옛 일괄값**이다. 즉 이번 세션과 지난 세션에서 실측으로 확인한
두 개선이 **라이브에는 하나도 반영되지 않는다**:

| 변경 | 커밋 | 실측 효과 | 라이브 반영 |
|---|---|---|---|
| 부유 시딩(식량 하한 × 도구 접근) | 1744e0e | 소멸 11.7 → 6.0 · 인구 696 → 1,118 | **안 됨** |
| 땅맞춤 초기 부존 | 2026-08-02 | 소멸 6.0 → 2.7 · 인구 1,118 → 1,630 | **안 됨** |

두 개선을 합치면 **소멸 11.7 → 2.7(−77%) · 인구 696 → 1,630(+134%)** 인데, 그 전부가
새 DB 에서만 발효한다.

## 선택지 (전부 재민 결정 — 리셋은 금지 규칙이라 나는 못 한다)

| | 내용 | 잃는 것 | 비고 |
|---|---|---|---|
| **가** | `world-hanbando.db` 리셋(새 세계 시작) | **플레이어 건축물·사유지·인벤·마을 상태 전부** | 가장 깨끗하다. 다만 플레이어가 쌓은 게 있으면 못 쓴다 |
| 나 | **마을만 재시딩** — 마을·영토·생활층 레코드만 지우고 플레이어 소유물은 남긴다 | 마을 건물·NPC. 플레이어 것은 보존 | 지금 그런 경로가 **없다**(부분 삭제 SQL + 재시딩 훅을 새로 만들어야 함) |
| 다 | **새 존을 연다** — 옛 존은 그대로 두고 새 시딩으로 만든 존을 추가 | 없음 | zone-config 에 존 추가. 옛 존은 "구세계"로 남는다 |
| 라 | 그대로 — 개선은 다음 세계에서 | 지금 세계의 마을이 계속 죽는다 | 게임 800일 = 실시간 13일 |

**내 의견**: 지금 라이브에 사람이 쌓은 게 얼마나 되는지를 내가 모른다. 그게 적으면 (가)가 옳고,
많으면 (다)가 옳다. (나)는 값이 크지만 새 코드 경로라 이번엔 안 만들었다(회부 우선).

## 덤으로 — 이번 부팅 스모크에서 확인한 것 (E19 본체)

- 새 DB 전체 부팅에 **예외 0** (`TypeError`/`ReferenceError` 없음, `boomed=false`)
- 후보 51 → 선별 19 — **랩과 정확히 같은 선별**(랩이 본 게임을 정직하게 대변한다)
- 노(爐)·숯가마 핸들러, 다광종 광맥, 운철 청크 스폰이 부팅 경로에서 예외를 안 낸다
- 시딩된 마을 land 값이 랩 값과 일치 (예: 임업2 F1.15/S1.45/O0.37 — 랩 덤프와 같음)
- 부팅에 **약 4분 30초** 걸린다(마을당 5~19초 × 18곳). 무거운 건 생활층 실체화다
- (환경 노이즈) central(3010)이 없어 NPC 길드 등록이 전부 실패한다 — 로컬 스모크에선 정상

## ★같이 알아야 할 것: 시대를 열어도 **NPC 경제는 안 바뀐다**

`scripts/era-rehearsal.js --lab` 실측(2시드 800일, 400일차 플립):
**모든 지표가 0.0% 변화**(인구 1,603 → 1,603 · 소멸 2.5 → 2.5 · 주조 2.0 → 2.0).

배선 고장이 아니다. **NPC 가 닿는 주요 광맥에 철이 한 톨도 없다**(철 광종 마을 0/19 — 1744e0e
설계 그대로: 철은 플레이어 전용 자잘 광맥 184개에만 있다). 그래서 시대를 열면 바뀌는 건
**플레이어 축뿐**이다 — 괴련로 해금 · 도가니로 수율 3.4% → 67.8% · 말 길들이기.

⇒ "NPC 철기 산업"을 원하면 시대만으로는 안 되고 **주요 광맥에 철을 넣어야** 한다.
