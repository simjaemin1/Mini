## 1. ★서버 이식 — **첫 항목은 성능이 아니라 대체다** (PM 카드 · 승인 게이트)

랩이 800일 3시드로 낸 답: `fruit` 실체화를 **추상 산출 위에 얹으면 마을이 무너진다.**

* `w(fruit)` 이 하한 0.05 로 붕괴 → Lewis 식 노동 배분이 채집 직업을 0 으로 읽는다
* → **채집꾼이 사라진다** → 채집꾼이 같이 가져오던 **채소·버섯·약재·돌**이 끊긴다
* → 세 시드 전부 인구가 내려간다: **−4.6% · −6.2% · −41.2%** · 시드 42 의 한 마을은 **117 → 5**

⇒ 이식 카드는 `sim/economy-sim.js:388 foragerYieldsFor` 의 `fruit`(그리고 `chestnut`·`grape`·`acorn`)를
**걷어내는 것과 같은 커밋에서** 실체를 얹어야 한다. 걷지 않으면 이중계상이고, 가격이 그걸 정확히 벌한다.

## 4. 목재 품목 분할 (레시피 다섯 표)

지금 `wood` 한 품목이라 `w(목재)` **하나가 일곱 종을 다 대표**한다.
소나무 기둥 · 참나무 숯 · 버들 바구니 · 산뽕 잠박이 다른 값이면 부등식이 훨씬 날카로워지고,
**`char`(숯 수율) 축이 비로소 쓰인다**(지금은 표에만 있고 아무도 안 읽는다).

## 4-b. 누락 품목 셋 — 표가 값을 못 읽는 자리

  T123 초안이 `hazelnut`·`mulberry_leaf` 로 800일을 그렇게 돌렸다. 하네스 ④' 가 이제 그걸 잡는다.
