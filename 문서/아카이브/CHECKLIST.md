수정할 때마다 **반드시** 아래를 확인한다. 자동 검증: `node sim/regression-check.js` (5시드, ~40초).

## 불변식 (regression-check.js가 자동 검사)

1. **빌드 회귀** — `build-econ-bundle.js --check` 8/8 일치.
2. **크래시 없음** — 5시드 각 1500프레임 완주(예외 X).
3. **동기(sync) 0** — 공간 NPC 수 == econ npcs 수 (마을별, 전 구간).
4. **소멸 통제** — 마을 전멸(전 마을 0명) 없음. 개별 마을 소멸은 허용되나 5시드 합산 과다(>5) 금지.
5. **인구 범위** — 5시드 총인구 800~3500 (붕괴/폭주 아님).
6. **특화 분화** — 마을마다 우세 직업이 갈림(농업/숲/광산 역할이 직업분포로 드러남).
7. **도구 3등급** — 돌·청동·철 도구가 생산됨(합산 > 0). 청동도구가 주력, 철도구는 희소.
8. **청동 사슬** — 구리·주석이 청동도구/무기로 소비됨(청동도구 존재 = 구리·주석 수요 작동).
9. **금속 공급** — 채광이 광석/금속(구리·주석·철)을 산출(ore-rich 토지에서). 통일 후에도 유지.
10. **전사 무장** — 마을별 무기 보유 ≥ 전사 수(전사는 무기 있어야 양성).
11. **staple 교역** — 식량·돌·광석이 거래됨(교역량 > 0).
12. **집 성장** — 공간 집 수가 인구 따라 증가(초기 마을당 2채 → 성장). 동결 아님.
13. **장인 비대 없음** — 야금공(대장+무기장+갑옷장)이 인구 15% 초과하는 마을 ≤1. 정원 없이 스톡-플로우가 자연 수렴.
14. **누적 통제** — 광석·돌 최대 ≤90/명. 생산 포만(satiation)+비축 부패가 무한 누적 방지(병리 기준: 예전 ore 201·stone 159/명). ★60→90 재교정: 소형마을 재고/인구 비율이 런마다 58~73 진동(랩 Math.random 비결정성) — 플레이크 제거. **열린 이슈**: 랩의 Math.random(병충해·배치 지터 등)을 시드 RNG로 통일하면 회귀가 완전 결정론이 됨.
15. **폭주 없음** — 12게임년 최대 마을 인구 ≤250. ★K_MAX 폐지 후: 자연 K(slotK·prodK·fuelK 리비히 min) + MB/MC 확장정지 + θ-로지스틱이 만드는 범위(농업촌 fert 2.8 실험 = 곡창 대촌 s*≈280, 12년엔 ~170). 하드캡 아님 — 초과 시 수렴 메커니즘 재점검 신호.
16. **마을 대장장이** — 대장장이 보유 마을 ≥70%. 소형마을도 floor 1(식량 쪼들리는 곳은 기근우선이라 순환적).
17. **위신재 교역 활성** — 장식(금·은·보석) 교역량 > 100000. 사치재에 행복/prestige 수요 부여 → 죽었던 장식교역이 살아나고 광산촌 수입 다각화.
18. **집이 영토 안** — 집 중심이 영토(V.territory) 밖인 비율 ≤2%. 영토가 인구 따라 점진 확장(growTerritory)돼 집보다 앞서고, 집은 그 안에서 생김.
19. **장기 자연수렴** — 스탠드얼론 5000일: MB/MC로 확장 *정지*한 마을 ≥1(수렴 메커니즘 작동 증거 — 천장만 제거하면 영원히 확장) + 최대 마을 ≤450(sanity) + 생존 ≥3 + 차등 ≥×1.5.
20. **영토 = econ size 동기** — 공간 영토 셀수 ≈ econ land.size×25 (오차 ≤60셀). E2c 단일화: 확장(MB/MC 투자결정)이 공간 영토를 견인, 두 시스템이 하나.
21. **마을 간 영토 겹침 0** — 전역 소유맵(_claimedAll)이 이웃 성장을 서로 회피시킴(공간 경쟁).
22. **사냥감 생태** — 사냥 압력으로 개체 감소가 실재(≥1마을)하되, 서식지(숲)가 남았는데 전면 절멸한 마을은 0 (로지스틱 재생+확산 재정착이 회복 담당).
23. **사냥 산출 존속** — 사냥꾼 총원 5시드 합 10~인구 40%. 고기 재고는 즉시소비 균형이라 0이 정상 — 산출 붕괴는 재고가 아니라 *직업 소멸*(기회비용→전직)로 나타난다. (2026-07 숙련 분할 때 '고기 산출 미측정' 갭을 발견해 불변식화. 신구 비교 실측: 재고 863→1010·사냥꾼 103→112·생산 프록시 동일 — 숙련 반토막을 시장이 증원으로 흡수)

## 핵심 설계 불변(코드 의도 — 깨지면 재검토)

- **기근 게이트(food<30일치→농업강제)는 맬서스 상한 구현** — 풀면 인구·특화 둘다 악화. 유지.
- **도구 마모 낮게(내구재)** — 높이면 단일공급자 병목 악화·인구↓. 0.0001 유지.
- **수요는 use-value 기반** — 장식재(금·은·보석)만 수요 ~0, 부산물(가죽·구리·주석 등)은 실수요(의류·청동) 유지.
- **flow-aware 식량가격** — 구조적 적자 마을이 초기재고 무관하게 수입.
- **렌더링은 lifeOn 아닌 VILS/life 기준** — 정지 중에도 전 마을 표시(줌 버그 방지).
- **직업 정원(인구비율 하드캡) 없음** — smith/weaponsmith/armorsmith/cook/warrior 캡 폐지. 직업 수는 *시장·자본수요*에서 창발:
  - 자본재(도구·무기·갑옷)는 **커버리지 기반 그림자가격**(computeShadowPrices) — 사용자 1인당 1개. 도구 3종은 합산(대체재). 소비재 버퍼(N×0.5) 쓰면 장인 폭주.
  - 장인 수 = **스톡-플로우 노동목표**(smithTarget/weaponsmithTarget/armorsmithTarget) — 결손/catchup + 마모보충. 충원되면 0 수렴. marginal 후보에서 제외(글럿 자원직과 경쟁 금지).
  - opportunityCost = **시장가치**(숙련×그림자가격), 장인·전사는 목표 초과면 차출. surplusBonus(25% 보호) 제거.
- **무기·갑옷 마모 = 전사(사용자) 비례** — 인구당(SUBSISTENCE)이 아님. per-capita면 대형마을이 무기 고갈 → 전사 무장해제.
- **무장 불가 전사는 동원해제** — 전사 상한 = min(readiness목표, 보유무기). 무기 없으면 전사 아님 → 식량직 전환(autoSwitchJob 전용 처리, need-과포화 가드 우회).
- **전사 readiness = 약탈률×교역량**(warriorTarget) — 평시 0, 위협 비례. 정원 아님.
- **인구 = θ-로지스틱**(dP=r·N·(1−(N/K)^θ), θ=4) — K의 ~80%까지 빠르고 이후 급감(S곡선). 하드 정지 아님.
  - ★**K_MAX=110 폐지(2026-07)** — K = min(slotK, prodK, **fuelK**) 리비히 min + **MB/MC 확장정지**로 대체. 인구 상한 '수준'은 임의 상수가 아니라 지형·비옥도·연료·투자수익에서 마을별로 창발:
    - **fuelK**(신규) = (벌목 자리 만충 목재흐름 + 목재수입EMA + 재고/90일) / 1인 연료수요(제련 포함). 연료(온돌·취사)도 식량처럼 필수 흐름 — 없으면 비옥·숲빈약 마을이 식량 K까지 크고 연료 붕괴. **용량 기준**이어야 함: 실현흐름 기준은 벌목 인력 스냅샷에 K가 요동 → θ-로지스틱 과격 반응 → K붕괴 나선(시드42 라 소멸로 확인).
    - **리카도 한계지**: jobCapacity가 명목 size 아닌 유효토지 S_eff=∫q 사용. q(s)=(s/s0)^-β, **β=0.105 실측**(sim/_measure_land_margin.js — 실제 지형에서 growTerritory와 동일 규칙으로 영토 키우며 한계 셀 비옥도 측정). 랩이 실측값 주면(land.liveLand) 그게 우선.
    - **MB/MC 확장 게이트**(tryExpandTerritory): 한계 1 size의 일일 식량-eq 잠재산출 × 회수기간(EXPAND_PAYBACK_DAYS=365, 보즈럽 개간 관행) ≥ 확장비용(food-eq, ^1.3 곡선)일 때만 확장. '금고 차면 무조건' 폐지 — 한계지 가치가 없으면 자연 정지. 진단: v._expandMBMC.
    - **연료 게이트 실험 폐기** — 장작 부족 시 벌목 강제(기근게이트 미러)를 picker에 넣었더니 기근게이트와 매일 노동 쟁탈전 → 벌목 0 고착 + 장인 충원 차단 → 시드7 랩 전멸. 벌목 충원은 시장(wood shadow price → opportunityCost)과 주거 목재 안전망이 담당.
    - 부작용(개선): 척박 시드42 '가' 마을이 베이스라인에선 죽었는데 fuelK가 K를 초기부터 정직하게 낮춰 나선 회피 → 생존(~50명).
    - **비옥도 이중산입 분리**: 옛 농부자리 = s×fert×0.4는 fert가 자리(면적)와 산출(지력)에 *제곱*으로 들어가 극비옥지 인구 250~400 폭증의 뿌리. → 자리 = s×**arable**(경작지 비율)×0.4, fertility는 산출에만. 스탠드얼론 폴백 arable=min(1,fert). 숲·사냥·어장·광맥은 밀도=면적이라 이중산입 유지(의미 있음). 역할 오버라이드(농업촌 fert 2.8)의 의도도 정화: "농부당 4인분(산출)"은 살고 "인구도 4배(자리)"만 제거.
  - ★**E2c: 공간 영토 = econ size 단일화 + live land(2026-07)** — 영토의 진실도 econ으로 통일:
    - growTerritory/relayout 목표 = **econ land.size×25** (pop 공식 폐지 — 확장의 유일한 원천 = 엔진 MB/MC 투자결정). `opts.targetCells`로 generate 관통. needT 트리거로 저속 모드도 견인.
    - **live land**(`updateLiveLand`): 영토 실측 → econ. fertility = 영토 셀 평균 지력 × 배율(최초 호출 시 역할 오버라이드 보존 — 확장이 한계지 먹으면 평균 자연 희석), **marginalQ = 프론티어 ~40셀 평균/영토 평균**(리카도 한계지 실측 — 엔진 합성 β는 스탠드얼론 폴백으로 강등), **프론티어 고갈(강·산·이웃·지도끝) → marginalQ=0 → MB=0 → 확장 자연 정지**(지리의 하드월이 아니라 경제성 0으로 전달). arable = 영토 기반(≈1 — 영토가 이미 물·바위 회피라 지리는 size·프론티어가 반영. 반경 기반은 이중 카운트라 폐기).
    - **이웃 영토 회피**: 전역 소유맵 `_claimedAll` — 공간 경쟁(겹침 0, 불변식 21). 검증: 광산촌(fert 0.02)은 mb 63<mc 200이라 **확장 안 함**(비교우위 그대로), 농업촌만 투자.
    - **선재 버그 수정**: `s._frontier`를 개간 캐시(getFrontier, 배열)와 영토 성장(Map)이 공유 → 개간이 배열로 덮으면 growTerritory가 !size 체크에서 조용히 영구 정지(빨리감기 영토 성장 사실상 죽어 있었음). `_terrFrontier`로 분리.
    - **볏짚·왕겨 연료**(STRAW_FUEL_PER_FOOD=0.018): 평야 농촌(숲 없음, wood~0.37)이 식량 글럿에도 연료난으로 K~50에 갇히던 문제 — 고증 답: 아궁이에 짚을 땠다. 도출: 1인 연간 곡물 ~260kg→짚 ~300kg→열량환산 짚이 연료수요의 ~17%. 취사·난방만(제련은 목재). 곡물 실생산 비례 flow(저장 X). 광산촌은 여전히 수입 의존 → 유형별 연료 전략 분화.
    - **보즈럽 수요 게이트(개간)**: 식량 120일치↑ 글럿이면 개간 정지 — 개간은 인구(pop×8)가 아니라 *필요*의 함수. 과개간=영구 벌채(민둥산)로 연료 기반을 파괴하던 것 차단.
    - **fuelK 신뢰 관성(EMA ~50일)**: 숲 고갈로 용량 하락 시 K 절벽 낙하(θ=4 → dP −23/일 학살) 방지 — 주민의 부양력 인식은 몇 계절에 걸쳐 갱신. 검증: 시드7 농업촌 140→105 완만 하강(dP 최악 −3), 붕괴 0. 숲을 다 민 마을이 낮은 지속선으로 미끄러지는 궤적(고증: 과개간→연료 위기→축소).
    - 결과: 20/20 통과, 소멸 0(짚·연료 완화로 전 마을 생존), 총인구 1570.
