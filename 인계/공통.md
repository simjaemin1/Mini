## 0. 부트스트랩

* 레포: `https://github.com/simjaemin1/Mini.git` → `/root/minirepo` 로 클론, `npm install`.
* GitHub PAT: 디바이스 파일 `~/Mini/durango-mini/.git/claude-pat.txt` (93바이트).
  `device_stage_files` 로 스테이징 → 셸 변수로만 읽고 즉시 `unset`. PAT 를 채팅·레포·메모리에
  절대 남기지 마라. push 출력은 반드시 `sed "s/${PAT}/***/g; s/github_pat_[A-Za-z0-9_]*/***/g"` 로 거른다.
* 시작하자마자 `git log --oneline -5`. 기준 커밋: **`f0a1c2d` 급(2026-08-02 배치 완료 시점)** —
  실제 HEAD 를 확인하고 그 뒤 커밋들을 먼저 읽어 상태 인식을 갱신해라.


  ②에서는 A/A 가 50/50 동일이라 A/B 만 갈린 것이 곧 신호였다.
  ⇒ 두 판을 비교하는 검사에는 **반드시 A/A 대조군**을 같이 세워라. 그리고 비교 대상이

* 좌표 단위: 광맥 `center`·`radius` 와 `terrain` 의 ore 함수는 **픽셀**. 플레이어 격자는 셀(=px/32).
