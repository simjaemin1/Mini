  PAT=$(cat "$HOME/mnt/Mini/durango-mini/.git/claude-pat.txt")          # PAT 는 여기서만 읽고 출력은 sed 로 가린다

* 번들 fetch 순서·`did not send all necessary objects` 는 **부모 없음**의 증상이다(T145) — `git fetch origin main` 을 먼저.
