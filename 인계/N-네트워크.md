### ① B-6 — 재접속이 몸을 잃는다 (해소)

**진단이 절반 틀렸다.** 회부 원문은 "입장 직후 재접속"을 원인처럼 적었는데, 신규 하네스

### ★원인 구조 — **에러 경계가 없었다**

`wss.on('connection', async (ws, req) => { … })` 에 **try/catch 가 없었다.** 중간 어디서든 던지면:

```

```
침묵은 **진단 불가능한 상태**다. 화면도 없고 로그도 없으니, 재민에게는
"기다리면 되는 것"과 "진짜 에러"가 **똑같이 보였다**. 그게 결함의 본체다.

★`server.listen` 은 파일 맨 끝(8345줄)이라 **부팅 중엔 연결을 아예 안 받는다** —

### ★수리 — 서버(4겹)

1. **본문을 함수로 빼고 `.catch`** — `_acceptConnection(ws, req, C)`. 던지면

2. **접속 즉시 `conn_hello`** — 인증·로드보다 **먼저** "받았다"를 말한다.
3. **조기 ping 응답** — `attachPlayerHandlers` 가 붙기 전에도 `pong{stage}` 를 돌려준다.

4. ★★**마감액**(`CONN_DEADLINE_MS`, 기본 30초) — try/catch 가 못 잡는 **반쪽**을 막는다.
