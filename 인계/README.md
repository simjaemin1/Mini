## 규약

* 이사할 때 **문장을 한 글자도 안 고쳤다.** 낡아 보이는 줄엔 `[낡음? 확인 필요]` 표만 붙인다 —
  고치는 건 **그 영역을 소유한 세션**의 몫이다.
* 한 절이 두 영역에 걸치면 **복제하지 않는다.** 주 영역에 두고 다른 쪽엔 참조 한 줄.
* 새 배치의 인계는 **자기 영역 파일 맨 위**에 절을 더한다(맨 아래가 아니라 — 최신이 위).
