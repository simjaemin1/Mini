### ★§0 인벤토리 — 지시서 전제와 다른 게 셋이었다 (전부 "이미 있다")

이 규약이 두 배치 연속으로 값을 했다. 실측 결과:

1. **배고픔·목마름은 이미 연속값으로 돌고 있었다** — 접속 중에만 감쇠(틱이 `players` 만 돈다),
   스프린트 게이트·HP회복 게이트·밤 추위 허기 가속까지. **아사는 재민 확정으로 이미 폐지**돼 있었다.
   ⇒ 오프라인 감쇠 금지는 **이미 지켜지고 있었다**(새로 막을 게 아니라 **지켜지는지 못 박을** 일이었다).
2. **장비 슬롯도 있었다** — `equipSlots{clothes,armor,weapon,tool}` + `clothes.attrs.warmth` 가
   이미 밤 추위를 막고 **옷이 닳았다**. ⇒ 지시 §0 의 "슬롯 없으면 추위 옷 저항 회부" 분기는 **해당 없음**.
3. **좌측 기둥·패널 프레임도 있었다** — `#sidebar` 6버튼 · `#sidePanel` · `openSide/closeSide` ·
   ESC · 논모달까지. ⇒ 이번 일은 "프레임 세우기"가 아니라 **규약 점검 + 칸 하나 채우기**였다.

**없던 것**: 추위/피로/부상/사기 축 · **연속 효과 곡선** · 무들 · 상태 패널 ·
그리고 **마을에서 식품을 사는 경로**(→ 회부 B-1).

### ① 축 다섯 + 사기 — §7 확정 그대로

**심심함·스트레스는 넣지 않았다**(§7 기각). 대신 **사기가 당근**이다 — 조리식 +0.55 · 생식 +0.10,
10분에 식고, 작업속도를 **올린다**(벌이 아니라 상).

* **배고픔·목마름** — 연속. `BODY_HUNGER_SEC` **2700**(45분) · `BODY_THIRST_SEC` 1200.
  ★채택 근거(실측): 1800s 면 조리 고기 기준 **4끼/시간**으로 잦았다. 2700s 에서 **2끼/시간** = 재민 목표(2~3) 안.
* **추위** — 밤·계절이 올리고 불·실내·옷이 내린다. 계절은 `events.seasonOf` **정본을 부른다**(겨울 1·봄가을 0.35·여름 0).
* **피로** — 노동 훅(채광 1.0 · 챔질 0.6 · 건설 1.5)으로 오르고 정지·**실내(×2)**에서 내린다.
* **부상** — ★**주사위가 아니라 피해량 문턱**(일관성 원칙). 12 미만은 안 다치고, 초과분 1당 0.02.
  회복은 시간 + **약초(herb) ×6**. `herb` 를 `FOOD_EFFECTS` 에 넣어 먹을 수 있게 했다(§7 약초 수요의 실배선).

### ② 속은 연속 — 곡선과 **바닥**

효과 = piecewise linear(제어점 4~6, 축마다 이속/작업 두 벌). **문턱 절벽 없음**을 하네스가 잰다:
0.002 폭 스윕에서 인접 표본 최대 도약 **0.0014 < 0.0024**.

★**1단계 경계를 상수로 박지 않았다** — 곡선에서 **이속 −5% 가 되는 x 를 유도**해 쓴다(§8.3 "1단계는 효과 체감점").
결과: 배고픔·목마름·피로 0.700 / 추위 0.650 / 부상 0.228.

**죽음의 나선 방지**(§7 확정): 곱 합산에 바닥 `0.6/0.6`. 전 축 최악이면 곱 원값 **0.353/0.286 → 0.6/0.6**,
그리고 **바닥이 걸렸다는 사실을 상태 패널이 말한다**(투명성). 동시 표시 무들은 **3개** 상한.

### ③ 겉은 계단 — 히스테리시스

단계 전환에만 ±0.04. 경계를 200회(서버)·14회(실클라) 오가도 **전환 0회**.
★자명 통과 금지로 "확실히 넘기면 실제로 켜지고 꺼진다"를 같이 잰다 — 무들이 죽어 있어도 0회는 나오니까.

### ④ 화면 — 새 패널 0, 프레임에 칸 하나

상태 탭(🫀 **Shift+H**)을 기존 기둥에 더했다. 패널은 §8.6 그대로 **"왜 내가 지금 이렇지"에 답한다**:

```
지금 걸린 효과
  🍖 이속 -9% · 작업 -14% (배고픔 0.82)
  😮‍💨 이속 -6% · 작업 -14% (피로 0.75)
합계  이속 ×0.69 · 작업속도 ×0.61
```

무들은 화면 오른쪽 모서리, 단계 색만. 아날로그 채널은 **최소만** — 3단계에서 가장자리 비네트 하나.

⚠**결함 하나를 화면이 잡았다**: 패널 제목이 영문 키 `body` 로 떠 있었다(제목 표에 안 넣어서).
스크린샷을 열어 본 순간 보였고, 그래서 `e2e-ui` 에 **제목이 한글인지** 묻는 줄을 넣었다.

★★**다음 패널 구현자를 위한 3줄** — 탭 하나는 **세 군데**를 다 밟아야 완성된다:
① `index.html` 의 `#sidebar` 에 `.sb-icon[data-side="이름"]` 한 줄(**단축키 병기** — §8.2)
② `client.js openSide` 의 제목 표에 한글 이름(**빠뜨리면 영문 키가 그대로 제목에 뜬다**)
③ `renderSide` 에 분기 + 렌더 함수. 하나라도 빠지면 반쪽 탭이 된다.

### ⑤ 넷코드 — 이속 배율은 **양쪽이 같은 수**를 써야 한다

몸이 걸음을 늦추므로 서버가 곱한 배율을 `gauges.body.moveMult` 로 실어 보내고
클라 `predictStep` 이 **같은 수**를 쓴다. 안 맞추면 매 틱 보정이 나서 **러버밴딩**이 된다
— 그 줄의 원래 주석이 경고하던 바로 그 함정이다.

### ★② 달력 — 원천은 econ 계절 정본 **하나**

HUD 시각 옆 `📅 0년 봄 1일`. **새 매핑 상수를 한 개도 안 적었다** —
`Events.calendarOf` 가 `seasonOf` 만 불러 한 해 길이·계절 시작일·계절 길이를 **전부 유도**한다
(`test-calendar ③`이 달력 코드에 90/180/270/365 가 **0개**임을 소스로 확인한다).
날짜는 **econ 게임일**(`SimVillages.econDay()`)을 쓴다 — 마을 재고창과 같은 시계.
※`econDay()` 는 `null` 을 낸다(0 이 아니라): **day 0 은 정당한 값**이라 `||0` 로 뭉개면
첫날에 벽시계로 잘못 떨어진다(하네스에서 "3402년 봄 1일"로 실제로 그랬다).


### ★③ 인벤 마무리

· **빈 행 제거** — 수량 0 은 **페이로드에서** 턴다(`invPayload`). 살아 있는 맵엔 0 이 남지만
  (옛 경로가 `-=` 로 그래 왔고 지우면 순회가 조용히 바뀐다) 클라는 0 을 **못 받는다**.
· **도구 통일 목록 편입 + 드롭** — 옛 `toolRowsHtml`(도구 전용 표) **삭제**.
  도구는 태생이 개체라 하위 줄이 곧 그 도구다. 착용·단축키는 **줄 우클릭**(좌클릭=착용/해제).
  `drop_item {toolId}` 로 버리면 바닥에 **내구도까지** 실려 떨어지고, 주우면 그대로 돌아온다.
  ⚠도구는 상자에 못 넣는다(상자는 수량 맵이라 개체를 못 담는다 — 화면이 그렇게 말한다).
· **드래그 수정키 복원** — 정비 배치에서 사라졌던 것(회부 B-2). 재민 확정("부모 드래그=전량")과
  **양립**시켰다: 수정키 **없으면 전량** · Shift=10 · Ctrl/Alt/Meta=99.
· **★상자 원장** — 왕복 보존을 상자까지. `b.data._led[item] = [{kg,d?}]`.
  밑줄 접두사라 기존 두 소비자가 **이미** 걸러낸다(`granaryItems` 의 `_` 스킵 · 철거 루프의
  `typeof v === 'number'`) ⇒ 곳간 회계·철거를 안 건드리고 얹혔다. **그 둘이 안 걸렀다면 회부감이었다.**
  철거 반환 경로도 원장을 돌려준다(안 그러면 철거가 **무게 세탁기**가 된다).
  ⚠상자 안 개체엔 **주소가 없다**(FIFO 로만 나온다) — 개별 인출은 회부.

### ★④ 버그·조사 4건

**ⓐ 안개 위 논밭 — 재현·수리·회귀 걸었다.**
기전: 영토가 `renderables` 에 **마을 중심 한 점**으로 실려, 중심을 한 번 본 마을이면
**반경 1,200px 의 경계 셀 전부**가 그려졌다. 배치 21이 자연물에서 고친 것과 **같은 결함의 다른 층**
(클라가 스스로 넓게 그리는 것은 개체 하나로 게이트하면 반드시 샌다).
⇒ 경계 셀·크립 링·라벨을 **셀마다** `_seenChunks` 로 판정. 실측:

```
  초원 화면: 경계 후보 251셀 · 그중 **미탐사 212셀**
    수리본  안 본 셀에 그림 **0**
    대조군  안 본 셀에 그림 **212** (`simvilCellGateOff` — 자명 통과 금지용 손잡이)
```

**ⓑ 시세 창 day — 표기 버그가 아니다. 시계가 둘이었다.**

```
  ⓐ zoneGameDay()      벽시계 파생(에폭부터 흐른 실시간 / 하루 길이)
  ⓑ state.world.day    econ 틱 카운터(하루 경계마다 +1 · **따라잡기 없음**)
  ⇒ 서버가 꺼져 있던 동안 ⓐ는 뛰고 ⓑ는 안 뛴다 = **영구히 벌어진다.**
```
마을 재고창은 ⓑ 를 그린다. 재민이 본 "몇 초마다 day 5씩"은 **그 서버의 하루가 짧았던 것**
(`VILLAGE_DAY_MS`)이다 — 라이브 기본은 24분이라 재현되지 않는다.
⇒ 달력도 ⓑ 를 쓰게 통일했고, 마을 재고창에 **달력을 같이** 적는다(둘이 같으면 시계가 하나라는 증거).
★로컬 테스트 서버는 하루가 빠르다 — `VILLAGE_DAY_MS` 를 준 판에서 날짜가 튀는 건 정상이다.

**ⓒ RTT 스파이크 — 상관 확인됨(수리는 회부).** `scripts/rtt-metrics.js`(신규 계측기 · 러너 금지):

```
  150초 · 하루 6초(econ 경계를 자주 만들려고 줄임) · 51마을
    RTT 표본 748 — 중앙 39ms · p95 3,088ms · p99 6,868ms
    econ_day  48회 · 중앙 684ms · 최대 8,410ms
    [econ_day] ±600ms 창 안 RTT 평균 1,195ms vs 바깥 110ms  → **×10.9  ★상관 있음**
    [tick]     ±600ms 창 안 868ms vs 바깥 2.5ms             → ×350
  ⇒ econ 하루 틱이 이벤트 루프를 붙잡는 동안 RTT 가 그대로 밀린다.
    라이브 영향은 **게임일마다 한 번**(24분에 1회) 수백 ms~1초 급 정지.
  ★수리(econ 틱 분산)는 **회부** — 지시대로 이번엔 계측만.
  ※하루 6초는 빈도를 부풀린 설정이다. 1회당 비용과 인과는 그대로지만 빈도는 라이브와 다르다.
```
서버에 `/perf` 엔드포인트(무거운 작업 링 400건)와 `perfMark()` 를 심었다 — **관측자**다(동작 불변).

**ⓓ 게스트 안내** — 로비에 한 줄 + **새로 시작** 단추(토큰 폐기 = 새 몸).
저장된 게스트 몸이 있고 계정명을 안 적었을 때만 뜬다. ★토큰은 화면에 안 찍는다(배치 13 규약).
옛 몸은 서버에 **남긴다**(지우지 않는다 — 되돌릴 수 없는 일은 안 한다).
