## 0-염. ★[T3 자염 2026-09-01] 다른 영역에 넘기는 것 셋

> 자염 배치는 **클라 무접촉** 조건이라 화면 쪽 두 자리를 못 고쳤다. 전부 **한 줄짜리**다.
> 상세는 `회부_자염_다음층.md` D-1·D-2·G.

1. **[R2 개체렌더 / 인벤]** `brine`(짠물)·`item_salt_kiln`(소금가마)이 클라의 `ITEM_ICONS`·`ITEM_LABEL`
   표에 없어 제작창 비용 칸에 **영문 키 그대로** 뜬다. 404 는 안 난다(프리로드가 `ITEM_ICONS` 키만 훑는다).
   ⇒ `brine: '🫙'`/`'짠물'` · `item_salt_kiln: '🧂'`/`'소금가마'` + `ICON_NO_RENDER` 에 두 키.
2. **[F 제작건축]** 클라의 보존 행이 `· 보관 ${shelfDays}일` 을 **무조건** 찍는다. 자염이 그 갈래를
   빌려 타는데 **소금은 안 썩는다** ⇒ 지금 `'∞'` 를 넣어 "보관 ∞일" 로 읽히게 해 뒀다.
   ⇒ `shelfDays != null` 가드 한 줄이면 칸이 지워진다.
3. **[B 신체서버]** ★**바닷물을 마시면 갈증이 회복된다.** `tryGather` 가 바다·강을 안 가린다.
   이 배치가 만든 결함은 아니지만 **바닷가를 목적지로 만든 건 이 배치**라 이제 사람이 그 자리에 선다.
   갈래 ⓐ 거절 ⓑ 갈증이 **더** 심해진다(고증·일관성 원칙에 가장 맞다) ⓒ 그대로 — **설계 판단**이라 안 건드렸다.

## 4. 작업 배치 — 재민 결정 대기 항목이 많다

**★먼저 재민의 회부 답을 확인해라.** 답이 있으면 그것부터. 없으면 아래를 순서대로:

### A. 회부와 무관하게 지금 해도 되는 것

1. **`era.canTame` 배선** — 지금 `breeding:true` 13종이 시대와 무관하게 먹이 3번이면 길들여진다
   (`era.canTame` 호출부 0곳). `tryFeed` 에 한 줄. era.js "송국리기엔 기마 없음" 의도가 코드로는
   안 지켜지고 있다. 하네스도 같이(`test-tame.js` 소품).
2. **노 조업 시간** — 지금은 클릭 1회 = 즉시 1회 제련이다. 움집처럼 진척도(시간)를 두는 게
   계약상 자연스러운지 검토. `설계_플레이어_NPC_집건설_해석안.md` 의 진척 공식 재사용.
3. **숯가마 조업 배치** — 지금 1회 3통나무. 여러 번 클릭이 지루하면 "가득 채우기" 한 번에.
4. **`iron` 라벨 정합** — `specialty.RESOURCES.iron.ko = '철광석'` 인데 econ 의 `iron` 은 **제련된 금속**이다.
   NPC 시장 UI 가 금속을 "철광석"이라 부른다. 바꾸면 econ 표시만 바뀌는지 확인 후 수정.
5. **플레이어 야금 사슬 실플레이 검증** — 로컬 풀스택(Playwright 실클라)으로
   채광→선광→숯가마→노→단조까지 **사람이 하듯** 한 번 통과시켜라. 서버 함수 E2E 는 됐지만
   클라 UI(건축 메뉴·2×2 고스트·클릭 판정·인벤 표시)는 아직 실화면 검증이 없다.
