★T283 이 도는 사이 **T282 가 야생 셋(`wolf_growl`·`tiger_growl`·`deer_call`)을 닫았다** —
키 행과 훅을 같은 커밋에 넣었더니 그 파일들이 **코드 0줄로** 그대로 울었다(그게 이 층의 계약이다).

★**T283 이 T261 의 회부 둘을 닫았다**:

   거절당한 동사도 소리가 났다. 이제 `handleMessage`(**받는 자리**)에서 난다 ⇒ 세계가 그 일이
   일어났다고 말할 때만 울고, **자원 자리에서 나므로 남이 옆에서 베는 나무도 들린다**(발신 판엔 없던 것).

   키도 훅도 없던 것 ⇒ 이었다. `test-assets-audit` 의 **`sfx` 고아가 26 → 2** 가 됐다(남은 둘은 `ui_click` — 훅이 없는 후보다).

⚠**이 카드는 25 커밋 뒤에 착지했다.** T261 이 도는 동안 T262·T266·T269·T272 가 먼저 들어가

## 2. 규약 — 남이 지켜야 할 것

### ★★[T283] 표 셋이 **배선**이다 — 무엇이 어떤 키를 내는지 코드에 안 적는다
1차 판엔 `'wolf'`·`'campfire'` 같은 낱말이 층 코드 안에 있었다. 이제 표다:

| 표 | 무엇 → 키 | 어디서 읽나 |
|---|---|---|
| `resourceHit` | 자원 `type` → 키 | 수신 `resource_update`·`resource_removed`(브로드캐스트 · 자원 자리 ⇒ 거리 감쇠) |
| `mobs` | 개체 `type` → 키 | 프레임 훑기(`scan`) |
| `buildings` | 건물 `type` → 키 | 프레임 훑기(반복 · 개체마다 하나 · 화면 밖이면 멎는다) |
| `fishState` | `fish_state.state` → 키 | 수신(좌표를 같이 보낸다 ⇒ 찌 자리) |

**소리를 더하는 값 = 표 한 줄 + (필요하면) 키 한 칸.** 코드를 고치는 것이 아니다.
`test-audio ⑦a` 가 표의 값이 전부 실제 키인지 본다(오타 한 글자면 그 소리가 **영영 안 난다** — 조용한 결함).
⚠개체 이름과 키 이름은 다르다: 멧돼지는 `wild_boar`(개체) → `boar_grunt`(키). 그래서 키를 개체 이름으로 안 쓴다.

### ★키 표가 정본이다 — `public/assets/sfx/manifest.json`
수는 **코드에 하나도 없다**. 볼륨·반경·반복·동시상한·쿨다운·감쇠식·버스 기본값·저장 키·BGM 페이드까지 전부 표다.
소리를 더하려면 **표에 키를 세우고 훅 한 줄**을 붙인다 — 코드를 고치는 것이 아니다.

```
keys.<key> = {
  file,        // 파일 이름(`public/assets/sfx/` 기준) 또는 null(=미확보 · 무음 · 빨강 아님)
  volume,      // 0..1 (효과음 버스 앞단)
  radius,      // 월드 px (32px = 1셀) · 0 = 위치 없는 소리
  loop,        // true = 환경음(개체마다 하나 · 화면 밖이면 멎는다)
  maxSame,     // 같은 키가 동시에 겹칠 수 있는 수(발자국 겹침 방지)
  cooldownMs,  // 같은 키의 최소 간격
  source,      // sources 의 id 또는 null
  gainK?,      // 세기를 볼륨으로 옮기는 계수(바람 1.4 = WX_TILT_K 와 같은 수 · 비 1.0)
  fade?,       // [T283] 반복 키 필수 — 페이드 **초**(setTargetAtTime 시상수). 세기가 크게 흔들리는
               //        소리(바람·비) 2.0 · 켜고 끄기만 하는 소리(불·물·새) 1.0
  indoorMul?,  // [T283] 반복 키 필수 — 실내 배율. 바람·비·새 0(완전히 멎는다) · 불 0.35 · 물 0.25
  sampleStride?, trees?, treeRadius?   // 그 키만 쓰는 칸(물 훑기 간격 · 새의 숲 문턱)
}
sources.<id> = { license, url, author, received }   // 네 칸 전부 — 하나라도 비면 하네스가 문다
```

* **감쇠는 `linear` 하나**다: `g = volume × max(0, 1 − d/radius)`. 역제곱을 안 고른 이유는 표에 적혀 있다
  (반경 밖이 **정확히 0** 이라 값이 하나다 — 역제곱은 컷오프를 또 정해야 해서 값이 둘이 된다).
* **미확보(`file: null`)는 빨강이 아니다.** "출처 없는 소리 0" 은 *나는* 소리에 걸린 규약이다.
  안 나는 키를 빨갛게 하면 음원이 들어오기 전까지 CI 가 계속 빨간데, 그건 결함이 아니라 순서다
  (`test-assets-audit ③` 의 "고아 표는 빨강이 아니다"와 같은 사고).

### ★음원 꼴 (T262·T266·T269 가 이미 이 꼴로 넣었다 — 다음 묶음도 같다)
* `.ogg` + `.m4a` **쌍** · 자리는 `public/assets/sfx/<key>.{ogg,m4a}`
* 단발 ≤ **3초** · 반복 ≤ **10초**(이음새) · 파일당 ≤ **150KB** (실측 최대 `water.ogg` 127.6KB)
* ★표는 **파일 이름을 그대로** 적는다(`"file": "wind.ogg"` — 어간 `wind` 가 아니다). 두 이유가 겹친다:
  ⓐ `asset-lock.keyOf` 가 소리만 **파일 이름을 키로** 쓴다(한 소리에 두 파일 — T266 이 거짓 빨강 둘로 배웠다).
  ⓑ `test-assets-audit` 이 `ogg`·`m4a` 를 **어간 대조에서 뺐다**(`wind`·`fire`·`eat`·`axe` 는 짧은 영단어라
     코드 아무 데나 걸려 "쓰는 데 없는데 쓰임 있음"이 됐다). **이름이나 URL 로 불러야** 고아가 풀린다.
* ★`.m4a` 는 `fileAlt` 로 같이 적는다. 장식이 아니다 — **사파리는 Ogg Vorbis 를 안 튼다.**
  층이 `canPlayType` 으로 **브라우저에게 물어보고** 고른다(짐작 0 · `test-audio ④` 가 그 한 줄이 있는지 본다).
* `sources.<id>` 네 칸(라이선스·URL·작성자·받은 날)을 채우고 **같은 값을 `CREDITS.md` §2-b 에** 둔다
  (크레딧 절은 세션8/ART 몫 — T261 은 안 건드렸다. 표 둘이 어긋나면 사람이 본다).
* 코드 수정은 **0** 이다. 파일이 들어오면 그대로 난다 — 6종이 실제로 그렇게 이어졌다.

### ★훅 규약 — 남의 파일엔 줄 하나 · 로직 0
훅은 `window.__sfx && window.__sfx.<메서드>(…)` 한 줄이고, **무엇이 울릴지는 소리 층이 고른다**.
`scripts/test-audio.js ③` 이 **파일당 두 줄 이상이면 문다**.

| 파일 | 줄 | 메서드 | 키 |
|---|---|---|---|
| `public/client/30-n-net.js` | **`handleMessage` 머리** | `recv(msg, c)` | `axe`·`bronze_hit`·`harvest`·`eat`·`cast`·`bite`·`hook` |
| `public/client/42-r2-char.js` | `drawCharSprite` 안 | `step(clip, frame)` (`isMe` 일 때만) | `step_dirt` · `step_grass` |
| `public/client/34-m-renderloop.js` | `renderables.sort` 다음 | `scan(renderables, worldCx, worldCy)` | 야생 4 · `fire` · `water` · `bird` |
| `public/client/37-r1-weather.js` | `drawWeather` 안 | `weather(w, indoor)` | `wind` · `rain` |
| `public/client/99-main.js` | `boot()` 다음 | `initAudio()` — **입구 한 줄** | — |

* 전역은 `window.__sfx` **하나**다. `test-client-globals` 는 **기준선을 안 늘렸다**(아래 §3).
* `48-a-audio.js` 는 **최상위 실행문 0** 이다 — 실려도 아무 일이 안 난다. 실행은 `99-main` 한 자리(T0-b).
* **`AudioContext` 는 첫 사용자 제스처(pointerdown·keydown·touchstart)에서만 난다.**
  `test-audio ④` 가 정적으로 검사한다(`new AC()` 는 `sfxWake` 안에만 있어야 한다).
* ★★**[T283] 소리는 발신이 아니라 수신에서 난다.** `sendPrimary` 는 **보내는** 함수다 — 거기서 울리면
  거절당한 동사도 운다. `test-audio ⑦b` 가 **발신 함수 안에 `__sfx` 가 0** 임을 정적으로 지킨다.
* ★★**[T283] 수신 훅은 `handleMessage` 의 첫 줄이어야 한다.** 아래에서 `c.resources.delete(...)` 가
  자원을 지우므로, 그 뒤에 부르면 **자리를 못 찾아 위치 없는 소리**가 된다. 장식이 아니라 계약이고
  `test-audio ⑦d` 가 줄 번호로 지킨다(훅 줄 < 지우는 줄).
* ★★★**[T323] 소리판 — 제품을 안 고치고도 제품을 불러 쓸 수 있다.**
  `public/sfx-board.html` 은 `bgm.js`·`48-a-audio.js` 를 **그대로 싣고** 공개 API 만 부른다(사본 0 · 제품 diff 0).
  배포하면 `<호스트>/sfx-board.html` — **서버 0줄**(`central.js` 정적 갈래가 `public/` 아래를 이미 내준다).
  세 가지가 "제품을 안 고치는 길" 의 본보기라 적어 둔다:
  ① **BGM 장면 바꾸기** — `__sfx` 에 세터가 없다. 그런데 층은 장면을 `__evNearVid`×`isNight()`
     두 **바깥 전역**에서 고르고, 다시 고르는 것은 공개 `__sfx.scan()` 의 끝줄이다 ⇒ 전역을 세우고
     `scan([],0,0)` 을 부르면 **층이 제 코드로** 바꾼다. 세터를 새로 다는 것은 제품 수정이다.
  ② **버퍼 데우기** — 층은 버퍼를 처음 쓸 때 받아 오므로 **어느 「층」 단추든 첫 클릭이 무음**이다.
     `__sfx.probe(전체 키)` 는 **오프라인 렌더**라 무음이고 버퍼를 다 기다린다 ⇒ 데우기와 뜻이 같다.
  ③ **배선 역인덱스** — 표(`resourceHit`·`mobs`·`npcAct`·…)만 훑으면 `bird`·`wind`·`eat`·발자국이
     "배선 없음" 으로 뜬다(그것들은 **코드가** 부른다). 키의 **`훅` 칸**이 그 자리를 이미 적어 두었으므로
     표 ∪ `훅` 이 배선의 증거다. ⚠첫 판이 "배선 없음 7" 을 냈다 — 자가 좁으면 멀쩡한 것이 결함으로 뜬다.
* ★★**[T323] 배포 이미지에 안 담기는 자리에 정본을 두지 마라.**
  `Dockerfile.central` 이 담는 것은 **`server`·`public`·`sim` 셋뿐**이다(`.dockerignore` 와 무관 — `COPY` 목록에 없다).

* ★★★**[T321] 없는 순간에 소리를 걸지 마라 — 있는 결말에 걸어라.**
  카드가 "던짐·입질·걸림 셋" 을 시켰는데 **NPC 어부에게는 그 셋이 차례로 일어나지 않는다**:
  한 시도가 **한 틱**이다(종 추첨·셀 예산·장부가 같은 순간). 플레이어 낚시에는 있는 대기 창
  (`biteAt`·`windowMs` — `fish_state` 가 'wait'→'bite' 로 두 번 온다)이 NPC 경로엔 **없다**.
  ⇒ 셋을 차례로 울리려면 **없던 시간을 지어내야** 한다(족보 226 의 거짓 소리).
  ⇒ 대신 한 시도의 **결말**이 원래 셋으로 갈려 있는 것을 썼다:
    안 물림 `드리움`→`cast` · 물고 놓침 `놓침`→`bite` · 건짐 `낚음`→`hook` (표 `npcAct`).
  ⚠**그 전제 자체를 자가 지킨다**(`test-audio ⑫d`·`⑫e`): NPC 자리에 대기 창이 없다 + 플레이어에겐 있다.
    세계가 NPC 에게 창을 주는 날 ⑫d 가 빨개진다 — 그때 소리를 차례로 바꾸면 된다.
* ★★**[T321] 머무는 라벨에서 소리를 뽑을 땐 모서리로 잡고, 첫 가시는 버려라.**
  `act` 는 `_lifeAct` 가 **바뀔 때만** 갱신하는 머무는 칸이고, `makeEntry` 는 그것을
  **바뀐 뒤 1.2초 창 + 최초 가시**에 보낸다(무상태 델타). 그래서 두 함정이 한 쌍이다:
  ① 값이 왔다고 울리면 **한 번 낚고 스물다섯 번 난다**(1.2초 = 최대 25틱). ⇒ 직전 값과 맞대 본다.
  ② 라벨을 단 채 시야에 들어온 어부에게 울리면 **일어나지 않은 일이 들린다**(10초 전 일이다). ⇒ 직전 값이 없으면 안 운다.
  ⚠훅 줄은 **0** 이다: `recv` 가 `handleMessage` **머리**에서 불리므로 그 순간 `c.others` 가 아직
    직전 값이다. 새 줄 없이 모서리가 잡힌다(`파일당 훅 하나` 규약 그대로).
  실측은 **수신 호출 수**로 한다(족보 226) — `e2e-audio-probe ⑭~⑱` 이 진짜 `recv` 에 진짜 `tick` 을 먹인다.
* ★★**[T321] 키가 '내 소리'에서 '남의 소리'로 넘어가면 반경을 줘야 한다.**
  `cast`·`bite`·`hook` 은 T283 이 **내 낚시**에만 걸어서 반경 0(감쇠 없음)이 맞았다 — 내 찌는 내 자리다.
  T321 이 마을 어부에게 걸면서 **남의 자리에서 나는 소리**가 됐고, 반경 0 이면 지도 반대편 어부가
  귓가에서 낚는다. ⇒ 384. **T292-b 의 `axe` 가 정확히 이 결함이었다**(발신→수신으로 옮기며 반경 0 을 안 고쳤다).
  ⇒ 규칙: **수신 훅에 거는 키는 반경이 0 이면 안 된다**(`test-audio ⑫i`).
* ★**[T321] 묻지 않으면 같아진다.** 버리기도 죽어 쏟기도 `ground_item_added` **한 방송**이라,
  층이 `isNpc` 를 안 묻는 것만으로 죽은 어부의 고기가 플레이어와 **같은 소리**로 난다(표 `groundDrop`).
  ⚠키는 `bronze_hit` 을 나눠 쓴다(새 키 0 규약 · 출처가 *Dull thud*) — 곡괭이질과 한 소리다 ⇒ 회부(재민 귀).

* ★★★**[T305 · 이 층의 서버 무접촉 규약에 난 구멍 둘 — 허락받은 자리다]**
  SOUND 는 서버를 **안 만진다**가 규약이다(T261부터). T305 카드가 **두 자리만** 예외를 줬고, 그 두 자리가
  이 층의 짐작을 0 으로 만들었다. 다음 세션은 **이 둘이 있다는 것을 알고** 설계해라 — 다시 짐작하지 마라.
  | 자리 | 서버가 대는 말 | 누가 읽나 | 왜 필요했나 |
  |---|---|---|---|
  | `sendInventory` 전문의 **`where`** 한 칸 | `'harvest'`(밭 수확) 등 | `manifest.inventoryWhere` 표 → 키 | 매개변수는 **원래 있었다**(`Carry.assertInvariant` 의 이름표). 전문에 안 실려 층이 못 봤다(T292 ⓑ). 수확은 `building_updated`·`sendInventory`·`notice` 셋으로만 나갔고 **셋 다 수확의 표식이 아니다** |
  | `doEat` 의 `gauges` 에 **`ate`** 한 낱말 | `'self'` / `'fed'` | `48-a-audio.js recv` | 먹기 전용 통지가 없어 두 번 짐작했고 두 번 틀렸다(아래) |
  ⚠**그 두 자리 밖은 한 글자도 안 만졌다**(서버 diff 6줄 · `gauges` 틱 무접촉). 이 예외를 근거로
    "서버도 고칠 수 있다"로 넓히지 마라 — 카드 한 장이 준 자리 둘이다.
* ★★★**[T305] 곡선은 한 벌이다 — 정본은 `bgm.js`.**
  T283 이 `bgm.js` 의 리미터 곡선을 **베껴** 효과음 버스에 달았다. T292 가 그 사본을 실측해
  **원점 기울기 1.4364 = +3.15 dB**(안전장치가 아니라 증폭기)임을 찾았지만 카드가 "재생기 수정 0" 이라
  **효과음 쪽만** 고쳤다 ⇒ **음악은 5일 더 3 dB 크게 울었다.** 두 벌이면 한 벌만 고쳐진다.
  ⇒ `DurangoBGM.softLimiterCurve(knee)` 하나이고 효과음 층이 그것을 **부른다**(`test-audio ⑪b` 가 지킨다).
  값과 모양의 임자가 갈려 있다: **모양**은 `bgm.js`, **문턱 값**은 `manifest.bus.limiter.knee`.

  `⑪c` 가 두 수를 맞대 놓는다. 싣는 순서(`bgm.js` 먼저)는 `⑪d` 가 지킨다.
  ⚠실측 −3.08 dB(네 장면) · 옛 크기를 되돌리는 볼륨은 **0.6414**(현행 0.45) — **값은 재민 몫**(회부).
  ⚠파이썬 렌더러(`gugak.py:739`)는 원래 기울기 **1.0** 이었다. 13곡을 뽑은 쪽은 성했고 **런타임만 튀어 있었다**.
* ★★**[T305] 넘침은 이제 재는 것이 아니라 증명한다 — 다만 재는 것도 그만두지 않는다.**

  ⚠그런데도 야간(`e2e-audio-probe` · `@nightly B`)이 **진짜 버퍼를 계속 센다**. 증명은 **곡선**의 것이고
    제품은 곡선 말고도 많다(표의 볼륨 · 파일의 실제 진폭 · 버스 이득 · 오버샘플 재표본). 그중 하나가
    조용히 바뀌면 **증명은 참인 채로 소리만 틀려진다**. 그 하네스는 층의 `__sfx.probe()` 를 **그대로 부른다**(사본 0).
