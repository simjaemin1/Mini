### ⓐ 색 — 자리가 둘이고 규칙이 **서로 반대**다

```
  판(DOM)      값은 `public/style.css` `:root` 토큰 18개 하나.  색 리터럴 0.
               쓰는 법: style/cssText/class 안에서 `var(--accent)` · `rgba(var(--accent-rgb), .4)`
  세계(캔버스)  값은 **리터럴이어야 한다**(`#f0c674` · `rgba(90,154,224,.18)`).
```
⚠**이것이 이 카드에서 제일 비싸게 배운 것이다.** `ctx.fillStyle = 'var(--accent)'` 는
**예외도 콘솔 오류도 안 낸다** — 그냥 무시되고 **앞에 칠하던 색이 그대로 남는다**.

  세터와 `addColorStop` 을 문서가 열리기 **전에** 가로채, 실제로 들어간 값에 `var(` 가 있으면 잡는다.
  소스 어림짐작이 아니라 **실행 실측**이다(`tileColor = …` 같은 줄은 줄 단위 규칙으로 못 가른다).
* 그리고 `test-itemlabel ⑫` 는 **판을 짓는 조각 10개**(파일 표)에 색 리터럴 0 을 잰다.
  세계 렌더 조각은 그 표에 없다 — 거기 리터럴이 있는 게 **정상**이다.

### ⓐ `pickAt` — 사슬은 **하나**다

종전엔 좌클릭 핸들러(`30-n-net`) 안에만 있었고, 우클릭이 같은 판정을 원하자 **두 벌이 될 참**이었다.
순서·반경·존 순회·"첫 히트에서 멈춤"을 한 비트도 안 바꾸고 옮겼다:

```
  ① 바닥 물건 ±14px   ② 터·시설(움집터 ±48/±40 · 그 밖 ±34)   ③ 상자·곳간 ±20px
  셋 다 **AABB**(네모)다 — 반경이 아니다. `Math.abs(dx) <= r`.
  ⓪ 사람 ±18px 은 **`{ players: true }` 일 때만** 본다 ⇒ 좌클릭은 종전대로 사람을 안 집는다.
```
⚠**거리 게이트("너무 멀리 있어 손이 안 닿습니다")를 `pickAt` 안으로 옮기지 마라.** 종전에도 그 검사는
대상을 고른 **뒤**였고, 걸리면 **다음 갈래로 안 넘어가고** 알림만 냈다. 안으로 옮기면 멀리 있는 상자가
"안 골라진 것"이 되어 사슬이 뒤로 흐른다 — 그게 행동 변경이다.
* 지키는 것: `e2e-verbs ⑦` — 바닥에 물건을 **실제로 떨구고** 13/14/15px 세 점을 `pickAt` 에 넣어
  경계가 정확히 14 임을 잰다. 그리고 사람 갈래가 기본으로 꺼져 있음도 같이 잰다.

### ⓑ 우클릭 셋의 우선순위 — **실측이 정했다**

우클릭 하나를 배치 회전·조준 홀드·메뉴가 나눠 쓴다. 진짜 Chromium 에 물어본 결과:
```
  mousedown(2) → contextmenu → (뗄 때) mouseup(2) → auxclick(2)
  ★`contextmenu` 는 **누르는 순간** 온다. 600ms 를 눌러도 거기서 먼저 온다.
   ⇒ "짧게 누름 vs 홀드" 는 `contextmenu` 에서 **가를 수 없다**. 뗄 때 오는 `auxclick` 이 그 자리다.
```
그래서 표는 이렇게 된다(타이머 0 · 조준 상태 무접촉):
```
  배치 모드                      → 회전   (종전 · `contextmenu` · 메뉴 0)
  홀드(≥250ms 또는 ≥6px 이동)     → 조준   (종전 · 메뉴 0 — **몸 위에서도 조준이 이긴다**)
  짧게 누름 + 커서 밑에 대상       → 메뉴
  짧게 누름 + 빈 땅               → 아무 일 없음(종전 · 조준이 잠깐 켜졌다 꺼진다)
```
⚠`_aiming` 은 한 비트도 안 건드렸다 — `mousedown` 이 켜고 `mouseup` 이 끈다(종전 그대로).

### ⓒ 동사 표 — 첫 판은 셋 (새 게임 동사 0)

```
  쓰러진 사람   먹이기…(하위 목록 = 내 짐의 먹을 것 · `foodEffects` 가 무엇이 먹을 것인지 정한다)
               물 먹이기 · 업기/내려놓기   ← 남이 업고 있으면 **아예 안 띄운다**(서버가 거절하는 자리)
  바닥 물건     줍기                        `pickup_item`(종전)
  터·시설       시공 · 조업 · 열기          좌클릭이 보내던 그 메시지에 **이름만 붙였다**
  상자·곳간     열기 — 상자/길드 곳간/마을 거래소
  건축 모드     해체                        `startBuildAction('dismantle')`(종전)
  성한 사람 · NPC · 자연물 · 자기 자신 → **회부**(빈 배열이면 메뉴를 안 연다)
```
보내는 메시지는 종전 그대로이고, **새 타입은 하나뿐**이다: `verb{ name, pid, item }`
(먹이기·물만 — 업기·줍기는 이미 `pid`·`giId` 를 받는 메시지가 있었다).
단축키 `R` 은 **남는다** — 단축키는 메뉴의 별칭이다.
