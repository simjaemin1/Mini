## 1-표. ★[T55 2026-09-02] 이름표는 **서버가 준다** — 화면의 한 문 `itemKo()`

**정본 = `server/zone.js ITEM_LABEL_SERVER`**(실측 **112키**). 그 표는 런타임에 넷이 합쳐 만든다:
리터럴 + `tidal.install` + `Spoil.PRESERVED_ITEMS` + `Crops.labelMap()` ⇒ **클라가 다시 만들 방법이 없다.**

```
  서버 : welcome.itemLabels = ITEM_LABEL_SERVER      (zone.js 접점 1줄 · 첫 primary welcome 한 번)
  클라 : 30-n-net.js  welcome → ITEM_LABEL_SRV       (있으면 갱신 · 없으면 유지 — promote welcome 엔 안 실린다)
         43-i-icon.js  let ITEM_LABEL_SRV            (담는 자리 · `ITEM_LABEL` 은 이제 **폴백**이다)
         50-i-panel.js itemKo(k)                     ★정본 → 사본 → 키.  화면은 이 함수 하나만 부른다
```

⚠**자리마다 `|| k` 를 쓰지 마라 — 그게 사본 문법이다.** 새 품목이 올 때마다 자리 수만큼 빠뜨린다.
실제로 세 번 샜다: T38(`brine` 제작창) · 자염 회부 0-염 · 갯벌 회부 0-갯(`oyster`·`seaweed`·`abalone`).
T55 가 그 자리를 전부 `itemKo()` 로 모았다 — 인벤 행 · 드래그 고스트 · 배치 알림 · HUD 먹이 행 ·
시설 재료 버튼(`data-fpick`) · 건물 라벨 · 배치 고스트.

* HUD 먹이 행(`44-h-hud.js`)은 종전에 **폴백이 아예 없어** 표에 없으면 `undefined` 를 찍었다.
* `60-t-market.js ITEM_KR` 은 **품목이 아니라 econ 카테고리**(food/wood/ore…) 표다 — 다른 이름 공간이라 안 건드렸다.
* 클라 사본 표(`43-i-icon.js ITEM_LABEL` 55키) **삭제는 회부** — `split-verify` 재-스코프와 얽힌다.
* 검사: `scripts/test-itemlabel.js`(표 대조) + `scripts/e2e-inv.js ⑩`(**실클라** — 서버 키 ∖ 클라가 찍는 키 = ∅).

## 1-키. ★[T55 2026-09-02] 키 체인 구조 — **Shift 는 머리에서 한 번 가른다**

키를 받는 리스너는 **둘**이다. 둘 다 같은 구조를 쓴다(규약을 둘로 두지 않는다):

```
  99-main.js:176   행동 키   — Shift: C 길드영토 · F 낚시 · N 납품 · G 게시판 · R 수리
  50-i-panel.js:780 패널 키  — Shift: K 시설 · H 상태 · T 거래소 · B 건축 · J 연대기
                              맨손:  I 인벤 · K 제작 · Y 사유지 · P 스킬 · Q 장마당

  구조:  if (e.shiftKey) { …Shift 전용… return; }      ← ★여기 한 곳에서만 가른다
         …맨손 체인(원문 순서 그대로)…
```

⚠**글자마다 `&& !e.shiftKey` 를 붙이지 마라.** T18 이 `j` 한 줄에 그렇게 했고, 나머지 글자는 그대로 새어
`Shift+L` 이 울타리를 짓고 `Shift+H` 가 상자를 지었다(패널과 **이중 발화**). T55 가 그 한 줄을 구조로 흡수했다.

★T55 가 고친 것 중 제일 조용했던 것: **맨손 `g`(원거리 공격)가 체인에서 먼저 서 있어 `Shift+G`(게시판)
분기에 영영 못 닿았다.** 촌장 대사는 "Shift+G" 라고 안내하는데 실제로는 화살이 나갔다 —
하네스가 `village_board` 메시지를 **직접** 보내고 있어서 여태 아무도 못 봤다.

⚠**대가**: `Shift` 는 달리기 키다 ⇒ **달리는 중엔 맨손 단축키가 안 먹는다**(이동은 `keys` 집합이라 무관).
그 대가를 줄이려면 달리기 키를 옮기거나 Shift 를 "가림"이 아니라 "우선"으로 바꿔야 한다 — **회부**.

⚠**죽은 분기 셋**(T55 는 행동 변경 넷만 하기로 해서 **안 건드렸다** · 회부):
`k === 'g'` 먹이 주기 · `k === 'o'` 수확 · `k === '1'` 도끼 장착 — 셋 다 같은 글자의 앞 분기에 가린다.

* 검사: `scripts/e2e-ui.js ⑦` — **나간 메시지를 세서** 전수로 잰다(맨손 L 은 짓고 · Shift+L 은 안 짓고 ·
  기존 Shift 다섯은 그대로 · Shift+G 가 화살을 안 쏘고 · Shift+H/J 로 패널이 열린다).

## 1-아묾. ★[T61 2026-09-03] HP 가 화면에 **살아 있다** — 그리고 아묾을 말한다

★**실측이 설계를 뒤집었다.** 카드는 "서버 칸을 더하기 전에 있는 값으로 되는지 먼저" 라고 했고,
재 보니 **있는 값으로는 안 됐다** — 이유가 나쁘다:

```
  클라의 myHp 는 welcome · player_damaged · player_respawn 에서만 갱신된다.
  자연 회복은 **아무 메시지도 안 낸다** ⇒ 40 에서 100 까지 아물어도 화면은 계속 `40/100`.
```
"HP 자연 회복이 화면에 안 실린다"는 **표식이 없다**는 뜻이 아니라 **숫자가 낡았다**는 뜻이었다.
⇒ 초당 하나 나가는 `gauges`(self 전용)에 `hp`·`maxHp` 두 수를 얹었다. 새 창구 0 · 방송 아님.

**아묾 표식** — `44-h-hud.js updateHud()`:
```
  서버 회복 게이트 넷 : hp<max · 피격 뒤 1초 · recoverMult>0 · 극단 감소 없음
  클라는 그 술어를 **흉내내지 않는다** — HP 가 실제로 올랐는가만 본다(게이트 넷의 결과다).
  hp-fill 밝기 + hpText 에 `▲` + title "아물고 있다(회복 ×N)".  깜빡임 방지 1.5초 유지.
```
⚠**"왜 안 아무는가"는 여기서 말하지 않는다.** 갈증·추위·부상 무들이 이미 그 말을 하고 있고
(`body.recoverParts` 가 축별 배율을 싣는다) 같은 말을 두 번 하면 그게 중복이다(§8.3).

## 1-타. ★[T61 ⓪ 2026-09-03] 글자를 치는 중이면 **게임 키는 없다** — 술어 하나

재민 실기: 로그인 칸에 타이핑하면 `i`(인벤)·`m`(지도)가 눌리고 **스페이스·탭이 아예 안 들어갔다**.
원인은 전역 키 핸들러 **여섯**이 각자 다르게(또는 아예 안) 가린 것이다 — 아는 것은 채팅칸 하나뿐이었다.

```
  20-r2-visibility.js   function isTypingTarget(e)     ★술어는 여기 하나
      input(누르는 버튼류 제외) · textarea · select · contenteditable · 그리고 chatActive
  머리에서 부르는 곳 여섯:
      99-main keydown(★첫 줄 — preventDefault 보다 앞) · 99-main keyup ·
      50-i-panel Esc · 50-i-panel 단축키 · 60-t-market Esc · 80-bigmap Esc(캡처 단계)
  잔류 0: keyup 은 Shift 해제를 **먼저** 하고 그 다음 술어 · focusin/focusout 에서 keys.clear()
```
⚠**`chatActive` 검사를 따로 두지 마라** — 술어 안에 흡수돼 있다. 규약이 둘이면 다음 입력칸에서 또 샌다.
⚠`99-main` 의 `' '`·`arrow*`·`tab` `preventDefault` 는 **술어 뒤**여야 한다. 앞에 있으면
스페이스·탭이 입력칸에 안 들어간다(그게 이 결함의 절반이었다).
* 검사: `e2e-ui ⓪`(로비에서 — 결함이 사는 자리) · `⓪-b`(채팅칸도 같은 술어).
  ★돌연변이는 **실행**으로 잰다: `window.isTypingTarget` 을 꺼 두면 `i` 가 다시 인벤을 연다.
