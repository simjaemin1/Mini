## 2-바닥. ★★2026-09-07 [T146 2판] — **사냥터가 없는 마을은 없다**

> 전문 `보고/T146_2026-09-06.md` §2판. 정본 `server/villages.js` · 하네스 `scripts/test-hunt-port.js`.

**한 줄** — `livelihood.js:27` 이 `FLOOR.game = 0.45` 를 두고 그 이유를 적어 뒀다:
*"초지 사냥(사슴·멧돼지) — 숲이 없어도 짐승은 산다"*. 그런데 밴드는 **숲만** 셌다.
그래서 51곳 중 **19곳**은 econ 이 "짐승이 있다"고 말하는데 실체가 0 이었다 —
사냥꾼은 서는데 깎을 데가 없고 `land.game` 은 **영원히 안 내려간다**(남획이 불가능한 마을).

```
정본 — server/villages.js
  _bandMinCells(vil, candN)   최소 셀 수 = candN × land.game / livelihood.GAIN.game  (역함수 · 새 수 0)
  _bandFloorFill(vil, st)     모자란 만큼을 **반경 안 풀밭 셀**에서 자리 해시로 채운다(Crops.h32 · 주사위 0)
  _cellOfPx(px)               px → 셀 **정본 하나** — 셀 중앙 c*SZ+SZ/2 를 되읽으면 그 셀이 나온다
```

**★실측 — 19곳은 전부 `land.game` 이 바닥에 정확히 앉아 있다**

| | |
|---|---|
| 밴드 0 인 마을 | **19 / 51** · 전부 `land.game` = **0.45 = `FLOOR.game`** (추출 `huntShare` 도 0%) |
| 그 마을들의 풀밭 셀 | 7,179 ~ 11,809 (중앙 11,116) — **채울 땅은 넘친다** |
| 역함수가 요구하는 셀 | 2,155 ~ 3,007 (`candN × 0.45/1.8`) — 풀밭이 모자란 마을 **0곳** |

**★★함정 — 이 절을 고칠 사람이 먼저 알아야 할 것**

1. ★★**문자 그대로의 `huntShare` 역함수는 0 을 준다.** `share = (game − FLOOR)/GAIN` 이고
   19곳은 `game == FLOOR` 다 ⇒ 0. **바닥은 셀의 함수가 아니기 때문**이다. 그래서 역함수는
   **바닥까지 포함해** `share = game / GAIN` 으로 되돌린다(같은 환율). 그 결과가 위 표의 3,007 이다.
2. ★★**그 수는 크다.** 3,007 셀은 지금 밴드 있는 32곳 중 **21곳보다 넓다**. 즉 `FLOOR.game = 0.45` 는
   이미 "숲 25% 짜리 밴드"를 약속하고 있었다는 뜻이다 — **`FLOOR.game` 자체가 값 판정거리**(재민).
3. ★★**그래서 기본은 밴드가 0 인 마을에만 채운다**(카드 §1 "32곳 비트 동일"). 카드 ① 문자 그대로인
   `max(밴드, 최소)` 꼴은 `T146_BAND_ALL=1` 로 켠다 — 켜면 32곳 중 21곳이 움직인다.
4. ★**풀밭 셀의 K 도 숲과 같은 `L_GAMEMAX`** 다(새 수 0). 초지 K 를 따로 두는 건 회부.
5. ★**왕복 정본은 `_cellOfPx` 하나**다. `Math.round(px/SZ)` 로 되읽으면 셀 중앙이 `c+1` 로 나온다
   (1판 회부 6 이 그 자리였다). 되읽는 자리는 전부 이 문을 쓴다.

**손잡이** — `T146_BAND=0`(최소 보장 끈다 = 종전 비트 · 19곳 밴드 0) · `T146_BAND_ALL=1`(카드 ① 문자 그대로).
둘 다 **부를 때** 읽는다.
