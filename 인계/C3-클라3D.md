## 0. 무엇인가 — 재민 확정(2026-09-29)

"최종은 3D · 브라우저 게임이 아니다 · **사람·동물만 3D** · 세계·시설은 2D 타일 그대로(좀보이드 B41 길)".
브라우저는 **테스트 뷰어**다 — 브라우저 최적화엔 시간을 안 쓴다(카드 "최적화 0"). 시트 굽기 투자는 여기서 멈춘다.
T522 는 첫 걸음이고 가정 둘을 확인했다: ⓐ Blender 리그·클립이 glTF 로 그대로 넘어간다 ⓑ 3D 층이 2D 세계에 **같은 카메라·같은 가림 규약**으로 선다.

## 3. 자산 파이프 — 새 형상 0

* 내보내기는 `char_render.py` 원문을 표지 줄 `# ═══════════════ 공유 프레임 박스 ═══════════════` **앞까지** 읽어 실행한다(굽기·상자 계산·시트 저장은 안 지난다). 표지나 필요한 이름이 없으면 **죽는다**(조용히 다른 장면을 안 낸다).
  `char_render.py` 는 늘 `--sheetdir=<사본>` 으로 부른다 — 안 그러면 추적 파일 `assets-src/char_body.blend` 를 다시 쓴다(내보내기가 임시 디렉터리를 넘긴다).
* 포즈 = `apply_pose(clip, 판, 판수, 방향 0)` **그 함수**. 판마다 뼈 회전을 쿼터니언 열쇠로(부호 연속) · 걸음 흔들림(bob)은 리그 대신 **root 뼈 위치**로(값 무변 · `rig.location.z ÷ ZSQ`).
* ★z 누르기(ZSQ)는 **안 굽는다** — 리그 스케일 1 로 참 3D 를 낸다. 누르기는 엔진이 부모 스케일로 한다(시트의 "포즈한 다음 누르기" 순서가 저절로 선다).
* 열쇠 눈금 `SCENE_FPS = 90` — 클립 fps 셋(0.9·10·2)의 판이 전부 정수 프레임에 떨어지는 가장 작은 수(60 이면 서기 4판째가 4.433초에 걸려 길이가 틀렸다).
* 옷 = 한 벌(가죽) — 같은 기하에 재질 슬롯만(`set_cloth_material('leather')` · T81 문법). 클립마다 NLA 트랙 하나 · 내보내기 `export_animation_mode="NLA_TRACKS"`.
* 결정적 — 두 번 구워 glb·메타 바이트 동일(T522 실측). 입력이 바뀌면 `e2e-char3d ⓐ 입력 지문` 이 빨개진다 ⇒ 다시 굽고 잠금을 같이 올린다.

## 4. 좌표 · 카메라 — 게임 투영 그대로

게임 투영 `w2i`: 화면 x = wx − wy · y = (wx + wy)/2 − 높이(px · 1칸 = 1m = 32px · 높이 32px/m).
시트 규약(`char_meta.json`): 타일 109×90 · 앵커(발밑) (54.5, 81.663) · 1m = `ppu` 45.2548px · `zsq` 0.8165.

| 무엇 | 식 |
|---|---|
| 모델 → three | glTF(Y 위)의 (x, z, −y)에 모델 스케일 **(1, zsq, −1)** ⇒ three (x, zsq·높이, y) — 게임 x·y 가 three x·z 에 그대로 선다. 행렬식 −1 = 시트의 좌우 뒤집기(`_flip_png`)와 **같은 거울**(three 가 감김을 알아서 뒤집는다) |
| 방향 | `root.rotation.y = −atan2(fy, fx)`(연속) · 돌아서기는 시상수 `TURN_TAU` 0.06초로 따라간다(그림만 · 이동 무관) · (−π, π] 로 접는다 |
| 카메라 | 직교 · 고도 30° · 방위 45°: 위 = (−s/√2, c, −s/√2) · 자리 = (c/√2, s, c/√2)×50 · 원점을 본다(c = cos30° · s = sin30°) |
| 절두체 | (−ax/ppu, (fw−ax)/ppu, ay/ppu, −(fh−ay)/ppu) ⇒ **원점(발밑)이 타일의 앵커 화소에 선다** — 시트와 같은 앵커 규약으로 `drawImage(round(x − ax), round(y − ay))` |
| 빛 | 태양 = 방향광(세기 = Blender 태양 3.6 · 방향 = 메타 `sunDir` 를 같은 거울로) · 하늘 = 고른 환경광(메타 하늘빛 × π × 0.55) |

맞춤(8방향 · 서기 0판 · 몸 + 가죽옷 — 시트 판 ↔ 3D 타일): 발밑 줄 Δ 0px(방향 2 만 +1) · 발 가운데 |Δx| ≤ 0.32px · 정수리 Δ 0 · IoU 0.983~1.000(자명 통과 금지: 방향 0↔2 를 맞대면 0.772).

## 5. 그리는 자리 · 가림

* 갈고리: `drawCharSprite(x, y, isMe, opts)` 첫 줄 — `__char3d.draw` 가 참이면 시트 대신 3D 가 그렸다. **내 몸 하나만**(`isMe`) · 주민·남은 시트 그대로.
  쓰러짐·업힘·업기·포로(`down`·`carriedOn`·`carrying`·`cap`)는 클립을 안 내보냈다 ⇒ 거짓을 돌려 시트가 그린다.
* 클립: 시트 상태기계(`charState`)를 **그대로** 돌리고(발소리 `__sfx.step` 도 같은 한 줄) 내보낸 셋에 붙인다 — `run` → 걷기를 fps 비(14/10)로 빨리 · `idle2`·`aim2` → 서기·조준 · `swing`(원샷) → 서기.
* 타일: WebGL 캔버스 하나에 몸마다 타일 하나(열 = min(N, 10)) — 뷰포트·가위로 자리 잡고 그 몸만 보이게 해서 그린다 → **프레임에 한 번** 2D 받침 캔버스로 떠 온다 → 몸마다 받침에서 `ctx.drawImage`.
  (WebGL 캔버스를 몸마다 `drawImage` 하면 몸마다 판 전체를 다시 떴다 — 1판 실측 100몸 241ms.) 그림자 = `drawCharShadow` 같은 함수·같은 자리 · 이름표는 부르는 쪽이 그대로 그린다.
* ★가림: 사람은 renderables 에서 **z + 500** 으로 선다(`34-m-renderloop` · 시트와 같은 한 줄) — 집·나무는 사람을 안 덮고 **벽·지붕이 비킨다**(컷어웨이 · `20-r2-visibility`). 사람을 덮는 것은 화가 순서에서 **renderables 뒤에 오는 층**이고, 그중 산의 **흐림 겹**(앞 산을 모아 알파 `MT_OCC_A` 0.34 로 맨 위에 얹는다 · `11-r1-mountain`)을 쟀다:
  * 제 차례(`=1`): 3D 도 시트도 흐림 겹 **아래** — 산을 켜면 몸↔바탕 대비가 (1 − 0.34) = 0.66 배로 준다: 3D **0.654** · 시트 **0.654**(같은 술어 · 새 규칙 0).
  * 덮개(`=overlay`): 산을 켜도 몸 화소가 **그대로**(바뀐 양 0) — 흐림 겹 **위**에 얹혔다. 카드 ② 의 글자("투명 캔버스로 얹고")대로 서면 가림을 받으려고 **새 규칙**(몸 자리에서 흐림 겹을 다시 그리는 것 따위)이 든다 ⇒ 기본값은 제 차례. 정본 선택은 PM(회부).

## 6. 재는 자리(하네스 · 손잡이 켬에서만 선다)

`window.__char3d` = `{ ready, why, info(렌더러·판), mode('mesh'|'sheet' — 벤치 기준선), benchN(벤치 몸 수), hide(몸 없는 판 · 가림 바탕), clothes, snap(방향, 클립, 판, 옷) → 타일 RGBA, lastDraw({gl, blit, n, clip, t, yaw, yawTarget, x, y, abs, w2s, pred}) }`.
`__charDbg[pid].mesh = true` 로 3D 가 그렸음을 적는다(시트 진단 훅과 같은 자리).
`scripts/e2e-char3d.js` 여섯 절: ⓐ glTF·잠금·판 · ⓑ 카메라 8방향 · ⓒ 걷기·가림(산 뒤 자리는 `__mtOccAt` 정본 방아쇠로 찾는다 · 몸 시계는 `_charAnim` 의 t 를 묶어 멈춘다) · ⓓ 옷 메시 · ⓔ 프레임 짝(`__frameCapture` · 몸 1·10·100) · ⓕ 끔.
맥 수치는 같은 `char3d.js` 를 싣는 따로 선 벤치로 잰다(보고 §ⓔ — 게임 밖 · 몸 그리기만).
