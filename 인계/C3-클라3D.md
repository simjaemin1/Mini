## 3. 자산 파이프 — 새 형상 0

* 몸: `char_render.py` 원문을 표지 줄 `# ═══════════════ 공유 프레임 박스 ═══════════════` **앞까지** 읽어 실행(굽기·상자·시트 저장 안 지남). 표지·이름이 없으면 **죽는다**. `char_render.py` 는 늘 `--sheetdir=<사본>`(안 그러면 추적 파일 `assets-src/char_body.blend` 를 다시 쓴다).
* 포즈 = `apply_pose(clip, 판, 판수, 방향 0)` **그 함수** — 판마다 뼈 쿼터니언 열쇠(부호 연속) · 걸음 흔들림 = root 뼈 위치(`rig.location.z ÷ ZSQ`).
* ★z 누르기(ZSQ)는 **안 굽는다** — 리그 스케일 1 로 참 3D · 누르기는 엔진 부모 스케일.
* 몸 파일 열쇠 눈금 `SCENE_FPS = 90`(클립 fps 셋의 판이 전부 정수 프레임 · 시각 = 초).
* [T539] 클립 파일 시각 = **판 번호**(판 k 의 열쇠가 시각 k · `SCENE_FPS = 1`) — 굽는 판 fps(0.9·14…)로 찍으면 내보내기가 장면 fps 로 다시 떠서 2.4MB 가 된다(1판 실측). 엔진이 파일 시각 = 초 × fps 로 읽는다(메타 `timeUnit`).
  쓰러짐·업기(`ground` 클립)의 내림 = root 뼈 위치 **참 3D**(굽기가 잰 값 · ÷ZSQ 안 함) — 부모 스케일이 누른다.
* 옷 = 한 벌(가죽) — 같은 기하에 재질 슬롯만(`set_cloth_material('leather')`). 클립마다 NLA 트랙 · `export_animation_mode="NLA_TRACKS"`.
* 결정적 — 두 파일 다 두 번 구워 바이트 동일. 입력이 바뀌면 `e2e-char3d ⓐ 입력 지문` 이 빨개진다 ⇒ 다시 굽고 잠금을 같이 올린다.

## 4. 좌표 · 카메라 — 게임 투영 그대로

게임 투영 `w2i`: 화면 x = wx − wy · y = (wx + wy)/2 − 높이(1칸 = 1m = 32px · 높이 32px/m).
시트 규약(`char_meta.json`): 타일 109×90 · 앵커(발밑) (54.5, 81.663) · 1m = `ppu` 45.2548px · `zsq` 0.8165.

| 무엇 | 식 |
|---|---|
| 모델 → three | glTF(Y 위)의 (x, z, −y)에 모델 스케일 **(1, zsq, −1)** ⇒ three (x, zsq·높이, y) · 행렬식 −1 = 시트 좌우 뒤집기(`_flip_png`)와 같은 거울 |
| 방향 | `root.rotation.y = −atan2(fy, fx)` · 온 메시 몸은 **연속**(시상수 `TURN_TAU` 0.06초) · 몸 메시 + 시트 층 몸은 **시트 행 × 45°**(시트 층이 붙게) |
| 카메라 | 직교 · 고도 30° · 방위 45°: 위 = (−s/√2, c, −s/√2) · 자리 = (c/√2, s, c/√2)×50(c = cos30° · s = sin30°) |
| 절두체 | [T539] WebGL 판 전체(열 × fw, 행 × fh)를 한 카메라가 덮는다: (−ax/ppu, (W−ax)/ppu, ay/ppu, −(H−ay)/ppu) ⇒ 칸 0 의 앵커 = 원점(발밑) |
| 칸 옮기기 | [T539] 몸 k 의 root = 카메라 오른쪽 vR × (열·fw/ppu) − 카메라 위 vU × (행·fh/ppu)(카메라 `matrixWorld` 첫·둘째 기둥) — 직교라 옮긴 만큼 화소가 옮고 깊이 무변 |
| 빛 | 태양 = 방향광(Blender 태양 3.6 · 메타 `sunDir` 같은 거울) · 하늘 = 고른 환경광(메타 하늘빛 × π × 0.55) |

맞춤(8방향 · 서기 0판 · 몸 + 가죽옷): 발밑 줄 Δ 0px(방향 2 만 +1) · 발 가운데 |Δx| ≤ 0.32px · IoU 0.983~1.000(자명 통과 금지 0↔2 = 0.772). [T539] 클립 열둘 × 8방향 × 판 전부 408표본 발밑 ≤ 1px · 합성 IoU ≥ 0.963.

## 5. 그리는 자리 · 장면 · 가림

* **층 고리(T539 · 정본)**: `drawCharSprite` 가 시트 상태기계를 돌리고 층을 고른 다음 `__char3d.body(pid, isMe, layers, stt, row, opts, x, y)` 를 부른다 → 타일 {sx, sy, clip, frame, row, full} 또는 null. 타일이면 층 고리에서 `body` 층 자리에 `__char3d.blit` 로 타일을 찍고, 나머지 층은 **타일의 클립·판·행**으로 시트 그대로 얹는다(온 메시면 `clothes_leather` 층은 건너뜀 · `__char3d.meshLayer`). 병종 띠 물들이기·궤주 반투명·업힘 오프셋·그림자·입 자리(`drawn`)·진단 훅은 같은 판·행으로 종전 식.
* 몸마다 모드 하나: ⓐ 온 메시(층 = 몸 + 가죽옷) — 방향·시각 연속 ⓑ 몸 메시 + 시트 층(그 밖 · 주민 거의 전부) — 시트 판과 같은 자세(행 × 45° · 판 열쇠) ⓒ 시트(`mode='sheet'` · 처음 보인 한 판 · 클립 없음).
* 첫 줄 갈고리 `__char3d.draw`(T522): 내 몸에서만 — 벤치 몸(`benchN − 1` · pid `__t522b<k>` · 가죽 한 벌)을 같은 `drawCharSprite` 로 부르고 · 재는 판(`hide`)이면 그림자만 그리고 참 · 덮개(`=overlay`)는 매 판 비운다.
* **장면은 한 번(T539 ②)**: 몸 웅덩이(pid → 몸 · 뼈 복제 · 120판 안 불리면 빈 몸으로) · 한 판의 요청이 모이면 **다음 판의 첫 몸**이 한 장면 · 한 카메라 · **렌더 하나**로 그리고 받침 캔버스로 한 번 떠 온다 → 몸마다 받침의 제 칸을 `drawImage`. 판(`tok`) = `requestAnimationFrame` 하나.
  ⚠**몸짓이 한 판 늦다**(자리는 그 판 · 시트 층도 같은 판이라 어긋남 0) · 처음 보인 몸은 그 한 판만 시트.
  WebGL 판 크기 = 몸 수(열 ≤ 16) — 늘릴 땐 곧바로 · 줄일 땐 필요한 넓이가 절반 아래로 30판 이어질 때만.
* ★가림: 사람은 renderables 에서 **z + 500** 으로 선다(`34-m-renderloop` · 시트와 같은 한 줄) — 집·나무는 사람을 안 덮고 **벽·지붕이 비킨다**(컷어웨이). 사람을 덮는 것은 renderables 뒤 층 — 산의 **흐림 겹**(알파 `MT_OCC_A` 0.34 · `11-r1-mountain`):
  * 제 차례(`=1` · 정본): 3D 도 시트도 흐림 겹 **아래** — 몸↔바탕 대비 0.66 배(3D 0.651~0.655 · 시트 0.653~0.655 · 같은 술어 · 새 규칙 0).
  * 덮개(`=overlay` · 자 전용): 산을 켜도 몸 화소 **그대로**(바뀐 양 0).

## 6. 재는 자리(하네스 · 손잡이 켬에서만 선다)

`window.__char3d` = `{ ready, why, info(렌더러·판), mode('mesh'|'sheet' — 벤치 기준선), benchN(벤치 몸 수), hide(몸 없는 판), overlay, lastDraw({gl, blit, n, calls, x, y, clip, full, t, yaw, yawTarget, tile, abs, w2s, pred} — 내 몸), stats({tok, renders, maxPerTok, glRenders, bodyFrames, bodies, calls, ms, stageMs, pool}), body, blit, meshLayer, snap(방향, 클립, 판, 옷) → 타일 RGBA(판 파이프라인 밖에서 따로 렌더), clips() }`.
`__charDbg[pid].mesh`·`meshFull` = 3D 로 그렸음 · 온 메시(켬에서만 싣는다 — 끔 = 종전 키).
`scripts/e2e-char3d.js`: ⓐ glTF·잠금(몸 · 클립) · ⓪ central · ⓑ 카메라 8방향 · ③ 클립 표(열둘 × 8방향 × 판 전부) · ⓒ 걷기·가림 · ⓓ 옷 메시 · ⓔ/② 프레임 짝 + 장면 한 번(렌더 = 3D 몸 판) · ① 남의 몸(둘째 접속 · 바탕 = 그 몸 층만 뺀 판 · 그림자는 둔다)·주민(0.7초 표본 · 제 판으로 합성 맞대기) · ⑤ 마을 광장 그림 · ⓕ 끔.
자 두 가지: **타일 자리**(알파 > 127 — ⓑ·③·① 합성) · **화면**(바탕과 RGB 차 > 8 — 가림 · ① 남의 몸 발밑). 시트 몸은 가장자리 반투명 고리가 있어 화면 자에선 시트가 1px 고리만큼 크다(화면 IoU 0.935 · 타일 IoU 0.982).
맥 수치는 같은 `char3d.js` 를 싣는 따로 선 벤치로 잰다(보고 T539 §②-4 — 게임 밖 · 몸 그리기만 · raw.githubusercontent 의 가지 커밋 자산).
