## 확정 문법 (재민, 2026-08-05 — 시안 왕복 13회로 확정. 바꾸지 마라)

**물가 = 각진 블록.** 셀 경계 그대로(곡선 스무딩 금지 — 물길 파기 시스템과 문법 통일을 위한 확정).
1. **수면 = 지면 −5px 평면.** 픽셀 기하: 내 자리(지면)가 뭍이면 뭍 / 5px 위 표본이 뭍이면 단면 /
   둘 다 물이면 내려간 수면. ★단면을 픽셀로 그리지 말 것 — 아래 3번의 벡터 프리즘 면이 담당.
2. **얕은물 투명.** 물밑 바닥 = **진흙 재질**(★풀 텍스처가 비치면 안 된다 — "반투명 풀" 사건).
   불투명도 wa = 0.42 + 0.58×수심. 수심 = 물가 거리장(3×3 평균 스무딩), 얕음 옥빛→깊음 남빛.
3. **블록 프리즘 단면.** 물에 접한 뭍 셀의 **남·동 변**에서 5px 수직면(벽 셰이드 문법 —
   남면 어둡게·동면 밝게), 상단 풀 넘김 립 ~2px, 하단 물 접촉선 그림자. 북·서 변은 뭍이 가린다(면 없음).
4. **흐름맵 셰이더 물 (60fps).** 유체 시뮬 아님 — M&B 문법. 흐름 방향 = `hanbando-terrain.json`
   rivers path(상류→하류 순서로 저장돼 있다)의 **최근접 구간 방향**. 꺾임은 자동으로 따라간다.
   파동 = 흐름 방향 사인 2파(λ 64px·32px, **진폭을 저주파 노이즈로 변조** — 안 하면 골판지) +
   값 노이즈 잔물결 2옥타브(스케일 8·3.2). 노멀 → 태양(52°/35° 정본과 일관) 확산 + 반사(pow≈90).
   하구(폴리라인 끝)에서 흐름 감쇠→호수는 무방향 파문. 바다 파도 = 해안 거리장 방향(§C-4).
5. **포말.** 시간 고정(위치 함수 — 흘러가면 꼭짓점에서 깜빡인다), 뭍이 북서일 때만(기울기 방향),
   기울기 **크기** 문턱(곶 끝 뭉침 금지), 뭍에 맞닿은 변 7px 이내만.
6. **물가 술(풀 오버행).** 물가 뭍 변에서 풀대가 수면 위로 넘어와 절단선을 가린다 — **물 다음에**
   그려야 가림이 성립한다. ★재민 미해결 지적: 현 시안(변 전체 균일 밀식)은 "일부러 심은 느낌".
   **자연 군락화가 이 배치의 숙제다**: 밀도 저주파 변주(빽빽/빈 구간), 높이·색 변주, 물가 안쪽으로
   1~2셀 이어지는 감쇠 산포, 갈대·부들 섞기. 균일 간격 금지.

시안 정본 코드: **`scripts/mock-terrain-v4.js`** (위 문법 전부가 작동 코드로 박혀 있다 — 이식 기준).
질감 베이크: `scripts/bake-terrain-tex.py`(탑다운)·풀은 **게임 카메라 각도(방위45·고도30) 베이크**
(`grass_angled` — 탑다운을 눌러 붙이면 "풀 얼룩"이 된다). Blender 설치: `apt-get update && apt-get install -y blender`.

## 시안 왕복에서 축적된 함정 (전부 실제로 밟았다 — 재발 금지)

- canvas 텍스처 삼각형: `transform`(합성)이지 `setTransform`(치환) 아니다 — 치환하면 암흑 화면.
- 클립 삼각형은 무게중심 기준 0.8px 팽창 — 안 하면 이음새 실금.
- UV 는 연속(핑퐁 래핑)으로 — 셀마다 무작위 창을 잡으면 조각보.
- GIF 는 **단일 팔레트**로 — 프레임별 적응 팔레트는 정지 픽셀도 깜빡인다(디버그용일 때).
- 애니 루프는 모든 시간항의 주기 정합 — 노이즈 advection 은 크로스페이드(실게임 연속 시간엔 불필요).
- 픽셀 패스 좌표는 장면-로컬 — 존 오프셋 재감산 금지(전면 침수 사건).
- 목업 뷰포트가 그리드 밖을 비추면 "일부만 구현된" 가짜 결함이 보인다 — 판정 전 뷰포트부터 확인.

## 작업 (순서대로 — 각 단계 커밋, 끊어 이월 가능)

### A. 지면 질감 실장 (client.js)
1. Blender 로 **씨멜리스** 풀밭 베이크(각도 베이크·1셀=1m 정합: 베이크 px/m ÷ 45.25 로 스케일).
   반복이 안 보이게: 씨멜리스 + **변주 타일 2~3장을 셀 해시로 혼합**. 맨땅 뙈기는 잘게.
   진흙(물밑)·마른땅 변주도 함께. 결과물은 `public/assets/terrain/` + 베이크 스크립트 커밋.
2. client.js 지면 타일 루프를 질감 타일링으로 교체 — **화면 공간 타일링**(mock 방식) + 위도 틴트·
   얼음 밴드(기존 문법)와 곱 합성. ★성능: 지면은 정적이다 — **청크 오프스크린 베이크** 후
   drawImage. `_tileAcc` before/after 실측해 보고에 적어라(퇴보 금지).

### B. 물 실장 — WebGL 셰이더 레이어
1. **흐름맵 생성**: rivers path 에서 존을 덮는 저해상 벡터 텍스처(셀당 2채널 방향+세기) 베이크 —
   부팅 시 1회 계산(§확정 문법 4). 하구 감쇠·호수 0벡터.
2. **WebGL 프래그먼트 셰이더**: 확정 문법 4·5 를 GLSL 로. 캔버스 합성: 물 영역만 WebGL 캔버스에
   그려 메인 캔버스에 drawImage(또는 전체 WebGL 오버레이 — 성능 실측으로 택1).
   유니폼: time·flow map·수심맵(거리장)·태양 방향. WebGL 불가 환경 폴백: 현행 단색(기능 저하 허용).
3. **블록 단면·얕은물 투명**: 확정 문법 1·2·3. 단면은 기존 벽 렌더 문법 재사용(셰이드 값 동형).
4. **바다**: 해안 거리장에서 파도 방향(해안으로), 먼바다 스웰 + 해안 포말 밴드. 강 하구와 이음.
5. 실화면 확인: `/tmp/zone-wrap.js` 좌표 스폰으로 강·호수·바다·하구 4지점 스크린샷.

### C. 물가 술 자연화 + 자연물 재렌더 (Blender)
1. **풀포기·갈대·부들 스프라이트** Blender 렌더(정본 씬: PPU 45.255·ZSQ 0.8165·태양 52°/35°·

   **자연 군락화**(§확정 문법 6 의 숙제 — 균일 간격 금지, 저주파 밀도 변주·군락·감쇠).
2. **나무 12종·수풀 재렌더** [재민 확정 "전면 통일"]: Kenney 로우폴리를 Blender 정본 씬의
