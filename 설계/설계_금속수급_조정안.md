## 1. 지금 청동 생산량 — **0**

주석 산지 마을이 **0 / 51** 이다.

두 경로 다 막혔다:
- **이름해시 경로**: `land.ore × (0.8 + 0.4×hash) ≥ TIN_DEPOSIT_ORE_SCORE(1.28)`
  → 필요 `land.ore ≥ 1.067`, 본게임 실측 최대 **1.06**. 전멸.
- **지도 경로**: 노동권(150셀)에 주석 광맥이 있으면 자격.
  → 광맥 787개 중 주석이 11개뿐이라 **어느 마을 노동권에 걸리느냐가 순전히 운**이다.
    직전까지는 광산7 하나가 걸려 있었는데, 광종 재배정(텅스텐·석탄·대리석 제거)으로 그 운이 끊겼다.

⇒ **한 마을의 우연에 대륙 전체의 청동이 달려 있던 구조였고, 지금은 그마저 0이다.**

## 2. 원인 — 합금비가 고증의 2~3배로 주석을 먹는다

| | 구리 : 주석 |
|---|---|
| 코드 (`economy-sim.js:1334`) | `0.3 : 0.12` = **2.5 : 1** |
| 한국 청동기 실제 (Sn 13~20%) | **4 : 1 ~ 6.7 : 1** |
| 세계 표준 청동 (Sn 10%) | 9 : 1 |

주석은 지도에서도 희소하고(가중치 2.0/95.4) 산출도 마을당 정액인데,
소비까지 고증의 2~3배로 잡혀 있어 **삼중으로 병목**이 됐다.
그 결과 구리가 **67% 남는다**(아래 A안 실측).

구조적 비대칭도 하나 있다:
- 구리 공급 = `1.5 × land.ore × 0.22 × 광부 수` — **광부 수에 비례**
- 주석 공급 = `0.46 × land.tin` — **마을당 정액**(광부 수·광맥 셀·품위 전부 무관)
⇒ 마을이 클수록 구리:주석 격차가 벌어진다.

## 3. 대안 비교 (인구 30/마을 · Lv0 · 실측)

| 안 | 청동 마을 | 청동검/일 | 순동검/일 | **구리 잉여** |
|---|---|---|---|---|
| 지금 | **0** | **0** | — | 전량 |
| **A** 문턱만 0.75 | 5 | 2.57 | — | 10.51 (**67%**) |
| **B** A + 합금비 6:1 | 5 | 4.81 | — | 4.12 (**26%**) |
| **C** B + 순동검 분기 | 5 | 4.81 | 1.36 | 0.31 (**2%**) ★ |
| **D** C + 문턱 0.50 | 7 | 7.20 | 0.85 | 0.44 (2%) |

**C 안을 권한다.** 세 수정이 각각 독립적으로 고증 근거가 있고, 합치면 구리 잉여가 2%로 떨어진다.

### C 안의 세 줄

**① `TIN_DEPOSIT_ORE_SCORE` 1.28 → 0.75**
문턱 1.28 은 **랩 기준**이다(코드 주석: "랩 마을3=ore 1.5 산지 보장 하한").
랩 광산촌은 `ore = 1.5` 고정인데 본게임은 `land.ore = 0.10 + 2.40×√(광맥면적비)` 라 최대가 1.06 이다.
**랩에서 맞춘 상수가 본게임 스케일과 안 맞는 것**이지 설계 의도가 틀린 게 아니다.
0.75 로 낮추면 광산1·2·4·5·7 다섯 곳이 산지가 된다 — "소수 광산촌만" 이라는 원 의도 그대로다.

**② 합금비 `copper 0.3 / tin 0.12` → `copper 0.36 / tin 0.06` (6:1)**
한국 청동기 주석 함량 13~20% 구간의 중앙이다. 총 금속량은 0.42 로 **동일**하게 잡아
검 1자루의 무게감은 안 바꾸고 배합만 고증에 맞춘다.
⇒ 같은 주석으로 검이 2배 나오고, 구리 소비가 1.2배로 늘어 잉여가 준다.

**③ 순동검 분기 — 주석 없는 마을이 `copper 0.42` 로 순동검**
고증: 세계적으로 순동기시대(Chalcolithic)가 있었고 순동 도구·무기가 실제로 쓰였다.
무르고 담금질이 안 돼 열등했지만 **석기보다는 나았다.**
게임적으로는 주석 병목이 **벽이 아니라 등급**이 된다:
```
마제석검(0.6) < 순동검(0.7) < 철검(0.85) < 청동검(1.0)
```
그리고 이게 **구리 잉여의 싱크**다 — 26% → 2%.
플레이어 쪽 등급표(`player-items.js` `MAT_GRADE.copper = 0.7`)와 장비 레시피
(`zone.js` accepts 에 copper)는 **이미 적용했다**. econ 분기만 남았다.

## 4. 적용할 패치 (승인 대기)

```js
// sim/economy-sim.js:491
const TIN_DEPOSIT_ORE_SCORE = 0.75;   // 1.28 → 0.75 (랩 ore=1.5 기준 → 본게임 최대 1.06 스케일 보정)

// sim/economy-sim.js:1334 — 합금비를 고증으로
v.storage.copper -= 0.36; v.storage.tin -= 0.06;   // 6:1 (한국 청동기 Sn 13~20%). 총 금속 0.42 불변
_cons(v, 'copper', 0.36); _cons(v, 'tin', 0.06);

// sim/economy-sim.js:1344 앞 — 순동검 분기 신설(청동 실패 시 철검보다 먼저)
} else if ((v.storage.copper || 0) >= 0.42) {
  v.storage.copper -= 0.42;                         // ★순동검 — 주석 없이 구리만. 무르지만 석기보다 낫다
  _cons(v, 'copper', 0.42);
  v._pureCuWeaponMade = (v._pureCuWeaponMade || 0) + amt;
  v._swordMadeToday = (v._swordMadeToday || 0) + amt;
  const wq = WEAP_Q_PURECU * _qSkill;               // WEAP_Q_PURECU = 0.70 신설
  v._weapQnum = (v._weapQnum || 0) + wq * amt; v._weapQden = (v._weapQden || 0) + amt;
  addProduce('weapon', amt);
  workNPC(npc);
}
```

⚠ 병기고 배분(`BRONZE_ARMORY_FRAC = 0.45`)도 손봐야 할 수 있다 — 지금은 청동:석기만 나누는데
순동이 끼면 3등급이 된다. 이건 적용 후 랩에서 재보는 게 맞다.

## 5. 남은 회부 — 주석 공급을 지도와 연결할지

지금 주석 산출은 `0.46 × land.tin` 정액이라 **광맥 셀 수·품위·광부 수를 전부 무시한다.**
지도에서 주석 광맥을 몇 개 심든 산출량이 안 바뀐다(자격 여부만 바뀐다).

- (가) 그대로 — 시드 간 편차가 없어 밸런싱이 쉽다(코드 주석의 원 의도).
- (나) 광맥 셀 기반으로 — 지도가 경제에 닿는다. 다만 econ 개편이라 크다.

같은 문제가 **구리에도** 있다: econ 부산물이 `{copper .22, iron .03, silver .05, gold .02, gem .01}`
**고정 dict** 라 금맥 옆 마을이나 철맥 옆 마을이나 같은 비율로 나온다.
지도의 광종 배분이 마을 경제에 **전혀 안 닿는다**. 이걸 닿게 할지는 별건이다.
