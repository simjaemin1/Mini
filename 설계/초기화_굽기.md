# 초기화 굽기 — 지형 정본을 한 줄로 (T601 · 2026-10-03)

> 초기화 전 지형 작업이 카드 여럿에 흩어져 있다(T591 폭 · T588 해안 · T595 동쪽 · T596 마을 자리 · T586/T574 광맥 · 다리 계획기 · T585 개울 · 에디터 내장).
> **차례를 틀리면 앞 단계가 뒤 단계를 깬다** — 해안이 바뀌면 마을·광맥이 물에 잠기고 개울 지문이 어긋난다(족보 541).
> 그 차례를 한 스크립트에 박았다: `scripts/reset-bake-all.sh`. 재민이 값을 고르면 PM 은 이 한 줄만 돌린다.
> 배포(서울·도쿄)는 이 파일 밖 — `설계/초기화_절차서.md`(T587) §3 0 ④ 가 "굽기 끝난 main 해시" 한 줄로 잇는다.

## §0 줄 — PM 손(레포에서)

```sh
bash scripts/reset-bake-all.sh --table                      # 단계 표만
T588_COAST=a T601_VILLAGES=1 bash scripts/reset-bake-all.sh  # 예행 — 작업 트리를 임시 사본에 떠서 차례로 적용 · "무엇이 바뀔지" 표 · 레포 무변
T588_COAST=a T601_VILLAGES=1 bash scripts/reset-bake-all.sh --apply   # 적용 — 빨강이면 그 단계에서 멈춘다
git add -A server lab && git commit …                        # 바뀐 정본 파일(표의 "바뀐 정본")
bash scripts/reset-bake-all.sh --rulers                     # 착지 전 마지막 — 바뀜 0 · 끝까지 초록 · 3시드(바뀌었으면 새 판 후보로 따로)
```

* 기본은 **예행**이다. 레포 파일은 안 바뀐다(임시 사본 `$TMPDIR/reset-bake-<시각>/w` — 끝나면 지운다 · `--keep` 이면 남긴다).
* `--keep-going` 은 예행에서만 듣는다 — 빨강에서도 안 멈추고 끝까지 돌려서 "그 손잡이를 켜면 무엇이 바뀌나" 표를 낸다(§3).
* `--audit` 는 입력이 그대로인 배치 단계(군락)도 다시 돌려 **정본이 계획기와 어긋난 자리**를 찾는다.
* 끝 게이트: `test-nippon-boot` · `test-jungwon-boot`(`--no-boot` 로 건너뜀) · `--rulers` 면 3시드 t17 이 일곱째 판(8,279 / 8,258 / 8,591 · `T601_BASE`)과 같은지.

단계마다 지키는 것:

* **부르기만** — 굽기 산법은 각 카드의 스크립트에 있고 이 셸엔 없다(사본 0). 셸은 차례 · 손잡이 · 게이트 · 바뀜 표(정본 파일 sha256 전후)만 쥔다.
* **재민 값이 비면 지금 정본 그대로 통과** — 손잡이가 빈 단계는 아무것도 안 부른다(2·3·4 · 5 의 자잘 광맥).
* **입력이 바뀐 단계만 다시 굽는다** — 군락(5)은 해안·동쪽·마을 자리(2~4)가 바뀌었을 때만 계획기를 다시 돈다(계획기가 멱등 · 옛 군락이 새 계획에 없으면 스스로 멈춘다 — seedKey 보호). 광종(5)과 개울(7)·에디터(8)는 결정적 판정이라 늘 본다(같으면 안 쓴다).
* **다리는 계획만** — 다리 셀 줄은 zone-config 에 사람이 옮긴다(T580 · T537 문법). 계획기가 새 섬을 내면 빨강(멈춤). 알려진 예외 한 곳: 한반도 어촌6 — 해안 띠 안 거짓 섬(재민 09-30 · zone-config `bridgeSites` 주석).
* **자잘 숲은 부르지 않는다** — `plan-small-forests.js` 는 11차 손 고름 도구다(돌리면 늘 후보를 낸다 · T586 "더할 것 0" 은 다른 자로 잰 답). 숲 바꿈은 사람이 고른 뒤 그 스크립트로.
* **광종은 두 번 안 굽는다** — 한반도는 이미 구운 판(`region-bake-off.json`)이라 바뀔 광맥이 생기면 빨강(되돌린 뒤 `t574-bake`). 닛폰은 새 자잘 광맥(광종 빈 칸)만 `t580-bake-nippon --L 500 --apply` 가 채운다.
