# 도적 습격 실체 층 — 이식 계획 (Phase 2)

오픈월드 맵에서 도적이 이동 중인 교역 캐러밴을 요격 → per-entity 근접 전투 → 승리 시 격퇴·패배 시 화물 전손.
`bandits.js` 헤더(21~24)가 유예한 "2파 실체 층" 구현. **econ 무개편**(호스트 주입 계약).

## 검증 완료 (헤드리스)
- **전투 모델 = zone.js 충실** per-entity: hp100 · atk = 10 + round(무기공격×0.2) · `damagePlayer` 평면. `sim/skirmish-lab.js`로 실측 = Lanchester 제곱법칙(전사 승리 ⇔ E/G > √(도적atk/전사atk)).
- **전사 효과**: 갱 90% 격퇴에 E≈G 필요, 무기 티어(석기 atk17→청동 atk22)는 요구비 ~14%만 절감. battle-core의 "청동 1=전사 4~8"은 군단모델 허구.
- **경제(손익분기, `sim/encounter-lab.js`)**: 어중간한 호위(E≤G)는 무호위보다 손해. **최적 = E ≈ 1.5~2×예상 갱크기**(확실히 보내거나 아예 안 보내거나).
- **모듈(`server/bandit-raid.js`)**: 헤드리스 단위검증 통과(스폰·추격·근접·격퇴/전멸·콜백·결정론·단조 교차).

## 파일별 이식

### 1. `server/bandit-raid.js` — 완료(신규)
호스트 주입식 `create(host)` → `{ spawnGang(gang), tick(dtMs, nowMs), raiders }`. wildlife.js 패턴.
- 상수: DETECT 45셀 · ENGAGE 2셀 · SPEED 2.6셀/s · ATK_CD 600ms(zone.js `PLAYER_ATTACK_COOLDOWN_MS`로 교체 확인).
- 진행형 티어: `light`(stone/wood/bone) · `veteran`(iron/obsidian/bronze) → 각 raider가 스킬3 무기 랜덤.

### 2. `server/zone.js` — 배선(최소 3점, wildlife.js 미러)
- `const BanditRaid = require('./bandit-raid')` (12행 근처, `Wildlife` 옆).
- `const raidLayer = BanditRaid.create(host)` — init 시(1790행 근처). **host 어댑터**:
  - `getCaravans()`: `villages.js` `caravanBodies`를 `{cid,x,y,alive,escorts:[def],trader,onDefeat,onRepel}`로 매핑. `def={hp,atk,alive,lastAtk}`.
  - `damage(def,dmg,src)` = `damagePlayer(def, dmg, src)` (몸체가 실제 players/npcs 엔트리라 그대로).
  - `spawnCorpse` · `terrainBlocked(px,py)` = 기존 `isTerrainBlockedLocal`.
- `raidLayer.tick(dt, now)` — 메인 몹 루프(5542행 `Wildlife.tick` 옆). try/catch.
- **게이트**: `const ENABLE_BANDIT_RAID = process.env.BANDIT_RAID==='1'` (기본 off).

### 3. `server/villages.js` — 호위 몸체 + 결과 되먹임
- `spawnCaravanBody`(823~854): econ `escort` 수만큼 **호위 전사 몸체 동반 스폰**(현재 없음). 각 호위 `atk = 10 + round(마을무기 attack×0.2)`, hp100. 상인 몸체는 기존.
- 캐러밴 결과 훅:
  - `onDefeat()` = 화물 전손(`giveAmt=0`·`_abandoned` 경로 재사용하되 **보존 아닌 폐기**) + `world.onBanditLoot(from,to,res,amt,day)` + `tradeStats.cargoLost` 가산.
  - `onRepel()` = 정상 배송 지속(호위 사상만 반영).

### 4. `server/bandits.js` — 갱 로스터·티어 노출 + 스폰 트리거
- 갱 → `{ id, camp:{px,py}, n, tier }` 노출(`GANGS` 이미 `camp.cx/cy`·`n` 보유; tier만 추가).
- **의도적 진행형**: `tier = (gang.gen>=2 || 무기시대==청동) ? 'veteran' : 'light'` (갱 세대/시대 기반).
- 캐러밴이 갱 길목(`pairSync`, `BDT_RT_R` 30셀) 진입 시 `raidLayer.spawnGang(gang)` 1회.
- **이중과금 방지**: 공간 처리 pair는 `world.banditRouteRisk(from,to)=0` 반환(econ 추상 주사위 비활성).

### 5. econ(`economy-sim.js` `warriorTarget`) — 호위 = 갱크기 기반(★26/26 @1500 프로토콜 필수)
- 현: `ceil(caravans×(0.5+raidRate)×warlike)` — raidRate만, 갱크기 무시.
- 목표: 호위 ≈ `ceil(1.5 × 예상 갱크기 Ĝ)` 계단식(Ĝ = `_banditRisk`/관측으로 추정, `BDT_GMIN 3~GMAX 8`). "확실히 or 제로" 정책 반영.
- ⚠️ econ 변경이라 페일패스트→앙상블 짝비교→@1500 26/26→해시감사 프로토콜 거쳐 별도 커밋.

## 잔여(라이브 검증 필요 — 샌드박스 30Hz 불가)
1. **밸런스 튜닝**: 모듈 창발 밸런스가 Lanchester 이상치보다 방어 유리(호위 6이 도적 8 격퇴 실측). SPEED/ENGAGE/표적선정(현 raider 집중포화 vs 방어 분산) 라이브 조정으로 E≈1.5×G 의도 난이도에 맞춤. 호위 몸체 **공간 분산**(현재 캐러밴 1점 집중이 집중포화 왜곡)도 반영.
2. **성능**: raider×캐러밴 근접질의 — wildlife `gkey/agrid` 64m 공간해시 재사용 권장(현 모듈은 O(raider×caravan) 단순 루프).
3. **AOI/렌더**: raider를 `H.mobs` shadow로 미러(wildlife `_makeShadow` 동형) → 기존 broadcast 파이프라인 사용.
4. econ warriorTarget 변경 후 전 회귀 스위트.
