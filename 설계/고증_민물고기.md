## 0. 구조 확인 — "상·중·하류"를 게임이 실제로 무엇으로 가르나

`server/freshfish.js`는 `WATERS=['upper','mid','lower','lake','paddy']`라는 꼬리표만 갖고 있고, 그
자체로는 지도 좌표나 강의 "위치"를 계산하지 않는다(읽기·grep만, 고치지 않음). 실제로 한 마을이
이 다섯 중 어디에 속하는지는 `server/villages.js`의 `_t312Water(vil)` 함수가 정한다:

```js
function _t312Water(vil) {
  if (vil._t312W) return vil._t312W;
  let w = 'mid';
  try {
    const f = state.deps._flowAtCell;
    if (typeof f === 'function') {
      const fl = +f(vil.ccx, vil.ccy) || 0;
      w = fl <= 0 ? 'lake' : (fl >= 0.66 ? 'upper' : (fl >= 0.33 ? 'mid' : 'lower'));
    }
  } catch (e) { _ignoreTerrainFlow(); }
  if (w === 'mid' && vil._potSet && vil._potSet.size > 0) w = 'paddy';
  return (vil._t312W = w);
}
```

즉 "상류/중류/하류"는 **강을 따라간 위치**(발원지에서 몇 km)가 아니라 **그 자리의 물살 세기**
(`_flowAtCell` 수치, 0.66 이상=상류·0.33~0.66=중류·0.33 미만=하류·0 이하=호수)로 정해진다 —
지형이 안 되면 중류로 폴백, 논이 있으면(그 자리가 중류일 때만) "논"으로 덮어쓴다. `server/fishing.js`는
강·바다를 구분하지 않고 **바이옴**(숲·타이가·산 등)으로만 어종을 뽑고(`SPECIES_BY_BIOME`, T592·T583에서
이미 확인), "상/중/하류" 개념 자체가 없다(읽기·grep 재확인). **이 표의 "사는 구간" 칸은 위 다섯
꼬리표를 하천 생태 1차·2차 자료 기준으로 채우는 것이고, 게임의 흐름-세기 판정과 같은 척도가 아니다**
— 그대로 정보 공유.

## 2. ② 청동기 민물 어로 유적

**여주 흔암리 유적**(청동기 — 한강 지류 연안 유적)에서 **그물추**가 석기 도구 목록에 포함되어
출토되었다고 확인했다: "돌화살촉, 반달칼, 그물추, 돌도끼, 바퀴날도끼, 간돌검, 간돌, 돌창끝 등"
(물고기잡이용 도구로 분류되어 서술됨). 다만 같은 자료에 **민물고기 뼈·어망추(그물추와 별개 표현)·
통발**에 대한 구체 언급은 없다 — 미확인으로 남긴다.

**정선 아우라지 유적**(청동기 마을 — 강가 유적)은 경향신문 기사를 직접 열어 확인했으나, 이 기사는
토기·고인돌·DNA·유적 훼손 보도에 집중되어 있고 **어로 관련 내용이 전혀 없음**을 확인했다(부정 결과
— 아우라지는 이번 카드 질문에 답을 주는 출처가 아니다).

**춘천 중도 유적**(청동기)은 이번 판에 보존 논란·고인돌 관련 기사만 검색에 걸렸고, 그물추·어로 관련
구체 서술이 담긴, 열리는 출처는 못 찾았다 — 미확인.

**제주 "그물추" 일반 설명 페이지**(디지털제주문화대전)는 robots.txt로 열람 자체가 막혀(이번 판·이전
판 공통) 못 열었다 — 미확인.

## 3. ③ 가물치 주의

**원산지·한반도 서식**: 나무위키는 가물치를 "한반도, 중국, 러시아 극동부에 서식하는 토종 담수어"라고
명시한다 — **원산지 자체에 대한 "논쟁"은 이번 판이 연 자료에 없고, 한반도 토착종으로 서술된다.**
한반도 내 **문헌상 최초 기록은 조선시대 《향약집성방》(1433년)**의 '加母致' 표기다 — 이는 조선시대
기록이고, **청동기 시대에 한반도에 가물치가 있었다는 직접 근거(출토 뼈 등)는 이번 판도 못 찾아
미확인**이다(단, 토착종이라는 서술과 1433년이라는 "늦어도 조선 초"라는 하한선은 확보).

**일본 전래**: "일본으로의 도입은 **제2차 세계대전 중**에 이루어졌다"고 명시한다 — "일본에서 바다로
나가서 낚시하기가 어려워지자, 회를 좋아하는 일본인들은 담수어에게 눈을 돌렸는데 그 중 한 종류가
식민지 조선에 서식하는 가물치였다"는 서술이다. 즉 **열도는 근대(2차대전 중, 조선에서) 도입설이
명시적으로 확인됨** — 다만 정확한 연도(몇 년)까지는 이 출처에 없어 미확인이다.

**결론(정보만, 판정 아님)**: 한반도=토착(조선시대부터 문헌 확인, 청동기는 미확인) / 일본=근대
이식(2차대전 중, 조선이 원산 — 시기는 "2차대전 중"까지만 확보, 연도는 미확인).
