## 0. 식 — 게임 월·일 환산

`dayOf(y,m,d)` → 게임일(1년 3월 1일 = 0) · `dateOf(day)` → `{year,month,dom}`. 예(카드 예시 그대로
검증): `dayOf(1,6,1)` = **92** → `dateOf(92)` = `{month:6, dom:1}` = **6월 1일**. 작물은
`sowDay = dayOf(1, sowMonths의 첫 월, 1)`, `harvestDay = sowDay + growDays`, `dateOf(harvestDay)`
= 게임 수확월(계산 스크립트는 §재민 칸 아래 "방법"에 남긴다). 계절 경계는 `SEASON_OF_MONTH`
(`calendar.js:70`) 그대로: 봄 3~5월·여름 6~8월·가을 9~11월·겨울 12~2월(기상청).

### ⓐ~ⓓ 집계

## 재민 칸 — 방법(계산 스크립트, 검증용)

```js
const cal = require('./server/calendar.js');
const crops = require('./server/crops.json').crops;
for (const [id, c] of Object.entries(crops)) {
  const m0 = parseInt((c.sowMonths.match(/^(\d+)/) || [])[1], 10);   // sowMonths 첫 숫자 = 파종월(새 수 0 — 파일 값 그대로 파싱만)
  const sowDay = cal.dayOf(1, m0, 1);
  const harvestDay = sowDay + c.growDays;
  const hd = cal.dateOf(harvestDay);
  // ... (전체 로그는 보고서 작업 기록에 있다. 34종 전수 돌렸다.)
}
```
* 1차 버그(이번 판 안에서 고침— 산출물엔 안 남음): 처음엔 `sow[0]`(계절명)을 `MONTH_START`로 대표월 매핑해 **거의 모든 작물이 3월(봄 첫 달)로 잘못 계산됐다** — `sowMonths` 문자열의 **실제 첫 숫자**를 파싱하도록 고쳐서 위 식으로 재실행했다(예: `adlay` sowMonths="4~5월" → 이제 4월1일 파종, 이전엔 3월1일로 잘못 계산됨).
