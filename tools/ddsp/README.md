# `tools/ddsp/` — 악기 맵시를 학습해서 곡선을 소리로 [T353]

> **학습은 재민 데스크톱(RTX 4060 · WSL2)에서 한 줄.** 세션(컨테이너)은 GPU 가 없어 **스모크만** 돌린다 —
> 학습 값을 지어내지 않는다. 산출물(모델·venv)은 **커밋하지 않는다**(`.gitignore`).

## 재민 순서 — 넷

1. `wsl --install -d Ubuntu` (관리자 PowerShell · 재부팅)
2. **NVIDIA 윈도우 드라이버를 최신으로.** WSL 용 CUDA 는 그 안에 들어 있다 —
   ⚠**우분투 안에 CUDA 드라이버를 따로 깔지 않는다**(깔면 WSL 의 GPU 통로가 깨진다).
3. 우분투에서 `nvidia-smi` 가 **4060 을 보이면** 준비 끝.
4. ```bash
   bash tools/ddsp/train.sh daegeum ~/소리/대금_단선율/
   ```
   (걸리는 시간은 **안 적는다 — 안 재봤다.** 첫 판이 돌면 그 수를 여기 적는다.)

## 무엇이 도나

| 단계 | 파일 | 하는 일 |
|---|---|---|
| ① 다듬기 | `prep.py` | wav 폴더 → 단선율 검사(다성 구간은 **버리고 표에**) · 무음 자르기 · 16kHz · f0 · 라우드니스 · 4초 조각 |
| ② 학습 | `train.sh` | venv · 의존성 **핀** · GPU 자동 감지 · **GPU 없으면 30초 스모크**(전 과정이 돈다는 것만 · 모델 값 0) |
| ③ 내보내기 | `export.py` | 학습 산출 → `models/<inst>/` (`phrase.render_curve` 백엔드 B 가 읽는 꼴) |

## 고른 것과 근거

| 갈래 | 고름 | 왜 |
|---|---|---|
| f0 | **pyin**(librosa) | CREPE 는 TF/torch 모델을 또 받아야 하고 단선율 관악에선 pyin 이 충분하다. 무엇보다 **의존성이 하나 적다** — 스모크가 CPU 30초 안에 돌아야 한다 |
| DDSP 구현 | **PyTorch 재구현**(`ddsp-pytorch` 꼴 · 이 폴더 안 최소 구현) | Magenta DDSP 는 TF 1.x 계열 고정이 많아 최신 CUDA·파이썬에서 설치가 자주 깨진다. 여기 쓰는 것은 **하모닉+노이즈 디코더 한 개**라 재구현이 짧고, 핀이 우리 것이다 |

⚠이 표는 **설치 가능성·유지 상태**로 고른 것이고, 음질 비교는 안 했다(모델이 아직 없다).

## 백엔드 B 가 붙는 자리

`public/assets/audio/bgm/phrase.py` 의 `render_curve(inst, f0_hz, loud, sr)` 하나다.
`models/<inst>/` 가 **있으면** B, 없으면 A(지금 합성기). ⚠**조용히 A 로 안 떨어진다** — 어느 백엔드가
울었는지 문자열로 돌려주고, `backend="B"` 로 시켰는데 모델이 없으면 **죽는다**.
