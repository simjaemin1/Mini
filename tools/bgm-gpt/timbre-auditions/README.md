# 대금 음색 진단: B1 이후 사적 청취 실험 (2026-10-11)

재민의 판정은 "비브라토는 좋아졌지만 모델은 아직 기계음이고 원연주는 대금답다"이다. **B1을 완성 대금 음색으로 채택하지 않는다.** 원연주/모델의 같은 C5 구간에서도 B1은 고역·숨결 성분과 시간에 따른 음량 변화가 적다. 모델 B1은 F0·음량만을 제어하는 16 kHz 건조 추론이며, 마지막 C5의 명시 음량값은 일정했다. 서로 다른 연주·마이크·공간을 비교했으므로 차이를 체크포인트 하나의 결함으로 단정할 수는 없다.

이 폴더의 세 도구는 서로 다른 질문을 따로 묻는다. **음색을 고쳤다고 주장하지 않는다.** 입력과 출력은 각 도구의 SHA/제작정보로 고정하고, 국립국악원 원본은 읽기만 한다.

모델 청취본은 `~/Mini/_bgm/gpt/새선율_시험/음색_시험/{다이내믹,공간감}/`, 원연주 014는 `~/Mini/_bgm/gpt/청취/원연주_새변주_시험/`에 있다. 같은 폴더의 제작정보 JSON에 SHA, 입력, 변환과 기술 QA가 있다. 세 재현 도구의 기본 출력도 이 작업 공간이며 레포의 게임 자산에는 쓰지 않는다. 이미 있는 산출물은 덮어쓰지 않는다.

이 Mac의 고정 입력·라이브러리 경로를 가진 재현 도구를 각각 **새** `~/Mini/_bgm/gpt/` 하위 출력 폴더에서 실행해 기존 청취본과 AAC SHA-256까지 일치함을 확인했다. 원본을 훼손하지 않는 읽기 전용 기존 파일 검사는 다음과 같다.

```sh
python3 -B tools/bgm-gpt/timbre-auditions/build_source_informed_b1_dynamics.py --check
```

재현 SHA-256: 음량곡선 `44f860e7…f967434`, 고유 FIR `ca30b5a3…1e6dd73be`, 원연주 014 `c090a1fb…71baf038b1df87`. 이 수치는 바이트 재현 확인일 뿐 음악적 우수성 판정이 아니다.

길이와 대략 −20 LUFS 정합·클리핑/접합 기술 검사는 통과했다. 2026-10-11의 추가 읽기 전용 감사에서 원본 `w3-914-002`와 세 모델판의 같은 C5 구간(17.0–18.3초)을 mono 16 kHz로 디코딩하고, 구간별 RMS를 맞춰 비교했다. 이는 서로 다른 연주·마이크·공간의 **기술적 특징 비교**이지 지각 품질 점수나 원인 분리 실험은 아니다.

결론: 두 사후 처리는 원본과 B1의 숨결·고역·시간 변화 차이를 실질적으로 좁히지 못했다. 특히 고유 FIR은 고역을 더 줄였다. **이 두 처리를 B1 음색 해결책으로 채택하지 않고, 같은 체크포인트의 음량/공간감 미세 조정 반복을 중단한다.** 청취 품질, 014의 실제 루프 반복감과 게임 적합도는 여전히 미판정이다. B1과 두 파생본의 모델 가중치 게임·공개 배포 권리는 확인되지 않았다. 원연주 014에는 `국악기 음원 제공 — 국립국악원 (공공누리 제1유형)`을 표기한다. 세 결과 모두 기본 BGM·`bgm.js`·main에 반영하지 않는다.

원연주 경로의 안전한 추가 팔레트는 `w3-914-002` 한 녹음의 A 0–4.8초, B 4.8–9.6초, C 9.6–14.3초, D 14.3–19.2초다. 같은 연주자·공간을 유지하지만 A 구간 RMS가 나머지보다 약 5 dB 크므로 무작정 순서를 바꾸면 음량이 튄다. 같은 C조 아리랑 `w3-914-001`도 후보이나 두 파일 사이 동일 연주자·세션 정보는 없다. E♭조 `003/004`는 무보정 C조 재배열에서 제외한다. 이 악구들은 동시 재생 스템이 아니라 순서를 고르는 수평 악구다.

재민의 후속 판정: 014는 사실상 원곡이라 원하는 **새 선율의 대안이 아니다**. 014를 새 곡 후보에서 제외하고, 다시 원연주 편집본을 새 작곡에 대한 답으로 제시하지 않는다. 새 8마디 악보와 원음색을 동시에 얻으려면 신규 실연 녹음 또는 별도 권리 검토·승인을 거친 음색 학습이 필요하다. AI Hub 71470은 대금 900클립을 표기하지만, 현지 데이터 묶음·신청 약관 기록이 아직 없으므로 다운로드나 학습은 시작하지 않는다. 국립국악원 원본의 ML 학습 허가와 DDSP-Gugak 체크포인트의 게임 산출물 권리도 별도 확인 전까지 승인된 것으로 간주하지 않는다.

추가 재료 감사: 로컬 국악원 정리본에서 `/대금/` 악구 1,667개·확장 375개와 산조/정악대금 단음 녹음 16개를 찾았다. 정악대금 기본음계의 다섯 목표 음 G4/A4/C5/D5/E5는 각각 자연 어택·지속·릴리스 후보가 있지만, 녹음 안의 연결 슬러는 없다. 현재 새 악보는 28음 중 18곳이 슬러이며 0.267초 음도 있다. 관련 민요 악구 54개+확장 민요 32개의 연속 2.4초 창 10,344개를 첫 마디 G–A–C–A와 비교한 자동 음고 검사에서, 한 원본 안에서 네 음 모두 맞는 후보는 0개(최고 2/4)였다. 이는 2,042개 파일 전체의 음악적 전수 판정이 아니다. 앞서 여러 녹음의 짧은 전이 7개를 이어 만든 2마디도 A음 내부의 −5.19 dB 접합 결함으로 기각했다. 따라서 단음 이어붙이기를 새 악보의 자연스러운 실연 대안으로 포장하지 않는다. 새 녹음이나 권리 확인된 데이터의 새 모델이 필요한 상태다.
