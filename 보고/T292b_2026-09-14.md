# T292-b — 마을에서 1초마다 나던 씹는 소리 (세션9 · 2026-09-14)

카드 없이 시작했다. 재민 신고: **"1.2초~1.3초마다 계속 들리는 이상한 소리가 있어.. 대체 뭔 소리지..? 마을에 있긴 한데.."**

## 결론 한 줄

`eat.ogg`(씹는 소리)가 **초당 한 번** 났다. T283 이 먹기를 `gauges` 메시지의 `carry` 칸 **존재**로 갈랐는데,
그 칸은 `doEat` 만의 것이 아니라 **초당 한 번 도는 게이지 틱**(`server/zone.js:11573`)에도 실려 있었다.

## 어떻게 틀렸고 어떻게 잡았나

**틀린 진단 둘.** 먼저 NPC 도끼질(`resource_update` 브로드캐스트)이라고 단정했다 — 읽기만 하고. 재민이 붙인
콘솔 프로브가 10초에 `resource_update` **0통**으로 뒤집었다. 다음 BGM 굿거리 대박(`0.395 × 3 = 1.185초`)이라고
했다 — 수는 맞지만 재민이 **"효과음인데"** 로 뒤집었다. 둘 다 "주기가 맞는 수"를 먼저 찾고 멈춘 병이다.
주기가 맞는 후보는 여럿일 수 있다.

**맞은 진단.** 남은 단발 경로를 전수로 훑었다. 첫 프로브가 `resource_update`/`resource_removed` 만 봤고
**`gauges` 를 안 봤다**는 것이 구멍이었다. `server/zone.js:11558`:

```js
// === 게이지 변화 주기 broadcast (1초 간격, self에만) ===
if (!p._lastGaugeSentAt || now - p._lastGaugeSentAt > 1000) { ... carry: Carry.payload(p) ... }
```

`cooldownMs: 120` 은 1000ms 간격을 못 막고, `radius: 0` 이라 감쇠도 없다 ⇒ 볼륨 0.7 로 계속 씹었다.
체감이 1.0초가 아니라 1.2~1.3초인 것도 맞다: 30Hz 틱에 `> 1000` 게이트라 실주기는 1초보다 길고,
NPC 가 많은 마을에서 틱이 제일 무겁다.

## 하네스가 왜 초록이었나 — 자가 짧았다

T283 은 이 위험을 알고 `test-audio ⑦f` 를 박아 뒀다. 그 자가 이랬다:

```js
const gaugeLines = srv.split('\n').filter((x) => /type:\s*'gauges'/.test(x.l));
const withCarry  = gaugeLines.filter((x) => /\bcarry:/.test(x.l));   // ← 같은 '줄'만 본다
ok(withCarry.length === 1, '⑦f ...carry 를 싣는 자리가 정확히 하나');
```

`doEat`(5114)은 **한 줄짜리** 전송이라 세어지고, 11573 은 **18줄짜리 객체 리터럴**이라 `carry:` 가 11591 에 있어
영영 안 세어진다. 중괄호를 맞춰 제대로 세면:

```
gauges 보내는 자리 9곳 · carry 실린 자리 2곳 (zone.js:5114 · zone.js:11573)
하네스 ⑦f 가 센 수(한 줄만 본다): 1
```

`⑦g` 의 자명통과금지 픽스처도 **한 줄짜리**를 더해 봐서, 망가진 자를 망가진 채로 확인해 줬다.
이 집의 "검사 범위가 어긋나면 검사가 거짓말한다" **다섯 번째**고, 이번엔 넓어서가 아니라 **좁아서** 틀렸다.

## 고친 것

**① 판별을 모양에서 값으로.** `public/client/48-a-audio.js`

```js
if (t === 'gauges') {
  const h = +msg.hunger;
  if (!isFinite(h)) return;
  const prev = _sfxHunger; _sfxHunger = h;
  if (prev !== null && h > prev) sfxPlay('eat');   // 올랐다 = 먹었다
  return;
}
if (t === 'welcome' || t === 'player_respawn') { _sfxHunger = null; return; }
```

허기는 자연히 **줄기만 한다**(회복 경로 0 — `doEat` 의 `eff.hunger` 가 유일한 +) 이므로 **오름 = 먹었다**다.
서버 메시지 **모양**에 안 기댄다. 기준선 지움 두 줄은 부활·재접속의 첫 통을 "먹었다"로 읽지 않기 위해서다
(부활은 허기를 가득으로 되돌린다 — 안 지우면 살아나며 한 입 씹는다).

**② 자를 중괄호 맞춤으로.** `scripts/test-audio.js ⑦e~⑦g5`
- `⑦f` **자를 먼저 검증한다** — `carry` 실은 전송을 **한 줄짜리·여러 줄짜리 둘 다** 집어내야 자가 성한 것이다.
- `⑦g` 지금 수(**2**)를 적어 둔다 — 조용히 변하면 문다.
- `⑦g2` 픽스처를 **여러 줄짜리**로 바꿨다. `⑦g3` 이 "그 모양은 옛 자로는 0개"임을 명시적으로 잰다 — **픽스처가 진짜로 옛 구멍을 겨눈다**는 증거다.
- `⑦g4`·`⑦g5` 클라가 `msg.carry` 에 **안 기대고** 허기 상승으로 가르는지 잰다.

**③ 안전망.** `eat.cooldownMs` 120 → **400**. ①이 있으면 필요 없지만, 다음에 누가 판별을 넓혀도 연사는 안 난다.

**④ 표에 왜를 남겼다.** `manifest.json` 의 `eat` 칸에 `_왜_carry_가_아닌가` · `_남은_구멍`.

## 남은 구멍 (회부)

**배가 꽉 찬 채로 먹으면 소리가 안 난다** — 허기가 이미 `HUNGER_MAX` 라 안 오른다.
회부 T292 ①(`sendInventory` 에 `where` 한 칸)과 **같은 뿌리·같은 해법**이다: 서버가 동사를 말하면 둘 다 닫힌다.
