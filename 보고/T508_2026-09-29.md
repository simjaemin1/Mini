## 1. ① 감쇠의 꼴 — 지수 k 의 유도 · 적분 표 · 두 곡선 그림

### 1-ⓐ 지금과 왜 순수 −k·x 가 아닌가

* 지금(`decayRate`): 게이지 50 위는 `50 ÷ (T·⅓)`, 아래는 `50 ÷ (T·⅔)` — **100→50 이 16분 · 50→0 이 32분**(허기 T = 2,880초). 재민: *"구간만 나뉘지 선형이잖아 · 지수함수 또는 유리함수여야"*.
* 순수 지수 dx/dt = −k·x 는 x(t) = 100·e^(−kt) — **0 에 영영 안 닿는다**(총시간 ∞). "100→0 = `HUNGER_SEC`·`THIRST_SEC`" 캐논(카드: 총시간 무변)과 T44 극단 사슬(게이지 0 에서 e = 1)이 같이 죽는다.
* ⇒ **상태에 비례하되 상수를 더한다**: dx/dt = −k·(x + b) ⇒ x(t) = (100 + b)·e^(−kt) − b. 게이지가 클수록 빨리 줄고(상태 비례 — 감쇠율은 게이지에 대해 **직선**), 유한 시간 T 에 0 에 닿는다.

### 1-ⓑ k·b 의 유도 — **새 수 0**(종전 매듭 셋)

종전 두 토막 선형이 지나는 세 점 **(0, 100) · (TOP_FRAC·T, SPLIT·100) · (T, 0)** 을 그대로 지나게 한다(두 수 = 두 방정식):

| 식 | 기본값(SPLIT ½ · TOP_FRAC ⅓) | 값 |
|---|---|---|
| b = (100 + b)·e^(−kT) | ⇒ e^(−kT) = b/(100 + b) | |
| 50 + b = (100 + b)·e^(−kT/3) | ⇒ (50 + b)³ = b·(100 + b)² ⇒ **b² + 50b − 2500 = 0** | **b = 25(√5 − 1) = 50/φ = 30.9017** |
| e^(−kT/3) = (50 + b)/(100 + b) = 1/φ | ⇒ **k·T = 3·ln φ** | **1.443635** |
| 허기 k = 1.443635 ÷ 2,880 · 갈증 k = ÷ 1,440 | | **5.0126×10⁻⁴/초 · 1.0025×10⁻³/초** |
| 유리 꼴 x(τ) = 100(1 − τ)/(1 + cτ) · τ = t/T | c = ((1 − ⅓)/½ − 1)/⅓ | **c = 1** |

* φ(황금비)는 고른 수가 아니라 **세 매듭이 낸 답**이다. 코드는 SPLIT·TOP_FRAC 를 읽어 b 를 수치로 푼다(기하 이분 — 손잡이를 돌리면 곡선이 따라온다 · 하네스 ㉑ⓑ 가 닫힌 꼴 50/φ · 3 ln φ 와 1e-9 안에서 맞춘다).
* "하루 평균 50" — 총시간이 두 게임일(2,880초 = 1,440 × 2)이면 어느 꼴이든 한 바퀴 평균이 하루 50점이다(§1-ⓒ). 그러니 **k 를 정하는 둘째 조건은 매듭(⅓T 에 50)** 이고, 그 매듭은 이미 캐논이다("위 절반이 전체의 1/3 — 대사 고증 + 유예").
* 적분기 = **정확 해**(`decayStep`): 지수 (x + b)·e^(−k·dt) − b · 유리 x → τ → τ + dt/T → x. 오일러(지금 식)면 지수 꼴에서 1초 틱마다 총시간이 0.03% 짧아지고 틱 길이에 따라 답이 갈린다 — 정확 해는 1초 틱 · 60초 틱이 같은 게이지(32.699283 — 하네스 ㉑ⓑ4). 끝의 10⁻⁹ 붙임은 부동소수 찌꺼기(유리 꼴 갈증이 1,441초로 한 틱 길어지던 것 — 실측)를 0 에 붙이는 수치 틀이다.

### 2-ⓒ 유도 · 팔

* **방한 1점 = CLO_C × CLO_TOP ÷ (천장 − WARMTH_MIN) = 5.556 × 2.853 ÷ (62 − 10) = 0.3048℃**(끔 0.09 · 3.39배). 천장 62 = 옷의 `attrScale`(갖옷 × 장인 — `player-items` 정본을 읽는다) · `WARMTH_MIN` 10(헐거운 옷 문턱)은 그대로 · 젖음 곱도 그대로(하네스 ㉑ⓔ3).
* 가장 따뜻한 옷(62)의 ℃ = 2.853 clo × 5.556 = **+15.85℃**(끔 +4.68). 카드의 예 — 겨울밤 −4.2℃ 옷 50점: 끔 **0.868** → 켬 **0.647**(1단계 문턱 0.65 아래 · 하네스 ㉑ⓔ4 · 미끼: 모피를 1.13 clo 로 낮추면 0.831 로 뒤집힌다).
* `CLO_C`·`CLO_TOP` 는 env(`BODY_CLO_C`·`BODY_CLO_TOP`)로 갈 수 있다 — 재민이 파카만(1.62)·섬유 털(1.13)을 고르면 그 한 수만 간다.
