## 0. §0 실측 (셋)

### ⓐ `lamL`·`hmaxL` 이 어디서 오나 → `r` 이 미는 식

`_mt3Field` 의 높이식은 **가장자리 거리 `dE` 의 지수 포화**다. 바위 마스크에서 챔퍼 거리장을 만들고:

```
lamL  = MT3_LAM  · exp(MT3_LAMV · (2·vn(ai/26, aj/26, 53) − 1))     기하평균 = MT3_LAM  = 12셀
hmaxL = MT3_HMAX · (1 − MT3_HV/2 + MT3_HV · vn(ai/37, aj/37, 59))    평균     = MT3_HMAX = 35m
h     = hmaxL · (1 − exp(−dEff / lamL))   (+ 거시 fBm · 결 · 마루 결 — 전부 HMAX 비례)
```

⇒ 모양을 정하는 건 **둘뿐**이다: `lam`(경사 길이 · 셀) 과 `hmax`(마루 높이 · m).
**둥근 = 완사면** 이니 `lam` 은 늘리고 `hmax` 는 낮춘다. 배수는 **새 수가 아니라 재료표의 평균비**다:

| | 밑변(평균) | 키(평균) | 종횡비 h/r |
|---|---|---|---|
| 뾰족 40종 (`mt_G` 24 + `mt_F` 16) | **2.44** | **4.66** | 1.910 |
| 둥근 40종 (`mt_RG` 24 + `mt_RF` 16) | **3.13** | **3.35** | 1.070 |
| **비** | `MT3_RLAM` = 3.13/2.44 = **1.2828** | `MT3_RHMAX` = 3.35/4.66 = **0.7189** | 둥근이 0.560배 납작 |

★**두 판이 같은 모양 언어를 쓴다.** 스프라이트 판의 `mt_R*` 40장과 3D 판이 **같은 표**에서 나온다.
`test-icons` 가 `bake-mountain.py` 에서 이 두 수를 **다시 계산해** 클라 상수와 대조한다 —
재료표를 고치면 이 검사가 먼저 빨개진다(자가시험: `MT_RBR` 3.05→4.05 로 바꾸니 ✗ `1.2828 ≠ 1.5287`).

**미는 식** (네 줄):

```js
if (MT3_ROUND > 0) {
  const q = Math.pow(_mt3vn(ai / 26, aj / 26, 89), (1 - MT3_ROUND) / MT3_ROUND);
  lamL  *= 1 + q * (MT3_RLAM  - 1);      // q=1 이면 ×1.2828 — 사면이 눕는다
  hmaxL *= 1 + q * (MT3_RHMAX - 1);      // q=1 이면 ×0.7189 — 마루가 낮아진다
}
```

### ★★카드의 `_cellHash` 이진 문턱을 **못 썼다** — 두 가지 이유, 둘 다 수로 섰다

카드는 *"자리마다 둥근/뾰족은 `_cellHash`(T145 그대로)"* 라고 했다. 스프라이트 판에서는 맞다 —
산 하나가 제 실루엣을 가진 **따로 선 그림**이라 이웃이 뾰족이든 둥글든 상관없다.
**높이장은 이어진 면**이다. 재 보니 둘 다 걸린다:

**(1) 이진이면 경계에 수직 벽이 선다.** 같은 창에서 `h(r=1)` 과 `h(r=0)` 을 재면
셀당 차이가 **평균 8.47m · 최대 14.13m** 다. 둥근 셀과 뾰족 셀이 맞닿는 한 셀에서
그만큼 갈린다는 뜻이다 — 그 창의 **가장 가파른 사면이 3.54m/셀** 인데 그 4배다.
(이 코드베이스가 "말뚝 울타리"라 부르며 두 번 싸운 그 종류의 인공물이다.)

**(2) 이진 문턱은 비율을 조용히 바꾼다.** `_mt3vn` 은 해시 넷의 보간이라 **종 모양**이다
(5% 분위 0.136 · 균등이면 0.05). `vn < 0.8` 로 자르면 넓이의 **90.1%** 가 둥글어진다 —
§0-ⓒ 에서 유도한 0.8 이 화면에선 0.9 가 된다.

⇒ **부드러운 장** `q = vn^((1−r)/r)` 을 쓴다. 넓이 평균이 `r` 이 되는 사상이고(균등이면 정확히 `r`),
실측으로 `r=0.8` 에서 **0.8195**(오차 1.9%p · `r=0.5` 에선 정확)를 낸다. 척도는 새로 안 짓고
`lam` 변주와 **같은 26셀**을 쓴다 — 둥글기는 경사 길이의 성질이니 같은 척도가 맞다.
`r=0` 이면 이 블록이 통째로 안 돌아 **비트 동일**이다.
