## 1. ① 히스토그램 — `needPath` 가 참이 되는 이유

자는 T356 그대로다(관측자 규약 · 사본에만 박는다 · 한 판 안에서 센다).
낮 창 **7,200틱**(phase 0.10~0.28 · 인구 1,475 · 비취침 1,123):

| 첫 참 이유 | /틱 | 몫 |
|---|---:|---:|
| **`pathIndex >= path.length`(경로 끝)** | **723.2** | **98.5 %** |
| `_pathFor !== targetKey`(목표 바뀜) | 8.9 | 1.2 % |
| `now - _pathAt > 5000`(5초 만료) | 1.8 | 0.2 % |
| `!npc.path`(경로 없음) | 0.5 | 0.1 % |
| **합** | **734.3** | 주민의 **49.8 %** |

⚠T356 은 **899/틱(61 %)** 이라 했다 — 그 창은 **비취침 1,464**(전원)였고 이 창은 1,123 이다. 같은 현상이다.

### 1-ⓐ `computeNpcPath` 가 어느 갈래로 돌아왔나

| 갈래 | /틱 | 몫 |
|---|---:|---:|
| **`d < 48`(목표가 코앞)** | **723.6** | **98.3 %** |
| 직선이 깨끗(`straightPathClear`) | 10.3 | 1.4 % |
| **진짜 A\*(`pfFindPath`)** | **1.2** | **0.2 %** |
| 2초 쿨다운이라 `null` | 0.8 | 0.1 % |
| 도주/비주민 배회 | 0.0 | 0.0 % |

### 1-ⓑ 누가·얼마나 오래 묻나

| | 몫 |
|---|---:|
| 연속 **1틱**(한 번) | 4.9 % |
| 연속 2~10틱 | 22.3 % |
| **연속 >10틱(계속 묻는다)** | **72.9 %** |
| 그때 목표까지 거리 | 평균 **12px** · 48px 밖은 **1.7 %** |
| 그때 행동 | **`wander` 100 %** |

⇒ **그림이 하나로 모인다.** 배회 주민이 목표에 닿아 경로가 소진된다(`pathIndex >= length`) → `followNpcPath` 가
`arrived` 를 돌려주는데 **`wander` 에는 도착 행동이 없다** → `nextDecisionAt` 도 안 바뀐다 → 다음 틱에 또
`needPath` → `d<48` 이라 목표 한 점짜리 경로를 다시 만들고 → 또 도착. **다음 결정이 올 때까지 이 고리를 돈다.**

## 2. ★값 — 899 는 값이 아니었다

같은 창, 같은 판(시계는 `performance.now` · 자 값은 호출 수로 뺐다 · clock 41.5 ns):

| | ms/틱 | 몫 | 호출/틱 | 한 번 |
|---|---:|---:|---:|---:|
| `computeNpcPath` **전부** | **2.024** | 100 % | 734.3 | — |
| ↳ **`pfFindPath`(진짜 A\*)** | **1.840** | **90.9 %** | **1.2** | **1.55 ms** |
| ↳ `straightPathClear` | 0.051 | 2.5 % | 12.7 | 4.0 µs |
| ↳ 나머지(**734회의 `d<48` 되묻기** · 배열 만들기 · 스무딩) | **0.133** | **6.6 %** | 723.6 | 0.18 µs |

> **사람당 1.37 µs 중 1.24 µs 가 틱마다 1.2명의 A\* 다.** 899명이 만드는 것은 0.09 µs 다.
> T356 의 "A\* 19.3 %" 는 맞았고, **그 19.3 %의 주인은 899 가 아니라 1.2 였다.**

## 3. ② 고침 — 경로 끝에서는 다시 묻지 않는다

```js
const needPath = …종전 네 조건 그대로…;
// 네 조건 중 '경로 끝' **하나만** 참이면 안 묻는다 — 있는 5초 만료가 깨운다(새 수 0)
const _skip = T370_PATH_REUSE && needPath
              && npc.path && npc.pathIndex >= npc.path.length
              && npc._pathFor === targetKey
              && !(npc._pathAt && now - npc._pathAt > 5000);
if (needPath && !_skip) { … }
```

★**끔 = 비트 동일**: `_skip` 의 **첫 항이 손잡이**라 끄면 단락되어 불리언 읽기 하나다.
`test-move-soa ⑧` 이 **진리표 16칸**을 종전 식과 대조해 **0 다름**을 걸고, 손잡이를 `true` 로 비트는 미끼로
자명 통과를 막는다. 줄이는 칸이 **'경로 끝만 참'인 칸 하나**임과, **목표가 바뀌거나 5초가 지나면 켬도 묻는다**를 따로 건다.

### 3-ⓐ 켬/끔 (같은 자 · 같은 하루 · 조각 8개씩)

| | **끔**(phase 0.10~0.28 · 비취침 1,123) | **켬**(phase 0.32~0.50 · 비취침 1,464) |
|---|---:|---:|
| **묻는 수/틱** | **734.3** (49.8 %) | **20.7** (1.4 %) — **÷35.5** |
| 안 묻고 넘긴 수(`_skip`)/틱 | — | **874.8** |
| 첫 참 이유(경로 끝) | 98.5 % | 47.9 % |
| 연속 >10틱 | **72.9 %** | **0 %** |
| 그때 목표까지 거리 | 12px | **109px**(진짜 갈 데가 있는 사람만 남았다) |
| **나머지 갈래 ms/틱** | **0.133** | **0.029** |
| `pfFindPath` ms/틱 | 1.840 (1.2회) | 2.425 (1.3회) ← **비취침 30 % 많은 창** |
| 존 틱 p50(조각 8 평균) | 10.835 ms | 10.080 ms |

⇒ **떳떳이 셀 수 있는 것은 나머지 갈래 −0.104 ms/틱 = 사람당 −0.07 µs(8.22 의 0.9 %)** 다.
⚠두 창의 비취침이 다르다(1,123 ↔ 1,464) ⇒ `pfFindPath` 와 틱 p50 의 차는 **못 가른다**(T345 §3-ⓑ 그 함정).

### 3-ⓑ ★반례 — 경로를 덜 물으면 못 가는 사람이 생기나

| 자 | 끔 | 켬 | 읽기 |
|---|---:|---:|---|

| **깨어 있는 사람당** | **4.27e-4** | **3.95e-4** | **−7.5 %** — 나빠지지 않았다 |
| `followNpcPath` 도착률 | 50.4 % | 69.9 % | 경로를 안 새로 만드니 '도착' 판정이 그대로 유지된다(정의상) |

**실서버 200일**(`t212-beds` · T326 자 · 50마을):

| | 끔 | 켬 | Δ |
|---|---:|---:|---:|
| 인구 | 2,723 | 2,606 | **−4.3 %** |

⚠**−4.3 %가 손잡이 탓인지 판 편차인지 못 가른다.** T326 이 **같은 자**로 잰 끈 팔 둘이 **2,953 ↔ 2,676(9.4 %)**
벌어졌다 — 이 차는 그 편차보다 작다. ⇒ **켜지 않는다**(카드 §1). 켤지는 판 여럿을 돌린 뒤 재민 몫이다(회부).
