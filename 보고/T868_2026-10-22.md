## 1. 결함 — 코드

* 승격 갈래(`handleObserverMessage` · `promote_to_primary`)가 사람을 세우는 몸 리터럴: 인벤 · 도구 옛 맵(`pending.tools` — welcome 이 "옛 호환(사용 X)" 이라 적은 칸) · 장착 이름 · 허기 · 갈증 · vp · 부족 · 층 · 집, 그리고 `equipment: [], equipSlots: {}, craftSkill: {}`("promote 경로는 빈 초기화(존 핸드오프 캐리는 후속)") · `hp: PLAYER_MAX_HP`. 그 뒤 T732 줄이 로트만 페이로드에서 잇는다.
  - `toolItems` 는 아예 안 선다 → `serializeBody` 가 `[]` 로 적는다. 장비 · 슬롯 · 숙련 · 제작이력 · 원석장부 · 이월 · 어획 · kg 원장 · 소속 · 신체(추위 · 피로 · 부상 · 사기) · 부재 기준일은 빈다. HP 는 최대로 돌아간다.
  - 도착 존이 그 몸을 저장하면(닫힐 때 · 주기 · 행동) central 행의 몸 칸이 덮인다 → 다음 접속에도 없다(영구 소실).
* 토큰 경로(`_acceptConnection` — 핸드오프 토큰으로 새 소켓)는 T47 뒤로 `parseBody(페이로드 몸 · 없으면 central 행, { vitals })` 로 몸 전부를 잇는다 — 두 갈래의 복원이 두 벌이었다(T47 "직렬화가 한 함수다"의 빈자리).
* 실제 클라는 이웃 존 관측 소켓이 열려 있으면 늘 승격으로 넘는다(`30-n-net.js` "promote existing observer ws" · 관측 소켓은 경계 1,500px 안에서 이미 붙는다 — `e2e-zone-cross` ⓐ1) — 라이브의 보통 경로다.

## 2. ① 고침 — 손잡이 `T868_PROMOTE_BODY` · 몸 한 자리

```js
// 넘어온 몸 한 자리 — 출처 순서(T47) + 복원. 토큰 경로와 승격 경로(켬)가 같이 부른다.
function _handoffBody(pending, playerId) {
  const done = (raw, src) => ({ B: parseBody(raw || {}, { vitals: true }), src });
  if (pending.body) return done(pending.body, 'payload');          // 페이로드에 몸이 있으면 그 자리에서(동기)
  return central.getPlayer(playerId)                                // 없으면 central 행 — 그때만 Promise
    .then((row) => (row && row.tools_json) ? done(JSON.parse(row.tools_json), 'central행(폴백)') : done(null, 'payload'))

// 복원된 몸을 승격 갈래의 몸에 얹는다 — 일반 접속 몸 리터럴(`_load*` · `initVital` · `tools.__toolItems`)과 같은 칸 · 같은 기본값
function _t868BodyInto(p, B) { … toolItems · hotkey1 · equipped(몸 → 페이로드) · equipment · equipSlots · craftSkill · craftLog · oreLedger · oreCarry ·
                                 fishStats · kgLedger · lots · body(빈 칸 0 채움) · lastSeenDay · member · hp · maxHp · isDown · downedAt … }
```

* **토큰 경로**: 종전 몸 출처 다섯 줄을 `_handoffBody(pending, playerId)` 한 줄로 옮겼다. 차례는 그대로다 — 페이로드에 몸이 있으면 기다림 0 이고, 없을 때만 central 을 기다린다. 로그(`몸 출처 …`) · 출처 이름도 같다. 손잡이와 무관하게 이 길을 탄다(뜻 같음 — `test-handoff-body` A · B(행 폴백 픽스처) · C(T732 끔 = 늘 행 폴백) · e2e 가 잰다).
* **승격 갈래**: 종전 몸통을 닫개(`_t868Go`) 안으로만 옮겼다(줄 · 차례 · 들여쓰기 그대로).
  - 끔 = `_t868Go(null)` — 종전 그대로다.
  - 켬 = `_handoffBody(pending, pending.player_id)` 를 받고 같은 몸통을 돌며, T732 로트 줄 뒤에 `_t868BodyInto(player, B)` 한 줄을 탄다. welcome 은 몸통 그대로 `player.toolItems` · `equipment` · `craftSkill` · `self.hp` 를 실으므로 그대로 따라온다.
  - 페이로드에 몸이 없으면(T732 끔 · 몸 안 싣는 픽스처) central 행을 읽은 뒤 돈다. 그동안 그 소켓은 관측 그대로다(토큰 경로와 같은 순서).
* **픽스처**(`E2E_GIVE` 문 안 — 운영 도달 0): `__e2e_body` 가 장부 칸(숙련 · 제작이력 · 원석장부 · 이월 · 어획)도 세운다. 빈 칸끼리 같음은 자명 통과라, 두 갈래가 몸 **전부**를 잇는지 재려면 값이 있어야 한다(같은 픽스처가 소속을 세우는 T11 의 문법 · 정본 길은 각 하네스가 잰다).
