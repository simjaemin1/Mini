### ⓒ BVH 수입 — 있다. 그런데 **안 쓴다**

* `bpy 5.0.1` 에 `bpy.ops.import_anim.bvh` **있다**(확인함).
* 그래도 `mocap_retarget.py` 는 표준 라이브러리로 파싱한다(파서+FK 60줄). 이유: Blender 없이 돌아야
  *"두 번 돌려 바이트가 같은가"* 를 **3.5분짜리 씬 구축 없이** 물을 수 있다. 실측 0.56초.
* 대응표(CMU 31관절 → 12뼈): `root←Hips→Spine · spine←Spine→Neck · head←Neck1→Head ·
  thigh←UpLeg→Leg · shin←Leg→Foot · uarm←Arm→ForeArm · larm←ForeArm→Hand`.
  **버리는 19개**: L/RHipJoint · L/RToeBase · LowerBack · Spine1 · L/RShoulder · 손가락 여섯 · 엄지 둘.
  `handR` 도 **안 옮겼다**(휴식 유지) — 손목이 흔들리면 26px 에서 도끼가 떨린다.
* 회전 규약: BVH 는 `Zrotation Yrotation Xrotation`(나열 순서대로 곱한다) · 리그는 XYZ 라디안.
  **휴식 포즈 차는 빼지 않았다 — 필요가 없게 만들었다**(아래).
* 주기도 **골라 적지 않고 쟀다**(왼 넓적다리 시상각의 상승 영교차):
  walk 07_01 **129프레임 = 1.075초** · run 09_01 **87 = 0.725초** → 각각 8프레임으로 리샘플.
* 루프 이음새(첫↔끝 최대 |Δ각|) vs 프레임 사이 최대: walk **20.6° ≤ 47.2°** · run **39.4° ≤ 57.1°**.
  이음새가 보통 걸음보다 작으니 되돌아올 때 안 튄다.

### ⓓ idle — 사인 유지. 그리고 ★**사인 걸음이 옆으로 벌리고 있었다**

`idle`·`swing`·`aim` 은 CMU 에서 맞는 클립을 고르지 않았다 ⇒ 사인 그대로(회부).
그런데 걸음을 재다가 이게 나왔다 — **카드가 "시계추"라 한 것보다 나쁘다**:

```
  사인 걸음 u=0.25 의 넓적다리 월드 방향 = (0, ±0.513, −0.859)      ← 앞뒤(x) 성분이 **정확히 0**
```

`depsgraph` 로 리그의 로컬 오일러가 뼈를 어디로 눕히는지 직접 쟀다:

| | rx = +30° | ry = +30° | rz = +30° |
|---|---|---|---|
| 사지 뼈(휴식 = 아래) | (0, **+.577**, −.816) | 변화 0 | (**−.577**, 0, −.816) |
| 몸통 뼈(휴식 = 위) | (0, **−.577**, +.816) | 변화 0 | (**−.577**, 0, +.816) |

`.577/.816` 은 리그 z 압축(ZSQ .8165) 탓이고 되돌리면 **정확히 30°** 다.
캐릭터는 **+x 를 본다**(메타 `d=0 은 +x` · 어깨·엉덩이가 ±y · 오른손이 −y).
⇒ **`rx` 는 좌우(관상) · `rz` 는 앞뒤(시상)**. 사인 걸음은 다리를 `rx` 로만 흔들었다 —
**시계추가 아니라 가랑이를 좌우로 벌린 것**이다. 그림(대조표 ①)이 그대로 보여 준다.
`_pose_swing`·`_pose_aim` 도 같은 축을 쓴다 — **이 카드 밖이라 안 건드렸다(회부).**

## 1. 작업

**① 먹선·셀 — `scripts/ink_post.py`(신규 · 함수 둘)**

`edge_darken` 은 테두리 RGB 를 0.78 배로 **곱했으니** 화소마다 색이 달랐다 — 그건 그늘이지 선이 아니다.
`ink_outline` 은 같은 자리를 **한 먹색**으로 덮는다. 계약 둘(반투명 무접촉 · 1겹)과 합집합 마스크는
그대로 물려받았다. 순서는 **셀 먼저 · 먹선 나중**(반대면 먹선이 양자화에 끌려 흐려진다).

**먹색은 유도했다**(눈대중 금지): 몸 시트 실루엣 안 휘도 1% = 39.3 ⇒ 그 **절반** 19.7,
색비는 시트가 이미 가진 가장 어두운 테두리 색 (34,31,27) = 1:0.91:0.79 ⇒ **(21,19,17)**.
순검정이 아니다 — 검정은 화면에서 구멍이 된다.

되돌림은 스위치다: `T96_INK=0`(옛 `edge_darken` 경로) · `T96_CEL=0` · `T96_SINE=1`.
`render_common.py` **무접촉**(T97 세션8 · 하네스가 import 0 을 상시 검사).

**② 모캡 — `assets-src/mocap/` + `scripts/mocap_retarget.py` + `poses.json`**

★**회전을 옮기지 않았다 — 방향을 옮겼다.** BVH 관절 회전을 그대로 넣으면 휴식 포즈 차(BVH 는 T 포즈 ·
우리 팔은 아래)를 따로 빼야 하고, 틀리면 어디서 틀렸는지 안 보인다. 대신 BVH 를 **전방기구학으로 풀어
마디의 월드 방향**을 얻고 그 방향을 리그의 (rx, rz) 로 **정확히 역변환**한다(위 표에서 유도):

```
  사지: d = (−sinα·cosβ, sinβ, −cosα·cosβ)    α = atan2(−dx,−dz)  β = asin( dy)   rz = +α
  몸통: d = (−sinα·cosβ, −sinβ, +cosα·cosβ)   α = atan2( dx, dz)  β = asin(−dy)   rz = −α
  둘 다 rx = β · ry = 0.  부모 대비는 각 평면에서 뺀다(지금 포즈 함수와 같은 문법 · 평면 근사).
```

⇒ **휴식 포즈 차가 저절로 사라진다**(BVH 의 T 포즈든 뭐든 방향만 본다). BVH 축도 쟀다:
앞 = 루트 이동(Hips 가 +Z 로 63.5 · X 0.7 · Y 1.5) · 왼쪽 = T 포즈의 `LeftArm→LeftHand` 가 +X.

  shinL  rz 14.6  −0.0  17.6  64.8  51.7  16.4  32.4  20.4     ← 무릎 최대 굴곡이 넓적다리가
                                                                 수직을 지날 때다(교과서 유각기)

**③ 대조표** — `산그림/디자인B/캐릭터_먹선_모캡_전후.png`.

## 3. 회부

* ★★**`e2e-charsprite ⓓ` 는 결함을 규격으로 적고 있었다 — 부호를 뒤집었다(남의 하네스 접촉 · 선언).**
  종전 규칙: *"화면 가로로 걸으면 가장 **좁은** 축, 세로면 가장 **넓은** 축"*, 근거는 **어깨**.
  그런데 폭을 정하는 건 어깨(0.4m)가 아니라 **보폭**(1m)이고, 옛 걸음은 그 보폭을 **좌우**로 벌리고
  있었으니 관계가 정확히 90° 어긋나 있었다. 실측(같은 `body_walk` 행별 실루엣 폭):

  ```
    옛(사인)  [33, 42, 33, 12, 33, 42, 33, 12]     최대 행 1·5 · 최소 행 3·7  (행3 의 12 = 두 다리가 겹친 막대기)
    새(모캡)  [35, 29, 36, 40, 35, 29, 36, 40]     최대 행 3·7 · 최소 행 1·5
  ```

  최대·최소가 **정확히 두 행(90°)** 옮겨 갔다. **문턱·여유(0.34/0.15)는 안 건드렸다** — 느슨해진 게
  아니라 방향만 바꿨다. 카드가 *"빨강이면 그게 접점"* 이라 한 그 접점이다.
* ⚠**`--rawdump` 는 미리보기지 재유도 도구가 아니다.** raw 가 8bit 로 저장되므로 거기에 후처리를 다시
  걸어도 굽기 산물과 **바이트가 다르다**(실측 화소 14,255곳 · 최대 채널차 160 — 양자화 칸 경계가
  8bit 반올림에 옮겨 간다). 세기를 바꾸려면 **다시 구워야 한다**(1시간 27분). raw 에 후처리를 걸어
  바이트까지 같게 만들려면 raw 를 **float(EXR)** 로 남겨야 한다 — 다음 카드 몫.
* **★`swing`·`aim` 도 같은 축 문제를 안고 있다** — `_pose_swing` 은 `rx` 로 팔을 올렸다 내리므로
  도끼질이 **몸 옆에서** 일어난다. 걸음과 같은 결함이고 같은 방법(모캡 또는 축 교정)으로 닫힌다.
  이 카드 밖이라 한 글자도 안 건드렸다.
* `idle` — CMU 에 맞는 정지 클립을 안 골랐다(사인 유지 · §0-ⓓ).
* MakeHuman(MPFB) 몸 갈아 끼우기 — 다음 카드(리타깃 표가 섰으니 이제 잴 자가 있다).
* 자연물·소품 먹선 공용 편입(T97 뒤 · `render_common`) · 옷 재질 이중화 공용(T97 뒤).
* NPC 업기 모션(R2) · 16방향.
* **크레딧 표기** — CMU 는 표기 의무가 없고 감사 표기를 권한다. 게임에 크레딧 화면이 생기면
  `assets-src/mocap/README.md` 의 문단을 그대로 넣으면 된다.
