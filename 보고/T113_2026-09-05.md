# 보고 — T113: 알림이 겹치면 줄이 선다 (2026-09-05)

## 0. §0 실측 (셋)

### ⓐ 알림을 읽는 하네스 — **누가 무엇을 읽나** (이 표가 계약을 정했다)

| 읽는 통로 | 하네스 수 | 무엇을 기대하나 |
|---|---|---|
| `window.__notices` (글자 배열) | **28** | 최근 40건의 **글자**. 포함 검사(`some(/…/)`)가 거의 전부다 |
| `#notice` DOM `textContent`·`querySelector` | **1** | `e2e-verbs ⑫`(T90 · 내 것) — "한 종류를 띄우면 그 그림 하나" |
| 둘 다 | 0 | — |

`e2e-events`·`e2e-winter` 는 주석에만 `#notice` 가 있고 실제로는 `__notices` 를 읽는다(확인함).

⇒ **계약 결정**: `__notices` 는 **한 글자도 안 바꾼다**(글자만 · 40건 · ×n 도 아이콘도 안 들어간다).
`textContent` 는 지시서가 허락한 대로(*"`__notices` 를 읽는 것이 다수면 `textContent` 는 자유"*)
**보이는 줄들을 `\n` 로 이은 것**으로 정했다 — 한 줄만 떠 있으면 **종전과 한 글자도 같다**.
DOM 을 읽는 하나(`e2e-verbs ⑫`)는 이 카드가 같이 고쳤다(종류마다 비우고 재게 두 줄 — 안 그러면
쌓인 줄의 **첫** 아이콘을 읽어 아홉이 다 같은 그림으로 보인다).

### ⓑ N 의 출처 — 캔버스를 **화소로 재서** 유도했다

설계 `설계_화면규칙_B_먹선.md` 에는 알림 자리의 높이·줄 수가 **안 적혀 있다**(§4 는 "촌장 한 줄은
상단(레일 오른쪽)에 · 뜨고 사라지는 규약은 현행" 뿐). ⇒ 지시서의 갈래대로 **HUD 그림에서 쟀다**:

| 잰 것 (`산그림/디자인B/디자인B_HUD.jpg` · 1440×900) | 값 |
|---|---|
| 알림 판 세로 | y 17 → 66 = **50px** |
| 글줄 피치(1행 머리 → 2행 머리) | 28 → 45 = **17px** |
| 위·아래 패딩 | 17→28 · 55→66 = **11px** |
| 그 안에 든 글줄 | **2줄**(11 + 17 + 11 + 11 = 50) |
| 판 가로 | x 539 → 1119 = 581px (**상단 가운데**) |

캔버스는 **스택을 안 그렸다**(한 메시지가 두 줄로 접힌 그림이다). 설계 §3 의 간격 눈금은 4·8·12·16 —
슬롯을 눈금 한 칸(16) 키우면 66~67px 이고 그게 정확히 **세 줄**이다(17×3 + 16).
⇒ **N = 3.** 새 수는 이 하나뿐이고, `style.css` 의 `line-height: 17px` 도 같은 자에서 왔다.
**실측 대조**: 세 줄이 뜬 실화면의 `#notice` 높이가 **65px** 이다(패딩 12 + 51 + 테 2) — 유도와 맞는다.
캔버스 갱신 제안(자리·슬롯 3줄)은 회부에 적었다.

### ⓒ 알림 빈도 — ×n 이 뜻이 있나

`e2e-ui` 한 판을 하네스가 250ms 로 폴링해서 쟀다(**제품에 진단 훅 0** · T57 — 이미 있는 `__notices` 를 센다).

```
  표본 568회 · 초당 최대 3건 · 연속 같은 말 2/11 (18%)
```
⇒ 초당 최대 3건이면 **N=3 이 한 판을 다 담는다.** 연속 같은 말이 18% 면 ×n 은 실제로 하는 일이 있다.

## 1. 한 일 — 클라 두 파일

`showNotice(text, ms, kind)` 는 **서명이 그대로다**(부르는 쪽 무접촉). 안쪽만 줄 배열이 됐다.

```
_ntLines [{text, kind, n, until}]   뒤가 최근 · NOTICE_MAX(3) 넘으면 앞(오래된 것)이 밀려 사라진다
같은 말 연속 → 마지막 줄 하나만 비교해 n += 1 → 화면엔 `말 ×3`
   ⚠맨 앞까지 뒤지면 "가 나 가" 가 `가 ×2 · 나` 로 뭉쳐 **온 차례가 거짓말**이 된다(그래서 마지막 줄만)
타이머 **하나** — 제일 먼저 죽을 줄에 맞춰 깨고, 죽은 줄을 걷고, 다시 잰다(줄마다 타이머를 달지 않는다)
줄 사이는 `\n` **텍스트 마디** 하나 — `#notice` 가 이미 `white-space: pre-line` 이라 그게 곧 줄바꿈이다
```

**새 패널 0 · 새 노드 0 · 새 CSS 클래스 0 · 이모지 0 · 서버 diff 0 · `NOTICE_ICO` 표 무접촉**(T110 대비).
`style.css` 는 `#notice` 에 `line-height: 17px` 한 줄(캔버스 값)만 더했다.
