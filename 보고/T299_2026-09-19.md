## 1 · 손잡이 자리 하나 — T244 문법 그대로

```js
function _cargoKnob(name) {                       // 랩 window → node env (··· `_allocKnob` 과 같은 꼴)
  const g = (typeof window !== 'undefined') ? window : null;
  if (g && g[name] !== undefined && g[name] !== null) return String(g[name]);
  if (typeof process !== 'undefined' && process.env && process.env[name] !== undefined) return String(process.env[name]);
  return null;
}
function cargoTwoOn(world) {
  if (world && world.cargoTwo !== undefined && world.cargoTwo !== null) return !!world.cargoTwo;   // 주입이 가장 세다
  const x = _cargoKnob('L_CARGO_TWO'); return x === null ? true : x !== '0';                       // 미설정 = 켬
}
function cargoTwoGateOn(world) { /* 같은 꼴 · L_CARGO_TWO_GATE */ }
```

* 문 두 자리: 출발 블록 `if (cargoTwoOn(world)) {` · 관문 `if (_c2gate && !(_pu2 * _q > 0))`.
  관문은 **leg 마다 한 번** 읽는다(`const _c2gate = cargoTwoGateOn(world);` 를 후보 루프 **밖**에 뒀다) — 값이 같으므로 비트는 그대로고 루프 안에서 env 를 읽지 않는다.
* `world.cargoTwo` 주입이 손잡이보다 **세다**. `false` 주입도 존중한다(`undefined` 검사지 진리값 검사가 아니다) — **A/B·계측기의 끔 팔이 거기 산다.**
* 랩(`lab/전쟁실험실.html`)은 이 손잡이 둘을 **안 심는다**(미설정 = 켬 = 서버 기본 · T244 가 `L_ALLOC_REAL` 에 쓴 그 문법). 주입 훅 둘(`cargoTwoInstallHook`·`cargoTwoGateInstallHook`)을 지웠다 — 끄는 길은 `window.L_CARGO_TWO=0` 하나다.
* ⚠**기본이 뒤집히면 픽스처가 거짓말을 한다**(T244 가 배운 것). 그래서 계측기 전수를 **명시 팔**로 고쳤다:
  `t17-metrics`(옛 이름 `T206_CARGO_TWO`·`T233_CARGO_GATE` 는 `=0` 도 받는 **덮어쓰기**로) · `t231-second-anatomy` ·
  `t215-cargo-who` · `t223-sparecap-ab` · `cargo-diag` · `t280-fish-gate`(닻도 `_c2gate` 로 옮겼다 — 안 옮기면 그 계측기가 `exit 3` 이다) ·
  랩 A/B 넷(`t215-lab-who`·`t223-lab-sparecap-ab`·`t233-lab-gate-ab`·`lab-stone-trade-ab`)의 `attached` 자기검사는
  "주입됐나" 가 아니라 **`EconEngine.cargoTwoOn()` 에게 묻는다**(주입이 없어도 켠 판이다).
