## §0-ⓐ 정규화 — 고친 자리는 **한 곳**

```js
/** 화소 해시의 알맹이 — 경로가 아니라 **화소**를 받는다(하네스가 파일 없이 반례를 먹일 수 있게). */
function pixelHashOf(width, height, data) {
  const px = Buffer.from(data);                    // 원본 버퍼를 안 고친다
  for (let i = 0; i < px.length; i += 4)
    if (px[i + 3] === 0) { px[i] = 0; px[i + 1] = 0; px[i + 2] = 0; }
  return sha1(Buffer.concat([Buffer.from(`${width}x${height}|`), px])).slice(0, CUT);
}
const pixelHash = (p) => { const im = decodeImage(p); return pixelHashOf(im.width, im.height, im.data); };
```

* **PNG·webp 가 같은 함수**를 쓴다(사본 0 · `decodeImage` 만 확장자로 갈린다).
* ⚠**반투명(`0 < a < 255`)은 안 만진다 — 그건 보인다.** 건드리는 것은 `a === 0` 하나뿐이고, 그 자리를 **반례 ⓑ** 가 지킨다.
* 경로 대신 화소를 받는 꼴로 쪼갠 이유: 반례 하네스가 **파일을 굽지 않고** 버퍼를 먹일 수 있다(픽스처 0).
