|---|---|---|

⚠SSH 금지 캐논이 있으니 서버 안으로 들어가 읽는 길도 없다. **회부: 주소 정본 자리가 없다**(N-배포뒤 빈칸 옆).

### ① #2 `/check_username` — 무엇이 회부돼 있나 (읽은 그대로)

`server/central.js:963` — `POST /check_username { username } → { taken: bool }`. 문 없이 열려 있고,
`findAccount` 하나만 읽는다(**쓰기 0**). 회부 #2 의 내용은 *"이름이 등록돼 있는지를 바깥 누구나 셀 수 있다"* 다.
실서버 기대: **셋 다 200** · 있는 이름 `true` · 없는 이름·빈 값 `false`. 그러면 09-18 배포본이 종전 그대로라는 뜻이고,
바뀌었으면 그때 #2 를 다시 연다.

### ② #9 `?as=` — **카드 전제 정정**

카드는 *"T245 가 닫은 문이 실서버에서도 닫혔나 — 401/403 한 줄"* 이라 했다. 라우트 정본이 아니라고 답한다:

```
zone GET ^/startinfo  =>  [ '공개', '회부9' ]     ← scripts/lib-routes.js
```

T245 는 이 문을 **안 닫았다**. `server/onboarding.js:906 httpStartInfo` 가 `?as=<이름>` 을 받아
`friendVidsByName`·`memberVidByName` 을 태워 준다 — **열쇠 없이 이름만으로** 남의 벗 마을·소속 마을이 읽힌다.
그게 회부 #9 이고, 아직 **재민 칸**이다(*"게스트 토큰으로 물으면 안 된다 — 그건 열쇠다"* 라고 그 주석이 이미 적어 뒀다:
열려 있는 건 실수가 아니라 **아직 안 정한 것**이다). ⇒ 검사는 **401/403 이 아니라 "as 로 더 나오나"** 다.

### ③ 62 라우트 — GET 갈래 **32**(디스패처 1 제외 ⇒ **31 침**) · 그 밖 **30**(안 친다)

| 갈래 | 수 | 이 스크립트가 치나 | 바깥 기대 |

⚠계측기 한계 둘(문 결함이 아니다): ⓐ `^/routedbg`·`^/bodydbg` 는 **안에서도 404**다 — 인자 없는 prefix 라
그렇고, `denyOutside` 의 404(몸통 있음)와 **몸통으로 갈린다**(T290 이 배운 그 자리 — 스크립트도 몸통으로 판정한다).
ⓑ `dispatcher GET =/health/zones` 는 **다른 호스트**라 안 친다.

### ④ `/perf` — **바깥에선 못 읽는다**(카드 전제 정정)

`zone GET ^/perf` 는 라우트 정본에서 **`안문`** 이다(T225 가 닫았다 · 관측창 열두 문 묶음).
⇒ 카드의 *"`docker exec` 한 줄 대신 HTTP 로 읽히면 그것"* 의 답은 **안 읽힌다**이고, 그게 **옳다**.
바깥에서 읽히는 존 지표는 `/health` 하나다(로컬 실측 그대로):

```json
{"zone":"hanbando","players":0,"humans":0,"cap":150,"observers":0,
 "resources":0,"buildings":3,"mobs":449,"claims":0,"latency_ms":0,"uptime":47.4}
```

| 카드가 원한 값 | `/health` 에 있나 |
|---|---|
| **관측자 수** | ✅ `observers` |
| 존 틱 p50 | ✗ — `latency_ms` 는 **한 수**(p50 아님). p50 은 `/perf` 안에만 있다 |
| **마을 수** | ✗ — `/health` 에 칸이 없다(`buildings`·`mobs` 뿐) |

⇒ **회부**: 틱 p50·마을 수를 바깥에서 보려면 ⓐ `/health` 에 칸 둘을 더하거나(투영 규약대로 **수만**) ⓑ `/perf` 를
`CENTRAL_SECRET` 뒤에 두거나 ⓒ 종전대로 `docker exec` — **셋 다 제품 변경이라 재민 칸**이다.
