## 1. 한 일 — 틱 한 자리

```js
const _elapsed = (now - lastTick) / 1000;
const _want    = TICK_DEBT_ON ? (_elapsed + _tickDebt) : _elapsed;
const dt       = Math.min(DT_MAX, _want);            // ★상한은 그대로 0.2
const _left    = _want - dt;
_tickDebt = Math.min(TICK_DEBT_MAX, _left);          // 남은 몫은 다음 틱으로
if (_left > TICK_DEBT_MAX) perfMark('tick_debt_drop', …);   // 넘치면 버리고 **로그**
```

* **새 수는 상한 하나**(`TICK_DEBT_MAX = 31초` · 위 유도) · 출처는 Gaffer, *Fix Your Timestep!*.
* **되돌림** `T153_DEBT=0` → 종전과 **비트 동일**(계측 줄만 남는다 — 관측자).
* **계측**(`/perf.tick`): `wall`·`sim`·`clip`·`clipped`·`maxGap`·`debt`·`dropN`·`dropped`·`lagPct`.
  손잡이가 아니라 **관측자**다 — 하네스가 "빚이 몇 %냐"를 소스가 아니라 **세계에** 묻는다.
* `moveDt` **무접촉** · 하루 경계(`SimVillages.onGameTick(now)`) **무접촉** · `villages.js` 무접촉.
