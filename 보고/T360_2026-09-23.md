## §0-ⓑ 고개 — 표만(놓지 않았다)

**`passes`·`valleys` 가 지형에서 읽히는 법**(`terrain.js:283 isRockCellLocal`): 순서가 정해져 있다 —

```
바위인가? = ridges 안에 있다  AND  passes(원) 밖  AND  valleys(선형 통로) 밖  AND  물이 아니다
```
· `pass` = `{name, pos:[x,y], radius}` — **원**. 능선을 낮춰 넘는 자리.
· `valley` = `{name, path:[{pos,width}…]}` — **강과 같은 꼴의 선형 통로**(11차 재민 확정: 반지름 50셀
  원이 산을 통째로 지우지 않게). 한반도는 이 꼴만 쓴다(`passes` 0 · `valleys` 24).

| | 닛폰 | 한반도 |
|---|---|---|
| `passes` | **2** — 쇠재 `[-216,40000]` r1850 · 한재 `[-216,60000]` r1850 | 0 |
| `valleys` | 0 | **24** |

★**닛폰의 두 고개는 이 장벽과 무관하다** — 둘 다 `x = -216`(서쪽 끝 · 셀 −7)이고 y 셀 1250·1875인데,
바위 갈래의 최단 자리는 **y 셀 185~224**다. 그 둘이 여는 것은 다른 구간이다.

**후보 자리 표**(놓는다면):
