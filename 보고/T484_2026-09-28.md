## 0. 풀어 쓴 답

재민의 네 물음에 하나씩 답한다.

* **연속인가** — 이제 그렇다. 전에는 하루를 "낮 값 하나 · 밤 값 하나"로 보고 해가 지는 순간(phase 0.7) 일교차 두 배만큼 **한 번에** 떨어졌다. 날이 바뀌는 순간에도 한 날 치가 뛰었다. 지금은 econ 이 원래 갖고 있던 시각 곡선(자정 최저 · 정오 최고의 코사인)을 그대로 쓴다. 저녁 HUD 가 1초에 8~12℃ 뛰던 것이 없어졌다.
* **평균이 매일 다른가 · 초겨울과 한겨울이 다른가** — 원래 그렇다(연주기 코사인 + 날마다 다른 편차 ±5℃). 날이 소수까지 흐르니 이제 자정에도 계단이 없다.
* **고증 함수인가** — 전에는 손으로 고른 사인파(연평균 12 · 진폭 12 · 일교차 5)였다. 이제 존마다 **기상청·중국기상국·일본기상청 30년 평년값**에서 유도한다. 한반도는 송국리가 있는 **부여** 관측소다. 한반도 값을 바꾸면 마을 경제가 움직이므로 켜기는 재민 몫으로 남겼다.
* **위도도 고려하나** — 존마다 관측소가 다르니 위도·해양성이 값에 들어온다. 베이징은 대륙성이라 진폭이 크고(15.0) 나라는 해양성이라 작고 따뜻하다(11.3 · 15.2).
* **청동기 온난습윤** — 논문 여섯 편을 읽었다.
  * 송국리 시기(3,000~2,500년 전)는 홀로세 따뜻한 시기(6,500~4,000년 전)가 끝나고 **식어 가던 때**다. 2,800년 전 무렵엔 건조·냉각 사건이 있었다(한반도 자료 둘).
  * 다만 우리가 쓰는 평년값(1991~2020)에 이미 산업화 뒤 온난화 +1℃ 가 들어 있다. 그래서 청동기는 **산업화 전보다는 따뜻했지만(+0.46℃) 오늘 평년보다는 조금 춥다(−0.54 ~ −0.20℃)**.
  * "습윤"은 자료가 둘로 갈린다 — 광양 화분은 −6 ~ +5 % 이고, 한반도 서해안은 2,600년 전부터 건조했다.
  * 권고는 −0.37℃ · 강수일 −0.7 % 이고 켜는 것은 재민이다.

## 1. ⓐ 연속 시각

```js
// server/weather.js — 정본
const PH = { noon: dayPhaseRatio / 2, midnight: (1 + dayPhaseRatio) / 2 };            // 0.35 · 0.85
function hourFracOf(phase) { f = (phase − PH.midnight) mod 1 }                          // 0 = 자정 · 0.5 = 정오
function tempAtT(t, elevKm, phase) {                                                   // t = 분수 게임일
  mean = E.temperatureAt(t, null, el)
  return mean + devCOf(t) + (E.temperatureAt(t, hourFracOf(phase), el) − mean) * ampMultOf(t)
}
```
