## 회부(한 줄씩 · 고치지 않음)

1. `T1393_HUNT_CHASE`는 `T1331_BEAST_BODY`(짐승 몸) 위에서만 선다(`server/villages.js` `_t1393On`). 서버 기준선 판 자는 짐승 몸이 꺼져 있어 400/400이 나온다. 켤지 판정에는 몸 판 자로 잰 표가 필요하다.
   - 재현: `T1393_HUNT_CHASE=1 node scripts/server-baseline-check.js --make /tmp/h.json --days 400 --seeds 7 --par 1 --vclock` → 끔과 400/400
2. `T1392_FIRST_LOT`는 손님 집터(`zone.js claimCost` · `firstLot`)에만 닿는다. 손님 0 판 자로는 못 잰다. 봇 · e2e 판이 맞는 자다.
   - 재현: `T1392_FIRST_LOT=1 node scripts/server-baseline-check.js --make /tmp/f.json --days 400 --seeds 7 --par 1 --vclock` → 400/400
3. 청동 둘 켬:
   - 청동 근접무기 누계가 100날 뒤로 거의 멎는다. 1020은 19.58이 400날까지 그대로이고, 끔은 12.2 → 17.4로 는다.
   - 400날 빈 마을이 1020에서 2, 7에서 1 생긴다(끔 0).
   - 42는 끔비 0.940에 떠난 사람이 1094다(끔 749).
   - 볼 일이다. 재현: `T1385_BRONZE_NOCAP=1 T1398_BRONZE_BAND=1 T1417_OBS=/tmp/o T1417_ARM=b NODE_OPTIONS="--require 계측/T1417_2026-11-21/t1417-observe.js" node scripts/server-baseline-check.js --make /tmp/b.json --days 400 --seeds 1020 --par 1 --vclock`
4. 카드가 든 `T1380_SPARE_EXPAND`가 main 코드에 없다(족보에만 이름). 다른 이름으로 들어왔는지, 아직 안 들어왔는지 볼 일이다.
