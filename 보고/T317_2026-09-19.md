## §0ⓐ 무엇을 고쳤나 — 자리 둘

### ① 켤 때 이웃까지 (`zone.js activateChunk`)

```js
+ const _overflow = overflowInto(ZONE_ID, ZONE.biome, cx, cy, chunkManager.chunkSize, harvestedSeeds, gameDayNow());
  const spawned = [];
- for (const r of seedResources) {
+ for (const r of seedResources.concat(_overflow)) {
+   if (resources.has(r.id)) continue;             // 이미 선 개체(이웃이 먼저 켜졌다) — 두 번 안 놓는다
    if (isTerrainBlockedLocal(r.x, r.y)) continue;
```

`chunk.js overflowInto(zoneId, biome, cx, cy, …)` = **이웃이 이 청크에 낳은 개체**.
넘침은 **서·북에서만** 온다 — 격자점 x 는 `cx*cs + gx + j1*SP`(gx ≥ 0 · j1 ≥ 0)라 `cx*cs` 보다 작아질 수 없다
(T309 실측도 서 0 · 북 0). 그래서 이웃 **셋**만 묻는다.
자원은 여전히 `generateChunkResources` 만 낳는다 — 이 함수는 **거르기만** 한다(사본 0).

### ② 제거는 낳은 청크 기준 (`zone.js deactivateChunk`)

종전은 **바구니 기준**이라 청크 (1,0) 이 꺼질 때 청크 (0,0) 이 낳은 나무까지 지웠다 — (0,0) 은 켜져 있는데.
새 규칙: **낳은 청크와 든 청크 중 하나라도 켜져 있으면 남는다.** 그래서 이 청크가 꺼질 때 지울 것은 둘이다.

| 무리 | 무엇 | 조건 |
|---|---|---|
| ⓐ | 이 청크 바구니에 든 것 | **낳은 청크가 꺼져** 있으면 지운다 |
| ⓑ | 이 청크가 낳았는데 **이웃 바구니**에 든 것(동·남·동남) | 그 이웃이 꺼져 있으면 지운다 |

낳은 청크는 `chunk.seedGenChunkOf(seedKey, x, y, chunkSize)` 가 답한다 —
씨앗 키의 꼴(`${cx}_${cy}_${n}` · `_met` · `_ft<gx>_<gy>` · 군락 `gv<gi>_<i>`)은 `chunk.js` 가 정하므로
**푸는 것도 `chunk.js` 가 한다**(부르는 쪽이 문자열을 쪼개면 그게 사본이고, 꼴이 바뀌면 조용히 어긋난다).

⚠**꺼진 뒤의 집합을 넘긴다.** `deactivateChunk(cx, cy, newActive)` — 호출 시점의 `activeChunkKeys` 는 아직
**옛 집합**이라, 같은 판에 같이 꺼지는 이웃이 "켜져 있다"로 보이고 그러면 넘친 나무를 **아무도 안 지워 샌다**.
