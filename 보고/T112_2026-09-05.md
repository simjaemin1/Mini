## 2. 술어 하나 · 갱신 한 곳

```js
// crops.js — 하늘은 weather 가 정본이다(사본 0). 강도 문턱 없음 = 새 수 0.
function rainedOn(day) {
  if (!RAIN_WATER) return false;
  const W = _weather(); if (!W) return false;          // 하늘이 없는 자리 → 비 없음(거짓말 안 한다)
  let p = 0; try { p = +W.precipAt(_day(day)) || 0; } catch (e) { p = 0; }
  return p > 0;
}
// villages.js — 갱신은 이 한 줄뿐. 상태기 셋이 각자 입구에서 부른다(멱등).
function _cropSky(e, day) { const C = _Crops(); if (e && C && !C.dormantAt(e.c, day) && C.rainedOn(day)) e.w = day; }
```

* **`e.w` 하나만** 만진다 — 그 자리 물 공급(`supply`)은 안 건드린다.
  비는 *"오늘 물을 댔다"* 이지 *"그 자리에 물이 있다"* 가 아니다(논 물길은 회부 E 그대로).
* **zone.js 무접촉** — 플레이어 밭은 상태기 셋만 부르므로(T58b 구조) 자동으로 같은 하늘을 본다.
* **맞물림 안전** — `weather.js` 는 달을 물으려고 `crops.js` 를 부른다. 양쪽 다 lazy 라 로드 시점엔 안 문다.

### ⚠첫 판이 T99 의 약속을 깼다 — 하네스가 잡았다

`_cropSky` 에 **휴면 갈래를 빼먹었다.** 겨울 비가 `e.w` 를 옮겨서 T99 가 세운
*"겨울이 끝난 자리가 겨울 들어간 자리와 같다"* 가 깨졌고, `test-crops ⑫ⓓ` 가 빨개졌다.
⇒ `!C.dormantAt(e.c, day)` 를 넣었다. **휴면은 성장·돌봄·품질을 다 멈추는 것이고, 물때도 그 안에 있다** —
겨울 밭은 물을 안 기다린다. (그 한 줄 때문에 물대기 일감이 5,576 → 6,072 로 올랐다 — 겨울을 난 밭이
봄에 한 번 물을 기다린다. 그게 맞다.)
