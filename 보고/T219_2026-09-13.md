## ⓐ 두 방아쇠 — 인용과 갈림

**서버**(종전 · `server/villages.js:5359–5360`, 이식 뒤 끔 경로):
```js
const cap = vil._houseCells.length * (_lifeVL().HOUSE_CAP || 6);
if (!vil._site && vil.econ.npcs.length > cap * 0.92) { _lifeAddHouseSite(vil); }
```

**랩**(`lab/전쟁실험실.html:11631` 위 블록 · `lab/마을실험실.html` 동문):
```js
const targetFloors = Math.ceil(Math.max(s.pop, (s.econ && s.econ.housing) || 0) / L_FLOORCAP);
/*★econ 수용력(목재 선지불, pop×1.15 버퍼) 추적 — pop 기준이면 '침대가 차야 인구↑, 인구가 늘어야 집터↑'의 데드락*/
let builtFl = 0, sites = 0;
for (const h of s.houses) { if (h.player) continue; builtFl += (h.builtFloors || 0); if ((h.builtFloors || 0) < (h.floors || 1)) sites++; }
if (builtFl + sites < targetFloors && sites < Math.max(2, Math.round(s.pop / 25))) addHouseSite(s);
```

| | 서버(종전) | 랩(정본) |
|---|---|---|
| 무엇을 보나 | **인구만** | **`max(pop, econ.housing)`** |
| 판정 모양 | **비율** — `pop > 침상 × 0.92` | **부족분** — `완공층 + 공사중 < 목표층` |
| 목표 | (없음) | `ceil(max(pop, housing) / HOUSE_CAP_PER_FLOOR)` |
| 동시 집터 | **하나**(`!vil._site`) | `sites < max(2, round(pop/25))` |
| 그 수의 출처 | `0.92` — 랩에 **없다 · 서버 고유** | `2`·`25` — 랩 정본 |
| 데드락 | 인구만 보므로 원리상 있다 | 주석에 명기하고 `max` 로 피한다 |

**★두 식은 좁은 띠에서만 갈린다.** `pop ≳ housing` 이면 랩 목표 ≈ `pop/6`, 종전 문턱 ≈ `pop/5.52` ⇒ **랩이 더 엄격**.
`housing > pop` 일 때만 랩이 더 넓다(econ 이 목재를 선지불한 그 여유분).

### 원인 가름 — 방아쇠인가 필터인가: **필터(기하)다**

| 잣대(실서버 200일 · 50마을 · 끔) | 값 | 뜻 |
|---|---|---|
| 집터 탐색 호출 / 성공 / **빈손** | 931 / 136 / **795** | 빈손 = 영토를 2패스 전수 훑고 **합법 셀이 하나도 없었다** |
| 싼 예비필터를 통과한 후보 | 114,078 | 그중 `reject()` 가 **113,942(99.88%)** 를 물렸다(성공 136) |
| 거부 사유 1위 | **기존 집과 너무 가까움(<18) 77.9%** | 집 하나가 반경 18 원판(≈1,018셀)을 닫는다 |
| 2·3위 | 쉼터 이격 12.1% · 영토 밖 7.0% | |
| 영토 성장 | **63셀 / 26일 / 50마을**(T212 판 93셀) | 땅이 열리지 않는다 |
| 공사 속도 | 움집 하나 **2일**(4단계 ÷ 하루 2단계 · `:4127`) | 슬롯 하나로 200일에 100채 가능 — 실제 **2.8채** |

⇒ **집터를 여럿 열 이유가 없다.** 그래서 랩의 동시 상한 `sites < max(2, round(pop/25))` 은

## ⓑ 이식 — 한 자리 + 정본 하나

**규칙의 집은 `server/village-layout.js`** 다(`HOUSE_CAP_PER_FLOOR` 가 사는 그 모듈 · 랩 인라인 사본의 원본):
```js
const houseSiteWant = (pop, housing, builtFloors, sites) => {
  const P = …, H = …, B = …, S = …;
  const target = Math.ceil(Math.max(P, H) / HOUSE_CAP_PER_FLOOR);
  return (B + S) < target && S < Math.max(2, Math.round(P / 25));
};
```

**`server/villages.js` 는 한 자리**(`:5364` 근처) — 규칙을 다시 적지 않는다:
```js
const _wantSite = T219_HOUSE_TRIGGER
  ? _lifeVL().houseSiteWant(vil.econ.npcs.length, vil.econ.housing, vil._houseCells.length, vil._site ? 1 : 0)
  : (vil.econ.npcs.length > cap * 0.92);
if (!vil._site && _wantSite) { … _lifeAddHouseSite(vil) … }
```
서버 움집은 단층이라 **완공 층수 = `_houseCells.length`**(레이아웃 `MAX_FLOORS=1` · T212 실측 50마을 전부 층합=채수).
`_houseCells` 는 이미 의뢰 집(`phouse`)과 쉼터(`shelter`)를 빼고 센다(`:4836`·`:4282`) — 랩의 `if (h.player) continue` 와 같은 뜻.
