## §0ⓑ 카드가 지정한 두 자리만으로는 **켠 팔이 한 번도 안 움직인다**

카드 ②는 `:4007` 이 "그 농부의 `_t172mul`"을 넘기라 했다. 그런데 수확 갈래의 `npc` 는 **없을 때가 있다**:

| 갈래 | `npc` | 언제 |
|---|---|---|
| 실걸음 | **있다** | 관측자 있는 마을 — 농부가 셀에 도착해 처리(`villages.js:5446`) |
| 헤드리스 결산 | **없다**(`null`) | 관측자 없는 마을 — `lifeFarmDay(vil, day, farmerN)` → `_lifeDoTask(vil, null, k, day)` |

★그리고 **이 카드가 ③에서 쓰라는 자(`t176-ab`)는 전부 헤드리스 갈래다.** 측정기가 세우는 마을은
`__labProbe._cropProbe.attach` 가 만드는데 거기엔 **`npcPids` 자체가 없고**, `_lifeEconLink` 는
`npcPids` 가 없으면 첫 줄에서 돌아선다 ⇒ `_esk` 는 거기서 **절대 안 선다**(하네스 ⑮ 가 둘 다 박았다).
⇒ 링크만 놓고 `npc._esk` 만 보면 켠 팔은 배율을 **한 번도 안 쓰고**, ③ 표는 T183 "후"와 한 자도 안 달라진다.
같은 마을이 **관측자가 있느냐로 다른 식량**을 내는 것도 그 길이다.

⇒ 그래서 배율을 집는 자리를 하나 두고, **두 갈래를 같은 규칙으로** 집게 했다 — `_lifeEconLink` 의
그 라운드로빈이고, 지표는 이미 있는 수확 누계(`econ._t100HarvestN`)다. **새 수 0 · 새 규약 0.**

```js
function _farmMul(vil, npc) {
  let e = (npc && npc._esk) ? npc._esk : null;                    // 실걸음 — 링크가 이긴다
  if (!e) {                                                       // 헤드리스 — 같은 라운드로빈
    const ec = vil && vil.econ;
    const ns = (ec && ec.npcs) ? ec.npcs.filter((n) => n.currentJob === 'farmer') : [];
    if (ns.length) e = ns[(ec._t100HarvestN || 0) % ns.length];
  }
  return (e && typeof e._t172mul === 'number') ? e._t172mul : undefined;   // 1 로 받는 것은 econ 문 한 곳
}
```
그리고 호출부는 한 줄이다: `harvestToGranary(vil.econ, 1, _farmMul(vil, npc))` — **생활층에 산수 0**.

★**이 세 번째 자리가 카드의 글자를 넘는 유일한 곳이다**(재민 거부권). 떼면 위 표대로 ③이 무의미해진다.
손잡이를 끄면 `_t172mul` 이 아예 안 심겨 `undefined` 가 나가므로 **끔은 그대로 종전이다**(§1 실측).
