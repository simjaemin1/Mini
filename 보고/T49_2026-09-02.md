카드가 지목한 셋이다. 처방은 족보 ⑻⓪(waterperf 판): **같은 실행 안에서 같은 조건을 두 번**
재서 잡음 바닥을 먼저 얻고, 효과비를 그 잡음비로 나눈다. 절대 ms/px 는 **참고 출력**으로 남긴다.

| 하네스 | 종전 | 지금 | 사보타주 스위치 |
|---|---|---|---|
| `test-tick-slicer` ③⑥ | 한 프레임 최대 **< 절대 ms** | `base` vs `base2` 잡음비 → `SLICER_RR_K=1.8` | `SLICER_SABOTAGE=1` (조각내기 끈을 뽑는다) |
| `e2e-rtt` ②a③ | 막힘 **< 절대 ms** | 같은 짝 → `RTT_FRAME_K=1.4` · `RTT_LOOP_K=1.6` | `RTT_SABOTAGE=1` |
| `e2e-weight` ④⑤ | 이동 거리 **< 절대 px** | 가벼운 걷기 두 번 → 잡음 바닥 · 문턱은 **서버 배율에서 유도** | `WEIGHT_SABOTAGE=1` |

### `e2e-weight` — 문턱을 **눈으로 찍지 않았다**(족보 ⑺⒋)

```js
  const expected  = 1 / Math.max(0.01, c2.moveMult);          // 서버가 말한 배율의 역수
  const need      = noiseR + (expected - 1) * 0.5;            // 잡음 위 + 약속 효과의 절반
```

## 5. `split-verify.sh` — 이건 **일회용 증명**이지 상시 게이트가 아니다

계약이 "조각을 붙이면 **분할 전** 정본과 바이트 동일"이라, 클라를 한 글자라도 고치면
**영원히 differ** 다. T38 이 `50-i-panel.js` 를 고친 순간부터 이 스크립트는 빨갰고,
그건 결함이 아니라 **계약의 수명이 끝난 것**이었다.

지금은 스크립트가 그 사정을 **스스로 말하고 중립 종료(0)** 한다:

```bash
  SPLIT="${DEL:-}"                                   # 분할 커밋 = client.js 를 지운 커밋
  CHANGED="$(git diff --name-only "$SPLIT" -- public/client/)"
  if [ -n "$CHANGED" ]; then
    echo "분할 커밋 이후 조각이 바뀌었다 — **이 검사는 분할 커밋 전용이라 differ 가 정상이다.**"
    exit 0
  fi
```

조각이 **안 바뀐 채** differ 면 그때만 빨갛게 죽는다. `--selftest` 는 그대로 살아 있다.
⇒ 볼 것은 '같은가'가 아니라 **'의도한 줄만 바뀌었는가'** 다. (`인계/공통.md` ⓒ 절에 적었다.)

★부수 수리: `cmp -s` 가 첫 차이에서 끝나 결합 스크립트가 EPIPE 스택을 토했다 —
`process.stdout.on("error", () => {})` 한 줄.
