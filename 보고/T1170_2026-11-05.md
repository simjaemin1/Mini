## 수정 내용

* 픽스처는 운영 무설정 테스트 훅이다. 마을별 자정·econ 조각·일괄 마감 모두 전쟁 처리가 끝난 공통 자리에서 선포한다. 당일 전쟁 하루가 바로 행군을 소비하던 순서를 걷었다.
* 재개 감사는 실제 재개형 문을 호출한다. 마지막 선택 인자 `auditNodes`는 감사의 노드 조각 크기이며 운영 호출은 종전 인자·조각 크기 그대로다. 동기 감사는 이미 실제 `computeRoutePts`를 사용한다. 캐시 전수 범위·비트 동일 단언을 줄이지 않았다.
* 기본 세계에서는 마을별 자정이 켜져 표본 광산촌과 첫 마을의 날짜가 어긋난다. 공용 `fixture-lab-clock.untilDay`에 관측 마을 인덱스 선택 인자를 추가하고 광산촌을 지정했다. 기본 인덱스는 종전대로 0. 서로 다른 자정의 회귀 4/4.
* 파일 URL이 Chromium 관리 정책으로 막힌 이 환경에서는 `LAB_URL`을 통해 같은 랩을 로컬 HTTP로 적재했다. 테스트 전용 HTTP 제공은 `/favicon.ico`에 정상 204를 반환한다(일반 정적 서버의 404가 콘솔 검사에 섞이던 것을 해결). 페이지·세계 코드는 수정하지 않았다. `LAB_FILE`·`LAB_QS` 명시값은 계속 지원한다.
