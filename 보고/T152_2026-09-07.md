### ⓑ STONE_NET 은 무엇을 잡고 무엇을 못 잡나

**발동 조건은 두 자리다**(`sim/economy-sim.js`):

| 자리 | 조건 | 언제 |
|---|---|---|
| :3356 | `_toolCrit && land.stone ≥ 0.25 && storage.stone < 0.2 && hasSlot(forager)` | **기근 게이트보다 먼저** |
| :3410 | `land.stone ≥ 0.25 && storage.stone < 0.2·max(1, masonTarget) && hasSlot(forager)` | 석공 채용 **직전** |
| :3435 | `land.stone > 0.2499 && storage.stone < N·1.5 && hasSlot(forager)` | 일반 석재 안전망 |

**잡는 것**: *부르는 사람*은 맞게 부른다. 게이트가 `>` → `>=` 로 고쳐져 있어서 **바닥 마을이 포함된다**
(그 주석이 정확히 그 수리를 적어 뒀다 — "FLOOR.stone 이 정확히 0.25 라서 엡실론 하나로 통째로 제외돼 있었다").
실측이 그걸 확인한다: 바닥 마을의 채집꾼 누적이 2,000~32,000 인·일이다 — **안전망은 상시 발동 중이다.**

**못 잡는 것 — 흐름의 굵기**:

```
채집꾼 돌 산출 = land.stone × 스킬 × MSY × 0.9      (economy-sim.js:2102)
              = 0.25 × … × 0.9  ⇒  **0.225 / 인·일** 이 바닥 마을의 상한
석공 도구 한 배치 = _stCost = 0.2 × taper           (:2152 · 게이트 :2178 `stone >= _stCost`)
마제석검 한 자루 = **0.5**                           (:2172)
```
⇒ 바닥 마을에선 **채집꾼 하나가 석공 하나를 겨우 먹인다.** 전사 무장이 한 번 끼면(0.5) 그 자리에서
재고가 0 이 되고, 석공은 `stone >= _stCost` 게이트에서 멈춘다. 안전망은 **사람을 부르지만 관을 넓히지
못한다** — 바닥 마을이 여는 관은 세계에서 가장 가늘고, 그 굵기는 `land.stone` 이 정한다.

**그리고 문턱이 하나 더 있다**: :3356 의 기근 앞 자리는 `storage.stone < 0.2` **절대값**이다. 재고가
0.2~0.4 로 조금 차면 그 자리는 안 서고, 그 아래 **기근 게이트가 먼저 반환**한다(식량 직업). 바닥 마을이
`돌<0.2` 인 날을 800일 중 387~435일 보내는 것이 그 자리의 실측 그림자다.

⚠**"농촌12 판에서 왜 안 섰나"는 여기서 못 답한다** — 셋이 앉은 지금도 그 판이 재현되지 않는다(ⓐ).

착지했다.** 위 표의 `e2e-rtt`(순서 의존)·`test-body`/`e2e-cold`(물때)·`e2e-salt`(소금 낱말) 넉 줄이
그 카드가 닫으러 간 자리다 — **다음 전수에서 다시 세어야 한다.** 이 표는 `58cc7382` 시점의 사진이다.

### ★새 빨강 둘의 진짜 원인 — 하네스의 주석 제거기가 파일의 68%를 삼킨다

`test-crops ⑦ⓓ`·`test-farm-life ⑥ⓓ` 가 같은 날 같이 빨개졌고, 둘 다 `server/villages.js` 를
`codeOnly()` 로 훑는 절이다. 실측:

```
server/villages.js  369,461자  →  codeOnly()  118,047자   (68% 가 사라진다)
indexOf('function _pestAt')            → -1
indexOf('function _lifeNextFarmCell')  → -1        ⇒ 슬라이스 0자 ⇒ "0곳 / 0자"
```

원인은 한 글자다. `codeOnly` 는 **블록 주석을 먼저** 지운다(`/\/\*[\s\S]*?\*\//g`). 그런데
`villages.js` 의 **줄 주석 안**에 `sim/*` 가 있다:

```
줄   20  // … 플래그 off면 sim/* 로드 자체가 없음.     → 여기서 24,903자를 삼킨다
줄 2473  if (!ENABLED) return; // … (sim/* require도 안 함)  → 여기서 155,838자를 삼킨다
```

`//` 안의 `/*` 가 **가짜 블록 주석**을 열고 다음 `*/` 까지 통째로 지워진다. **제품은 멀쩡하다** —
`_pestAt`(3882행)·`_lifeNextFarmCell`(4074행) 둘 다 제자리에 있다.

**왜 하필 지금 났나**: 삼키는 길이는 다음 `*/` 가 어디 있느냐가 정한다. 최근 착지가 `villages.js` 에
주석 블록을 더하면서 `*/` 지형이 바뀌었고, 삼키는 구간이 마침내 `_pestAt` 을 덮었다.
⇒ **회귀는 착지 카드가 아니라 시한폭탄이 터진 것**이고, 폭탄은 이 레포가 이미 금지한 그것이다 —
**파일 전체 정규식**(족보: 소스 검사는 acorn AST 로). 처방은 줄 주석을 **먼저** 지우거나 AST 로 가는 것.
**하네스 카드 한 장**(회부).
