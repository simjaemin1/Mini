## 0. 풀어 쓴 답

## 2. ⓑ 규약 여섯째(= ⓖ · T451 의 ⓕ 시계 다음) — `lib-tick-rule.js` diff (요지)

```js
// ⓖ 같은 설정을 n판 — s = 같은 설정 판 사이 sd · 판 값 = 조각 p50 중앙값
//   두 팔(nA·nB 판) 중앙값 차의 폭 = s·√(π/2)·√(1/nA+1/nB)       (중앙값 SE = 평균 SE × √(π/2) — 상수)
//   규약: 폭 ≤ 효과/3 ⇒ n ≥ π·(3s/효과)² · 최소 3                    (3 = 카드 · π = 상수 · 새 수 0)
//   ★짝 바퀴면 s 대신 짝 차 sd s_d: 폭 = s_d·√(π/2)/√n · n ≥ (π/2)·(3·s_d/효과)²
const RULE_REPEATS = { min: 3, ratio: 3, n(s, e), width(s, nA, nB), verdict(d, w), widthPaired(sd, n), nPaired(sd, e) };
summarize(vals) → { n, med, lo, hi, sd } · fmtRepeats → `중앙값 [lo–hi · n판]` · n<3 이면 `값 [단판]`
SINGLE_NOTE — 자 한 번 = 한 판 표지(t356·t376·t381·t410 끝줄)
```

* **효과**는 재는 손잡이의 값이다. 옛 단판 값을 넣어 n 을 뽑고, 잰 뒤에는 잰 차로 다시 판정한다.
  예산 판정(#54 · T410)의 효과는 **예산·캐논까지의 거리**(33.3 − p95 · 3.3 − µs)다.
* **s 는 그 판 묶음 안에서 잰다** — 컨테이너가 바뀌면 s 도 바뀐다.
  이 컨테이너: s(p50) 0.47(fixed ∪ k-on · 10판) · 짝 s_d 0.21(T385) ~ 0.71(T394).
* 문법: 표의 값은 `중앙값 [lo–hi · n판]`, 손잡이 몫은 `Δ [lo–hi · n바퀴 짝] ± 폭 → 가름/못 가름`, 한 판짜리는 `[단판]`.
  **컨테이너가 다른 값끼리는 견주지 않는다** — 같은 묶음의 켬 팔을 늘 같이 적는다.
