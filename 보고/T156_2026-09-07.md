### ★★main 푸시가 **네 번 죽었다** — 원인은 팩 350개

`batch` 에는 **같은 커밋이 한 번에 들어갔다.** 그런데 곧이어 같은 sha 를 `main` 에 밀자

```

```

맥 클론이 **팩 350개 · 느슨한 객체 437개**다(`gc.auto = 0` — PM 설정이라 합쳐지지 않는다).
푸시마다 git 이 팩 인덱스를 전부 연다. 공통 §T143 이 *"한도를 올려도 나고 안 올려도 되므로
상관이 없다 — 재시도만이 통한다"* 고 적어 둔 그 증상이고, **이번엔 재시도가 안 통했다.**

⇒ 객체는 이미 원격에 있으므로(방금 `batch` 로 올렸다) **참조만 전진**시켰다:

```

```

`force:false` 라 **서버가 fast-forward 를 강제한다** — 안 되면 GitHub 이 거부한다.
객체 전송 0 · 로컬 인덱스 무접촉 · PAT 은 맥에서만 읽고 출력은 `sed` 로 가렸다.
