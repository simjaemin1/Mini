## 집 N 계약

새 손잡이 하나 `T1159_HOME_N=1`, 기본 끔. 호스트가 집 N을 제공하고 econ은 집의 성장·침상·곳간 식에 쓴다.

집 N = econ 명부 − 집 영토 밖의 실제 전쟁·토벌 원정 몸 수. 출정 표지만 붙고 집결 중인 몸, 귀환해 집 영토에 닿은 몸은 집 N에 든다. 보통 일터 주민은 원정으로 세지 않는다. 전쟁 몸은 econ 징발 명부의 pid 결속 또는 실제 소집 때 결속한 살아 있는 주민을 확인해 이미 사망·포로로 빠진 사람을 이중 차감하지 않는다. 장부 귀환일에 징발 표지가 먼저 지워져도 몸이 실제 귀환 중이면 집 밖으로 센다(WeakMap 결속, 저장 상태·손잡이 추가 없음). 죽은 몸은 원정 수에서 빼고 pid 중복은 한 번만 센다. 몸/좌표/영토를 모르는 항목은 임의로 원정 처리하지 않는다. 호스트가 없는 랩은 종전 N이다.

| 갈래 | 적용 |
|---|---|
| 로지스틱 | 비율·성장항, 식량 밖 K 대조, 건강·행복·위신 성장항, 하루 변동 상한 |
| K | 땅·식량 용량은 기존 정본, 연료 수요와 1인 연료 K 분모는 집 N |
| 주거 | 집 증축 목표·하루 건설량·침상 출생 문. 그날 태어난 사람은 즉시 집 침상을 차지한다 |
| 곳간 | 겨울 출생 문 N+1, 옛 굶주림 문턱 N×3 |
| 총 명부 | POP_MAX는 전체 인구, 원정 군량·먹기·옷·도구 장부는 기존 정본 |
