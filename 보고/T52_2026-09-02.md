## 3. ★★함정 — 실클라 하네스가 서버 하네스를 또 이겼다

`sourceAt` 에 갯벌 채집을 넣었고 **서버 하네스는 통과했다**(`tryForage` 를 직접 불렀으니까).
그런데 실클라에서는 굴이 **한 개도 안 잡혔다**(`굴 0`). 진범:

```js
// tryGather — 물가에서 갈래를 가른다
if (isSea(...) && (player.inventory[Salt.VESSEL] || 0) >= 1) { tryForage(); return; }  // ← 게이트가 "병이 있나"
if (isSea(...)) { Body.drinkBrine(...); return; }                                      // ← 병 없으면 여기서 돌아선다
```

**병 없는 사람은 `tryForage` 에 도달조차 못 했다.**
T3 의 물병(`COOK_RECIPES` 에 넣었더니 `doCook` 이 다른 걸 했다)과 **같은 족**이고,
이번엔 **표가 아니라 입력 경로**였다 — ★**`sourceAt` 에 갈래를 넣는 것과 그 갈래에 도달하는 것은 다른 명제다.**

⇒ 게이트를 `Forage.seaSourceAt(...)`(**바다 것만** 보는 술어)로 바꿨다. 갈대·자갈은 **안 센다** —
세면 바닷가에서 갈대가 열려 T4 의 `drinkBrine` 안내를 덮는다(종전 동작을 뺏는 것이다).
그리고 `test-tidal` 에 **"입력 경로가 그 갈래에 도달하는가"** 절을 따로 넣었다.

## 9. 족보 제안

* **(94) ★★★`sourceAt` 에 갈래를 넣는 것과 그 갈래에 도달하는 것은 다른 명제다** — (83)의 **입력 경로판**.
  표를 고치고 서버 하네스로 확인해도, **입력이 그 표에 닿는 길**은 다른 함수에 있다.
  T3 은 표를 읽는 함수에서, T52 는 **표에 닿기 전 게이트**에서 물렸다. 둘 다 **실클라 하네스가 잡았다.**
* **(95) ★★벽시계·게임시각에 기대는 판정은 대조군에서도 자명 통과한다.**
  T52 의 강가 대조군이 "그때 마침 물이 차서" 통과했고, 그래서 **갯벌 판정을 통째로 빼도 초록**이었다.
  ⇒ 시각에 기대는 검사는 **양쪽 상태를 다 못 박아라**. ㊾의 대조군판.
* **(96) ★반쪽 기능은 넣지 마라 — "조달 없는 기계"의 거울은 "쓸 데 없는 조달"이다.**
