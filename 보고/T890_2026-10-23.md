## 1. ① 먼저 잰 것 — 지금 잃나(탐침 · 끔 = 종전 글자)

`scripts/t890-takeover-probe.js`(한 존 실서버 · central + 한반도 · `E2E_GIVE=1`) 판마다 새 손님 하나:

2. `__e2e_body` 로 **산 몸만** 바꾼다. 이 픽스처는 저장을 안 부른다(족보 ㊻). 바꾸는 칸: 숙련 · 제작이력 · 원석장부 · 이월 · 어획 · 소속 · 신체 넷(0.8 · 0.6 · 0.4 · 0.3) · HP 42.
   * ★상황 선행: 행이 그 값을 **아직 안 가졌다**. 그 사이 주기 저장이 끼면 그 판은 "재는 판"에서 뺀다.

## 2. ① 고침 — 승계도 칸 목록 한 벌(`server/zone.js` 승계 자리)

```js
if (_takeover) { 자리 · 층 · 인벤 }                                   // 몸 칸 밖 — 두 판 같은 줄
if (_takeover && T890_TAKEOVER_BODY) {                                 // 켬
  const _tb = parseBody(serializeBody(_takeover), { vitals: true });  // 핸드오프 페이로드와 같은 길(저장 · 넘기기의 두 함수)
  _tb.lastSeenDay = Number.isFinite(_takeover.lastSeenDay) ? _takeover.lastSeenDay : player.lastSeenDay;   // ★[T7] 보강(종전 뜻)
  _tb.member = _takeover.member || player.member;                                                          // ★[T11] 보강(종전 뜻)
  _bodyInto(player, _tb, _takeover.equipped !== undefined ? _takeover.equipped : player.equipped);         // 얹기 한 자리(T873)
}
if (_takeover && !T890_TAKEOVER_BODY) { 종전 승계 몸 칸 줄 그대로 }     // 끔
if (_takeover) { 브리핑 표 · 허기 · 갈증 · 위반 · 정해진 깨어남 · 로그 }  // 몸 칸 밖 — 두 판 같은 줄
```

* 몸에 칸이 새로 생겨도 `serializeBody` · `parseBody` · `_bodyInto` 셋만 받으면 된다. 그러면 일반 접속 · 토큰 · 승격(T873)과 **승계**가 같이 받는다. 사람에 몸을 얹는 자리가 이제 셋 다 `_bodyInto` 다.
* 보강 둘은 종전 뜻 그대로다(덮어쓰기 아님).
  * 기준일: 산 몸이 아직 못 가졌으면 저장본이다. 저장 규칙(`_lastSeenDayToSave`)이 아니라 산 몸 값 그대로다 — 종전 승계와 같은 글자이고, 부재를 앞당기지 않는다.
  * 소속: 산 몸에 없으면 저장본이다.
* 장착은 종전 그대로 산 몸의 것이다(`undefined` 면 저장본).
* **켬이 종전과 달라지는 것**(산 몸이 진실 — B-6 규약을 몸 칸 전부로):
  * 제작이력 · 어획 · 신체 · 최대 HP 를 산 몸에서 받는다(고침).
  * 쓰러짐은 산 몸 값 그대로다. 종전은 산 몸이 쓰러져 있을 때만 이었다 — 산 몸이 일어서 있는데 저장본이 쓰러짐이면 쓰러진 채로 태어났다.
  * 신체의 저장 밖 칸(`stages` 등)은 핸드오프와 같은 꼴(`Body.toSave` → 빈 칸 0)이다. 존을 넘을 때와 같다.
* `/health` 와 하네스 말고 서버 판 동작은 무변이다. 승계는 사람 소켓 길뿐이라 서버 기준선 10-23 이 같음 3/3 이다(§4).

## 5. 회부 · 알림

1. **[PM · 켤지]** `T890_TAKEOVER_BODY` 는 켬 기본 후보로 냈다(`!== '0'`). 끔이면 라이브의 같은 존 재접속(클라 `ensurePrimaryConnection` 의 close→connect 등)마다, 마지막 저장 뒤 바뀐 제작이력 · 어획 · 신체가 사라지고 행까지 덮인다. 켬 기본으로 착지할지는 PM 몫이다.
2. **[정보 · 켬의 다른 점]** 켬이면 쓰러짐 · 최대 HP 도 산 몸 값이다(종전은 저장본이 이길 수 있었다). 신체의 저장 밖 칸은 존을 넘을 때와 같은 꼴로 0 이 된다. 둘 다 "산 몸이 진실"(B-6) 쪽이다.
3. **[정보 · 합침]** 이 가지는 T873 · T887 미착지 가지를 합쳤다. T873 의 `T868_PROMOTE_BODY` 줄(`=== '1'`)은 main 이 켬 기본(`!== '0'`)으로 착지했으므로 main 쪽을 살렸다. `test-handoff-body` ① 의 손잡이 검사 · 미끼도 main 꼴 + `_bodyInto` 다.
