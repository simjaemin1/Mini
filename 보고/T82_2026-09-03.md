## 0. §0 실측 (셋)

### ⓐ 자연물은 `pickAt` 에 잡힌다 — 그런데 **서버가 동사에 이름을 안 붙인다**

```
  자연물   `c.resources`(id · type · x · y · hp · r) — 좌클릭 사슬엔 **없다**(E 키가 종전 통로)
  종류     tree · rock · ore · herb · berry_bush · water_pool · meteorite
  ★이름표  **없다.** `tryGather` 는 종류를 보고 갈래를 타지만 그 갈래에 이름을 안 붙인다.
           `ITEM_LABEL_SERVER` 에 있는 것은 **전리품** 이름이다(wood→나무 · stone→돌 · ore→광물 ·
           herb→약초). `tree`·`rock`·`berry_bush`·`water_pool` 은 아예 키가 아니다.
  ⇒ 지시서가 예고한 대로 한 단어 표를 `46-h-verbs.js` 에 두고 **회부에 적었다**(사본 후보).
    고침은 서버 한 줄(`welcome.resourceVerbs`)이고 그날 이 표는 지운다.
```
★★그리고 더 큰 것이 하나 나왔다: **`gather` 는 지목을 못 받는다.** 인자가 없고 `tryGather` 가
`GATHER_RANGE`(48) 안에서 **제일 가까운** 자원을 고른다 — 누른 것과 서버가 고를 것이 다르면
메뉴가 거짓말이 된다(T68 의 `_downedNear` 와 같은 얼굴). 서버 무접촉이 이 카드의 규칙이므로:

```
  ⇒ **누른 것이 제일 가까울 때만** 동사를 낸다. 아니면 빈 메뉴다(더 가까운 걸 누르라는 뜻).
  ⚠거리 상수 48 은 클라에 **안 적었다** — "제일 가까운가"만 보면 되고,
    너무 멀면 서버가 **E 키와 똑같은 문장**으로 답한다(메뉴는 별칭이지 새 판정이 아니다).
```

### ⓑ E 반복과 메뉴 — **한 번 = 반복 시작**, 그리고 타이머는 하나다

E 는 누르고 있으면 `setInterval` 1초로 `gather` 를 보낸다(키를 떼면 멎는다). 채굴은 60타에 덩이
하나라 **메뉴 한 번 = 한 타**는 뜻이 없다. ⇒ 판정:

| | 시작 | 멈춤 |
|---|---|---|
| E 키 | 누르는 동안 | **키를 떼면**(종전 무변) |
| 메뉴 | 한 번 누르면 | **다시 우클릭**(라벨이 "멈추기"로 바뀐다) · 또는 **그 자연물이 없어지면** |

★타이머는 **`46-h-verbs.js` 하나**로 모았다(`startGatherLoop(stopWhen)`). 두 벌이면 E 와 메뉴가
겹칠 때 서버로 **두 배**가 간다. 멈추는 조건만 부르는 쪽이 준다.
⚠"없어졌나"는 **두 번 연속**으로 물어야 한다 — 시야 묶음이 갱신되는 찰나에 자원 맵이 잠깐 비어서,
한 번만 보면 **다 캐지도 않았는데 멎는다**(하네스가 실제로 잡았다).

### ⓒ 자기 자신 — **새 서버 메시지 0**

```
  먹기…    `eat{item}` (종전)   하위 목록 = 내 짐 중 `foodEffects[k].hunger > 0`
  마시기…  `eat{item}` (종전)   하위 목록 = 내 짐 중 `foodEffects[k].thirst > 0`  ← `fresh_water` 가 여기 든다
  짐과 장비 `toggleInv()` (클라) — `I` 키의 별칭
```
★무엇이 먹을 것이고 무엇이 마실 것인지를 **클라가 안 적었다** — 서버 표(`FOOD_EFFECTS`)가 가른다.

### ⑧-b — 이 카드에서 제일 정직해야 하는 줄

`gather` 가 지목을 못 받으므로 **먼 나무를 눌렀는데 메뉴가 뜨면 다른 나무가 베인다.**
그래서 자원 둘을 찾아 **먼 쪽을 눌렀을 때 빈 메뉴**인지 재고, 같은 판에서 **가까운 쪽은 뜬다**는
것도 잰다(늘 안 뜨는 규칙이 아니라는 증거 — 자명 통과 금지).

### 하네스가 저를 **다섯 번** 속였다 — 다섯 다 검사 쪽. 그 중 셋은 **재접속** 하나가 원인이었다

```
  ⓐ hp 3 짜리 나무를 골랐다      3초 만에 다 베여 반복이 **저절로 멎었다**(옳은 동작인데)
                               하네스는 "토글이 안 된다"로 읽었다. ⇒ hp 가 제일 큰 것을 고르고,
                               토글은 **바로** 잰다. 그래도 먼저 멎으면 그 갈래도 계약으로 받는다.
  ⓑ `||` 로 붙인 곁가지 조건     "자원 hp 가 줄었다 **또는** 인벤이 안 비었다" 로 써서
                               `hp 3 → 3` 인데도 초록이었다. ⇒ 증거는 그 자원이 깎였는가 하나다.
  ⓒ ⑧-b 의 "가까운 건 뜬다"      뜨기만 하면 통과로 썼더니, 자원이 내 몸 상자(±18) 안에 들어
                               **자기 자신 메뉴**가 떴는데 초록이었다(자연물 규칙을 하나도 안 쟀다).
                               ⇒ 몸에서 비켜선 뒤 누르고, **자연물 동사인지까지** 본다.
```
★★그리고 남은 둘은 **같은 뿌리**였다. 2코어 상자에 실클라 셋이면 소켓이 한 번씩 끊기고
클라가 **새 pid 로 다시 붙는다**. 진단이 그걸 정확히 찍어 줬다:

```
  ⓓ "R 이 입장 못 했다"          실은 들어왔다가 **재접속 중**이었다(입장 실패 진단줄이 안 찍힌 게 증거).
                               ⇒ 입장 판정을 90초까지 기다린다.
  ⓔ "메뉴가 안 뜬다"            `{pick:{kind:'player', down:false}, verbs:0, downs:3}` · 시도마다
                               pid 가 **p410 → p415**. A 가 새 pid 로 붙어서 R 의 `downStates` 엔
                               **옛 pid** 만 있었다. ⇒ **R 이 그 사람을 쓰러진 것으로 볼 때까지** 기다린다.
  ⓕ "240초를 굶겨도 안 쓰러진다"  `parts: []` · `moveMult 1` — **`hp:3` 픽스처 한 통이 재접속에 씻겼다.**
                               (매번 보내면 HP 가 되돌아가 역시 안 쓰러진다 — 그 함정은 앞서 밟았다.)
                               ⇒ **화면의 HP 를 보고 정한다**: 아직 높으면 다시 낮추고, 낮으면 굶주림만.
```
★그래서 "안 떴다"로 끝나는 줄은 없다 — 안 뜨면 `pickAt` 결과·`verbsFor` 개수·보이는 사람 수·
`downStates` 크기를 같이 찍는다. **이 카드의 실패 셋을 전부 그 한 줄이 풀었다.**
★제품 쪽에서도 하나 나왔다: "그 자원이 없어졌나"를 **한 번만** 물으면 시야 묶음 갱신 찰나에
자원 맵이 잠깐 비어 **다 캐지도 않았는데 반복이 멎는다**. ⇒ 두 번 연속일 때만 멎는다.
