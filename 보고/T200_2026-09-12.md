## 2. §0-ⓑ 수출 문턱 자리 — 순간 재고가 어디서 들어오나 · EMA 칸이 이미 있나

```js
// sim/economy-sim-v2.js — tickTradeV2 출발 leg 후보 고르기
for (const r of TRADABLE) {
  const stock = a.v.storage[r] || 0;                 // ← ★**오늘 곳간 하나**가 여기서 들어온다
  const target = Math.max(subs * 30, buffer);        // stone 은 subs = 0 ⇒ target = N × 0.8
  ... else { keep = target * 0.5; thresh = target * 0.8; }
  if (stock > thresh) candidates.push({ res: r, surplus: Math.max(1, stock - keep) });
}
```

**EMA 가 이미 있는 재고 칸은 — 없다.** 이 세계의 EMA 는 전부 **흐름**이다:

| 이름 | 무엇의 EMA | 관성 | 자리 |
|---|---|---|---|
| `surplusEMA.food` | 식량 **수지**(생산−소비) | **0.95 / 0.05**(≈20일) | `economy-sim.js:2920` |
| `_consEMA[r]` | 품목 **소비 흐름** | 29/30, 1/30(≈30일) | `:2096` |
| `_fishRawEMA` | 잠재 어획 | 1/30 | `:2200`대 |
| `prodK` EMA | 부양력 | — | — |
| **재고(stock)** | **없다** | — | — |

⇒ 재고 EMA 칸을 새로 만들되 **관성은 빌린다** — 카드가 지정한 `surplusEMA` 의 0.95/0.05.
그 두 수를 `economy-sim.js` 에서 **이름으로 올려**(`SURPLUS_EMA_A/B` · 값 무변) v2 가 읽는다(**사본 0 · 새 계수 0**).

```js
// 문이 열렸을 때만 칸이 생긴다 — 닫히면 `_stockEMA` 자체가 없다(비트 동일)
let cmpStock = stock;
if (_exEma) {
  const _e = a.v._stockEMA || (a.v._stockEMA = {});
  _e[r] = (_e[r] == null) ? stock : (v1.SURPLUS_EMA_A * _e[r] + v1.SURPLUS_EMA_B * stock);
  cmpStock = Math.min(stock, _e[r]);          // 오늘도 있고 **평소에도** 있어야 잉여다
}
if (cmpStock > thresh) candidates.push(...);
```
`min(오늘, 평소)` 인 이유: 평소엔 많은데 오늘 없는 것을 실으면 `surplus = max(1, stock−keep)` 이 1 을
돌려주어 **곳간이 음수**가 된다. 손잡이 `L_EXPORT_EMA` — **기본 끔**(세계를 움직이는 손잡이).
