## 2. ⓐ 고리 거울(`T1348_LOOP`)

- `npcs`(pid Set)가 `OrdSet` 이다. 같은 Set 이고, 넣은 차례 거울 배열(`P` pid · `S` 칸 캐시)을 같이 든다.
  - 새 pid 는 끝에 붙는다. 지웠다 다시 넣으면 끝이다. 지운 자리는 구멍이다.
  - 구멍 메우기는 고리 머리에서만 한다(구멍 ≥ 64 · 배열의 ¼).
- `players`(pid → 몸 Map)가 `PMap` 이다. 같은 Map 이고, 쓰기(`set` · `delete` · `clear`)마다 첫 거름 칸의 `GN` 표를 고친다. `GN` 은 "players 의 그 pid 몸 ≠ 칸 몸"이다.
- 결정 고리는 거울 배열을 돈다. 길이를 매번 읽으니 고리 안에서 넣은 pid 도 같은 바퀴 끝에서 돈다. Set 의 살아 있는 순회와 같다.
  - 건너는 몸: Map 0 · 열만 본다.
  - 안 건넌 몸: 표 줄이 칸을 받는다(`_t1322Grant(npc, now, s)`) — `SS.slot` 한 번을 덜 짚는다.
- 미세 판(`scripts/t1348/bench-loop.js` · 몸 1,500 · 데운 캐시): 건너는 몸 하나가 34 ~ 41 ns → 5 ns 다.
- `verify`(`T1322_PREFILTER=verify`)는 거를 때마다 `GN` 표와 종전 술어(`players.get(pid) !== own[s]`)를 견준다. 야간 판 2날 · 30날 · 400날 모두 어긋남 0 이다.

## 3. ⓑ 걷는 몸 열 커널(`T1348_WALK`)
