## ⓪ 추신 — `e2e-move` 가 흔들린다(35/2 ↔ 37/0) — 주인은 표본 시각이다

**무엇이 흔들렸나.** 빨간 두 줄은 늘 ②(키 뗌 → 미끄러짐)였다. 옛 자:

```js
const posBefore = await me();          // __getMyAbs() — page.evaluate 왕복으로 떼기 **전에** 찍는다
await page.keyboard.up('KeyD');        // 실제 떼기는 그 뒤(Playwright 왕복)
await sleep(600); const posAfter = await me();
R.slide = |posAfter − posBefore|       // ⇒ 떼기까지 **더 걸은 걸음**이 미끄러짐에 섞인다
```

클라는 30Hz 고정 스텝으로 걷는다(`31-m-move.js` `PRED_STEP = 1/30` = 존 `TICK_HZ` 30) — **한 걸음 = 64px/s ÷ 30 = 2.133px**.
그래서 옛 자의 legacy 값은 **걸음의 배수**만 나온다: 0 · 2.13 · **4.27(2걸음)** · **6.40(3걸음)** — PM 의 6.40 은 **한 프레임이 아니라 세 걸음**이다.
accel 은 감속 3.79px + 걸음(5.93 = 3.79 + 1걸음). 빨강의 두 길: legacy 가 2걸음 이상이면 `< 4` 가 깨지고, legacy 3걸음 · accel 1걸음이면 미끼(accel > legacy)가 5.93 < 6.40 으로 깨진다. 세계(같은 나무 · 같은 씨)는 같다.

1. **교역이 세 배가 된다(가름)** — 원정 거리는 그대로다(기록 p50 0.69~0.73km → 0.63~0.73km — 더 멀리가 아니라 **더 자주** 간다). 교역 상대는 정보 반경(5,000 econ = 2.0km) 안이라(기록 최대 4,969) 켬의 원정은 **전부 하루**다(≤ 0.69일 → 바닥 1). 코드로 읽은 까닭(분해는 안 쟀다): 한 원정의 기회비용 문 `profit > mv × 왕복일 × (1 − 0.5·slack)`(`economy-sim-v2.js:806-809`)과 교역 나간 NPC 가 생산에서 빠지는 날 `_tradingUntil = day + 왕복일` 이 **둘 다 왕복일에 비례**한다 — 왕복일 7.4~7.7 → 2 면 같은 여유 노동이 ~3.7배 원정을 띄운다(실측 ×3.1).
2. **세계가 커진다(가름)** — 인구 +13.6 % · 확장셀 +49 % · 생곡 +32 % · 도구Q +26 % · 무기Q +28 % · 소멸 0. 교역이 흔하면 더 먹고 더 짓는다.
3. **사건이 거의 두 배가 된다(가름) — 밀도 캐논 밖** — 부족 4,787 → 8,666 · 글럿 4,522 → 8,331 · 값 오름 5,607 → 10,299 · 값 내림 5,346 → 10,590(시드 1020 · 넷이 다 ~두 배) — 100단위 짐이 매일 도착하면 곳간·값이 문턱을 더 자주 넘는다. 게시 +82 %. 밀도 ㉮ 1.84~1.88 → **1.04~1.05 일/건** — 캐논 2~3일의 절반(끔도 이미 하단 밖).
4. **소문은 하루에 전 마을(가름)** — 7일 안 25곳 → 50곳 · 평균 지연 8.2 → 1일. 존 기하(다리 포함 BFS)로도 한 사건이 전 마을에 닿는 날 p50 20 → **1**(최대 24 → 2 · §1 기계).
5. **존에서(3시드 밖 · 표로만)** — 교역이 서는 641쌍의 캐러밴 몸 속도가 몸 걸음의 0.064~0.104배 → **0.16~0.69배**(p50 0.44 · 몸보다 빠른 쌍 **0**). 날이 **전부 하루 바닥**이라(몸 걸음으론 0.04~0.69일 거리) 몸은 여전히 몸보다 느리게 걷는다 — econ 은 하루보다 짧은 원정을 못 적는다(**자의 해상도**). 몸보다 빠를 수 있는 자리는 **재routing 뒤 귀환 구간 하나**다(새 목적지는 지금 자리에서 반경 안 ⇒ 집까지 최대 2 × 5,000 econ = 1일 → 몸의 ×1.39 · 반올림 `round` · 페이싱에 MOVE_SPEED 상한 없음). 반경 밖까지 치면 1,275쌍의 22 % 가 ×1.0~1.5 지만 그 쌍엔 캐러밴이 안 뜬다.
6. **못 가름** — 보존식 · 소금 지역차.

⇒ 값이 아니라 정합인데 **세계가 크게 움직인다**(#77 꼴) — 켜기는 재민. 켤 때 같이 갈 줄(켜기 조건): ① 소문 거울이 이 시계를 읽는 한 줄(+ `test-events ⑲b` 표본 — 켬이면 일수가 하루 한 점이라 대조 구간이 무너진다) ② 반올림(재routing 귀환 ×1.39 — `ceil` 이면 0) ③ 하루 바닥(자의 해상도) ④ 번들에 move-model 표(WORLD 는 T471 이 실었다) ⑤ T436 과 같이 켜면 `T436_K` 재유도 — §6.
