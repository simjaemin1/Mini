## ⓒ `#enter` — 라벨과 하네스를 끊었다

`public/index.html` 의 버튼 글자를 **「나루터로 간다」** 로 바꿨다(T66 이 되돌렸던 그 개명).
게임 코드 diff 는 이 한 줄 + `70-lobby.js` 의 라벨 언급 주석 둘뿐이다.

* **글자 셀렉터 30파일 · 37자리** → `page.$('#enter')`.
* **옛 사다리 26파일 · 30자리** — `['#startBtn', 'button:has-text("시작")', 'button:has-text("입장")', 'text=게스트']`.
  ★이 사다리가 이번 카드의 진짜 발견이다. 네 칸 중 화면에 있는 것은 **"입장" 한 칸**뿐이고
  (`#startBtn` 은 없고, `"시작"` 은 숨은 「새로 시작」에 걸리고, `게스트` 는 버튼이 아니다),
  앞 칸의 **click 시간초과 30초**가 우연히 로비의 `/zones` 응답과 청크 적재를 기다려 주고 있었다.
  라벨을 바꾸면 네 칸이 **한꺼번에** 죽는다. ⇒ 사다리를 지우고 기다림을 **말로** 적었다:

  ```js
  await pg.waitForFunction(() => { const b = document.getElementById('enter');
    return !!(b && b.onclick && !b.disabled); }, { timeout: 45000 }).catch(() => {});
  try { const b = await pg.$('#enter'); if (b) await b.click(); } catch (e) {}
  ```
  둘을 다 기다린다 — 버튼이 살아나는 것(`disabled`, T61·T68 의 그 흔들림)과 손잡이가 걸리는 것
  (`onclick` 은 `30-n-net.js` 의 `boot()` 이 건다 — 그 전에 누르면 아무 일도 안 난다).
  `e2e-cutaway` 는 고정 대기가 14초로 형제들(15~24초) 중 가장 짧아 그 30초가 **지붕 텍스처 적재**까지
  받치고 있었다(실측: 밖 화면 이엉 0.0%) — 그 만큼도 말로 적었다(진단값 폴링 + 옛 흐름과 같은 44초).
* 하네스가 아닌 도구 14개(`probe-*`·`prof-*`·`shot-*`·`smoke-*`·`sweep-*`)도 같은 사다리를 쓴다.
  개명이 그것들을 조용히 죽이므로 **같은 한 줄로 같이 고쳤다**(카드의 30파일 밖 — 자인한다).
