## §1 ① 랩 상한 켬 기본

### 1-1 서버가 거는 상한(정본 · 그대로)

* **시딩:** `extractLandParamsApprox` → `server/sustain.js sustainOf` 가 그 마을 어장 MSY(`fishSustain` — 노동권 물 셀 × `L_FISHR`/4 × 2.5 · 눈금 `legacy`)를 잰다. 서버는 그 값을 `land._fishBase` 로만 붙잡는다(`villages.js` 시딩 두 자리). land 의 `fishSustain` 칸은 아직 비어 있다.
* **하루 마감**(T661 · 캐러밴 동기 바로 앞): `refreshFishSustain` 이 `land.fishSustain = max(0, 기준 − stockToEcon(결손))` 으로 매긴다.
  * NPC 어획은 재고를 안 깎는다(`T60_FISH2WAY` 끔 기본). 결손은 플레이어 낚시뿐이라, 손님 0 인 판에선 0 이다 ⇒ 값 = 시딩 MSY.
  * 첫 마감은 첫날 econ 뒤에 온다 ⇒ **서버 econ 은 둘째 날부터 상한을 본다.** T661 의 "켬 판은 상한이 첫날부터 걸린다"는 첫날 마감에 선다는 뜻이다 — econ 이 무는 첫날은 둘째 날이다(§4 둘째 날 갈림).
* 상한이 서는 마을은 물 있는 45곳이다(51곳 중 · 시드 셋 같음 — 지도 값). 랩 자의 시딩 캐시도 같은 45곳에 같은 값을 둔다(같은 시딩 함수).

### 1-2 고침 — 같은 값 · 같은 때(서버 무변)

```js
const T17_MSY = !(typeof process !== 'undefined' && process.env && process.env.T17_MSY === '0');   // 켬 기본 · 되돌림 =0
function fishMsyDayClose(v) {   // 마을 하루 마감 — 아직 상한이 없으면 시딩 MSY 로

}
// createVillage 끝:  if (T17_MSY && opts.fishSustain != null) Object.defineProperty(v, '_fishMsySeed', { value: opts.fishSustain, writable: true, configurable: true, enumerable: false });
// V2 _villageBody:  applyLandModifiers → tickVillage → restoreLand → v1.fishMsyDayClose(v)
```

* 랩 자(t17 · t176)는 서버와 **같은 시딩 함수**로 마을을 세운다 ⇒ `opts.fishSustain` 이 서버 `_fishBase` 와 같은 값이다(새 수 0 · 사본 0).
* 마감 한 줄은 서버의 첫 `refreshFishSustain`(결손 0)과 **같은 값을 같은 날** 세운다 — 첫날은 상한 없이 돌고 둘째 날부터 문다.
* 서버에선 같은 날 마감 갱신이 그 칸을 곧바로 덮는다(결손이 있으면 그 값 · 없으면 같은 값) ⇒ **서버 무변**(§4 서버 기준선 3/3).
* land 화이트리스트의 종전 줄(`T17_MSY === '1'` 이면 시딩 순간 land 에 꽂던 줄)은 걷었다. `=0` 이면 두 칸(`_fishMsySeed` · 마감 줄)이 다 안 선다 = 종전 바이트.
* `_fishMsySeed` 는 **열거 안 되는 칸**이다. 서버도 같은 `createVillage` 를 부른다. 저장 줄(`serializeEcon` · `Object.keys`)이 그 칸을 DB 로 퍼 나르면 서버 `land._fishBase` 의 사본이 저장된다. 열거를 끄면 마을 JSON 이 종전과 같다(§4 저장 줄).
