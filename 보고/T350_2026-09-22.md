## 1. ① `decideNpcBehavior` — 열다섯 굴림을 씨 하나로

T340 이 센 그 열다섯이다. 한 걸음에 **한 번** 씨를 뿌리고, 그 흐름에서 열다섯을 꺼낸다:

```js
//  전: npc.nextDecisionAt = now + 500 + Math.random() * 1000;   … 그리고 열넷 더
//  후:
_diceNpc.seed(_SEED.seedOf(_shOf(npc),
    Math.floor(npc.x / BUILDING_SIZE), Math.floor(npc.y / BUILDING_SIZE), zoneGameDay(), _tick.n));
npc.nextDecisionAt = now + 500 + _dn() * 1000;                   // … 그리고 열넷 더
```

| | 값 |
|---|---|
| 씨 | **(신원 · 셀 x · 셀 y · 게임일 · 틱)** — 카드가 정한 그 다섯 |
| 신원 | `pidHash(playerId)` 를 **한 번만 굽는다**(`npc._sh`) — 걸음마다 문자열을 해시하면 그게 T345 가 지운 쓰레기다 |
| 흐름 | **모듈에 하나**(`makeStream`) — 결정마다 클로저를 만들지 않는다(할당 0) |
| 성질 | **순수 함수** — 같은 다섯이면 같은 열다섯. ⇒ **도는 순서와 무관** |

★**흐름을 자리마다 따로 둔 이유는 재진입이다.** 주민 결정 중간에 `SimVillages.npcLifeTick`(villages) 이 끼어든다 —
같은 흐름을 나눠 쓰면 그 사이에 씨가 갈려 **뒤 굴림이 달라진다**. 그래서 흐름이 일곱이다:
`_diceNpc`(주민 결정) · `_diceCan`(카나디아) · `_diceTick`(존 틱) · `_diceLife`·`_diceVil`(생활층·마을) ·
`_diceB`(도적) · `_diceW`(야생).

```js
setInterval(() => { const now = Date.now(); … const _elapsed = (now - lastTick) / 1000; … }, …)
```

⇒ 두 프로세스는 **같은 게임일에 같은 틱 수를 안 돈다**(부하가 다르면 틱이 밀린다). 그러면 `_tick.n` 이 갈리고
씨가 갈린다. 걸려면 길은 둘이고 **둘 다 이 카드 밖**이다:

| 길 | 무엇을 해야 하나 | 왜 이 카드 밖인가 |
|---|---|---|
| ⓐ 시뮬 시계 손잡이(`FIXED_CLOCK=1`) | 틱마다 `now` 를 `t × TICK_MS` 로 | 카드 §1 **손잡이 0** |
| ⓑ 결정 박자를 틱 수로(`nextDecisionAt` ms → `nextDecisionTick`) | 30Hz 에선 같은 뜻이지만 **밀린 존에서 뜻이 달라진다** | 카드 §1 **분포 무변 · 굴림만 결정적** 밖 |

★**그래서 이 카드의 게이트는 "결정이 결정적이다" 를 건다.** 시계까지 결정적으로 만드는 것은 회부 1 이다.

### 5-ⓐ ★`test-war-world ⓓ` 가 빨개졌다 — 그리고 그게 이 카드의 **결과**다

`ⓓ ★대조 — 씨가 다르면 결과가 다르다` 가 빨개졌다. 귀속:

```
scripts/test-war-world.js:57    Math.random = seeded(opts.seed || 7);   // 한 판마다 **전역을 간다**
```

옛 대조는 `opts.seed` 로 **전역 `Math.random` 을 갈아** 세계를 흔들었다. T350 이 존의 세계 자리에서
그걸 전부 걷어내자 — **그게 카드가 시킨 일이다** — **전역을 갈아도 세계가 안 움직인다.**
⇒ 회귀가 아니다. 자가 **없어진 것을 재고 있었다.** 대조를 둘로 갈랐다:

| | 대조 | 답 |
|---|---|---|
| ① | 세계가 **실제로 읽는 씨**(`warId` → `_muRng`)를 갈면 | **결과가 다르다** ✔ (해시가 뭔가를 보고 있다) |
| ② | **전역 `Math.random` 을 갈면** | **결과가 같다** ✔ ★**주사위 0 의 산 증거** |

★**②는 이 카드가 산 새 증인이다.** 린트 ⑪ 은 소스를 보고, ②는 **세계를 돌려서** 본다 — 자가 둘이 됐다.
