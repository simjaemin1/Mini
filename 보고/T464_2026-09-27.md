### ⓐ-3 번들의 꼴 — `inline-engine.js --check` 가 비교하는 것

* `sim/economy-engine.browser.js`(자동 생성 · `sim/build-econ-bundle.js`)는 **classic 스크립트**다 — `;(function(root){ … root.EconEngine = … })(typeof window!=='undefined'?window:globalThis);`. `import`/`export` 0 · module 아님 ⇒ `file://` 의 `<script src>` 로 실린다(module 이면 CORS 로 막힌다 — ⓐ-2).
* 랩 두 장의 인라인 글자 = 번들 파일 **바이트 동일**(778,439 B · sha256 `8c0356fe77ac6a77` · 두 장 다). 번들에 `</script>` 가 0 이라 `inline-engine.js` 의 이스케이프(`<\/script>`)도 바꾸는 글자가 0 이다.
* `inline-engine.js --check` 는 블록 **전체 글자**(표식 줄 + `<script>` + 번들 + `</script>` + 끝 표식)를 번들로 다시 짜서 랩 안의 것과 `===` 로 견준다. 같은 계약이 CI 게이트(T293)와 `lab-wiring-check [G]` 에 걸려 있다.
* 머리말이 인라인의 까닭을 적어 두었다: *"랩 HTML 은 file:// 로 직접 열리는 자체완결 프로토타입이라, 외부 src 대신 인라인이 안전."*(`sim/inline-engine.js:2` · `inline-battle.js:2` 같은 문장).
