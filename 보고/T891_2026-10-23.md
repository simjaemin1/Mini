## §1. ① 손잡이 — `T891_WATER_HALF`

**서버** `server/zone.js` welcome `uiCfg` 에 한 줄을 넣었다(T870 `mtBand` 줄 바로 앞).
```js
...(process.env.T891_WATER_HALF === '1' ? { waterHalf: true } : {}),
```
끔이면 칸이 없다 — welcome 바이트가 같다.

**클라** `public/client/10-r1-terrain.js` `_drawWaterLayer`
- `S = uiCfg.waterHalf === true ? 2 : 1`.
- GL 캔버스를 `ceil(W/S) × ceil(H/S)` 로 잡는다.
- 물 상자(scissor)를 GL 칸으로 바꾸고 바깥으로 둥글린다.
- `ctx2.drawImage(_wgl.cv, gx0, gy0, rw, rh, gx0·S, gy0·S, rw·S, rh·S)` — 2D 가 S 배로 늘린다.
- 셰이더가 더 아는 것은 균일값 하나다: `uPx` = GL 칸 하나가 덮는 화면 픽셀 수. 그래서 `ix = gl_FragCoord.x*uPx − …` · `sy = (uRes.y − gl_FragCoord.y*uPx) − …` 이다.
- 월드 좌표 · 마스크 · 물결 · 물가 굽이 식은 그대로다.
- 끔(S=1)이면 캔버스 · 상자 · 식 · `drawImage` 인자가 종전 값과 같다.

켬 판에서 셰이더가 도는 GL 칸 수는 ¼ 이다.

## §2. 그림 비교 — 켬/끔 (`scripts/t891-water-probe.js`)

**판의 꼴**
- 실서버(central + zone)에 Chromium 클라 하나가 들어가 어촌1로 텔레포트한다.
- 가장 가까운 물 칸을 `isWaterAtAbs` 로 찾아, 그 물가 뭍 두 칸 뒤에 선다. 화면 절반쯤이 물이고 물가 굽이가 보인다.
- 물 시각을 얼린다(`__terrain19.freezeT = 12.25`). 그다음 끔 a → 끔 b → 켬 → 끔 c 순으로 찍는다. 페이지 안에서 `uiCfg.waterHalf` 를 바꾼다.

**차이**(같은 판 · 화면 1100×720 · 물 상자 = 화면 전체)

| 비교 | 화면 전체 평균 차(0~255) · 큰 차 % | 물가 400×240 자름 평균 차 · 큰 차 % |
|---|---|---|
| 끔 a ↔ 끔 b(잡음 바닥) | 0.23 · 0.31% | 1.32 · 1.79% |
| 끔 a ↔ **켬** | 0.30 · 0.31% | 1.48 · 1.81% |
| 끔 a ↔ 끔 c | 0.29 · 0.38% | 1.33 · 1.80% |

- 켬/끔 차이는 끔/끔 잡음 바닥과 같은 크기다. 잡음은 비 줄기 · NPC 걸음 · 이름표가 낸다.
- 확대 본(`zoom-shore.png`)에서 물결 무늬 · 수면 밝기 · 물가 경계 지그재그 · 물가 녹색 선(벡터로 그리는 선이라 손잡이와 무관)이 같다.
- 켬 쪽은 아주 작은 반짝임 점이 조금 무르다. 계단 · 띠 · 틈 · 어긋남은 없다.
- 그래서 **물결 · 물가 경계가 깨지지 않는다 — 회부 없음**.
- (광산5도 시도했다. 그 판 화면 안에 물 칸이 없어 자가 멈췄다. 그래서 물 마을은 어촌1 한 곳으로 쟀다.)

## §4. ③ WebKit — `scripts/t891-webkit-check.js`

- 이 상자에는 Playwright WebKit 이 없고 `playwright install` 은 금지다.
- 대신 apt `webkit2gtk-driver` · `xvfb` 를 깔았다. **WebKitGTK MiniBrowser 2.52.6** 을 W3C WebDriver(`WebKitWebDriver`)로 직접 몰았다 — Safari 와 같은 WebKit 엔진(JavaScriptCore · WebKit WebGL)이지만 **Safari 그 자체는 아니다**(macOS · Metal 백엔드 아님).
- 판: 존 `T891_WATER_HALF=1` → 입장 → 어촌1 물가로 텔레포트 → 켬 읽기 · 찍기 → 페이지에서 끔 → 읽기 · 찍기.

|---|---|---|---|---|---|
| 켬(welcome) | true | true · true | **550×341** | 1100×682 | 0,0,1100,682 |
| 끔(페이지에서) | false | true · true | 1100×682 | 1100×682 | 0,0,1100,682 |

- 두 스크린샷 모두 물이 그려진다. 물가 경계 · 녹색 선 · 수면 결이 같다(이 판은 ms 를 안 쟀다 — 그림만 본다).

## §5. 회부 (판정 0)

1. **켬 기본 여부** — 그림은 안 깨지고 물 층은 ¼ 이다. 그러나 이 상자에서 텔레포트 묶임은 반 초 남짓 남는다(켬 0/5 늦음 · 다섯 다 0.4~0.7초 덩이).
   - 실제 GPU 기기(맥 · 아이폰 Safari)에서의 물 층 ms 는 **미측정**이다.
   - 켤지, 더 낮출지(⅓ 등은 새 수라 안 했다)는 PM 판정이다.
2. **⑬ NPC 우클릭이 물 마을에서 빗나감** — `e2e-verbs` ⑬ 이 NPC 를 어촌1에서 잡은 두 판(켬 1 · 끔 1)만 빨강이다("아무도 안 눌렸다"). 광산 NPC 판은 5/5 초록이다.
   - 짐작(미검증): 물 층 프레임에 주 스레드가 묶인 사이 NPC 가 걸어, 하네스가 읽은 화면 자리와 두드린 자리가 어긋난다(T881 꼴).
   - 하네스 쪽이면 T880 꼴(상한 안에서 다시 읽고 두드림)이다. 이 카드는 하네스를 안 고친다.
3. 계측 자는 러너 밖이다(`t891-water-probe` · `t891-webkit-check`). WebKit 자는 `apt-get install webkit2gtk-driver xvfb` 가 먼저 있어야 한다.
