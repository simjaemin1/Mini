## §0-ⓑ 가공 관로 — **실측으로 검증했다**(받는 즉시 쓸 수 있다)

파일이 없으니 **이미 있는 BGM `.ogg` 를 대역 원본으로** 삼아 관로를 끝까지 돌렸다(임시 폴더 · 배포 0 · 커밋 0).

**단발(≤3초)**
```bash
# ① 자르고 무음 머리·꼬리 다듬기 → wav
ffmpeg -y -ss <시작> -t 3 -i <원본> \
  -af "silenceremove=start_periods=1:start_threshold=-50dB,areverse,\
       silenceremove=start_periods=1:start_threshold=-50dB,areverse" \
  -c:a pcm_s16le -ar 44100 cut.wav
# ② 피크를 재고 → 이득 = −1.0 − 잰피크   (2단이라 재현된다. loudnorm 은 안 쓴다)
ffmpeg -i cut.wav -af astats -f null -   # → "Peak level dB: −3.737880"
# ③ 두 꼴로 굽는다
ffmpeg -y -i cut.wav -af "volume=2.74dB" -c:a libvorbis -q:a 4                    <key>.ogg
ffmpeg -y -i cut.wav -af "volume=2.74dB" -c:a aac -b:a 96k -movflags +faststart   <key>.m4a
```

**반복(≤10초 · 이음새)** — 11초를 떠서 **끝 1초를 머리에 크로스페이드**로 겹친다(`acrossfade` · 삼각창):
```bash
ffmpeg -y -i loopsrc.wav -filter_complex \
 "[0]atrim=0:10,asetpts=N/SR/TB[a];[0]atrim=10:11,asetpts=N/SR/TB[b];[a][b]acrossfade=d=1:c1=tri:c2=tri" \
 -c:a pcm_s16le loop.wav          # 뒤는 단발과 같다(피크 재기 → volume → ogg/m4a)
```
