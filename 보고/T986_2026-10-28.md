# T986 — econ 길의 벽시계 타이머 전수 (세션16 · 2026-10-28)

**한 줄 답:** 전수 결과, 빠른 판 자(800날)에서 벽시계 판과 가상 시계 판을 가르던 것은 **도적 하루를 부르는 자리**였다(T969 쉼터 백필을 켠 뒤에도 남은 것).
- 도적 하루는 존 틱이 `world.day` 바뀐 걸 보고 부른다. 그런데 하루 마감은 현지 자정 창(T731)이라, 날을 올린 머리 뒤에 마을마다 제 조각이 틱 몫으로 끊겨 돈다.
- 그래서 도적 하루가 **마을 결산 몇 곳 뒤에 끼어드나**가 벽시계(밀림 · 부하)에 달렸다. 결과로 절망 이탈 · 해체 · 약탈이 다른 날에 났다.
  - 시드 7 임업6 이탈: 벽시계 D516 ↔ 가상 시계 D518
  - 시드 1020 어촌9: D527 ↔ D523
- 1위 하나를 지었다 — 손잡이 **`T986_BANDIT_DAY`**(끔 기본 · `'1'` 켬 · 끔 = 종전 글자).
  - 켜면 같은 몸통을 하루 마감의 정한 조각에서 부른다(날을 올린 econ 머리 **바로 뒤**).
  - 이 자리가 그 함수 머리 주석이 말하는 "econ 틱이 world.day 를 민 직후"다.
  - 켬(T969 와 같이)이면 두 시계가 **800날 3/3 바이트 같음**이다(집 행위 끔 · 켬 둘 다 · 부하 판). 끔이면 같은 짝이 3/3 갈렸다.
- 전수 표: 시계를 직접 읽는 자리 **495**(부록 `계측/T986_벽시계_전수_2026-10-28.md` · 갈래 35)와 틱 `now` 를 받아 셈하는 자리(§1-②).
  - 그중 econ · 마을 · 몸에 닿고 판 자에서 갈릴 수 있는 자리는 §1 표 **14줄**이다.
  - 1(도적 하루)을 지었고, 2 는 T969 손잡이다. 나머지는 후보 한 줄씩 남기고 회부한다(§3).

### 2-① 원인 가르기(관찰기 셋 · 읽기만 · 커밋은 증인 하나)

1. **전쟁이 아니다**
   - `t969-trace`(T969 관찰기)로 560날 두 시계를 쳤다. 정산 6 · 6 · 8 개, 걸음 수, 자취가 다 바이트 같았다.
   - 같은 판의 econ 은 2/3 갈렸다(위 셋째 판).
2. **광부 몸(T724)이 아니다**
   - 420날 3시드 관찰에서 몸이 친 마을 표식 `_t724Walk` 이 **0번**이었다.
   - 원석 · `land.ore` 도 두 시계가 날마다 같았다.
3. **갈린 날 하루 앞까지 마을 칸 전부가 같다**
   - 곳간 전 품목 · 금고 · 노동 배율 · 사냥 위험 · 사람 hp · 허기 · 직업 · 땅 · 주거가 같다.
   - 갈린 날 처음 다른 것은 **사람 하나**다(임업6 농부 47 ↔ 48 · 어촌9 채집꾼 57 ↔ 56).
4. **그 하나는 도적 절망 이탈이다**
   - 같은 마을의 이탈 줄이 두 시계에서 다른 날에 섰다: 7 임업6 벽 D516 ↔ 가 D518 · 1020 어촌9 D527 ↔ D523.
   - 해체도 D535 ↔ D531 로 갈렸다.
5. **까닭은 도적 하루의 자리다**
   - 도적 하루(`_dayRun` — 결성 · 이탈 · 해체 · 약탈 · `_bdtCri` · `_bdtFall` 누적)는 존 틱이 `world.day` 바뀐 첫 틱 끝에 돈다.
   - 현지 자정 창은 머리(날 +1) 뒤 마을마다 제 조각을 돈다.
     - 가상 시계는 몫이 안 닳아, 머리가 든 틱에 그 틱까지 자정이 온 마을이 다 든다.
     - 벽시계는 econ 이 밀려 자정이 다 지난 마을들을 16ms 몫으로 끊어 돈다.
   - ⇒ 도적 하루가 본 "그날 결산한 마을" 집합이 판마다 다르다.
   - 증인: 하네스 ③. 끔이면 가상 시계 판에서도 도적 하루 39/39 날이 머리 뒤 마을 결산 몇 곳 **뒤**에 돌았다.
6. **E1 · E2 의 광산 · 어촌 st·tr 첫 갈림도 같은 꼴로 본다**(약탈 = 곳간 · 금고 · 해체 = 주거)
   - 그 판의 도적 로그는 판 자리를 지워 남지 않았다.
   - 대신 켬 판으로 같은 짝을 다시 쳐서 받친다(§2-②).
   - 곁 증인: 가상 시계 끔 ↔ 켬의 첫 갈림이 시드 7 **D394 광산5[st·tr]** 이다(§2-②). E1 벽시계 판의 첫 갈림과 같은 날 · 같은 마을 · 같은 칸이다. 집 행위 켬 판은 셋 다(D411 · D493 · D500) E2 와 같다.
     그날 벽시계 판의 도적 하루가 "머리 바로 뒤"(켬 자리) 쪽에 섰다고 읽는다.

### 3-① 지은 것 — `T986_BANDIT_DAY`

```js
// server/bandits.js — 끔이면 종전 글자(onGameTick 끝 줄이 `_dayRun(world.day)` · 같은 몸통)
const T986_BANDIT_DAY = … process.env.T986_BANDIT_DAY === '1';
function onGameTick() { …부팅 · 결합…; if (T986_BANDIT_DAY) return; _dayRun(S.host.world.day); }
function dayTick() { if (!ENABLED || !T986_BANDIT_DAY || S._boot || !S.ready) return; _dayRun(S.host.world.day); }
function _dayRun(day) { if (day === S.lastDay) return; S.lastDay = day; …daily · save · 방송 · 몸 재동기… }   // 종전 몸통 글자 그대로
// server/zone.js — SimVillages.init deps: dayBandits = 켬일 때만 () => Bandits.dayTick()
// server/villages.js — 현지 자정 창 머리 `econ:head` 바로 뒤 · 종전 마감 econ 1일 틱 바로 뒤: if (state.deps.dayBandits) add('bandit', () => state.deps.dayBandits())
```

- 몸통은 옮긴 것뿐이다(`_dayRun` = 종전 `onGameTick` 끝 블록 글자 그대로).

## 5. ③ 회부 (판정 0)

1. **[PM · 판 자 기본]** 서버 기준선 자에 `T986_BANDIT_DAY=1`(T969 와 같이)을 실을지.
   - 실으면 벽시계 기준선 = 가상 시계 판이다(800날 · 집 행위 켬 포함 — §2-②).
