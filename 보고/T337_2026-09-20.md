## 1. §0-ⓐ `_consEMA` 0/51 의 기전

### 사슬 — 문이 **넷**이다

```
_cons(v, r, amt)            ← ① 누가 부르나            economy-sim.js:499
  → v._consDay[r] += amt
  → 일 경계 폴드(α=1/30)     ← ② 하루가 지나야 한다      :2267
  → v._consEMA[r]
  → ema > 0 && stock < ema × SHORT_DAYS(5)   ← ③ 부족 판정   events.js:599 · :658
  → !DEL.fromEcon.has(item) 이면 안 건다      ← ④ 벽          events.js:838
  → 의뢰 게시
```

T302·T328 이 연 것은 **④** 다(15 → 10 → 3). 닫혀 있는 것은 **①** 이다.
⚠**③ 은 이중 게이트다**: 설령 `short` 가 서도 `wantQty = round(ema × REQ_DAYS)` 라
EMA 0 이면 구하는 양이 0 이다(`makeRequest` :859). 그래서 ①이 닫히면 ③④를 다 열어도 아무 일이 없다.
