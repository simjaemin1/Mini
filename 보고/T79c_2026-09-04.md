## 무엇이 바뀌었나 — 같은 여덟 자리

`산그림/디자인B/밭_8군.png` (위 = 옛 좌표 해시 · 아래 = 새 group)

**옛 규칙은 여덟 자리 중 여섯을 틀리게 골랐다.** 콩밭이 잎채소로, 마늘밭이 황금 이삭으로,
박밭이 이삭으로 그려지고 있었다. 벼와 배추 둘만 우연히 맞았다 — 해시는 그렇게 맞는다.

```js
// 전
const h = Math.abs(((wx|0) * 73856093) ^ ((wy|0) * 19349663));
const im = CROP_SPR[(h % 2) ? 'veg' : 'grain'][st];
// 후
const ser = CROP_SPR._slug[CROP_SPR._of[crop]] || 'grain';
const im = CROP_SPR[ser] && CROP_SPR[ser][st];
```

`_slug` 는 **서버 group(한글) → 파일 슬러그** 여덟 줄이고, `_of` 는 서버 페이로드가 채운다.
작물표 사본은 없다. 심긴 것을 모르면 **곡물**이다 — 주곡이 기본값이고, 그건 규약이지 주사위가 아니다.
