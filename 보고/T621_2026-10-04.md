## §0. 무엇을 어떻게 했나

* T605 §4-6: `syncGhostsToNeighbors`(100ms 마다)가 건물 **전부**(한반도 라이브 판 2,196채)를 훑어 그중 경계 1,200px 안 벽·문·울타리(라이브 판 **12채**)만 이웃 존에 보낸다.
* **색인 자리 = `buildings` Map 자신.** 존의 건물 Map 은 게으르게 채워진다(켜진 청크 몫만 메모리에 · 청크를 켜고 끌 때 넣고 뺀다 · 짓기·부수기·DB 적재·마을 층 `dp.buildings.delete` …). 넣고 빼는 자리를 하나하나 고치면 하나만 빠져도 유령이 갈린다 → `Map` 을 이어받은 `_BuildingMap` 이 `set`·`delete`·`clear` 에서 띠 색인을 같이 고친다. **호출부는 한 줄도 안 바뀌었다**(조회·순회·크기 전부 종전 `Map` 그대로).
* **움직이는 것 없음** 확인: 건물을 만드는 자리는 전부 `{ id, type, x, y, … }` 를 새로 짓고 `set` 한다 — 제자리에서 `type`·`x`·`y` 를 바꾸는 줄 0(고치기·부수기는 `data.damaged` 만 바꾼다 → 그 줄은 함수가 **매 부름 다시 본다**). 존 크기(`ZONE.zoneWidth/Height`)는 존 설정 적재 뒤 안 바뀐다.
* **순서까지 같게**(몸통 바이트 같음의 조건): 종전 함수는 `buildings` 넣은 차례로 훑는다. 색인도 넣은 차례 Map 이라 — 새 키는 둘 다 끝에 붙고, 지우면 둘 다 빠진다. **한 갈래만 다르다**: 있던 키를 덮어써서 띠 밖 → 띠 안이 되면 큰 Map 에선 제자리, 색인에선 끝이 된다 → 그때만 색인을 통째 다시 센다(`#rebuild` · 드문 갈래 — 게이트 시나리오는 같은 키 덮어쓰기를 일부러 1,000부름에 23·30번 넣었고, 이 줄을 빼면 미끼 ②-b 가 21·90부름에서 갈린다).

## §1. 고친 것 — `server/zone.js` 두 자리(+33 −3)

```js
const GHOST_REACH = 1200;   // 경계에서 유령을 보내는 폭(px) — `syncGhostsToNeighbors` 가 쓰던 그 수(새 수 0 · 함수 안에서 여기로 옮겼다)
function _ghostBandOf(b) {   // 색인 후보 — `syncGhostsToNeighbors` 건물 거름의 종류·띠 줄 그대로
  if (!b || (b.type !== 'wall' && b.type !== 'door' && b.type !== 'fence')) return false;
  const zw = ZONE.zoneWidth, zh = ZONE.zoneHeight;
  return b.x < GHOST_REACH || b.x > zw - GHOST_REACH || b.y < GHOST_REACH || b.y > zh - GHOST_REACH;
}
class _BuildingMap extends Map {
  #band = new Map();
  constructor() { super(); }
  set(k, v) {
    const had = super.has(k);
    super.set(k, v);
    const gb = this.#band;
    if (_ghostBandOf(v)) { if (!had || gb.has(k)) gb.set(k, v); else this.#rebuild(); }
    else gb.delete(k);
    return this;
  }
  delete(k) { this.#band.delete(k); return super.delete(k); }
  clear() { this.#band.clear(); super.clear(); }
  ghostBand() { return this.#band.values(); }
  #rebuild() { const gb = this.#band; gb.clear(); for (const [k, v] of super.entries()) if (_ghostBandOf(v)) gb.set(k, v); }
}
const buildings = new _BuildingMap();    // id -> { id, dbId, type, ownerId, ownerName, x, y, data }
```

* 함수: `for (const b of buildings.values())` → `for (const b of buildings.ghostBand())` **한 줄** · 그 아래 거름 줄(종류 · `data.damaged` · 네 변 · 이웃 존 · 바다)은 **한 글자도 안 바뀌었다** · 함수 안 `const GHOST_REACH = 1200;` 한 줄은 모듈 상수로 옮겼다(사람 유령 줄도 같은 이름을 읽는다 — 값 같음).
* 비용: `set` 마다 `_ghostBandOf` 한 번(종류 비교 셋 · 수 비교 넷) — 짓기·청크 켜기 자리에서만 돈다(틱 0).
