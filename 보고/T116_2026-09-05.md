### ⓑ `ink_post.py` 의 의존 — **묶은 게 없다**. 그래서 그대로 올라간다

카드는 "SS·알파 문턱·합집합 마스크가 캐릭터 고유인지 공용인지" 표를 시켰다.
눈으로 읽는 대신 **AST 로 자유 이름을 전수로 뽑았다**(모듈이 정의하지도, 인자로 받지도 않으면서
참조하는 이름 = 밖에 매달린 것):

```
모듈 밖에 매달린 이름  →  ('load_exr','bpy') ('save_exr','bpy') ('save_png','bpy')   — 그게 전부다
```

**`SS` 를 안 쓴다.** 함수가 전부 `(sheet, w, h, …)` 를 받으므로 초과표본이 몇이든 상관이 없다.
캐릭터 층 이름(`body`·`clothes_*`·`tool_*`)도 **코드에는 한 번도 안 나온다**(주석에만 나온다).

| 무엇 | 캐릭터 고유인가 | 어떻게 다뤘나 |
|---|---|---|
| `SS`(초과표본) | **아니다 — 의존 자체가 없다** | 그대로 |
| 알파 문턱 `INK_A`(200/255) | 값의 **유도**는 캐릭터(④ 의 `a<200` 정의) · 쓰임은 공용 | 인자 `athr=` 로 이미 열려 있다. 기본값째 올렸다 |
| 셀 문턱 `EDGE_A`(0.60) | **캐릭터 손잡이** | 안 올렸다 — 호출부가 넘긴다(`char_render` 것) |
| 먹색 `INK_RGB`(21,19,17) | 값은 몸 시트 실측 · 쓰임은 공용 | 인자 `rgb=` 로 이미 열려 있다. 기본값째 올렸다 |
| 셀 범위 `CEL_P_LO/HI` | **아니다** — "시트 제 것의 1~99%" 라 자산군과 무관 | 그대로 |
| 합집합 마스크(몸↔옷) | **캐릭터 정책이다** | `post_all` 의 인자 `silhouette`·`partner_of`·`alpha_of` 로 **이미 밖에 있었다**. 정책은 `char_render` 에 남는다 |
| float 입출력(EXR·PNG) | 아니다 | 그대로(지연 `import bpy` 만 뺐다 — 공용은 맨 위에서 들여온다) |

⇒ **올릴 수 없는 부분이 없었다.** T107 이 후처리 본문을 `post_all` 한 자리로 모으면서
정책을 전부 인자로 뽑아 뒀기 때문이다. 이 카드가 한 일은 그 파일을 **한 층 위로 옮긴 것**뿐이다.

★그런데 옮기면서 **함정 하나**를 실측으로 찾았다 — 두 파일이 `PPU` 라는 **같은 이름을 다른 값**으로 쓴다:

```
render_common.PPU = 64/√2            = 45.255   (px/미터)
char_render.PPU   = PPU0 * SS        = 135.765  (굽기 픽셀)
   ↑ ZSQ 는 둘 다 0.8165 로 같다(공용은 PPU 로, 캐릭터는 PPU0 로 계산해 값이 만난다)
   ↑ SAMPLES·SS·THETA·NHAT·RHAT·UHAT·V 일곱은 글자까지 같다 — 갈리는 건 PPU 하나뿐이다
```

`from render_common import *` 한 줄이면 캐릭터의 카메라 배율이 **조용히** 3분의 1이 된다.
그래서 캐릭터는 **`import render_common as rc`(이름 붙여서)만** 쓰고, 하네스 둘이 그걸 지킨다.

### ⓒ 상자 못박기가 읽는 메타 — 자산군마다 **다르다**. 게다가 건물은 **없다**

| 자산군 | 파일 | 상자 키 | 앵커 키 | 모양 |
|---|---|---|---|---|

| 자연물 | `public/assets/nature/nature_anchors.json` | `w`·`h` | `ox`·`oy` | **자산마다** `{키: {...}}` (56개) |

**카드 전제 정정 둘.**
ⓘ 카드는 `building_anchors.json` 을 자산군 셋 중 하나로 셌지만, 그 파일은 **배포되지 않는다**
  (`building_render.py:522` 가 `OUTDIR` 에 쓴다 — 그 폴더는 `.gitignore`).
  ⇒ 건물에 못박기를 걸려면 **먼저 그 메타를 배포로 올려야 한다**. 세션8 몫으로 회부한다.
ⓘ 다른 넷은 이름이 다른 게 아니라 **`render_common` 자신이 내는 서식**이다 —
  `render_world_pass()` 의 반환값이 그대로 `{"w","h","ox","oy","ppu"}` 다.
  ⇒ 공용이 **쓰는 서식을 공용이 읽는다**. 새 이름을 짓지 않았다.

⇒ 헬퍼 인터페이스는 그래서 둘로 갈린다:
```
read_pinned_box(path, key=None, *, scale=1.0)   # 읽개 — 서식 둘을 다 읽는다. 파일이 없으면 None,
                                                #        **있는데 서식이 아니면 크게 실패**(없는 것 ≠ 깨진 것)
fit_pinned_box(pinned, umin, umax, wmin, wmax)  # 판정 — 안 들어가면 SystemExit
```
`scale` 이 필요한 이유도 여기서 나온다: 캐릭터 메타는 **클라 픽셀**이라 굽기 픽셀로 올리려면 `SS`
를 곱해야 하고(`scale=SS`), 자산별 서식은 이미 출력 픽셀이라 `scale=1` 이다.

### ★★못 지킨 것 하나 — 그리고 그게 왜 이 카드 탓이 아닌지

카드 §3 의 "**다섯 클립 전부** 바이트 동일" 은 **안 됐다.**

```
되굽기(EXR) ↔ 배포 PNG :  swing 14/14 · aim 14/14   ✔  (28장)
                          idle 0/14 · walk 0/14 · run 0/14  ✘  (42장)
```

**차이의 생김새를 먼저 쟀다**(원인을 부르기 전에):

| 시트 | 다른 화소 | 최대 알파차 | 다른 화소의 평균 RGB 차 | 최대 채널차 |
|---|---|---|---|---|
| `body_walk` | 12,088 / 627,840 (1.93%) | **2** | **0.82** / 255 | 200 |
| `body_idle` | 4,077 / 313,920 (1.30%) | **2** | 0.81 / 255 | 192 |
| `clothes_hemp_run` | 6,330 / 627,840 (1.01%) | **2** | 0.95 / 255 | 174 |
| `body_swing` | **0** | 0 | 0 | 0 |

알파가 **최대 2** 밖에 안 움직였다 = 실루엣도 포즈도 상자도 그대로다. 평균 0.8/255 는
**몬테카를로 잡음 한 판** 크기다. 최대 200 은 먹선이 만든다 — `INK_A = 200/255` 라는 **딱딱한
문턱** 위에서 알파가 ±2 흔들리면 그 화소가 먹(21,19,17)에 들어갔다 나갔다 하며 ±200 이 된다.

**원인은 굽기의 비결정성이 아니다.** 오늘 같은 층을 두 번 구우니 EXR 이 **바이트 동일**이었다.
입력이 다른 것이다. 그리고 입력의 차이는 **하나**로 좁혀진다:

```
T96  : 상자를 새로 재서 구웠다 → 앵커는 전정밀도 값
       메타에 적을 때만 round(ANCH_Y/SS, 3) = 81.663   ← **여기서 잃었다**
T107~: 상자 못박기가 그 **반올림된 81.663** 을 다시 읽는다 → ×3 = 244.989
       T96 의 참값은 [244.9875, 244.9905] 어딘가 — 최대 **0.0015 SS px** 어긋난다
       (anchorX 는 54.5 → ×3 = 163.5 로 딱 떨어져 손실 0. 그래서 세로만 어긋난다)
```

**그만큼으로 갈리는가?** 한 변수만 옮겨서 쟀다 — 앵커를 **0.0012 SS px**(반올림 폭보다도 작다)
움직여 같은 층을 다시 구웠다:

```
EXR 화소 627,840 중 30,181(4.81%)이 갈렸다 · 평균 RGB 차 0.37/255
```

⇒ **사이클스는 입력이 한 비트만 달라도 잡음을 새로 굴린다.** 반올림 하나로 판이 갈린 것이다.
swing·aim 이 맞는 이유도 같은 자리에서 나온다 — 그 둘은 **T107 이 못박기와 함께 구웠으므로**
PNG 와 EXR 이 같은 판이다.

**그래서 이 카드는 42장을 못 맞춘다.** 맞추려면 배포 PNG 42장을 오늘 EXR 로 갈아 끼워야 하는데,
그건 이 카드의 첫째 절대 규칙(**배포 바이트 무변**)과 정면으로 부딪친다. 규칙을 지켰고,
**고칠지 말지는 회부한다**(§3 · 세 길 · 전부 배포를 건드리므로 재민 판정).

★**남길 한 줄:** **EXR 은 배포 PNG 를 낸 그 판이 같이 남겨야 한다.** 나중에 따로 구운 EXR 은
"세기를 바꾸는 데"는 쓰지만 "지금 바이트를 되살리는 데"는 못 쓴다.
(그래서 `assets-src/char_repost_proof.json` 은 **28장 그대로 뒀다** — 70장으로 늘리면
`test-charsheet ⑧-ⓓ` 가 빨개진다. 빨간 것을 초록으로 덮지 않는다.)

### 하네스 규칙 하나를 **뒤집었다** — 밝혀 둔다

`test-charsheet` 에 이런 줄이 있었다:

```js
ok(!/^\s*(import\s+render_common|from\s+render_common)/m.test(src),
   '★`render_common.py` 무접촉 — import 0 (T97 세션8이 그 파일을 만지는 중)');
```

주석이 스스로 **유효기간**을 밝히고 있다("T97 세션8이 만지는 중"). T106 이 끝났고 카드 T116 ②③ 이
그 파일로 올리라 했으므로 뒤집었다. 다만 **그 규칙이 막던 진짜 위험은 그대로 막는다** —
§0-ⓑ 에서 잰 `PPU` 이름 충돌이다. 대신 들어간 두 줄:

```js
ok(!/^\s*from\s+render_common\s+import/m.test(src), '★별표 들여오기 금지 — PPU 가 같은 이름 다른 값');
ok(/^PPU0 = .../m && /^SAMPLES = 64/m && /^SS = 3/m && /^ZSQ = /m, '★씬 값은 여전히 이 파일 것이다');
```

옛 규칙은 "닿지 마라"였고 새 규칙은 "**이렇게만 닿아라**"다. 전자보다 좁고 정확하다.
