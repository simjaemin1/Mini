  * `tickWarBodies`: 교전 몸을 안 걷는다.
  * `_t681Flush`: 교전 몸 몫 가운데서는 `TB.slice` 예산으로 안 끊는다.
* 380일 판을 두 시계로 쳤다. 판 JSON md5 가 손잡이 없는 판과 같았다(벽시계 `1a3d4850…` = 켬 · 가상 시계 `46927cbd…` = 켬). 전쟁 2 정산도 같았다.
* ⇒ 이 판에선 조각 끊김이 결과에 안 닿는다. 시험 손잡이는 가지에 없다(되돌렸다).

## 3. 고침 — `T969_SHELTER_DAY`

```js
// server/zone.js — 끔이면 종전 setTimeout 그대로(if (!T969_SHELTER_DAY) setTimeout(...))
const T969_SHELTER_DAY = process.env.T969_SHELTER_DAY === '1';
function _t969ShelterDay(day) {
  const dms = parseInt(process.env.VILLAGE_DAY_MS || '', 10) || WORLD.dayLengthMs;
  if (_t969Sh.next === null) _t969Sh.next = Math.ceil(Math.max(3000, Math.round(SHELTER_BACKFILL_MS / 4)) / dms);
  if (_t969Sh.next < 0 || day < _t969Sh.next) return;
  const r = _shelterBackfill(); _shBackfillTries++;
  _t969Sh.next = ((r.left | 0) > 0 && _shBackfillTries < 20) ? day + Math.max(1, Math.ceil(SHELTER_BACKFILL_MS / dms)) : -1;
}
// SimVillages.init deps: dayShelter = 켬일 때만 _t969ShelterDay
// server/villages.js — 하루 마감 두 자리(T731 창 · 종전 마감) 사건 장부 뒤: if (state.deps.dayShelter) add('events', () => state.deps.dayShelter(state.world.day | 0))
```

* 같은 백필 함수(`_shelterBackfill` → `ensureShelter`)를 같은 판 수 상한으로 부른다. 부르는 자리만 벽시계 타이머 → econ 날 자리로 옮겼다.
* 빠른 판 자(250ms)는 첫 판 60일 · 다음 240일마다다. 라이브(24분)라면 첫 판 1일 · 다음 1일마다다(그 몇 초가 하루 안).
* 가상 시계 판 econ 은 그대로다(종전 타이머가 이미 60일에 울렸다). 마을 칸 `_t719N`(새 집 곁 칸 기억 — 틱마다 8명씩)만 날 61부터 다르다 — 쉼터가 그날 한낮 대신 그날 마감에 선다.
