## 1. §0-ⓐ 한 자리 — `happyWorkMul` 에 하한만 얹는다

```js
function happyFloor1On() {                                  // 랩은 window · 서버·CLI 는 env (T100·T193 관습) · 빈 값/0 은 끔
  const on = (x) => x !== undefined && x !== null && String(x) !== '' && String(x) !== '0';
  const g = (typeof window !== 'undefined') ? window : null;
  if (g && on(g.L_HAPPY_FLOOR1)) return true;
  if (typeof process !== 'undefined' && process.env && on(process.env.L_HAPPY_FLOOR1)) return true;
  return false;
}
function happyWorkMul(happiness, W) {
  if (!(W > 0) || typeof happiness !== 'number' || !isFinite(happiness)) return 1;
  if (happyFloor1On()) return Math.max(1, Math.max(1 - W * 0.5, Math.min(1 + W * 0.5, 1 + (happiness - 0.5) * W)));   // ★[T209]
  return Math.max(1 - W * 0.5, Math.min(1 + W * 0.5, 1 + (happiness - 0.5) * W));                                      // ← 종전 줄 그대로
}
```

* **새 수 0** — `1` 은 이 함수가 이미 쓰는 중립값이다(주입이 없으면 `return 1`). 계수 `H=0.24` 는 T165 정본 그대로, 한 자도 안 만졌다.
* **위쪽 무변** — 켜도 0.5 위의 값과 상한(`1 + H/2 = 1.12`)은 그대로다: `f(0.6)=1.024 · f(0.8)=1.072 · f(1.0)=1.12 · f(2.07)=1.12`(끔과 **동일**).
* **아래는 정확히 1** — `f(0)=f(0.1)=f(0.2)=f(0.3)=f(0.4)=f(0.5)=1.000`(끔은 0.880 · 0.904 · 0.928 · 0.952 · 0.976 · 1.000).
* **읽는 곳 전수**: `happyWorkMul` 을 부르는 엔진 자리는 `sim/economy-sim.js:2201` **하나뿐**이다(작업량 배수). 하한이 무는 자리도 함수 안 **한 줄**이고, 부르는 쪽은 무접촉.
