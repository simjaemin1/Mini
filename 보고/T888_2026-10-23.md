**한 줄 답:** 손잡이 하나 `T888_NPC_WALK` 를 켬 기본으로 냈다(`!== '0'` · `=0` 이면 main 과 바이트로 같다). 배회 배율은 이제 한 글자 `NPC_WALK_MULT` 다 — 켬 1 · 끔 0.6 이고, `npcStep` 기본 배속과 `followNpcPath` 기본값이 같이 쓴다. 도주 2.5 와 사냥꾼 `_huntSpd`(잠행 0.5 · 추적/회수 2 · 속보 1.25)는 그 위에 그대로 곱한다 — 랩 `moveNPC(a, L_WALK × 배속)` 와 같은 꼴이다(랩 글자로 확인). 재 보니 이렇다.

## 1. 결함 — 랩 글자 대조

* **랩** `lab/마을실험실.html` 생활 층이 몸을 걷게 하는 줄:
  `moveNPC(a, L_WALK*(a.state!=='work'?1:(a._hold?0:(a.sneak?0.5:((a.job==='hunter'&&(a.action==='추적'||a.action==='회수'))?2:(a.job==='hunter'?1.25:1)))))*dGM)`
  * 평보 배속이 **1** 이다(근무 밖 1 · 근무 평보 1). 사냥꾼 배속(정지 0 · 잠행 0.5 · 추적/회수 2 · 속보 1.25)은 **`L_WALK` 에 곱한다** — 카드 ①이 물은 것의 답은 "그렇다"이다.
  * `L_WALK=2` 는 셀/분이다(랩 유닛 1 = 시계 1분). 존 `MOVE_SPEED` 64px/s = 2셀/초와 같은 걸음이다(그 상수의 주석 "마을실험실 정본(2셀/초)과 통일").
* **서버** `npcStep` 은 `let speedMult = npc.behavior === 'flee' ? 2.5 : 0.6` → `followNpcPath(npc, speedMult)` 로 **38.4px/s**(1.2m/s)를 걸었다. 플레이어는 `MOVE_SPEED` 64 다.
* 그래서 이식이 랩보다 얕았다. 서버 안에서도 어긋났다 — 몸이 언제 닿고 하루에 몇 번 오가는지를 **미리 세는** 자리는 다 존 `moveSpeed`(64)로 센다(`_t341TripsPerDay` 짐 수 · T681 걸음 장부 · T772 귀환 상한 · T790 전쟁 걸음 · T347 채집 왕복 — §3 ⑪). 몸만 38.4 로 걸었다(T491 §2-ⓒ 의 1.67배).

## 2. ① 고침 — 손잡이 `T888_NPC_WALK`(켬 기본) · 배회 배율 한 글자

```js
const T888_NPC_WALK = process.env.T888_NPC_WALK !== '0';
const NPC_WALK_MULT = T888_NPC_WALK ? 1 : 0.6;   // 배회(평보) 배율 — 두 자리가 같이 쓴다
…
const speed = MOVE_SPEED * (speedMult || NPC_WALK_MULT);                 // followNpcPath 기본값
let speedMult = npc.behavior === 'flee' ? 2.5 : NPC_WALK_MULT;            // npcStep 기본 배속
if (npc.behavior !== 'flee' && npc._huntSpd) speedMult *= npc._huntSpd;   // 그대로 — 평보 위에 곱한다(랩 동형)
```

* 켬 = 배회 배율 1(`MOVE_SPEED` 그대로 · 64px/s)이다. 끔(`=0`) = 종전 0.6 이고, main 과 바이트로 같은 갈래다(서버 기준선 끔 같음 3/3 · §4).
* 도주 2.5 · 사냥꾼 `_huntSpd` 는 손대지 않았다 — 평보 위에 그대로 곱한다. 켬이면 사냥꾼은 잠행 32 · 속보 80 · 추적/회수 128px/s 다(= 랩 1 · 2.5 · 4m/s · 종전 19.2 · 48 · 76.8).
* `followNpcPath` 기본값은 실제로는 안 탄다 — 부르는 자리가 하나뿐이고 늘 0 아닌 수를 넘긴다(사냥꾼 조준 정지도 0.02). 그래도 "기본 걸음"이라는 같은 뜻이라 같은 글자를 쓴다.
* `villages.js` 의 짐 수 주석(T491 §2-ⓒ "몸의 배회는 0.6")에 켬 기본 한 줄을 더했다(주석만).
* 클라는 손대지 않았다. NPC 걷기 시트는 64px/s 에서도 걷기다(문턱 `charRunMin` 102 · NPC 는 달리기 문턱 아래로 묶어 넘긴다 — `34-m-renderloop.js` "NPC 는 걷기·서기 둘만").
