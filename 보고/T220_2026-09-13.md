### 러너가 고를 수 있나 — **그렇다. 러너는 한 글자도 안 고쳤다**

`run-regress.sh` 의 `_disc()` 는 T104 부터 **태그를 인자로 받는다**:
`grep -lE "^// @${2:-regress}([[:space:]]|$)"`. 태그에 공백이 있어도 그대로 먹는다 ⇒

```
  bash scripts/run-regress.sh --list "nightly A"   → 24종
  bash scripts/run-regress.sh --list "nightly B"   → 24종
  bash scripts/run-regress.sh --list                → 143종
```
표식은 하네스 제 머리, `// @regress` **바로 아래 한 줄**이다(있는 문법 그대로):

```

  // @nightly A   ← 야간 두 밤 분할(T220 · 소요로 균등) · `run-regress.sh --list "nightly A"`
```

### 래퍼 `scripts/nightly-split.sh` — **목록을 하나도 안 들고 있다**

단위는 **전수 − (A ∪ B)** 로 러너 출력끼리 빼서 얻는다 — `test-*` 는 단위라는 **이름 규칙을 안 믿는다**.

```
  bash scripts/nightly-split.sh A|B|auto [--list-only]
  → [야간 A] 단위 95종 + e2e 24종 = 119종  (전수 143종 · 묶음 A B)
```
· 어느 줄이든 비면 **거기서 죽는다**(조용한 빈 목록 금지) · A·B 에 **둘 다** 달린 것도 죽는다 ·
`auto` 는 날짜로 돌린다(묶음이 셋이면 사흘 주기 — **코드 무변**).

⚠실기 하나를 적어 둔다: 변수 이름을 `GROUPS` 로 썼다가 묶음이 늘 1개로 나왔다.
`GROUPS` 는 **bash 가 제 것으로 쓰는 이름**(현재 사용자의 그룹 id)이라 `GROUPS=()` 가 안 지워진다.
