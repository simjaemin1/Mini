# T134 — 주민 등짐 · 도구 축 통일 (2026-09-06)

T125 가 남긴 회부 둘을 닫는다. 둘 다 **필드는 이미 있었고**, 갈려 있던 것은 클라의 층 선택이었다.
게임 행동 변경 0 · 배포 자산 diff 0 · 굽기 0(시트에 이미 다 구워져 있다).

## 0. §0 실측 (셋) — **셋 다 카드 전제를 고쳤다**

### ⓐ 주민의 운반 상태 — 정본은 `_lifeAct` 라벨이 아니라 **`npc._carry`** 다

카드는 *"`_lifeAct` 라벨 '운반'/'저장'"* 를 지목했다. 그런데 그 라벨은 **곳간 과업 창 안에서만** 찍힌다
(`_lifeGranStep` — 사다리 앞에 섰을 때). 수확한 짐을 지고 밭에서 걸어 나오는 주민은 그 창 **밖**이면서
**짐은 지고 있다**. 상태가 곧 진실이다:

```
npc._carry   수확 +1 (`_lifeDo` 'harvest') · 곳간 인출 +q · 저장 0 · 귀가 0   ← 곳간② 물리 장부(회계 아님)
G_CARRY = 3  그 짐의 **상한**이지 상태가 아니다(카드가 이 이름을 상태로 불렀다 — 정정)
```

그리고 그 술어는 **이미 노출돼 있다**: `/lifedbg` 의 `carrying` 이 `_carry > 0` 인 주민 수를 센다
(`villages.js:3837`). 하네스가 서버 진실을 물을 자가 이미 있었다.

### ⓐ′ ★그런데 **갓 심은 마을에서는 아무도 짐을 안 진다** — 재고 넘어 실측

양성 갈래(지게를 진 주민)를 실클라에서 보려고 프로브를 두 판 돌렸다(레포 밖 `/tmp`):

| 프로브 | 조건 | 결과 |
|---|---|---|
| 1차 (180초) | 브라우저 **없이** | `carrying` 내내 0 · 라벨 전부 `·` · `on:0`(청크 비활성) |
| 2차 (150초) | 브라우저로 광장에 사람을 세움 | 생활 층은 **돈다**(actPct 8% → **77.5%**) · 라벨 출근·휴식·귀가 · **`carrying` 내내 0** · `granStock` 0 |

원인은 시계다: **세계 하루가 현실 24분**(`zone-config.WORLD.dayLengthMs`)이고 작물은 게임일이 걸린다.
`VILLAGE_DAY_MS` 는 **econ 일**만 빠르게 하지 생활 층의 하루는 안 줄인다. 150초는 하루의 **1/10** 이다.
⇒ 수확이 안 일어나고, 곳간이 비어 인출도 없다. **관찰 창 안에서 양성 갈래는 못 만든다.**
그래서 하네스가 **"통과"라고 말하지 않게** 했다 — §2 참조.

### ⓑ 도구 층은 시트에 **여섯**이 있다 (카드는 다섯이라 했다)

`char_meta.json` 의 `layers` 실측:

```
tool_axe · tool_rod · tool_hoe · tool_hammer · tool_spear · tool_basket      ← 여섯
body · clothes_{fur,ramie,leather,hide,fiber,hemp} · back_carrier
```

⇒ **굽기 0.** 표만 쓰면 된다.

### ⓒ ★사람의 도구 실루엣은 둘이 아니라 **하나**였다

카드는 *"사람은 도구 실루엣 둘(`tool_axe`·`tool_rod`)"* 이라 했다. 종전 코드는 한 줄이었다:

```js
if (t) L.push(/rod|fish|낚/i.test(t) ? 'tool_rod' : 'tool_axe');
```

사람이 실제로 들 수 있는 `tool` 문자열을 **전수로** 뽑아 보면 열이다:

| 출처 | 값 |
|---|---|
| `zone.RECIPES`(도구 인스턴스) | `axe` · `pickaxe` · `sword` · `saw` · `hammer` · `crude_axe` · `crude_pick` · `crude_blade` |
| 장비 슬롯 인스턴스(`player-items.ITEM_TYPES`) | `tool` · `weapon` |

**그중 `rod|fish|낚` 에 걸리는 것이 하나도 없다** — 낚싯대라는 품목이 이 게임에 없기 때문이다
(`grep` 전수: `fishing_rod`·`'rod'` 정의 0). ⇒ **곡괭이도 망치도 검도 톱도 전부 도끼로 그려지고 있었다.**
`tool_rod` 시트는 구워 놓고 **아무도 안 쓰는 층**이었다(주민 `fisher` 만 쓴다).

## 1. 한 것 (둘)

### ① 주민 등짐 — 새 필드 0

`server/zone.js makeEntry` 는 **같은 한 비트**다. 출처만 갈린다:

```js
e.carrier = o.isNpc ? (((o._carry || 0) > 0) ? 1 : 0) : (Carry.carrierOf(o) ? 1 : 0);
```

전송 창은 옷과 같은 무상태 델타(최초 가시 + `_wornAt` 뒤 1.2초)라, **0↔1 이 뒤집힌 순간에만** 도장을
찍어야 한다(매 틱 찍으면 창이 영영 안 닫힌다). 그 도장은 `npcLifeTick` 맨 위 세 줄이다:

```js
const on = (npc._carry || 0) > 0;
if (on !== !!npc._carryOn) { npc._carryOn = on; npc._wornAt = Date.now(); }
```

**클라는 한 줄도 안 고쳤다.** `charLayersFor` 가 이미 `!!(o && o.carrier)` 로 남의 지게를 본다 —
T125 가 층 함수를 하나로 합쳐 뒀기 때문에, 서버가 비트를 놓는 순간 주민에게도 그대로 걸린다(사본 0).

### ② 도구 축 통일 — 정규식 한 줄을 표로

`40-r2-sprites.js` 에 표를 놓고(직업표 옆), `charLayersFor` 가 그 표를 읽는다:

```js
const PLAYER_TOOL_LAYER = {
  axe: 'tool_axe', crude_axe: 'tool_axe',
  pickaxe: 'tool_hoe', crude_pick: 'tool_hoe',   // 곡괭이 ≈ 괭이 실루엣(판단 · 아래)
  hammer: 'tool_hammer',                          // ★새로 산다 — 종전엔 도끼로 그려졌다
  hoe: 'tool_hoe', spear: 'tool_spear', basket: 'tool_basket', rod: 'tool_rod',   // 품목이 생기면 그날 맞는다
};
```

**⇒ 사람의 실루엣이 1 → 3 이 됐다**(도끼 · 괭이 · 망치). 표에 없으면 종전 기본값(도끼)이라
**톱·검·장비 슬롯의 그림은 한 톨도 안 바뀐다.**

★**두 줄은 판단이다 — 밝혀 둔다.** `pickaxe`·`crude_pick` → `tool_hoe`. 곡괭이와 괭이는 다른 물건이지만
둘 다 **긴 자루 + 가로 날**이고 26px 에서는 같은 실루엣이다. 도끼로 그리는 것보다 참말이라 골랐다.
되돌리려면 표에서 그 두 줄을 지우면 된다(그러면 종전대로 도끼).
★**없는 것은 지어내지 않았다** — 톱·검은 시트에 없으므로 도끼 자리에 그대로 뒀다.

### ★양성 갈래를 **못 봤다** — 그리고 통과라고 부르지 않았다

`e2e-npcsprite ②″` 의 관찰 창에서 서버가 말한 '짐 진 주민'은 **0명**이었다(§0-ⓐ′ 의 그 이유).
음성 갈래(0 ⇒ 지게 없음)만 밟은 것이므로, 그 자리에 "통과"를 적는 대신 **글로 남기고**
양성은 **자 둘로 대신** 걸었다:

* ⓐ **주민과 사람이 지게를 같은 한 줄로 고른다** — 소스에서 그 줄을 정규식으로 확인한다.
  `const back = isMe ? !!(equipSlots && equipSlots.back) : !!(o && o.carrier);`
  갈래가 생기면 그날 빨개진다.
* ⓑ 그 줄의 **양성**(비트 1 → `back_carrier` 등장)은 `e2e-charsprite ⑤` 가 **사람으로 이미 잰다**
  (지게 진 남이 `body,clothes_*,back_carrier,tool_*` 로 그려지는 것을 본다).
* ⓒ 서버가 그 비트를 **`_carry` 로 놓는다**는 것과, **뒤집힌 순간에만** 창을 연다는 것도 소스로 건다.

⇒ 살아 있는 주민이 지게를 진 그림은 **아직 아무도 못 봤다.** 회부한다(§3).

### 덤으로 회부 하나를 닫았다 — 부하에 흔들리던 판정

`e2e-charsprite ⑤` 의 *"남이 걸으면 A 화면에서도 walk"* 는 `인계/회부.md` 가 이렇게 적어 둔 자리다:
*"부하가 걸리면 `clip=idle speed=0` 으로 빨개진다(T106 실측). … `clip` 이 walk 가 될 때까지 폴링하면
끝난다. **char 영역(T96) 손이라 세션이 안 만졌다.**"* — 이번엔 char 영역 카드라 손댔다.
한 판 읽던 것을 **최대 5초 폴링**으로 바꿨다(안 되면 그때 실패로 센다 — 감추지 않는다).
★실제로 이 카드의 1차 실행에서 그 줄이 빨갛게 났고, 폴링 뒤 사라졌다.
