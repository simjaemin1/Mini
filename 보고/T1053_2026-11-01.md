## §2 ② 글자 — 정본 문 하나 · 랩 식 그대로 · 새 수 0

```js
const T1053_DEFOREST_GAME = process.env.T1053_DEFOREST_GAME !== '0';
const L_DEFOREST_H = 12;    // 랩 19406 그대로 — 집 주변 벌채 반경(±셀 · 정사각 · "5→12 §3b 실축")
const L_DEFOREST_GRAN = 3;  // 랩 19241 그대로 — 곳간 자리 벌채 반경(`deforestArea(s,g.cx,g.cy,3)`)
function _t1053Deforest(vil, cx, cy, rad) {
  if (!T1053_DEFOREST_GAME || !vil || !vil._gameRich) return 0;
  let n = 0;
  for (let dx = -rad; dx <= rad; dx++) for (let dy = -rad; dy <= rad; dy++) if (huntDeforest(vil, cx + dx, cy + dy)) n++;
  _t1053Stat.cells += n;
  return n;
}
```

* **훑음 = 랩 `deforestArea` → `deforestCell`** — ±rad 정사각을 1칸씩 지나며 그 셀 열쇠를 장부에서 지운다(`huntDeforest` = `m.delete(cx+','+cy)` — 랩 `s.gameRich.delete`). 장부는 랩처럼 2칸 표본이라 표본 밖 칸은 `delete` 가 거짓(지운 칸 셈에 안 든다). 셀 좌표는 부르는 자리가 가진 그 셀(`_site` · `_granPend` · 개간 셀) — 랩과 같은 셀 단위.
* **장부를 다 지은 순간 한 번**(`_t1053Developed` — 집 `_houseCells` ±12 · 집터 셋 `_site` · `_psite` · `_pendSite` ±12 · 곳간 `_granList` ±3 · 착공 `_granPend` ±3 · 밭 `_farmSet` 그 셀): 랩은 정착(`setupVillage` 20233 집 · 20242 첫 논밭)이 장부(20277)보다 먼저라 개발된 칸이 처음부터 장부에 없다. 서버는 장부를 며칠에 걸쳐 짓고(T146 · T1013) 그 사이 마을이 이미 서 있으니, 다 지은 그 순간 지금 개발된 칸에 같은 식을 한 번 — **`_gameTot0`(기준 총량) 앞**이라 그 칸은 랩처럼 처음부터 장부 밖이다(`land.game` 비율이 1 에서 시작). 다 지워져 장부가 비면 종전 "숲 없음" 길(`_gameNone = 1`).
* **끔**(`=0`) — 문 첫 줄에서 돌아간다 · 장부 지을 때 줄도 손잡이 뒤 = 부르는 자리 0 = 종전 바이트(기준선 끔 같음 3/3 · §4-2).
* **저장** — 장부는 마을 행 곁 칸 `_t728Game` 이라 지운 칸도 그 행에 실린다(생활층 일 = 주기 저장 · 의뢰 집터 = T1005 순간 저장 `t1005Save(vil, 'house')` 가 `lifeRequestPlayerSite` 바로 뒤).
