## 2. 무엇을 지었나

### 새 파일 `server/rescue.js` — **판정을 하나도 안 짓는다**
마을 반경 `SimVillages.shelterAt` · 물/바다 `isWaterTileLocal`/`isSeaTileLocal` · 먹기 `doEat` ·
방위말 `Onboarding.dirWord` · 이름표 `ITEM_LABEL_SERVER` · 먹을 것 `FOOD_EFFECTS` —
**전부 남의 정본을 부른다.** 이 파일이 새로 만드는 것은 **소리**와 **두 동사의 문법**뿐이다.

zone 접점은 넷이다: `require` · `Rescue.init({…})` · `handleChat` 1줄 · `damagePlayer` 의 쓰러짐 블록에 1줄.
⚠이름표만 **함수로** 받는다 — `ITEM_LABEL_SERVER` 는 작물·특산을 흡수한 뒤 **`Rescue.init` 보다 늦게**
완성되므로 값으로 넘기면 빈 표를 붙든다(부팅 순서에 물린 자리다 · 실제로 한 번 터졌다).

### ① 외침 — 야생에서만, 걸음으로, 촌장과 같은 어휘로
```
  🗣️ 여행자이(가) 쓰러졌다 — 해 지는 쪽 150걸음
```
* **야생만.** 마을 안에서는 안 외친다 — 부를 사람이 이미 있고 거기선 죽지도 않는다(§12).
  판정은 추위가 쓰는 **완충 정본** 하나(`shelterAt > 0`)다.
* **걸음.** 1걸음 = 1셀 = 1m = 32px(실축화 캐논) — **새 환산을 안 만들었다**. 겉은 계단(가까우면 촘촘히).
* **방위.** `onboarding._DIRWORD` 를 `dirWord` 로 **내보내 부른다**. 같은 8방 표를 두 벌 두면
  "촌장은 해 지는 쪽이라는데 외침은 서쪽"이 된다(§9.5 어휘가 하나여야 한다).
  ⇒ 지시서의 예문 *"서쪽 40걸음"* 은 이 세계의 말로 **"해 지는 쪽 40걸음"** 이 됐다.
* **주사위 0.** (지금, 쓰러진 자리, 내 자리)의 순수 함수 — 같은 상황이면 **글자까지 같다**.
* **시계는 스스로 든다.** 쓰러진 사람이 0 이면 시계도 없다(`unref`). 30초에 한 번 도는 일을
  zone 의 30Hz 틱에 얹지 않는다.
* **장부 무접촉**(PM 판정 ⑴).

### ② 구조 동사 둘 — 채팅 명령(클라 코드 **0줄** · T11 선례)
```
  /먹이기 <음식>   옆(80px)의 쓰러진 사람에게 **내 인벤의** 음식을. 창이 지났으면 거절.
                   키도 한글 이름표도 받는다. 인자가 없으면 가진 것을 알려 준다.
  /물              물가에서 **손으로 떠** 먹인다(+35 = 정본 한 모금 `WATER_DRINK_AMOUNT`).
```
★★**`/물` 은 갈래가 둘이다** — 리베이스 도중 **T54(갯벌 3차)가 민물 휴대를 열었기 때문이다.**
초안은 *"이 세계엔 물병에 민물을 담는 동사가 없다(T52 회부 A)"* 를 전제로 **물가 갈래 하나**만
만들었는데, 그 회부가 같은 날 T54 로 닫혔다. ⇒ 전제가 바뀌었으니 동사도 따라간다:
```
  ⓐ 들고 온 물이 먼저다   내 인벤에 `fresh_water` 가 있으면 → **`doEat` 한 문으로** 먹인다.
                          회복량도 빈 병 반납도 표가 한다(여기서 안 짠다) · 물가가 아니어도 된다.
  ⓑ 손이 비었으면        물가에서 **손으로 떠** 먹인다(+35 = `WATER_DRINK_AMOUNT`).
                          그러자면 쓰러진 사람을 **업어서 강가로 옮기게 된다** — §12 의 "불가로 옮기기"다.
```
★★**빈 병은 준 사람 손에 남는다**(`doEat` 의 `returns` 는 주는 쪽) — 물을 먹여 주고 병까지 넘어가면
그건 **주기(give)지 먹이기가 아니다**. "물건은 주는 쪽, 몸은 받는 쪽"이 이 함수의 규약이고, T54 의
`returns` 계약(병 개수 보존)이 그 규약 아래서 그대로 산다. `test-downed ⑬` 이 준이 1 · 받은이 0 으로 못 박는다.
★**짠물은 못 먹인다**(T4 의 판정을 다시 부른다). 그리고 *"물이 없다"* 가 아니라 **"짠물이다"** 라고 말한다.
★민물 품목 id 는 `tidal.FRESH` 를 **rescue.js 가 직접** 묻는다 — zone 을 거치지 않는다:
zone 이 갯벌 정본을 부르는 자리는 **셋으로 못 박혀 있고**(`test-tidal` 이 T54 의 예산을 지킨다),
초안이 `Rescue.init` 에 한 줄을 얹었다가 그 하네스가 **넷째 줄을 잡아냈다**(고쳤다).
★자격은 T43 과 같다 — **소속을 안 본다**(열쇠가 없다). 게이트는 거리와 창뿐이다.

### ③ 먹이기는 **먹기와 같은 함수다** (`doEat` 에 대상 인자 하나)
```
  doEat(player, item, amount, who)          who 기본값 = player  ⇒ 종전 호출은 한 글자도 안 바뀐다
    · 인벤 · 로트 FIFO · kg 원장 · 신선도 · 탈  →  **player**(주는 사람)
    · 허기 · 갈증 · HP · 사기 · 약초           →  **who**(받는 사람)
```
두 벌이 되면 **로트 FIFO 와 부패 판정이 갈린다** — "먹여 줬는데 왜 상한 게 안 셌지"가 나는 자리다.
★"섭취했다"는 **받는 사람**의 말이라 알림도 그쪽으로 간다.

### ④ 후유증이 화면 재료로 나간다
`Body.selfPayload().aftermath = { days, cap }` (없으면 **`null`** — 0 을 보내면 화면이 "0일 남았다"는
없는 말을 한다). **새 계산 0**: 두 수는 `tick` 이 스태미나 상한을 누르며 이미 구한 값이고 여기선 메모다.
★지시서는 "vitals 페이로드"라 했지만 `serializeBody().vital` 은 **클라에 안 간다**(저장·핸드오프용) —
거기 넣으면 죽은 필드가 되므로 **화면이 실제로 받는** 몸 페이로드에 넣었다. 무들 한 칸은 T55 뒤(회부).

## 4. ⓔ 더위 실측 — **온도로는 성립하지 않는다** (구현 금지 · 회부 B-1 갱신)

```
  24년 × 낮·밤 = 17,520 표본 · 고도 0(설 수 있는 유일한 고도)
    앵커      여름낮 29℃ · 여름밤 19℃ · 겨울낮 5℃ · 겨울밤 −5℃
    최고      **33.69℃** (17년차 141일 낮) · 연도별 최고 **28.88 ~ 33.69℃**
    29℃ 초과 712회(4.06%) · 32℃ 초과 76회(0.43%) · **35℃ 초과 0회**
```
`coldOfC` 의 표는 **29℃(=여름낮 앵커)에서 끝난다**. 그 위로 이 세계의 기온은 **4.7℃ 밖에 더 안 올라간다**.
그 폭에 0→1 을 욱여넣으면 **여름 낮이 매년 극단**이 되고, 넓게 잡으면 **24년에 한 번도 안 닿는다**.
추위는 −5℃ 아래로 외삽할 여지가 있었지만(T44 천장 해제) **더위는 위쪽이 33.7℃ 에서 끝난다** — 여지가 없다.

⇒ 열려면 **온도가 아닌 축**이어야 한다. 한반도 여름의 실제 위험은 열사병보다 **탈수와 노동**이고,
그 축은 이 세계에 **이미 있다**(갈증 · r=0.046296 HP/게임분). **여름철 갈증 배율 하나**가
"더위 축 신설"보다 고증에도 §7(죽음의 나선 방지)에도 가깝다 — 새 축 0, 디버프 표 무변,
물·그늘이라는 **이미 있는 동사**가 답이 된다. **판정은 재민 몫이다.**
