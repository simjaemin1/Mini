## §0ⓑ 밭이 삼킨 배율의 **크기** — 실측

끈 팔에선 안 심긴다. 켠 팔(`T100_FIELD_YIELD=1` · 시드 42 · 5마을 400일)에서 농부들의 배율:

|---|---|---|---|---|
| 64명 | 0.2625 | 0.9333 | 1.3440 | **5.12배** |

대체는 이 **5.12배 폭**을 전부 평평하게 눌러 놓고 있었다 — 굶는 마을의 맨손 초보 농부와
도구 갖춘 숙련 10 농부가 수확 한 번에서 **똑같은 식량**을 거뒀다. 값 판정이 아니라 **자리 결함**이다.

## §1 옮김 — 밭만(죽은 문만 · T172 와 같은 자리)

```js
function harvestToGranary(v, n, mul) {                      // ← 문은 **양**(n)과 **배율**(mul)을 따로
  if (!T100_FIELD_YIELD || !v || !v.storage) return 0;
  const _m = (typeof mul === 'number' && mul >= 0) ? mul : 1;   // 미전달·음수·NaN = 1 → 종전 비트
  const amt = ((n > 0 ? n : 1)) * T100_K * _m;                  // 배율이 물리는 줄은 **여기 하나**
  ...
  v._t100HarvestN += (n > 0 ? n : 1);                           // 건수는 배율에 **안 물린다**
```
```js
if (!(T100_FIELD_YIELD && npc.currentJob === 'farmer')) addProduce(jdef.output, baseAmt);
else npc._t172mul = skillMul * toolBoost * inputMult;       // ← 걷어낸 자리에 배율만 **심어 둔다**
```

* 사냥·벌목 문과 **같은 필드**(`_t172mul`)다 — 정본 하나, 사본 0. 농부는 `jobScale === 1` 이라 배율은 셋뿐.
* **여기서 곱하지 않는다.** 곱하면 이중이다(배율은 실체가 나는 곳에 한 번).
* 채집·석재는 **한 글자도 안 고쳤다**(살아 있으니 표만 · 카드 ②).
