### ⓑ `test-icons.js:488` 이 `_` 키를 거른다

```js
const META = (k) => String(k).startsWith('_');
const anK = Object.keys(AN).filter((k) => !META(k)).sort(), …
```

**자명 통과 금지** — 거르는 줄이 *다른* 여분 키까지 눈감지 않는가:
`{...AN, _상자:…}` 는 **88 = 88**(거른다) · `{...AN, zzselftestghost:…}` 는 **89 ≠ 88**(**문다**).

⚠**그 시험을 처음엔 `__selftest_ghost__` 로 적었다가 빨개졌다** — 주입 키가 `_` 로 시작하니
거르는 줄이 **시험까지 먹었다**(88≠88). 시험이 자기를 못 무는 꼴이었고, 하네스가 그걸 잡아 줬다.
주입 키를 `zzselftestghost` 로 바꿔 고쳤다.

실제로 앵커에 `_상자` 를 싣는 것은 **다음 굽기 카드**다(이 카드는 길만 열었다).
