…  if (JOB_RES[j].includes(r.type))   ← 버킷은 이 한 줄로 거른다

동사(`RESOURCE_VERBS` · T90 서버 정본): `sapling: '벌목'` 하나만 더했다.
**그루터기는 동사 표에 없다** — 캘 수 없어서 `RESOURCE_HP_TABLE` 에도 없고(hp 0 으로 난다),

클라는 이름 목록이 아니라 **물리**로 거른다: `if (!(t.obj.maxHp > 0)) return out;`
