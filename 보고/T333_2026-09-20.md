## 1. ① 미리 굽기 — "처음 밟는 셀" 을 없앤다

T324 가 남긴 표를 먼저 갚는다. 메모를 켠 팔에서 **지형 함수가 쓴 36.7초를 누가 불렀나**(호출자 귀속):

| 부른 자리 | 몫 | 정체 |
|---|---:|---|
| `isRockTileLocal@zone.js` | **54.5 %** | 메모 **적중 실패**(처음 밟는 타일) |
| `isWaterTileLocal@zone.js` | **35.4 %** | 같음 |
| **`isRock@villages.js`** | **9.6 %** | **메모를 아예 안 지나간다**(직통 호출) |
| 나머지(청크 생성·작물·낚시) | 0.5 % | 한 번씩 |

⇒ 고칠 것이 둘로 갈렸다. **90 %는 "아직 안 구운 칸"**, **9.6 %는 "굽는 데를 안 지나가는 호출"**.

**ⓐ 안 지나가는 호출** — `villages.js` 지형 어댑터의 한 줄:

```js
// 전: terrain.isRockCellLocal(zoneId, px(cx), px(cy))    ← 메모 통과 0
// 후: deps.isRockTileLocal(px(cx), px(cy))               ← 존의 술어(= 메모 뒤) · 같은 셀 중심 · 같은 답
```

**ⓑ 아직 안 구운 칸** — `terrain-tilecache.prebake(상자, 물함수, 바위함수)` 하나를 더하고,
부팅 때 **마을 생활권 상자 50곳**을 통째로 굽는다(반경 = `_maxRPx + 1600` — `anyViewerNear` 가 쓰는 그 수 · 새 수 0):

```
[hanbando] 🗺️ 지형 미리 굽기 — 마을 50곳 상자 · 3,665,553칸 · 61,018ms
```

| | 값 |
|---|---:|
| 구운 칸 | **3,665,553** (전 존 8.9M 의 41 %) |
| **부팅 추가 시간** | **61.0 초** |
| 칸당 | 16.6 µs (런타임 산발 호출 42.7µs 보다 싸다 — 국소성) |
| 정상 구동 중 지형 몫 | **17.9 % → 0.1 %** |

⚠**전 존을 굽지 않는다** — 8.9M칸 × 42.7µs ≈ 6분 이상이다. 걷는 자리만 굽는다.
⚠값은 정의상 같다(같은 함수·같은 인수). `test-terrain-memo ⑤` 가 **미리 구운 판 ↔ 그때그때 구운 판**을
13,122칸(그 상자에 강이 지난다 — 물 501칸) 전수 대조해 0 다름을 건다 + 두 번 안 굽기 + 격자 밖 0칸.
