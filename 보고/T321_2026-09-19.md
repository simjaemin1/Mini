# T321 — 어부의 소리 · 낙하 · 어부 다섯 probe (세션9/SOUND · 2026-09-19)

## 결론 (머리 15줄)

1. **카드가 시킨 "던짐→입질→걸림 셋을 차례로"는 못 한다 — 그 순간들이 없다.** NPC 어부의 한 시도는 **한 틱**이다: 종 추첨·셀 예산·장부가 같은 순간에 끝난다(`villages.js` 8초 게이트 안).
2. **플레이어 낚시에는 그 창이 있다**(`biteAt`·`windowMs` · `fish_state` 가 'wait'→'bite' 로 **두 번** 온다). NPC 경로에는 **없다**. 대조를 하네스가 둘 다 잰다(`⑫d`·`⑫e`).
3. **그래서 셋을 차례가 아니라 결말로 붙였다.** 한 시도의 결말은 **코드가 이미 셋으로 갈라 놓았다**: 안 물림(`!_sp`) → `cast` · 물고 놓침(`_got<=0`) → `bite` · 건짐(`_got>0`) → `hook`. 키 셋이 다 쓰이고, **없는 시간을 지어내지 않았다**(족보 226).
4. **서버 diff 실효 2줄**(`_lifeAct` 낱말 둘 — `'드리움'`·`'놓침'`. `'낚음'` 은 T312 가 이미 세우고 있었다). 새 메시지·새 칸 **0** — 낱말은 `zone.js makeEntry` 의 `e.act` 를 그대로 탄다.
5. **클라 훅 줄 0.** `recv` 가 `handleMessage` **머리**에서 불리므로 그 순간 `c.others` 에는 아직 **직전** 값이 있다 ⇒ 거기서 바로 모서리를 잡는다. `30-n-net.js` 에 줄을 안 더했고 `test-audio ⑦c`(파일당 훅 하나)가 그대로다.
6. **모서리로 잡아야 하는 이유가 실측으로 잡힌다**: 라벨은 1.2초 창 동안 같은 값이 **최대 25틱** 온다. 값이 왔다고 울리면 한 번 낚고 **스물다섯 번** 난다 — T292-b 와 똑같은 모양의 사고다. `⑮` 가 25틱 먹여 **1** 을 확인한다.
7. **첫 가시에는 안 운다**는 계약도 못 박았다(`⑭`). `_lifeAct` 는 **머무는 칸**이라 10초 전에 낚은 어부도 여전히 '낚음' 이다 — 시야에 들어왔다고 울리면 **일어나지 않은 일이 들린다**.
8. **`cast`·`bite`·`hook` 에 반경을 줬다(0 → 384).** T283 은 이 키를 **내 낚시**에만 걸어서 반경 0(감쇠 없음)이 맞았다. 이제 **남의 자리**에서도 나므로 반경이 없으면 지도 반대편 어부가 귓가에서 낚는다 — **T292-b 의 `axe` 가 정확히 그 결함이었다**.
9. **낙하는 배선으로 같아진다.** 버리기도 죽어 쏟기도 `ground_item_added` **한 방송**으로 나온다(`zone.js:7728`). 층은 사람인지 주민인지 **묻지도 않는다** ⇒ 죽은 어부의 고기는 플레이어가 떨어뜨리는 그 소리로 난다. 새 경로 0 · 표 한 줄.
10. 낙하 키는 **새 키 0** 규약대로 있는 키에서 골랐다 — `bronze_hit`(출처가 말 그대로 **Dull thud**). ⚠**곡괭이질과 한 소리를 나눠 쓴다** ⇒ 아니면 표 한 칸(회부 ①).
11. **어부 다섯 동시 실측**: 피크 **−0.20 dBFS · 클리핑 0**. 리미터 **없이는 +3.75 dBFS · 클리핑 46** 이었다.
12. ⇒ **어부 마을이 이 게임에서 리미터가 실제로 값을 하는 첫 조합**이다. T292 가 "최악 조합조차 문턱을 안 넘는다"(0/400창)고 쟀던 것과 달리 이 조합은 **5/400 창**에서 문다.
13. **수신에서 셌다**(족보 226). 진짜 `__sfx.recv` 에 진짜 모양의 `tick` 을 먹이고 `stat.played` 증분을 센다 — 세계를 안 띄우고 층의 계약을 그대로 잰다.
14. `test-audio` **89 → 105** · `e2e-audio-probe` **16 → 26** · `test-fish-act` 37/0(무접촉 확인) · `test-harness-lint` 42/0 · `test-client-globals` 26/0(새 전역 0) · `e2e-weather` 31/0 · `lab-modules` 교집합 ∅.
15. **자를 네 번 헛짚었다 — 셋은 주석에, 넷째는 보고에 남겼다** — 기대값을 이름·직관에서 뽑았고, 세 번 다 **잰 값**이 답이었다(아래 ⓔ).

## ⓐ 훅 셋 — 차례가 아니라 결말

`server/villages.js` 어부 자리(한 곳 · 실효 2줄):

```js
const _sp = _fresh().pick(...);
if (!_sp) _lifeAct(npc, '드리움');      // ★[T321] 아무것도 안 물었다
if (_sp) {
  ...
  if (_got > 0) { ...; _lifeAct(npc, '낚음'); }   // 건졌다 (T312 부터 있던 낱말)
  else _lifeAct(npc, '놓침');                      // ★[T321] 물었는데 셀 예산이 비었다
}
```

| 결말 | 조건 | 낱말 | 키 |
|---|---|---|---|
| 아무것도 안 물었다 | `!_sp` | `드리움` | `cast` |
| 물었는데 못 건졌다 | `_sp && _got <= 0` | `놓침` | `bite` |
| 건졌다 | `_got > 0` | `낚음` | `hook` |

셋은 **서로 배타**다(`⑫c` 가 지킨다) — `_lifeAct` 가 덮어쓰는 칸 하나라 한 틱에 둘이 서면 마지막만 남는데, 배타라 그 성질이 해가 안 된다.

**왜 차례로 못 하나** — `⑫d`·`⑫e` 가 이 전제를 **자로** 잡아 둔다:

```
⑫d 전제: NPC 어부 자리에 대기 창(biteAt/windowMs)이 없다   → 창 0 · 한 시도 = 한 순간
⑫e 대조: 플레이어 낚시에는 그 창이 있다                      → biteAt 은 zone.js 에 있다
```

세계가 NPC 에게도 대기 창을 주면 **⑫d 가 빨개진다**. 그때 소리를 차례로 바꾸면 된다 — 지금 지어내지 않는다.

## ⓑ 낙하 — 묻지 않아서 같아진다

```js
if (t === 'ground_item_added') { sfxPlay(_sfxMan.groundDrop.key, { x: gi.x + ox, y: gi.y + oy }); }
```

층에 `isNpc` 도 `npc` 도 **없다**(`⑫k` 가 그걸 잰다). 같은 방송 하나라 배선으로 같은 소리다. `test-fish-act ⑤` 가 이미 못 박아 둔 것과 맞물린다 — *죽은 어부의 손에 든 것은 플레이어 낙하 함수 그 자리로 간다(새 경로 0)*.

## ⓔ 자를 세 번 헛짚었다 — 세 번 다 잰 값이 답이었다

1. **첫 가시가 울 줄 알았다** — `⑭` 를 "낱말이 오면 운다"로 짰다가 0 이 나왔다. 코드가 옳았다: 라벨은 **머무는 칸**이라 첫 가시의 '낚음' 은 이미 지난 일이다. ⇒ 기대값을 고치고 **그 계약을 단언으로 승격**했다.
2. **쿨다운 탓인 줄 알았다** — `⑯` 이 3 대신 2 여서 쿨다운(200ms)만큼 쉬게 했는데 그대로 빨갰다. 진짜 범인은 **`maxSame` + 표본 길이**(`hook.ogg` 1.099초)였다. ⇒ 쉬는 시간을 **표본 길이**에서 뽑고, 토막 안에서 `blocked` 가 0 인지 **함께 재게**(`⑯a`) 했다 — 칸막이가 새면 그 자가 거짓말하므로.
3. **설정과 측정을 두 번에 나눠 불렀다** — `feed` 가 부를 때마다 새 `c` 를 만드는데 그걸 잊어 다섯이 다시 첫 가시가 됐다(0). ⇒ 한 번에 먹인다.

세 번 다 같은 병이다: **기대값을 이름·직관에서 뽑고, 코드가 아니라 자를 의심했다.** T305 의 "줄은 이름이 아니라 잰 값으로 고른다"와 한 줄기다. 셋 다 하네스 주석에 경위를 남겼다.

## 회부

**① [재민 귀] 낙하 소리가 곡괭이질과 같은 키다(`bronze_hit`).** 새 키 0 규약이라 있는 키에서 골랐고, 그 출처가 말 그대로 *Dull thud* 라 바닥에 닿는 소리로는 표에서 가장 가깝다. 다만 한 소리가 두 뜻을 진다. 아니면 `groundDrop.key` **한 칸**이다(코드 0). 전용 음원을 받을 값이 있으면 세션8.
**② [PM/세계] NPC 어부에게 대기 창을 줄 것인가.** 주면 '던짐 → (기다림) → 입질 → 걸림' 이 **진짜 순서**가 되고 소리도 그 순서로 난다. 문법은 이미 있다 — 플레이어의 `biteAt`·`windowMs` 그대로다. 안 주면 지금 배선이 정답이다. `test-audio ⑫d` 가 그 전제를 지키고 있으니 세계가 바뀌는 날 저절로 빨개진다.
**③ [세션9 자기점검 · 안 낸 회부] 하마터면 거짓 회부를 낼 뻔했다.**
