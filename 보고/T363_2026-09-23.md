### ★왜 2번이 지우기를 막나 — 술어가 하나뿐이다

```js
// server/central.js:385
const stmtGetAccountByName = ... 'player_id = ? OR name = ?' ... AND password_hash IS NOT NULL
function findAccount(username) { ... }
```

| 문 | 쓰는 술어 | 승계 계정(`player_id ≠ name`)을 잡나 | 비밀번호가 필요한가 |
|---|---|---|---|
| `POST /check_username` | **`findAccount`** | ✅ | ✗ |
| `POST /auth` | `findAccount` | ✅ | **✅** |

⇒ *"비밀번호 없이 · 승계 계정까지"* 를 답하는 문은 **이것 하나**다. 그게 이 문의 값이자 이 문의 죄다.
게스트 갈래는 그 답이 필요하고(비밀번호가 없으니까), 바깥은 그 답을 가지면 안 된다.
**같은 문을 안으로 옮기면 둘 다 선다.**

### 클라 흐름 — 문을 닫으면 로비가 어떻게 되나
