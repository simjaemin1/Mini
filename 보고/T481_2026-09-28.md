### ⓑ-2 어떻게 — 잠금표 `_갈래` 한 칸 + 클라 한 줄

**잠금표**(`public/assets/icons.lock.json` · `icons` 바로 뒤 · 발췌):

```json
"_갈래": {
  "_": "[T481] 특산 갈래 대표 그림 — 제 그림이 없는 econ 특산 품목이 제 갈래의 대표 그림을 빌린다 · 라벨은 제 이름 …",

  "forest":  { "_": "소나무 성목 — …", "icon": "grp_forest", "items": [ … 24 ] },
  "mineral": { "_": "있는 그림 `ore` …", "icon": "ore",        "items": [ … 23 ] },
  "spice":   { "_": "약초 풀 — …",     "icon": "grp_spice",  "items": [ … 21 ] },
  "goods": { "icon": null, "items": [ … 19 ] }, "livestock": { "icon": null, … }, "jewel": …, "marine": …, "gem": …
}
```

* `items` 는 **손으로 안 적었다** — 특산 표에서 뽑았다(그 갈래 중 `icons/<키>.png` 가 없는 것 · 스크래치 `make_galrae.js`). `icon: null` 다섯은 대표가 없다(§ⓒ) — 재민이 고르면 **그 칸 하나**만 채우면 된다.
* `_` 로 시작하는 칸이라 `asset-lock.js` 의 무리(디렉터리) 밖이고 `--write` 가 보존한다 · `test-icons ⑧`(무리 행 = 파일 전수)도 안 건드린다(전제 대조 ①).

**클라**(`public/client/43-i-icon.js` · `itemIconImg` 바로 뒤 · 한 줄):

```js
if (typeof fetch === 'function' && typeof Image === 'function') fetch('/assets/icons.lock.json').then((r) => (r.ok ? r.json() : null)).then((L) => { for (const g of Object.values((L && L['_갈래']) || {})) { if (!g || !g.icon || !ICON_RENDERED.has(g.icon) || !Array.isArray(g.items)) continue; for (const k of g.items) { if (ICON_RENDERED.has(k)) continue; const im = new Image(); im.onload = () => { ITEM_ICON_IMG[k] = im; }; im.src = '/assets/icons/' + g.icon + '.png'; } } }).catch(() => {});
```

* 물건 그림은 여전히 **함수 하나**(`itemPic` → `itemIconImg` → `ITEM_ICON_IMG[k]`)다 — 짐 창·제작 목록·핫바·게시판·곁 창 표·바닥 낙하물(캔버스)이 전부 같은 자리를 읽는다. 이 줄은 그 표에 **빌린 그림**을 얹을 뿐이다.
* **제 그림이 있는 키는 안 덮는다**(`ICON_RENDERED.has(k)`) · 대표가 구운 목록에 없으면 요청하지 않는다(404 0) · 잠금표가 안 오면 종전 그대로 점선 칸이다.
* 라벨은 부르는 쪽이 그대로 `itemKo(k)` 로 쓴다 — 이 줄은 이름을 안 만진다.
* 같은 규약의 앞선 예: `00-const.js` 가 `crops_anchors.json` 을, `40-r2-sprites.js` 가 `tree_species.json` 을 **자산 JSON 한 번 fetch** 로 읽는다.
