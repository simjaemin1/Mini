## §0-ⓑ 기근 판정 — 엔진의 판단을 **읽는다**

굶주림 술어는 `sim/economy-sim.js` 의 인구식 **안에** 인라인으로 산다
(`surplusEMA.food < 0 && totalFoodEquivalent(v) < N×3` · `foodGap > 0`) — 밖으로 안 나온다.
그리고 `sim/**` 은 이 카드가 못 건드린다(econ 무수정).

⇒ 그런데 그 식이 **자기 판정을 매일 적어 둔다**: `v._dpDebug.hunger`(= `_hungerTerm`).
**음수면 그날 인구식이 굶주림으로 사람을 깎았다**는 뜻이다. 그 **부호 하나가 곧 기근**이다.

```js
function villageFamine(vil) {            // server/villages.js
  const d = vil && vil.econ && vil.econ._dpDebug;
  if (!d || !Number.isFinite(d.hunger)) return false;   // 아직 하루도 안 돈 마을 — 모르면 막지 않는다
  return d.hunger < 0;
}
```
**술어를 옮겨 적지 않았다.** 옮기면 그게 사본이고, 문턱(N×3)이 바뀌는 날 둘이 갈린다.
