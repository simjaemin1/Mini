## 0. §0-ⓐ — 순간이동 뒤 **어느 표가 낡았나**: 하나도 안 낡았다

카드는 쿼드트리·활성 청크·가시성 캐시·`act` 창 넷 중 어느 것인지 재라고 했다. **넷 다 멀쩡했다.**
관문을 층층이 떠서 갈랐다(Playwright `framereceived` 로 선을 직접 봤다):

| 관문 | 실측 | 판정 |
|---|---|---|
| 쿼드트리 | `rebuildSpatialIndex()` 가 **매 틱** `players` 로 새로 짓는다 | 안 낡는다 |
| 활성 청크 | `updateActiveChunks()` 도 **매 틱** 산 좌표로 갱신 | 안 낡는다 |
| 서버 송신 | A 가 받은 tick 의 pid 들 = `["p1","p2"]` | **짝을 보낸다** |
| 클라 수신·적재 | A 의 `renderables` player 자리 = [자기, 짝] | **싣는다** |
| 그리기 | `__charDbg` 엔 `["p1"]` 뿐 | ← **여기서 끊겼다** |

끊은 줄은 그리기 **직전**이다(`34-m-renderloop.js` player 가지):

```js
  if (!item.isMe) { vis *= entityVisibility(item.ax, item.ay, d); if (vis < 0.05) continue; }
```

`coneMultEntity` 는 **80px 안이면 무조건 보이고**, 그 밖은 페이싱과의 내적이 −0.2 이하면 **0** 이다
(`20-r2-visibility.js` — 그 파일이 *"이건 안개와 **다른 시스템**"* 이라고 이미 적어 뒀다).
하네스는 짝을 `SPOT + 60` 으로 보냈는데 그건 ⓪ 의 자리고, ①~③ 이 A 를 걷게·달리게 해 놔서
그때 A 는 SPOT 에서 **140~190px** 밀려나 있다 ⇒ 짝은 A 로부터 **110~150px(80px 밖)**, 그리고 A 의 **뒤**.

**⇒ 제품 무접촉.** `teleport_debug` 는 한 글자도 안 고쳤다(그 문으로 배치를 잡는 하네스 25개가
영향을 안 받는다는 뜻이기도 하다). 수리는 **하네스 한 줄**이다: 짝을 A 의 **지금 자리** 옆 60px 에
세운다 — 60 < 80 이 근거다. 이 절을 처음 쓴 사람도 그럴 뜻이었다(`sp = await meAbs(A)` 를 받아
놓고 안 썼다). 그리고 왜 그런지 화면에 말하도록 **상황 줄**을 하나 세웠다:
*"짝이 A 의 무조건 보이는 반경(80px) 안에 있다"*.

### ★T81 의 귀속을 정정한다

T81 보고·`인계/R2` 는 이 빨강을 *"`teleport_debug` 가 쿼드트리를 다시 색인하지 않는다"* 로 적었다.
**틀렸다.** 그때 관문 셋까지만 보고(서버 송신을 안 봤다) 멈췄다. 카드가 되받아 준 덕에 다시 쟀다.
두 문서 다 고쳤다.

## 1. 작업

**② 손에 든 것 · 등에 진 것** — `makeEntry` 에 두 줄(옷과 같은 창):

```
  e.tool    = getEquippedTool(o).type      서버 정본 술어(zone.js:958)
  e.carrier = Carry.carrierOf(o) ? 1 : 0   서버 정본 술어(carry.js:275)
  창을 여는 곳 둘: sendEquipment(옷·지게) · doEquip(손에 든 것)  → `_wornAt`(옛 `_clothesAt` 을 넓혔다)
```

클라는 **갈래를 없앴다** — `charLayersFor(isMe, o)` 하나가 자기 것이든 남의 것이든 같은 규칙으로
고른다. 다른 건 값을 어디서 읽느냐뿐이다(나는 내 장비에서, 남은 tick 이 실어 온 값에서).
종전의 `if (!isMe) return L` 은 사라졌다. 순서 = **몸 → 옷 → 등짐 → 손**.

**③ 등짐 층 `back_carrier` 5장** — 형태 정본은 `props_render.py` 의 `m_carrier()`
(그 파일이 *"등에 진 모습은 **캐릭터 시트 규약**이라 여긴 안 만든다(회부)"* 라고 적어 둔 자리를 닫았다).
재질도 그 파일 값을 베꼈다(`p_haft` · `p_fiber` · 출처 주석). 리그는 강체 `spine`(도구가 `handR` 인 것과 동형).

**방향 표**(idle 프레임 0 · 실측):

| 방향(행) | 0(+x) | 1 | 2 | 3 | **4** | **5** | **6** | 7 |
|---|---|---|---|---|---|---|---|---|
| 등짐 화소 | 46 | 47 | 38 | 78 | **125** | **129** | **119** | 79 |
| 그중 밀삐 | 32 | 19 | 19 | 26 | 2 | 1 | 2 | 26 |

등을 보이는 쪽은 **틀이 통째로**, 앞을 보는 쪽은 **거의 어깨끈만**(46 중 32가 밀삐).
홀드아웃이 몸이라 저절로 그렇게 된다 — 도구 층과 같은 규약이라 새 술어가 0이다.

⚠**두 번 되물렸다**(실측이 시켰다): ⓐ 새고자를 z 1.70(정수리)까지 올렸더니 **머리 옆 창 두 자루**로
보였다 → 어깨 위 한 뼘으로. ⓑ 밀삐를 x 0.112(몸 **안**)에 뒀더니 홀드아웃이 통째로 파내 앞에서
아무것도 안 보였다 → 가슴 표면 밖으로.
