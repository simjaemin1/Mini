### ⓐ 나무 절 열둘 — **화면에게 묻는다**

소스 대조가 아니다. `__treeSpriteFor` 는 **실제로 그리는 그 함수**를 타고, 기대값은
`tree_species.json` **표를 그대로 대조**한다(하네스가 이름을 손으로 안 적는다).

```
✓ ①  클라가 표를 읽었다 — 종 8개 (표 8개 · 클라에 종 목록 0)
✓ ⓐ  종이 다르면 다른 판 — 소나무 tree02 ≠ 밤나무 tree10 · 둘 다 표가 그 종에 적어 둔 판
✓ ⓑ  같은 자리·같은 종은 몇 번을 물어도 같은 판(주사위 0)
✓ ⓒ  다른 자리도 소나무 판 셋 중 하나 (tree01)
✓ ⓓ  열매가 달리면 열매판 — tree10 → tree10_a (표의 `autumn`)
✓ ⓔ  열매판이 없는 종은 그대로 — 소나무 tree02(없는 그림을 지어내지 않는다)
✓ ⓕ  `sp` 가 없거나 모르는 종이면 표 경로를 안 탄다(되돌림)
✓ ⓖ  자명 통과 금지 — 아는 종엔 답이 있고 모르는 종엔 없다
✓ ⓗ  시더가 내는 나무가 전부 종을 들고 있다 — 5/5 (mulberry,grape,oak,pine)
✓ ⓗ  그 종 이름이 전부 표에 있다 — 서버의 낱말과 그림 표의 낱말이 같다
```

ⓗ 는 클라 훅을 새로 만들지 않으려고 **시더 정본(`chunk.js`)에게 직접 물었다** —
화면이 받는 그 행을 만드는 그 함수다(사본 0 · 새 전역 0).
