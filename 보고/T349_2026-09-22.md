## §0 잰 것

### §0-ⓐ ③ 2,400초의 자리 — `fetch` 에 마감이 없다

**실험(한가한 상자 · 러너 미호출).** 접속은 받되 **아무 답도 안 하는** TCP 서버를 세우고 `await fetch(url)`:

```
fetch 시작 — 답 없는 서버로
  ... 15초 경과, 아직 안 돌아옴      ... 75초 경과, 아직 안 돌아옴
  ... 30초 경과, 아직 안 돌아옴      ... 90초 경과, 아직 안 돌아옴
  ... 45초 경과, 아직 안 돌아옴      ... 105초 경과, 아직 안 돌아옴
  ... 60초 경과, 아직 안 돌아옴      ... 120초 경과, 아직 안 돌아옴   ← timeout 이 끊었다
```

**돌아오지도 던지지도 않는다.** 그러면 집의 표준 관용구

```js
async function waitHttp(u, n = 600) { for (let i = 0; i < n; i++) { try { const r = await fetch(u); … } catch (e) {} await sleep(1000); } }
```

에서 `n`(600·900)은 **아무 뜻이 없다** — 다음 바퀴로 못 간다. 끊는 것은 `run-regress.sh` 의 `TIMEOUT_SEC=2400` 하나이고, 그게 **RC=124** 다.

**대조 — 합으로는 2,400 이 안 나온다.** 예산형(시도×잠) 전수:

| 하네스 | 예산형 자리 | 합 | 야간 실제 | 단독 |
|---|---|---|---|---|
| `e2e-winter` | 8 | **510초** | RC=124 (2,400초) | 76~82초 |
| `e2e-events` | 6 | **318초** | RC=124 (2,400초) | 76~82초 |

합의 4.7~7.5배가 실제다 ⇒ **"여러 곳이 느린 것"이 아니라 "한 곳이 안 돌아온 것"**이다. T344 §1 의 "느린 게 아니라 막혔다"에 자리 이름이 붙었다.

**고침.** 기다림 루프의 `fetch` **79자리 + 1자리**(`test-terr-persist` 는 헤더가 붙은 다른 꼴)에 `AbortSignal.timeout(5000)`. 던지면 **이미 있는 `catch` 가 받아 다음 바퀴가 돈다** — 재시도는 그대로 살고 `tries` 가 비로소 듣는다. ⚠판정을 바꾸지 않았다: 5초는 **한 번의 왕복** 상한이지 전체 예산이 아니다.

**자(린트 ⑪).** 60자리를 세어 **마감 없는 것 0** 을 판정한다. 자명 통과 금지 미끼 둘(마감 뗀 것은 **잡고**, 단 것은 안 문다).

### §0-ⓒ 이관의 함정 둘 — 둘 다 이 카드가 물었다

**ⓐ 듣기는 "띄운 그 틱"에 시작해야 한다.** `waitUp` 은 아이의 stdout 에 귀를 붙이는데 아이는 **~100~300ms 뒤**에 표식을 찍는다. `ok` 자리에서 부르면 그 사이 `await` 를 지나며 줄을 놓쳐 **상한 120초를 통째로 버린다**. ⇒ 전 파일에서 **`boot` 바로 뒤에 약속을 잡고 `await` 만 내렸다**:

```js
const _central = boot('central', …);
const _upP = FB.waitUp(_central, /central server up on/, { name: 'central' });   // 여기서 듣기 시작
…
const _up = await _upP;                                                          // ok 자리에서 받는다
ok(_up.ok, 'central 기동', _up.ok ? `${_up.ms}ms · 아이가 제 입으로 말했다` : _up.why);
```

**ⓑ 입이 막힌 아이는 못 듣는다.** `test-doors` 는 `stdio: ['ignore','ignore','ignore']` 라 `✗ ⓪ central 기동` 인데 **나머지 62문은 전부 통과**했다 — 세계는 떠 있었고 **자가 눈이 먼 것**이다. 입을 열고(`['ignore','pipe','pipe']`) 고쳤다(**39/0**). 정본에도 **입이 막혔으면 상한까지 기다리지 않고 곧바로 이름 붙이는** 갈래를 더했고, 린트 **⑩b** 가 그 모양을 센다.

* `prof-mt3merge` 의 화소 잡음 바닥 — 러너 밖이라 이 카드가 안 쟀다.

## §2 내가 틀린 것

* **T344 의 린트 ⑩ 표가 두 군데 틀렸다(내가 쓴 표다).** 정규식이 둘째 인자 붙은 여섯을 놓쳤고, **지역 사본 셋을 "맹목 잠"이라 불렀다**. 이번에 자에 **네 번째 갈래(지역 사본)**를 만들어 다시는 못 뭉치게 했다.
* **첫 스윕을 38종 헛돌렸다.** `require('./fixture-boot')` 를 넣는 조건을 `'fixture-boot' not in s` 로 썼는데, 바로 위에서 넣은 **주석에 그 낱말이 들어 있어** 조건이 늘 거짓이 됐다 — 38종이 `ReferenceError: FB is not defined` 로 0~3초 만에 죽었다. 조건을 `require('./fixture-boot')` 실제 문자열로 바꿨다.
* **`e2e-village` 첫 고침이 NaN 으로 거짓 안심을 냈다**(위 ⓓ). 판정이 빨강이라 들켰지 안 그랬으면 "닿았다"고 적을 뻔했다.
* **백그라운드 구동기를 두 번 잃었다** — `nohup … &` 만으로는 셸이 정리될 때 같이 죽는다. `setsid nohup … < /dev/null & disown` 으로 바꾸고, 구동기를 **재개 가능**하게(이미 초록인 것은 건너뛴다) 고쳤다.
