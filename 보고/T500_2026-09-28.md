## §① 눈보라 — `37-r1-weather drawWeather`(켬 ∧ 눈일 때만)

### ①-1 식 — 있는 수 셋(`WX_TILT_K` · `WX_RAIN_PXPS` · `WX_SNOW_PXPS`)과 굵기 둘(`WX_SNOW_W` · `WX_RAIN_W`)뿐

```
tiltAir = clamp(wind × WX_TILT_K, −1, 1)                      ← 종전 식 그대로(비·끔 눈이 쓰는 그 값)
tilt    = tiltAir × (WX_RAIN_PXPS / WX_SNOW_PXPS)              ← 켬 ∧ 눈 : 760 / 95 = 8
n       = min(WX_MAX, round(넓이/셀 × precip × (1 + |tiltAir|)))
width   = max(WX_RAIN_W, WX_SNOW_W / √(1 + tilt²))             ← 무풍이면 √1 = 1 ⇒ 종전 2.6
```

| 항 | 어디서 왔나 |
|---|---|
| 기울기 × 8 | 기울기 = 가로 공기 속도 ÷ 낙하 속도. 빗줄기를 `tiltAir` 만큼 눕히는 **그 공기**가 눈도 민다 — 눈은 8배 느리게 떨어지므로 8배 눕는다(760/95 · 새 수 0) |
| 밀도 × (1 + \|tiltAir\|) | 보이는 눈 = 내리는 눈 + 바람이 다시 들어 올린 눈(날림눈). 그 몫이 바람 세기에 비례 · 상한은 공기 자 상한 1(카드 "세기 비례 · 새 문턱 0") |
| 굵기 | 한 송이의 먹이 **줄 위에 퍼진다**(번짐은 먹을 늘리지 않는다) — 줄이 √(1+기울기²) 배 길면 그만큼 가늘고, 이 층의 가장 가는 획(빗줄기 1px)에서 멈춘다 |
| 획 모양 | 종전 식 그대로 `(x0, y0) → (x0 + tilt·len, y0 + len)` — 누운 만큼 가로 줄(한 판에 날아간 길이 = 움직임 번짐) |

★**굵기 규칙은 성능이 시켰다**(1판 실측 · `e2e-blizzard ⓕ`): 굵기를 2.6 그대로 둔 1판은 최악 판(강수 1 · 바람 1 · 획 1400 · 기울기 8)이
**5.717ms vs 밤 오버레이 5.680ms(1.01배)** — T93 규약("비싼 쪽도 밤 오버레이보다 싸다")을 어겼고 프레임 짝에서도 +4.36ms(한 장의 37%)였다.
굵고 긴 획이 비싸다(격리 벤치: 1400획 기울기 8 — 굵기 2.6 5.38ms · 굵기 1 0.65ms). 먹 보존 굵기 뒤 **0.543ms(밤의 0.11배 · 종전 눈 최악 2.713ms 의 0.20배)**.

## §③ 서리 — `server/snow.js` `frostAt` + 지면 굽기

### ③-1 식(적설과 같은 재료 셋 — 두 기온 · 어는점 · k = 1)

```
F₀(d)  = [T밤(d) < 0 ∧ S(d+1) = 0] · min(1, (0 − T밤(d)) / (T낮(d) − T밤(d)))     ← 그날 일교차 가운데 어는점 아래 몫
보임   : 밤 d  = F₀(d)                  (그 밤 보이는 적설 S(d) = 0 일 때)
         낮 d+1 = F₀(d) — k·max(0, T낮(d+1))·(아침부터 흐른 날) ≥ F₀ 인 순간 0   (이진 · 첫 낮에 사라짐)
```

* "snow = 0" 은 **다음 아침의 적설**이다(반례: 그날 적설로 읽으면 눈 온 밤에도 서리가 선다 — `test-winter-fx ②f`).
* 이진인 까닭 — 값이 바뀔 때마다 지면 타일을 다시 굽는다(지문 `_kf`). 이진이면 **아침에 한 번 · 녹을 때 한 번**.
* 위상은 세계 시계(`worldPhase` · 낮 = 0~0.7). 클라 하늘은 경도로 최대 4.5% 밀린다(동쪽 끝은 해가 ≈1분 먼저 · 서리는 세계 시계로 녹는다 · 회부 6).

* 제외 = 물·바위·길(`road > 0`)·존 밖(적설 표 그대로) · 투과율 캔버스도 같은 알파로 지운다(덮인 풀은 덜 흔들린다).
