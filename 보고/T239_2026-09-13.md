```js
if (!_picked) {                           // ★선언 순서상 첫 개 — T206~T233 이 싣던 그것
  _res2 = c2.res; _n2 = _q; _p2 = a.prices[c2.res] || 0; _pp2 = _pu2; _picked = true;
}
const _tot = _pu2 * _q;                   // ★[T239] 첫째와 같은 자 — `_legProfitPerUnit × 수량`
if (_tot > _bTot) { _bTot = _tot; _bRes = c2.res; ... }
// ⚠여기서 멈추지 않는다 — 멈추면 `_bTot` 이 첫 개만 보게 되어 갈림이 늘 0 으로 나온다(첫 판이 그랬다)
...
if (world.cargoTwoBest && _bRes) { _res2 = _bRes; _n2 = _bN; _p2 = _bP; _pp2 = _bPP; }
```

이 덕에 **손잡이를 켜지 않고도** `twogate` 팔에서 갈림을 셀 수 있다(§ⓐ).

⚠**하네스 ㉑ 을 정정했다** — T206 이 "셋째 이상 0" 을 `break` **라는 기전**으로 잠가 두었는데, T239 가
그 `break` 를 없애자 빨갛게 됐다. 불변식은 그대로이므로(`_res2` 지정이 `_picked` 로 잠긴 한 자리뿐 ·
셋째 변수 자체가 코드에 없음) **기전이 아니라 불변식을 잠그도록** 고쳤다.
