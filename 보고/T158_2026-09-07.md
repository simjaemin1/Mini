## §0-ⓐ 뷰 kill vs 장부 — **뷰가 하루 2마리 · 장부 최대 4마리**

정본 `tick()` 을 게임 하루치(43,200틱 = 1,440게임분)로 돌려 잰다. 결정론 시드 PRNG(랩 처방과 같다).

| | 하루 마릿수 |
|---|---|
| 뷰 사냥꾼 한 명(되돌림 = 종전 연출) | **2** |
| 장부 예산(`huntTake` · 만땅 밀도) | **최대 4**(`L_HUNT`) |
| 예산 1 로 묶은 판 | **1** ← 게이트가 실제로 문다 |
| 예산 0 | **0** |

⇒ **어긋남은 "몇 배"가 아니라 "무관"이었다.** 뷰는 몹이 보일 때만, 자기 속도로 잡았고
장부는 따로 셌다. 관객이 있든 없든 곳간이 같아야 한다는 규약(랩)은 지켜지고 있었지만,
**보는 사람에게는 두 수가 다르게 보였다.**

⚠뷰가 느리다는 것은 **연출이 장부를 못 따라간다**는 뜻이다. 카드가 미리 정한 대로
*"예산이 남았는데 몹이 안 보이면 장부가 그대로 진실"* — 세계의 손실이 아니다.

## §0-ⓑ 게이트 자리 — **두뇌**다(실행층은 원문 무수정)

`wildlife.js:465` 가 못 박아 둔 규약: *"블록(287행~)은 `a._bm`·`a.sneak`·`a._carc` 를 소비하는
**실행층** — 원문 무수정 원칙."* 그래서 예산은 **두뇌(`_hunterBrain`)** 가 든다.

| | |
|---|---|
| 잡은 수 세기 | 실행층이 사체를 물면 `a._carc` 가 새로 앉는다 — **그 갈림**을 두뇌가 본다(`_carcSeen`) |
| 소진 시 | 표적을 놓고(`_bm`·`_tgt`·`_cm` = null) **귀환**(행동 상태 하나 · 새 수 0) |
| 예외 | **이미 물어 둔 사체는 마저 바른다** — 그 마리는 이미 예산에서 나갔다 |
| 갱신 시점 | 하루 틱 `huntHunters` — 예산을 열고 **어제 쓴 것을 지운다**(누계 아님) |

주입은 T146 과 같은 규약이다: `villages.js` 가 정본(`huntVisLeft`), `zone.js` 가 한 줄로 넘기고,
`wildlife.js` 는 `H.huntBudgetOf` 만 읽는다. **`wildlife.js` 는 수확 식을 여전히 모른다.**

## §0-ⓒ 이중 차감 — **이미 0이었고, 이제 물리적으로 불가능하다**

`wildlife.js` 코드에 `gameRich` 에 **쓰는 줄이 0개**다. 그리고 T146 이 깔아 둔 얇은 보기가
`set: () => {}` · `delete: () => false` 라, 누가 나중에 쓰려 해도 **정본이 안 변한다**.
하네스가 실기로 확인한다(보기에 써 본 뒤 정본을 대조 — 42 그대로).

⇒ 카드 ②는 **이미 지켜지고 있었다**. 이 카드는 그것을 **잠갔다**.

★도살은 곳간에 뼈·호피·약재를 넣는다(`wildlife.js:291`) — 고기는 아니다. 즉 kill → 곳간 회계는
