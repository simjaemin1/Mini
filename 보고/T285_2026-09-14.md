## §0-ⓑ 죽은 다리 — 줄 하나가 아니라 **함수 전체**

```
  시드     옛 `pickDeficitJob` 진입    `pickDeficitJob_rational` 진입    옛 위기줄(참/충원/막힘)
  1020                        0                        16,963            0 / 0 / 0
  7                           0                        17,267            0 / 0 / 0
  42                          0                        21,952            0 / 0 / 0
```

**함수 첫 줄에 누계를 얹어 셌다** — 조기 반환까지 다 잡힌다. 셋 다 **0**.
T275 는 "그 줄이 안 돈다"까지 갔는데, 이 카드는 **함수가 통째로 안 돈다**를 호출 횟수로 세웠다.

### 옛 picker 에만 있는 조건 — 같은 목표라도 **문이 다르다** (전부 소스 인용)

```
  ─ lumberjack
    옛      : if (v.storage.wood < N * 5 && hasSlot(...)) return 'lumberjack';
    rational: if (v.housing !== undefined && N >= v.housing * 0.95 && (v.storage.wood || 0) < N * 2 && hasSlot(...)) ...
  ─ forager
    옛      : if (v.storage.stone < N * 3 && hasSlot(...)) return 'forager';
    rational: if ((v.land.stone || 0) > 0.25 && (v.storage.stone || 0) < N * 1.5 && hasSlot(...)) ...
  ─ cook
    옛      : if (foodRich && sideTotal > N * 2 && hasSlot(...)) return 'cook';
    rational: if ((counts.cook || 0) < cookTarget(v)) return 'cook';
  ─ 목표 자체가 rational 에 없는 것: (없다)
```

**가장 무거운 차이는 첫 줄이다.** 옛 규칙은 **재고 하나만** 본다(`wood < N×5`). 살아 있는 규칙은
**주거가 거의 찼을 때만**(`N ≥ 주거 × 0.95`) 그리고 문턱도 더 낮다(`N×2`).
⇒ **집에 여유가 있는데 목재가 바닥난 마을은 안전망을 못 받는다.** 그 마을이 나무꾼을 얻으려면
한계가치 후보줄(`candidates.push(['lumberjack', land.wood × 0.3 × period × w('wood')])`)에서
**그림자가격으로 경쟁해 이겨야** 한다.

### ★정본 주석 둘이 죽은 규칙을 근거로 댄다

```
  :3055  "재고를 실제로 축내므로 subsistence picker(wood<N×5)가 벌목꾼을 더 배치 → 숲 압박."
  :1078  "집 부족하면 성장만 멈춤(감소 아님). picker가 '집 지을 목재 부족 → 나무꾼' 안전망으로 고리 닫음."
  :3128  "용량 기준(slotK와 동일 가정) — 연료 게이트(picker)가 위기 시 벌목 충원을 보장하므로 정직."
```

`:3055` 가 이름을 대는 `wood<N×5` 는 **안 도는 줄**이다. `:1078`·`:3128` 이 말하는 안전망은 있긴 하지만
**주거 조건이 붙은** 좁은 것이다. `:3128` 은 그 안전망을 근거로 `fuelK` 의 **용량 기준**(자리를 필요하면 채울 수 있다)을
"정직하다"고 정당화하는데, ⓒ 가 보이듯 **위기의 16~23% 는 자리가 꽉 차서 못 채운다.**

## §0-ⓒ `hasSlot` 이 막을 때 — 상한은 무엇으로 정해지나

⇒ **"위기에 자리 상한이 걸리는 것"은 결함이라기보다 설계다**: 숲이 없는 마을에서 나무꾼을 더 뽑을 수는 없다.
남는 것은 `:3128` 의 **문장**이다 — "필요하면 자리를 채울 수 있다"는 가정이 16~23% 의 위기에서 안 맞는다.
