## 0. 한 줄 요약

**"극단"이 이 세계에 정의돼 있지 않았고, 그걸 어디로 잡느냐가 이 카드의 전부였다.**
상태 1.0 으로 잡으면 추위 축이 죽은 채로 실린다 — 추위는 평형 수렴이라 한겨울 야생 밤 맨몸의
평형이 **0.9278** 이라 1.0 에 닿는 밤이 드물기 때문이다. 그래서 **3단계 문턱**으로 잡았다:
문턱에서 초과 정도가 0 이라 감소율이 **0 에서 연속으로** 시작하고(계단 금지 요구 충족),
새 상수를 한 개도 안 적는다(단계 표에서 유도).

## 2. 설계 판단 — "극단"을 어디로 잡을 것인가

```
  ⓐ 상태 1.0     ⇒ **추위 축이 죽은 채로 실린다.** 평형 0.9278 < 1.0 이라 닿는 밤이 드물다.
  ⓑ 3단계 문턱   ⇐ **채택.**
       · 문턱에서 e=0 ⇒ 감소율이 **0 에서 연속으로** 시작한다(지시서의 "계단 금지" 충족)
       · 새 상수를 안 적는다 — `extremeAt(a) = STAGE_AT[a][2]`(리터럴 0개 · 하네스가 소스로 확인)
       · 3단계는 이미 화면이 "심각하다"고 말하는 자리다(설명이 필요 없다)

  e(축)  = clamp01( (심각도 − 문턱) / (1 − 문턱) )      ∈ [0,1] · 연속
  감소율 = Σ  r(축) · e(축)                             HP/게임분 · **가산**
  벗어나면 e=0 ⇒ **즉시 0**(이월분까지 버린다)
```

## 3. r 표 — 역산 근거

★단위 **HP/게임분**. 환산은 시간 구조 불변 캐논이 고정해 준다 —
`zone-config.js:437` *"하루=현실 24분(**현실 1초=게임 1분**)"* ⇒ **1 게임분 = 1 실초**
(하네스가 설정 파일에서 그 환산을 유도해 확인한다).

| 축 | 게임 시간 | 게임분 | r (HP/게임분) | 실시간 | env |
|---|---|---|---|---|---|
| 허기 | 3 게임일 | 4,320 | **0.023148** | 72분 | `BODY_EXTREME_HP_HUNGER` |
| 갈증 | 1.5 게임일 | 2,160 | **0.046296** | 36분 | `BODY_EXTREME_HP_THIRST` |
| 추위 | 6 게임시간 | 360 | **0.277778** | 6분 | `BODY_EXTREME_HP_COLD` |
| 더위 | (8 게임시간) | (480) | (0.208333) | — | ★**축이 없다** — 배선 안 함 |

★**고증과 게임적 압축을 갈라 적는다**(조용히 정한 수를 남기지 않는다 — 족보):
```
  현실 "3-3-3": 물 없이 ~3일 · 음식 없이 ~3주  ⇒ 갈증 : 허기 = **1 : 7**
  게임:                                        ⇒ 갈증 : 허기 = **1 : 2** (1.5일 : 3일)
  ★왜 압축했나 — 1:7 이면 허기가 10.5 게임일 = **실시간 4.2시간**이라 한 세션에서 한 번도 안 보인다.
    "둘 다 한 세션 안에서 보이되 **갈증이 먼저**"가 이 압축의 목적이다.
  ★추위만은 압축이 **없다** — 저체온증 사망은 극한 노출에서 3~6시간, 여기서도 **게임 6시간**이다.
    실시간 6분이 짧아 보이는 건 하루가 24분이기 때문이지 값이 사나운 게 아니다.
```

## 4. 배선 — 합산기 하나 · 적용은 정본 피해 경로

```
  body.js  extremeHpRate(p) → { rate, parts }     ★합산기 하나. 추위 축도 여기서 센다.
           tick() 이 rate×dt 를 `b.hpDebt` 에 **쌓기만** 한다(p.hp 를 직접 안 만진다).
  zone.js  생존 루프에서 `Body.takeHpDamage(p)` 로 정수 HP 를 꺼내
           `damagePlayer(p, n, 'extreme:추위+갈증')` ⇒ HP 0 → **쓰러짐 사슬이 공짜로** 따라오고
           사망 로그에 원인이 남는다. 부상은 안 생긴다(1HP ≪ `INJURY_DMG` 12).
  ★비율은 연속, 적용만 양자화 — 총량은 정확히 보존된다(하네스가 항등으로 잰다).
  ★weather.js 는 목표점(℃→0..1)만 만들고 HP 를 모른다. 추위발 감소를 저기 두면 **두 번째 합산기**다.
```

★★**무너지는 중엔 아물지 않는다** — 자연 회복에 게이트 하나를 얹었다.
안 그러면 **추위 극단인데 배는 부른** 몸이 회복(초당 ~10HP)으로 감소(초당 0.28HP)를 덮어써
**얼어 죽지 않는다**. 회복 식은 그대로 두고 `extremeHpRate(p).rate > 0` 이면 멈춘다.
(이 한 줄이 없으면 캐논이 문서로만 사는 자리였다.)

```

  갈증        게임 1.50일 (실시간 36.0분)     ← 고증 순서: 갈증이 먼저 죽인다
  추위        게임 0.25일 (실시간  6.0분)
  허기+갈증    게임 1.00일 (실시간 24.0분)     ← 가산이라 각각보다 빠르다
  셋 다       게임 0.20일 (실시간  4.8분)

  실서버 실측(`e2e-thirst`) — 갈증 극단 2분에 5HP → 외삽 40.3분 (표 36.0분 · 1HP 양자화 오차)
  실서버 실측(`e2e-cold ⑧`) — 추위 극단 15초에 3HP → 표 0.278×15 = 4.2HP
```

★★**정직 보고 — 평범한 한겨울 밤은 극단 문턱을 못 넘는다**
```
  평범한 한겨울 밤 야생 맨몸 평형 0.9278   <   추위 극단 문턱 0.930     ← 0.002 차이
  ⇒ 24년 표본에서 **19년만** 얼어 죽는다(날씨 편차가 얹히는 추운 해). 5년은 안 죽는다.
  ⇒ 마을 안은 **0/24년**.
```
읽을 수 있는 규칙이라 이대로 뒀다("가장 추운 밤이 진짜 위험하다"). 다만 두 수가 0.002 차이라

⇒ **회부 B-2**(하네스 `⑭㉧` 이 24년 분포로 감시한다 — 조용히 넘어가지는 않는다).
