## §0-ⓐ 랩에서 `L_LANDNEED` 를 바깥에서 덮을 수 있나 — **못 덮는다**

```
  lab/전쟁실험실.html:9249   const L_CLEAR=90, L_FRONTIER_R=180, L_LANDNEED=8;      ← 최상위 **const**
  lab/전쟁실험실.html:7759   const LAND_NEED=(typeof L_LANDNEED!=='undefined')?L_LANDNEED:8;
  ⇒ `window.L_LANDNEED=12` 는 **안 먹는다** — `typeof` 가 그 const 를 먼저 본다(실측 확인).
  ⇒ 그래서 **/tmp 복제본에 주입**해서 열었다(`scripts/farm-mutations.sh` 의 하드링크 복제 규약과 같은 자리).
    랩 파일은 **한 바이트도 안 건드렸다.** 주입이 실제로 먹었는지 판마다 `L_LANDNEED` 를 읽어 대조한다(자명 통과 금지).
```
**`lab/` 한 줄 제안(PM 승인 뒤 · 지금 안 넣었다)** — 랩을 밖에서 실험할 수 있게:
```js
const L_LANDNEED = (typeof window !== 'undefined' && window.L_LANDNEED != null) ? +window.L_LANDNEED : 8;
```

## 남는 말 한 줄 (판정거리 아님 · 관찰)
