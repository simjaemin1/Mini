## §3 ③ 「지금 할 일」 칸

```js
// 70-lobby.js — 단계 고르기(순수 · 입력 = 서버가 보낸 것) — 위가 먼저다
if (state.lotOk)          inLot ? '내 집 짓기' : '빈터로 가기'(목표 = 서버 lot + 존 오프셋 · 닿음 = lot.r)
else if (state.firstDone) '게시판 의뢰 하기'(남은 수 = need − contrib · 목표 = 시작 마을)
else if (촌장 인사 한 통)  quest ? '○○ n개 구해 오기'(목표 = 인사한 마을) : '쉬어 가기'(화살 없음)
else if (게이트 안)        '촌장 이야기 듣기'
else                      '마을로 들어가기'(목표 = 시작 마을 중심)
// 그 마을 게이트 안이면 화살 없음(닿았다) · 자리 = 게이트 안 "○○ 마을 안" · 도착 둘레(lot.r) "○○ 나루터/어귀" · 그 밖 "○○ 마을 밖"
```

| 단계 | 할 일(명사형) | 설명(하십시오체 · 단축키) | 화살 |
|---|---|---|---|
| enter | 마을로 들어가기 | 광산1 마을이 화살표 쪽에 있습니다. [WASD] 키로 걸어 들어가면 촌장이 맞아 줍니다. | 시작 마을 중심 |
| wait | 촌장 이야기 듣기 | 마을에 들어왔습니다. 촌장이 곧 말을 걸어 옵니다. | 없음 |
| quest | 나무 2개 구해 오기 | 촌장의 부탁입니다. 촌장이 “해 뜨는 쪽 강가로 가 보게.” 하고 일렀습니다. 다 모으면 마을 한복판에서 [Shift N] 키로 납품하십시오. | 마을 밖이면 그 마을 중심(납품할 곳) |
| rest | 쉬어 가기 | 촌장이 “지금은 급한 일이 없네. 모닥불 곁에서 쉬게.” 하고 일렀습니다. 게시판에 일이 걸리면 다시 오십시오. 게시판은 마을 한복판에서 [Shift G] 키로 봅니다. | 없음(쉼터 자리는 클라가 모른다) |
| more | 게시판 의뢰 하기 | 의뢰를 2번 더 하면 촌장이 빈터를 내어 줍니다. 게시판은 마을 한복판에서 [Shift G] 키로 봅니다. | 마을 밖이면 시작 마을 |
| lot | 빈터로 가기 | 촌장이 어귀 빈터를 내어 주었습니다. 화살표 쪽으로 가면 빈터입니다. | 서버 빈터 자리 |
| build | 내 집 짓기 | 여기가 빈터입니다. [C] 키로 땅을 걸고 건축 판 [Shift B] 에서 움집 터파기를 고르십시오. | 없음 |

* **규칙(새 수 0):** 단계 · 목표 · 수는 전부 서버 값이다. "닿았나"는 게이트(`EV_BRIEF_PX` 260px → `evNearVid`)와 서버 `lot.r` 둘로만 판다. 고르기 함수 몸의 수 글자는 0 · 1 · 2(촌장 말 줄 자리)뿐이다(하네스 ③ 이 잰다).
* **보이는 것 = 일어난 것:** 촌장 인사 한 통이 **온 뒤에야** 의뢰 · 쉬기 단계로 넘어간다. 첫 납품 뒤 단계는 서버 `firstDone` 으로만 넘어간다. 촌장 말은 지어내지 않고 그대로 옮긴다 — 쉼터가 없는 새 세계에선 촌장이 "모닥불 곁"이라 하고 칸도 그렇다(실클라 판에서 그 줄이었다).
* **자리 · 먹선(카드대로 · 오석 판은 회부 8):** 지도 판 바로 밑, 폭은 지도 판의 폭(약 340px)이다. 무들 칩 기둥이 지도 판보다 길어지면 그 밑으로 내려선다. 판 · 판 머리(`.pane-head`) · 테 1px · 모서리 · 그림자 0 · 강조는 화살 하나(호박색 `--accent`) · 단축키는 `.key` · 이모지 0 · 색은 `style.css` 토큰뿐이다. 눌림을 안 먹는다(`pointer-events: none`). 낱말 가운데서 줄을 안 끊는다(`word-break: keep-all`).
* **말투(지시_T1069):** 할 일은 명사형, 설명은 하십시오체다. 가운뎃점 · 화살표 · 괄호 기호 나열 · 느낌표 · 이모지 0. 단축키 뒤 조사는 "키로"다(키 이름의 받침을 안 가린다).
* **손잡이:** 서버 env `T1064_NEXT_STEP`(켬 기본 후보 · `=0` 이면 welcome 칸 없음) → 클라 `uiCfg.nextStep === true` 일 때만 칸이 선다. 끄면 칸을 아예 안 만든다(종전 화면 · 종전 HUD 줄 "의뢰 0/3" 은 켬 · 끔 무관 그대로).
* **T1064 가 새로 쓴 글자는 칸 안의 저 문장들뿐이다.** 서버 문구(촌장 대사 · 알림)는 한 글자도 안 바꿨다(T1069 몫).
