## §0-ⓐ 삼자 대조 — 구멍이 실제로 있었다

### 무엇이 비어 있었나

소리 자산은 **표 셋**이 따로 적는다. 각자 지키는 자가 있는데 **셋 사이**는 비어 있었다:

| 표 | 무엇을 적나 | 지키던 자 |
|---|---|---|
| `public/assets/sfx/manifest.json` | 키·파일·출처 id·볼륨·반경… | `test-audio`(세션9) |
| `public/assets/icons.lock.json.sfx` | 파일마다 해시 | `test-assets-audit ②` |
| `CREDITS.md` §2-b | 파일마다 출처 URL·라이선스 | **아무도 없었다** |

### ★구멍을 말로 주장하지 않고 쟀다

`public/assets/sfx/` 에 `.ogg` 한 장을 복사해 놓고 둘 다 돌렸다:

```
node scripts/test-assets-audit.js   → 결과: PASS      (고아 표에 sfx 가 1 늘 뿐 — 그 표는 빨강이 아니다)
node scripts/test-audio.js          → PASS 45 / FAIL 0 (매니페스트에 없는 파일은 안 본다)
```

⇒ **잠기지도 크레딧에 적히지도 않은 소리가 그대로 배포된다.** 이것이 이 절의 근거다.


### ★자명 통과 금지 — 그리고 시험이 저 때문에 넘어진 것을 고쳤다

절 안에 돌연변이 넷이 **매 판** 돈다(픽스처가 아니라 순수 함수에 값을 먹인다):

| | 깨는 것 | 물어야 하는 절 |
|---|---|---|
| ⓐ | 잠금에도 크레딧에도 없는 `.ogg` 한 장 | ⑤a·⑤b 가 **하나씩 더** |
| ⓑ | 크레딧 한 줄 지우기 | ⑤b 만 **둘 더**(.ogg+.m4a) · ⑤a 는 그대로 |
| ⓒ | 크레딧 URL 한 글자 바꾸기 | ⑤c 만 **하나 더** · ⑤b 는 그대로 |
| ⓓ | 아무것도 안 깨기(대조) | 수가 그대로 |

⚠**처음엔 `=== 1` 절대값으로 적었다가 스스로 물렸다.** 진짜 결함이 하나 있는 판에서 돌려 보니
**시험 ⓐ·ⓑ 까지 같이 빨개졌다**(기준선이 이미 1 이라 +1 이 2 였다). `r.a.length + 1` 로 고치니
결함 있는 판에서도 넷이 다 선다(`a 1→2 · b 1→2`). **T272 의 `__selftest_ghost__` 와 같은 줄이다 —
시험은 제가 시험하는 것에 걸려 넘어지면 안 된다.**

### ⚠후보·미확보는 빨강이 아니다

절이 둘을 **표로만** 낸다 — 파일은 있는데 키가 없다(`ui_click` · 후보) · 키는 있는데 파일이 없다(`harvest`·`boar_grunt`).
