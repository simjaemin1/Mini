## 1. ① 자를 먼저 설계했다 — 왜 "끄기" 가 아니라 "시계" 인가

카드는 갈래를 **끄거나 고정**해 빼라고 했다. 그 꼴을 안 쓴 이유를 먼저 적는다:

| 끄면 | 무슨 일이 나나 |
|---|---|
| 결정을 끄면 | 아무도 목표를 안 받아 **걸음 갈래까지 사라진다** — 두 갈래를 한꺼번에 뺀 수가 된다 |
| A\* 를 끄면 | 막힌 주민이 벽을 비벼 `movePlayerStep` 이 **더** 돈다 — 뺀 수가 음수가 될 수 있다 |
| 관측자를 끄면 | 활성 청크가 줄어 **순회 자체가 짧아진다** — 세계가 달라진다 |

⇒ T345 §3-ⓑ 가 실측으로 그 함정에 빠졌다(낮 조각 편차 **±8 %** > 효과). ⇒ **한 판 안에서 갈래마다 시계를 댄다**
(관측자 규약 · T324 `_walk` 와 같은 자리). 같은 씨 · 같은 세계 · 한 번에 여섯. **빼기가 0이라 국면 편차가 안 든다.**
합이 틱과 안 맞으면 그 차가 곧 **"못 가른 나머지"** 다 — 지어낼 자리가 없다.

★**자 값을 자도 낸다 — 그래서 자가 자를 잰다.** 기동 때 시계 한 번 값(`clockNs`)을 재고 갈래마다 호출 수를 세어
`2 × clockNs × 호출수` 를 **계수로** 뺀다(추정 0). 실측 `clockNs = 41.7 ns` · 틱당 자 값 **0.39 ms**.
⚠첫 판은 `process.hrtime.bigint()` 를 썼다 — 호출마다 **BigInt 를 할당**해 밤 틱이 3.7 → **9.5 ms** 로 뛰었다.
`performance.now()`(double · 할당 0)로 갈았다. **자가 잰 것을 자가 만든 꼴**이었고, 그걸 고친 것이 이 카드의 첫 수술이다.

```js
// 전: isRockTileLocal → isDitchTileLocal → isWaterTileLocal → isBridgeTileLocal   (걸음당 6.2회 × 술어 넷)
// 후: 셀당 두 비트(계산됨·값) — 처음 묻는 셀에서만 그 넷을 부른다
const T356_SOA = process.env.T356_SOA === '1';                       // 기본 끔
const _BLK_BITS = T356_SOA ? new Uint8Array(((_WT_W * _WT_H) >> 2) + 2) : null;   // 2,188×4,063 → 2.1MB
function _terrBlocked0(x, y) { … 종전 네 줄 그대로 … }                // ★정본
function isTerrainBlockedLocal(x, y) {
  _walk.terrQ++;
  if (_BLK_BITS && !ZONE.isOcean && x >= 0 && y >= 0 && x < ZONE.zoneWidth && y < ZONE.zoneHeight) { … 읽기 하나 … }
  return _terrBlocked0(x, y);
}
```

| 규율 | 지킨 방법 |
|---|---|
| **정본 하나** | 술어 넷은 한 글자도 안 바뀐다. 비트는 그 넷에서 **유도**한다(T333 이 `WATER_TILES` **에서** 비트 색인을 유도한 그 규율) |
| **가드 동형** | px 범위·해양 가드를 **술어 넷과 같은 자리**에 둔다. ⚠`zoneWidth` 가 32의 배수가 아니면 `tx` 범위가 px 범위보다 **넓다** — `tx` 로 가드하면 **존 오른쪽 끝이 갈린다**(하네스 ⑦-a 가 그 띠를 일부러 표본에 넣는다) |
| **무효화** | 런타임에 바뀌는 원천은 환호 하나(`DITCH_CELLS`) ⇒ `refreshDitchCells` 가 비트를 통째로 영점 |
| **손잡이 하나·기본 끔** | `T356_SOA` · 끄면 `_BLK_BITS === null` 이라 배열조차 안 만든다 |
