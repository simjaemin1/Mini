# T223 — leg 의 인과 방향 (`spareCap` 고정 팔)

- 베이스 `725cba93`(가지 `batch/lab-cargo-two-0912` · T215 머리) · 같은 가지 위 · **main 무접촉**
- 답 한 줄: **인과는 둘 다 돈다 — 그러나 비대칭이다. 준 마을의 손실은 `leg→인구` 가 과반(−32.1% 중
  고정 팔에서도 −18.8% 가 남는다 = 58%), 는 마을의 이득은 전부 `인구→spareCap→leg` 되먹임에 기댄다
  (+17.9% → 고정하면 **−32.2%** 로 뒤집힌다). 고정 팔 인구 Δ **−14.6%**(끔 7,148 → 6,107) ·
  #26 켜기 조건은 "되먹임에 기댄 이득을 이득으로 세지 않는 것" — 둘째 화물의 순효과는 표가 보이는 것보다 나쁘다.**

## 0 · §0-ⓐ `spareCap` 정의와 고정값 출처

`sim/economy-sim-v2.js` — 인구 `N` 의 **곱**이다. 이것이 T215 가 자인한 되먹임 경로다:

```js
const N = a.v.npcs.length;                                                            // :606
const currentlyTrading = a.v.npcs.filter(n => n._tradingUntil && n._tradingUntil > day).length;  // :607
let spareCap = Math.max(1, Math.floor(N * (a.v._idleFrac || 0) * TRADE_SPARE_UTIL));  // :611  TRADE_SPARE_UTIL = 0.11 (:252)
if (a.v.surplusEMA && a.v.surplusEMA.food < 0) {
  spareCap = Math.max(spareCap, Math.ceil(N * CRISIS_TRADE_PC));                      // :615  CRISIS_TRADE_PC = 0.015 (:257)
}
while (caravansLaunched + currentlyTrading < spareCap) { ... }                        // :633
```

`:609` 의 정본 주석이 이 문의 의도를 이미 말하고 있다 — "여유 많은 마을은 많이, 빠듯한 마을은 적게 →
**자연 자기제한 + 붕괴 방지**". 즉 `spareCap` 은 설계상 **브레이크**다. T223 은 그 브레이크를 뗀 팔을 잰다.

**고정값 출처 = 끔 팔 800일 궤적**(마을별·날짜별). **첫날 값은 기각**했다 — 근거:

| | 시드 7 서버 끔 팔 `spareCap` 분포(51마을 × 800일 = 40,800회) |
|---|---|
| `=1`(`max(1,…)` 바닥) | 35,184회 (**86.2%**) |
| `=2` | 2,929 (7.2%) · `=3` 1,380 (3.4%) · `=4` 658 (1.6%) · … 최대 **13** |
| 평균 | **1.29** · `>1` 을 한 번이라도 본 마을 **33/51** |

첫날은 인구가 `INITIAL_POP` 라 거의 모든 마을이 바닥 1 이다. 첫날 값으로 고정하면 네 팔이 전부
"`spareCap`=1 세계" 가 되어 **비교가 아니라 다른 세계**가 된다. 궤적 고정은 지어낸 수 0 이고,
끔 팔에 도로 주입하면 끔이 그대로 나와야 한다 — 그게 아래 자기검증 팔이다.

## ④ 답 한 줄

> **인과는 `leg→인구` 와 `인구→leg` 가 **둘 다** 돌되 비대칭이다 — 준 마을의 손실은 `leg→인구` 가 과반
> (−32.1% 중 되먹임을 끊어도 **−18.8%** 가 남는다 = 58%가 둘째 화물 자체의 손해), 는 마을의 이득은
> **전부** 되먹임에 기댄다(+17.9% → 고정하면 **−32.2%** 로 뒤집힌다). 고정 팔 인구 Δ **−14.6%**
> (7,148→6,107 · 지니 0.316→0.357 · `<30명` 3→7곳 · 소멸 0/51). #26 켜기 조건은 **"되먹임이 부풀린
> 이득을 이득으로 세지 않는 것"** — 둘째 화물의 순효과는 `two` 표가 보이는 −8.5% 보다 나쁘다.**

## §4 · 스스로 낸 한계

1. **`spareCap` 고정은 "leg 고정" 이 아니다** — 상한만 묶었고 실현 leg 은 여전히 `candidates`·
   `lowestProducer` 가 정한다(서버 총 leg 은 네 팔이 8,376~8,406 으로 거의 같다). 그래서 이 표는
   **`spareCap` 경로를 통한 되먹임**만 끊는다. 다른 인구 의존 경로(`lowestProducer` 의 후보 수 등)는 남아 있다.
2. **서버는 시드 7 한 개다**(카드의 "서버 한 팔"). 51마을 4팔 × 3시드는 약 1시간이라 안 돌렸다 —
   시드 1020·42 로 넓히면 묶음별 수치는 달라질 수 있다. 방향(고정 시 는 마을 붕괴)은 랩 두 시드가 같이 말한다.
3. **랩 시드 42 는 자명 통과라 뺐다**(위). T215 가 −25.5% 를 크게 다뤘으므로, **그 시드의 인과는
   이 카드로 못 갈랐다**고 명시한다.
4. `twofix` 는 줄어든 마을에 **제 인구보다 큰** `spareCap` 을 준다 — 의도한 반사실이지만, 그만큼
   "있을 수 없는 세계" 다. 표는 기전을 보이는 자리이지 처방이 아니다.
