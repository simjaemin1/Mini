## §0-ⓐ `e2e-zoom ⑤` — ⓐ 로 닫았다(제품 무접촉)

### 시계의 모양 (T238 이 찾은 자리를 수로)

| | |
|---|---|
| 오버레이 갱신 | **연속**(매 프레임 `darknessLevel()`) — 주기가 따로 없다 |
| `dk` 가 **움직이는** 구간 | 하루 24분 중 **경사 둘** — 황혼 `p 0.65~0.70` · 새벽 `p 0.95~1.00` · **각 72초** |
| `dk` 가 **상수**인 창 | `dk=0` 은 **936초** · `dk=1` 은 **360초** |
| 위상 | `p = (Date.now() − epoch)/dayLengthMs + _lonView` — ★`_lonView` 는 **카메라 경도**(0~0.045)다 |
| 종전 두 장 사이 | **25~26초** |
| 이 판 두 장 사이 | **6.2~6.4초** |

⚠`_lonView` 는 T238 이 안 셌다. 첫 겨냥이 빗나가 실측으로 드러났다(고정 스폰이라 상수 ≈ **+0.02**).
그 보정을 넣으니 T238·T220 의 빨강·초록이 **전부** 모델과 맞는다.

### 왜 ⓐ 인가 — 그리고 **첫 ⓐ 는 못 닫았다**(적어 둔다)

첫 판은 *대조군만* 넣었다: 같은 시간 동안 배율을 안 건드렸을 때의 흐름을 바로 썼다.
판정은 통과했으나(9.226 ≤ 11.857) **자명 통과 금지 전제가 빨갰다** — 경사 한가운데선
흐름(**10.857**)이 확대 신호(**6.08**)보다 커서 **바가 판정을 삼킨다**. 바를 넓히는 길은 거기서 끝났다.

⇒ 시간을 **좁혔다**. 계약("1 → 1.5 → 2 → 1 을 돌고 와도 처음과 같다")은 그대로 두고
**그 돌기를 ⑤ 가 직접 돈다**: 바로 앞에서 기준 장을 찍고 → 1.5 → 2 → 1 → 다시 찍는다.
①②③④ 가 이미 중간 배율을 각각 검사하므로 계약은 안 약해진다 — 돌기만 **격리**된다.
바는 여전히 세계가 준다(같은 시간 배율 무접촉 흐름 + 기존 바) · 문턱 지어내기 0 · 제품 무접촉.
