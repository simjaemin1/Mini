# scripts/mac-long-run — 맥 본체 긴 판 러너(정본 · T1335)

몸 세계 긴 판(120 ~ 400날 · 하루 CPU 100 ~ 900초)을 **맥 본체 터미널**에서 돌린다. 판이 멈추면 **T1308 체크포인트에서 이어 간다**.

* 왜 맥 본체인가: 맥 연결 VM(`device_bash`)은 부를 때마다 새 bwrap 상자라, 부름이 끝나면 띄운 판도 죽는다(T1285 §0). 클라우드 컨테이너는 10 ~ 46시간에 한 번 다시 선다.
* T1304 가 끔 판 365날을 맥 본체에서 22.2시간에 끝냈다(클라우드 어림 58시간의 0.38배). 날 300 까지 클라우드 판과 바이트가 같았다.
* T1304 꼴(`계측/T1304_2026-11-13/끔판.sh`)은 멈추면 처음부터였다. 이 자는 T1308 판 자(`t1308-long-run.js` · 감독 `t1308-guard.sh`)를 써서 마지막 체크포인트에서 잇는다.

## 파일

| 파일 | 어디서 | 무엇 |
|---|---|---|
| `make-pack.sh` | 클라우드(GNU tar) | 판 코드 tgz — `git archive <커밋>`(계측 · 보고 · 증거_* · 문서 뺌) + 더 실을 파일(계측 훅) + `REV` · `.sha256` |
| `판.sh` | 맥 `~/Mini/_runs/<카드>/` | 러너 — tgz 검사 · 풀기 · `npm ci`(처음 한 번) · 판목록의 판마다 끝 / 도는 중 / **이어 띄움** / 새로 띄움(perl setsid + nohup + `caffeinate -ims` — 창을 닫아도 돎) |
| `진행.js` | 맥 · 클라우드 | 판마다 상태 · 체크포인트 날 · 인구 · 몸 · CPU · 남은 어림 · 판 둘이면 같은 날 인구 비 |
| `판.command` | 맥 `~/Mini/<카드>_판.command` 로 베낌 | 더블클릭 한 번 — 파일 이름의 카드(첫 `_` 앞)로 `_runs/<카드>/판.sh` 를 부른다 · 전원 · 뚜껑 안내 한 줄 |

## 판목록(`~/Mini/_runs/<카드>/판목록.txt`)

```
CODE=code-<짧은 해시>.tgz        # make-pack.sh 가 만든 판 코드(이 폴더에)
EVERY=30                          # T1308 체크포인트 간격(날) — 견줄 판끼리 같은 값(마디 경계가 다르면 판이 갈린다 · 보고 T1308 §2)
OBS=scripts/t1243-observe.js …    # 판 코드 뿌리 기준 관찰기(읽기만 하는 훅) — 아이 존에 -r 로
<이름> <날> <시드> [K=V …]        # 판 하나 — 손잡이 줄 · 날 수 · 시드
```

* 판 폴더 `~/Mini/_runs/<카드>/<이름>/` 은 T1308 꼴이다: `progress.json` · `progress.txt` · `ck/`(마지막 체크포인트) · `seg-<시작 날>.*`(마디 조각 — 관찰기 · 훅 · 로그) · `guard.log`. 러너가 더하는 것은 `guard.pid` · `runner.txt`(띄운 줄 · node · 기계 · rev) 둘이다.
* 판 코드가 바뀌면(tgz `REV` ≠ `run/REV`), 끝나지 않은 판이 있는 동안은 새로 풀지 않는다. 판 하나가 두 코드에 걸치지 않게 하려는 것이다.
* ⚠ 마디 판은 "한 번에 돈 판"과 바이트가 같지 않다. 다시 뜰 때마다 서버 마을 칸 · 몸이 새로 선다(보고 T1308 §2 · 회부 1). 끊기고 이은 판은 같은 마디 경계의 안 끊긴 판과 같다(클라우드 시험 — `계측/T1335_2026-11-15/러너-시험.txt`).

## 띄우기

```bash
# 클라우드: 판 코드 tgz
bash scripts/mac-long-run/make-pack.sh <커밋> <내보낼 폴더> 계측/T1275_2026-11-12/t1275hook.js …
# 맥 ~/Mini/_runs/<카드>/ 에: code-….tgz(+ .sha256) · 판.sh · 진행.js · 판목록.txt — ~/Mini/<카드>_판.command(= 판.command 베낌)
# 재민: ~/Mini/<카드>_판.command 더블클릭(다시 더블클릭 = 진행 보기 · 멈춘 판 이어 띄우기)
# 진행(맥 연결 VM 에서도): node ~/Mini/_runs/<카드>/진행.js ~/Mini/_runs/<카드>
```
