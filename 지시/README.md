# 지시/ — 지시서 정본 (다른 기기·계정 세션용 · PM 2026-09-18)

재민 맥이 아닌 기기·계정에서 도는 세션(세션10 부터)은 `~/Mini/지시_T◯◯◯.md` 를 못 본다. 그래서 **PM 이 카드를 여기(`지시/지시_T◯◯◯.md`)에도 민다** — main 에 문서만.

세션 쪽 순서: 클론 → `git pull --ff-only origin main` → `지시/` 에서 제 번호 카드를 읽는다 → `인계/공통.md` §0~§2 · 제 영역 인계 · `tail -n 12 인계/족보.md` → 일 → 가지 `batch/<이름>` 푸시(403 이면 `git bundle` 을 채팅에) → `보고/T◯◯◯_<날짜>.md` → **다시 `pull`**(판정·다음 카드).

맥 세션(1~9)은 종전대로 `~/Mini/지시_*.md` 를 읽는다 — 같은 카드가 여기에도 있을 뿐이다.
