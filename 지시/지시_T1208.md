## 왜
PM 이 land1049(가지 열둘 + T1188 마을 차례 고침)를 착지하는 중이다. 바뀐 하네스만 돌리면 야간에 빨강이 몰려 나온다(11-07 야간 42). 하네스 401개(`@regress` 전수)를 한 상자(2코어)에서 돌리면 몇 시간이라, 넷이 나눠 돌린다.

## 할 일
1. 받기 · 목록(몫 K = 1 · 2 · 3 · 4 — `NR%4` 의 나머지는 K4 가 0):
   ```bash
   git fetch origin && git checkout -B batch/land1049-reg-K<몫> origin/batch/land1049
   K=<몫>; R=$((K%4))
   L=$(bash scripts/run-regress.sh --list regress | sort | awk -v r=$R 'NR%4==r' | tr '\n' ' ')
   echo "$L" | wc -w      # 100 언저리여야 한다(0 이면 멈춘다)
   mkdir -p /tmp/reg && NIGHT_LIST="$L" LOG=/tmp/reg/regress.log nohup bash scripts/nightly-run.sh > /tmp/reg/boot.log 2>&1 &
   ```
   폴링은 `cat /tmp/reg/regress.log.state` 한 줄만. 러너가 빨강을 혼자 한 번 더 돌린다(단독 재실행).
2. **아래 T1203 목록은 건너뛴다**(S15 몫 — 빨개도 표에 "T1203" 이라고만 적는다): `test-t1161-two-prices` · `test-village-view` · `test-war-world` · `test-lab-mining` · `test-moment-lot` · `test-resume-one` · `test-server-market` · `test-t835-quote-weight` · `test-hp-src` · `test-npc-hp-door`.
3. 남은 빨강 하나하나 — `origin/main` 에서 같은 하네스를 혼자 돌려 가른다:
   * **옛 빨강**(main 도 빨강) · **새 빨강**(main 초록 · land1049 빨강) · **흔들림**(혼자 돌리면 초록 — 세 번 돌려 몇 번 빨간지).
