# 설계·계측 지시 — T722: **서버가 멈춰도 시계는 흐른다 — econ 따라잡기**(세션7 · 2026-10-13 · 하루) — 재민 10-13: 시계를 실제 UTC 기준 절대 시각(60×)으로 — "서버 틱이 렉 걸려도 시간이 절대 밀리지 않고, 클라도 시각을 정확히 계산할 수 있게". 하늘(`worldPhase`)은 이미 `Date.now()` 의 순수 함수다. 그런데 **econ 의 날은 경계마다 +1 하는 계수기**라 재기동 때 따라잡지 않는다(`villages.js` "재기동 따라잡기 없음 — 실시간 앵커" · `state.world.day` "따라잡기 없음"). 60× 면 서버가 1시간 멈추면 2.5일이 흐르는데 마을은 그만큼 안 산다 — 달력과 장부가 갈린다(§19 설계 주석이 예약한 "캐치업 별도 설계 세션 몫").
