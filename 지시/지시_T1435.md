# 지시 T1435 — 긴 판: e2e 한 종마다 스무 판 — 빨강 비율 표 (코드 손 0)

**세션:** S11(클라우드 · 오래 걸리고 토큰 적은 판) · **베이스:** `origin/batch/land1089`(착지 뒤 main 과 같다) · **가지:** `batch/e2e-flake-1122` · 커밋 `[승인 대기 · T1435]` · 제품 코드 손 0 · 판정 0

## 왜
- PM 착지는 e2e 를 로컬에서 안 돌린다(CI 와 야간러너 몫) — e2e 가 흔들리면 착지가 한 바퀴(50분)씩 밀린다. 단위 하네스 흔들림은 T1364 · T1400 · T1418 이 쟀고 **e2e 는 표가 없다.**
- `scripts/nightly-known.txt`(상시 빨강 목록)에 든 e2e 가 아직 빨간지도 모른다.

## 할 일(판만 · 표만)
1. `scripts/e2e-*.js` 전부를 **혼자 · 종마다 스무 판**(`scripts/run-regress.sh` 순차 단독 · 제 `TMPDIR`). 판마다 통과 / 실패 · 걸린 초 · 실패면 첫 `✗` 줄.
2. 표: 종 × (통과 ○/20 · 가운데 초 · 최대 초 · 실패 줄 종류 수). 갈래 — 늘 초록 / 늘 빨강 / 흔들림(1 ~ 19).
3. 흔들리는 종마다: 실패 줄이 늘 같은가(같은 줄 = 때맞춤 문제 후보) · 걸린 초와 실패가 같이 가는가(느린 판이 빨간가) · 포트 · 시한 · 그림 기다림 가운데 어느 냄새인가 — **한 줄 어림만**(고치지 않는다).
4. `nightly-known.txt` 의 e2e 줄 대조: 아직 빨강 / 이제 초록(내릴 후보) / 목록에 없는데 늘 빨강(올릴 후보).
5. 둘씩 나란히(`-j 2`)로 한 바퀴 더 — 혼자 초록인데 나란히 빨간 종.
