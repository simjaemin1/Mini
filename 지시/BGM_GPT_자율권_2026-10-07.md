# BGM 자율 기간 — GPT(Codex) 위임장 (2026-10-07 · 재민 요청 · PM 발급)

## 2. 권한 — 묻지 않고 해도 되는 것
1. 재민과 직접 대화하며 방향·곡·악기·구조를 정한다. 카드·보고서·PM 승인 없음.
2. 작업 공간 `~/Mini/_bgm/gpt/` 아래 무엇이든 만들고 지운다(스크립트·중간 파일·렌더·모델).
3. 레포에서는 **자기 가지**(`codex/bgm-*`)에 마음대로 커밋·푸시. 파이썬·JS 도구는 `tools/bgm-gpt/`, 시험은 `scripts/` 에 `bgm-gpt-` 접두로.
4. `public/assets/audio/bgm/` 의 새 파일 추가, `bgm.js` 에 **opt-in 경로** 추가(기본 경로 바이트 그대로).
5. 공개·무료이고 라이선스가 분명한 도구·라이브러리 설치(pip·npm·brew) — `_bgm/gpt/출처표.md` 에 한 줄.
6. 국악원 음원 정제(잡음 제거·EQ·리버브·음정 보정·자르기·이어 붙이기) — **원본은 그대로 두고** 사본에.

## 3. 넘지 말 것 (자율 기간에도 그대로)
1. **원본 음원 읽기 전용** — `~/Mini/_bgm/국악원/raw/` · `정리/` 를 고치거나 지우거나 옮기지 않는다.
2. **게임 서버·시뮬 무접촉** — `server/` · `sim/` · econ · 랩 html · 다른 세션 파일 · 하네스 기준. BGM 밖 파일이 필요해지면 멈추고 재민에게.
3. **`bgm.js` 기본 경로·배포 13곡 교체**는 재민이 "이걸로 바꿔"라고 확정한 뒤 — 그때 PM 이 착지한다(아래 §5).
4. **main 에 직접 푸시 금지 · force push 금지** · 배포(서버 재배포)는 재민만.
5. **라이선스**: 국악원 음원 = 공공누리 제1유형(출처 표시 · 상업·변형 가능) — 크레딧 `국악기 음원 제공 — 국립국악원 (공공누리 제1유형)` 을 산출물 메타·README 에 남긴다. **DDSP-Gugak 공개 체크포인트는 BLOCKED**(학습·게임 이용 권리 미확인 — 재민이 확인 전엔 게임 산출물에 쓰지 않는다 · 실험 청취는 가능). AI Hub 데이터(71470 등)는 약관 확인 후 재민 승인으로. 다른 외부 음원·모델은 출처표에 라이선스와 함께.
6. **지어내지 않는다** — 수·사실·출처. 근거 없는 수는 "잠정"이라고 쓴다. 들어 보지 않은 것을 "좋다"고 하지 않는다(판정은 재민 귀).
7. 비밀(토큰·키·비밀번호)을 파일·채팅·커밋에 남기지 않는다.

## 4. 일하는 방식
* **청취본**: `~/Mini/_bgm/gpt/청취/NNN_<한줄설명>.m4a`(AAC · ★Safari 에서 재생돼야 한다 — Ogg 단독 금지) · 견줄 때는 같은 길이·같은 음량(LUFS 맞춤) · 무엇이 다른지 한 줄. 재민이 듣고 바로 고를 수 있게 2~4개씩.
* **작업일지**: `~/Mini/_bgm/gpt/작업일지.md` 에 하루 끝마다 — 한 것 · 재민 판정(그대로 인용) · 정한 것 · 파일 · 다음. PM 은 보고 대신 이걸 나중에 읽고 따라잡는다.
* 재민이 "좋다/이걸로"라고 한 것은 `_bgm/gpt/확정/` 에 모은다(원본 렌더 + 만드는 법).
* 큰 계산(학습 등)은 재민 맥/4060 PC 자원을 쓰기 전에 재민에게 시간·용량을 말한다.
