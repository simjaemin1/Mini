# 지시 T1438 — 구조물은 낡는다: 재료별 내구도(풀 · 나무 · 흙과 돌) · 한 값(낡음 = 공격 = 체력) · 떨어질수록 제 구실을 덜 한다 · 넣은 재료만큼 회복 (★재민 11-22 판정 38 · 39)

- 판정 38(11-22): "가 좋아(재료별). 그런데, 저 시간이 지나면 수리해야 하는 상태로 변하는 게 아니라.. **연속값으로서 일정 시간마다 내구도가 떨어지고, 내구도가 떨어질수록 제 기능을 못 하게** … 내가 생각하는 건, **내구도가, 영토 관리 점수를 위한 값이 아니라, 애초에 당연히 관리해야 할 값인데 영토 관리 점수는 덤** 같은 거야.. 농사처럼 말야.."

- 지금: 시간으로 낡는 구조물 정본이 없다(부서짐 = 공격 · 갇힘 풀이뿐 — T1402 회부 2).

## 정해진 것
1. **재료 셋의 빠르기 = 고증**(`설계/고증_2026-11_구조물_운반_청동.md` — S1 T1430 · 가지 `batch/research3-1122`): 풀(짚 이엉 1 ~ 2해 · 억새 ~10해) · 나무(움집 뼈대 손질 없이 10 ~ 20해 · 땅에 박은 참나무 기둥 5 ~ 25해 · 다른 나무 5해 안) · 흙과 돌(벽체 확인 · 화덕 · 우물 **미확인**). 범위의 어느 값을 쓸지는 표로 내고 **가운데**에서 시작(끝 값 둘도 판으로) — 미확인 칸은 "미확인"이라고 코드 주석 · 표에 적는다.
2. **구조물은 제 재료를 따른다:** 움집 = 지붕(풀) + 뼈대(나무 — 기둥 · 서까래) (+ 벽 · 화덕 = 흙과 돌) — 지을 때 든 재료 단계(터파기 · 기둥 · 서까래 · 이엉) 그대로 부위가 된다. 울타리 · 목책 · 다리 = 나무 · 곳간 · 저장 구덩이 · 우물 · 시설 터는 지을 때 든 재료로.
3. **문턱 없이 비례:** 떨어진 만큼 제 구실을 덜 한다 — 지붕: 비 · 눈 · 추위를 막는 몫(실내 판정 T526 · T536 · 온도) · 곳간 · 저장 구덩이: 안의 것이 상하는 빠르기(부패 정본 `server/spoil.js`) · 울타리 · 목책: 남은 체력 그대로(뚫기 쉬움) · 뼈대 · 다리: 0 이면 무너짐 · 끊김(폐허 — 치울 수 있다). "몇 % 아래면 수리 필요" 같은 문턱을 새로 적지 않는다.
4. **수리 = 넣은 재료만큼:** 그 부위를 지을 때 든 재료 양에 대한 몫만큼 오른다(지붕 풀 15 가운데 5 = ⅓) — "한 번에 몇 %"라는 새 수 0. 수리는 사유지의 "일"이다(판정 26 — 점수는 덤 · 세계가 바뀐 손 T1402).
5. **NPC 도 같은 규칙:** NPC 마을의 집 · 곳간 · 울도 낡고 NPC 가 손질한다(재민 11-08 "플레이어와 NPC 는 같은 활동을 같은 규칙으로") — 풀 · 나무 수요와 일손이 새로 선다(T1422 "남는 시간에 하는 일"에 집 손질이 든다).

## 할 일
1. **진단(전수):** 구조물 종류 전부 × (지을 때 재료 · 단계 · 지금 체력 칸 · 공격이 깎는 길 · 지금 기능) 표. 체력 칸이 없는 종류 · 종류마다 다른 체력 단위. "한 값"으로 합칠 때 바뀌는 자리(공격 · 갇힘 풀이 · 불 · 전쟁 · T1423 막힘 부숨).
2. **시계:** 낡음은 **서버가 켜져 있던 시간**으로(판정 13 — 사유지 시계와 같은 쪽 · 꺼진 동안 안 낡는다) · 하루 조각으로 나눠 틱에 싣는다(구조물 수십만에 틱마다 쓰지 않는다 — 마지막 손질 시각 + 빠르기로 **읽을 때 셈**하는 꼴이면 쓰기 0 · 저장 칸 하나). DB 행 수(T1433 · T1379)를 늘리지 않는다.
3. **기능을 잇는다:** 위 "정해진 것 3" 넷 — 지붕 → 실내 · 온도 · 비 / 곳간 → 부패 / 울 → 체력 / 뼈대 · 다리 → 무너짐. 무너진 자리는 폐허(재료 일부가 남는다 — 몫은 지금 헐기 규칙 그대로) · 길을 막던 낡은 울은 저절로 열린다(T1423 과 견줌).
4. **수리 손:** 플레이어(우클릭 동사 한 줄 — 새 창 0 · 넣을 재료 고름) · NPC(남는 시간 · 제 집 먼저 · 재료는 곳간에서 — 걸어 나름). 사유지 일 점수는 덤으로 오른다(T1402 `T1332_USE` 길 — 되풀이 악용 표: 재료 0 으로 되풀이 못 한다).
5. **판:** 끔 = 종전 바이트(끈 판 1/1) · 켠 판 랩 / 서버 3시드 400날 + 두 해 — 마을 풀 · 나무 쓰임(집 손질 몫) · 손질 일손 몫 · 집 내구 가운데 · 무너진 집 · 인구 · 식량 상함 · 나무꾼 · 풀 값. 빠르기 셋(범위 아래 · 가운데 · 위)에서 세계가 어떻게 다른가.
6. **보이는 것:** 낡은 지붕 · 무너진 집의 그림(없으면 점선 칸 규약 · 그림 요청 목록 — 어홍 몫) · 구조물을 보면 부위별 내구(숫자 하나씩) · 비가 새는 집 안.
7. **하네스 + 미끼:** 꺼진 시간에 낡는 사본 · 문턱을 둔 사본 · 수리가 재료 없이 오르는 사본 · 공격과 낡음이 다른 칸을 깎는 사본 · NPC 집만 안 낡는 사본.
