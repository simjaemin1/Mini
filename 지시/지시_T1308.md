# 지시 T1308 — 긴 판을 끊겨도 이어 돌리게(체크포인트 · 재개 · 결정성) · 라이브 스냅샷 표지 없는 몸 세기 (T1285 회부 3 · T1263 회부 4 · T1300 회부 3)

**세션:** S5(맥 · T1285) · **베이스:** main(land1072 뒤) · **가지:** `batch/long-run-resume-1114` · 커밋 `[승인 대기 · T1308]` · 판 자 · 하네스 손(제품 0) · 판정 0

## 왜
몸 세계 긴 판(120 ~ 365날 · 하루 CPU 300 ~ 900초)이 끝까지 못 간다: 클라우드 컨테이너는 10.5 ~ 46시간에 한 번 다시 서고(T1263 끔 판 날 300 에서 끊김 · T1285), 맥 VM 은 호출이 끝나면 프로세스가 죽는다(T1285 §0). T1304(S1 · 끔 첫 겨울) · T1307 · 앞으로의 몸 세계 400날 판 모두 여기 걸린다.

## 할 일
1. **이어 돌리기** — `scripts/t577-server-run.js`(+ 관찰기 · 판 자)가 N날마다 체크포인트(존 DB · econ 상태 · RNG · 관찰기 누계 · 판 JSON 조각)를 남기고, 다시 띄우면 마지막 체크포인트에서 이어 간다. 세계는 이미 DB 로 되살아난다 — 판 자 쪽(누계 · 시드 · 날 번호)만 이으면 되는지 먼저 확인.
2. **결정성** — 30날 판을 (가) 한 번에 (나) 10날에 끊고 이어서 — 날 지문 · 몸 자리 지문 · 판 JSON 이 같아야 한다. 다르면 갈리는 칸(되살림에서 안 실리는 몸 칸 · RNG)을 찾아 판 자 쪽에서 맞춘다(제품 결함이면 회부).
3. **지킴이** — 끊김을 스스로 다시 띄우는 감독(쉘 고리 · 컨테이너 재시작 뒤 첫 세션이 부르는 한 줄) · 진행 줄 파일.
4. **라이브 스냅샷 세기(T1300 회부 3)** — 맥 `~/Mini/_db/` 한반도 11-03 · 닛폰 11-12 스냅샷에 `node scripts/t1300-count-unmarked.js` — 표지 없는 몸 수 · T1289 규칙과 갈린 칸 수.
5. 하네스: 짧은 재개 판(5날 + 5날 = 10날 지문 같음) `@regress` · 미끼(RNG 상태를 안 잇는 사본 → 빨강).
