## 정해진 것
1. **식 하나:** 그 시설에서 하는 일에 걸리는 시간 = 원래 시간 × **m(x)** · m(x) = (1 + a) ÷ (x + a) · x = 남은 내구 몫(0 초과 ~ 1).
   - x = 1(새것) → 1배. x 가 0 에 가까워져도 (1 + a) ÷ a 배에서 멎는다(끝없이 늘지 않는다).
   - **(1 + a)를 곱한 것은 PM 읽기다** — 재민 글자는 "1/(x+a) 꼴". 새것일 때 1배가 되게 맞춘 것. 다르면 재민이 바로잡는다.
2. **x = 0 이면 고장** — 못 쓴다. 0 바로 위(가장 느린 배수)와 0(못 씀) 사이의 한 계단이 재민이 말한 "살짝의 문턱 · 경계"다. 다른 문턱은 두지 않는다.
3. **a = 0.25 로 시작한다**(PM 시작값 · 재민 거부권 — 출처 없는 수라 `decay.js` 한 자리에 "재민 11-22 꼴 · PM 시작값"으로 적는다): 절반 남으면 1.67배 · 넷에 하나 남으면 2.5배 · 거의 0 이면 5배. 견줌: a = 0.5 → 1.5 · 2 · 3배 / a = 0.1 → 1.83 · 3.14 · 11배.
4. **줄어드는 것은 시간뿐이다.** 나오는 양 · 드는 재료 · 품질은 안 바뀐다(재민 10-15 "개수가 줄면 안 된다").
5. **PM 결정(재민 거부권) — 헐어도 낡음은 안 지워진다:** 헐면 그 물건이 통째로 돌아오던 것(T1438 회부 10 — 헐고 다시 세우면 재료 0 · 품만으로 새것)을, 켬에서는 **남은 내구 몫만큼만** 재료가 돌아오게 한다(낱개 올림 규칙은 수리와 같은 쪽 — 회부 14). 벌점 줄은 안 건드린다.
6. 수리 · 빠르기 · 한 값 · 쓰기 0 — T1438 그대로.
