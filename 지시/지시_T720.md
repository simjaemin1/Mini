# 구현 지시 — T720: **경도 하루 1단계 — 절대 시계(실제 UTC × 60) · 원통 경도 · 날짜선은 태평양 이음매 · 손은 곳간에 닿는 순간**(세션5 · 2026-10-13 · 하루~이틀) — T712(세션5) 설계 위 재민 10-13 판정: ① 환산 **ⓐ 원통**(세계 폭 = 360° · 새 수 0) ② 시계는 **실제 UTC 기준 절대 시각 · 배율 60×**(1실초 = 1게임분 그대로 — "24배"는 재민 착오로 정정) · 날짜선 = **베링 끝과 캐나다 사이 태평양 이음매**(세계 x = 0 ↔ 끝) ③ 마을이 정산하는 현지 시각 = **자정 00:00**(2단계) ④ 2단계 영토·채굴 차례 = **동쪽 먼저**(방향은 실제 몸이 하는 순간 — 채굴은 T724) · 곧 초기화하니 하늘이 한 번 밀리는 건 문제 아님.

## 1. 할 것(손잡이 하나 `T720_LON_DAY` · 기본 끔 = main 바이트)
* ① **시각 한 식** — `zone-config` 에 `localPhase(x, t)` · `localDay(x, t)`. 경도 λ(x) = x ÷ `WORLD.worldWidth` − 0.5(−180° ~ +180° · λ = 0 은 세계 가운데 x = W/2 · 날짜선 = x 0 ↔ W 이음매). 게임 시각 = 실제 UTC ms × 60(§19 `ABS_CLOCK_DESIGN` 을 이 배율로 채택 · `GAME_EPOCH` 은 초기화 날 — T587 "1년 3월 1일"과 맞춤). 상수 0.045(서버 §19 · 클라 `_lonView` · 랩 `L_LON_SPREAD`)는 이 식 하나로 바뀐다.
* ② **낮밤 · HUD** — 해 자리는 지금 그대로(낮 = 하루의 0.7 · HUD 해 뜸 06:00). 클라 하늘·어둡기·HUD 시각·소리 · 몸 일과(기상·잠·야간 귀가) · 몸 일과의 **그날 = 현지 날**(지금은 세계 날이라 동쪽 마을 아침이 어제로 굴림 — T712 §3). 클라 HUD 시각은 그 식의 현지 시·분(하드코딩 +6 시간을 식으로).
* ③ **손 → 곳간 = 닿는 순간** — 해 질 녘 손에 무엇이든 든 몸은 곳간 사다리를 거쳐 귀가(곳간 없는 마을은 회관 · T561 ②ⓒ). 곳간 과업 밤 중단 → "저장 먼저". 경계 손 일괄(`_lifeHandsIn` · `_lifeDaily` 손 비우기 넷)은 걷는다. **하루 문**(재민 10-13 ○): 깨어 걸은 시간이 낮 하나(`dayMs × dayPhaseRatio`)를 넘도록 곳간에 못 닿으면 포기하고 집 — 짐은 손에 든 채 · 다음 날 일 끝에 다시 곳간(촌장 마중 과업의 그 문 · 새 수 0). 곳간 자체에 길이 없는 마을은 표만(T710 코너케이스로).
* ④ econ 경계·마감 조각은 **그대로**(1단계). 2단계(마을 현지 자정 정산 · 동 → 서)는 econ 공유 씨 흐름(`srand` · `_nextNpcId`) 가르기 뒤 — 이 카드 밖.
* ⑤ 재기: 기준선 게이트(빠른 시계 — 손 몫이 거의 0 일 것) · 실제 하루 판 T686 자 + `t712-probe`(품목별 곳간 든 때 · 경계 ms) · 다일 실제 하루 판은 열흘 하나(4시간 넘으면 회부).
