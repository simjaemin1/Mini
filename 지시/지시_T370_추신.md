# 지시_T370 추신 — 재민 실기(09-23): **"NPC 들이 강에 대고 몸 비비느라 집으로 돌아가지를 못한다"** (세션3 · T370 진행 중 · 2026-09-23)

아래를 **세션3** 에 붙여넣으면 된다. 카드 T370 본문은 그대로다 — 이 추신은 히스토그램에 **넣을 이유 하나와 반례 하나**를 더한다.

---

재민이 실서버에서 본 것: 주민들이 강가에서 물에 몸을 비비며 제자리에 있고 집으로 못 간다. 코드를 보면 그 모양이 나올 자리가 `zone.js:2745~2755` 에 그대로 있다:

```
const p = computeNpcPath(npc, now);
npc.path = p || [{ x: npc.targetX, y: npc.targetY }];   // 못 찾으면 beeline
```

`computeNpcPath` 는 **둘**일 때 `null` 을 준다 — ⓐ A\* 쿨다운(`_lastAStarAt` 2초 안) ⓑ A\* 실패(`maxCells 1500` 안에 못 닿음 · 강 건너 집). 어느 쪽이든 그 틱의 경로는 **목표로 곧장**(beeline)이고, 강이 사이에 있으면 `movePlayerStep` 이 물 앞에서 막는다 → `_stuckPos` 1.5초 → `unstuckNpc` → 재경로 → 다시 `null` → beeline … 이게 "몸 비비기"고, 동시에 **틱마다 899명이 다시 묻는 것**(`pathIndex ≥ length` 가 아니라 `!npc.path`/beeline 갈래일 수 있다)의 한 얼굴일 수 있다.

**히스토그램 ①에 더할 것 둘:** ⓐ `null` 의 이유(쿨다운 / 실패)를 갈라 센다 ⓑ 실패한 주민의 **목표가 물 건너인가**(목표 셀과 현재 셀이 같은 뭍 덩어리인가 — T360 `t360-border` 의 실셀 BFS 자 그대로 · 마을별 "집이 강 건너인 주민 수"). **반례 표에 더할 것:** 켬 판에서 강가 정지 주민 수(1.5초 이상 `_stuckPos` 인 주민 · 물 인접 셀) 전/후.

**고침 원칙(카드 ② 그대로 · 새 수 0):** `null` 일 때 beeline 을 넣지 않는다 — 쿨다운이면 **있던 경로를 유지**하고, 실패면 **그 틱은 서 있는다**(목표 무변 · 다음 결정이 바꾼다). "강 건너 집" 자체가 있으면(집터가 물 건너 영토에 섰다) 그건 이 카드 밖 — 표만(회부 · V/Z).
