**세션:** S10 · S11 · S12 · S13 · S14 (한 세션 = 한 몫 K · ★재민 11-07 "하네스 전수는 세션10~14") — S10 = K1 · S11 = K2 · S12 = K3 · S13 = K4 · S14 = K5
**베이스:** `origin/main`(land1051 착지 뒤) · **가지:** `batch/land1051-reg-K<몫>` · 커밋 `[승인 대기 · T1220-K<몫>]` · 하네스만 · 판정 0

## 왜
PM 이 land1051(가지 열여섯 · 행복 식 켬 기본)을 착지했다. 바뀐 하네스만 돌리면 야간에 빨강이 몰려 나온다(11-07 야간 42). 하네스 401개(`@regress` 전수)를 한 상자(2코어)에서 돌리면 몇 시간이라, 다섯이 나눠 돌린다.

## 할 일
1. 받기 · 목록(몫 K = 1 · 2 · 3 · 4 · 5 — `NR%5` 의 나머지 — K5 가 0):
   ```bash
   git fetch origin && git checkout -B batch/land1051-reg-K<몫> origin/main
   K=<몫>; R=$((K%5))
   L=$(bash scripts/run-regress.sh --list regress | sort | awk -v r=$R 'NR%5==r' | tr '\n' ' ')
   echo "$L" | wc -w      # 80 언저리여야 한다(0 이면 멈춘다)
   mkdir -p /tmp/reg && NIGHT_LIST="$L" LOG=/tmp/reg/regress.log nohup bash scripts/nightly-run.sh > /tmp/reg/boot.log 2>&1 &
   ```
   폴링은 `cat /tmp/reg/regress.log.state` 한 줄만. 러너가 빨강을 혼자 한 번 더 돌린다(단독 재실행).
2. 건너뛸 목록 없음(T1203 끝 · 남은 `test-lab-mining` 하나만 "T1203 회부"라고 적는다).
3. 남은 빨강 하나하나 — `origin/main` 에서 같은 하네스를 혼자 돌려 가른다:
   * **옛 빨강**(main 도 빨강) · **새 빨강**(main 초록 · land1051 빨강) · **흔들림**(혼자 돌리면 초록 — 세 번 돌려 몇 번 빨간지).
   * 새 빨강은 어느 손잡이 탓인지 — land1051 이 새로 켠 것: `T1205_HAPPY`(행복 식) · `T1214_STEP_FAST`(µs · 값 0) · `T1212_FARM_REST` · `T1213_DERIV_ADD` · `T1211_STOCK_FE` · `T1204_NOW_WORDS` — 하나씩 `=0` 으로 돌려 초록이 되는 손잡이를 적는다.
4. 고치는 것: **하네스만**(픽스처 · 옛 글자 · 손잡이 묶기 `if (process.env.X == null) process.env.X = '0'` 꼴 — 묶을 땐 왜를 한 줄 주석으로). 단언을 느슨하게 하지 않는다. **제품 결함(`sim/` · `server/` · `public/`)은 고치지 말고 보고**에 — 어느 줄 · 어떤 판에서 · 무엇이 틀리는지.
5. 서버 기준선 · 랩 게이트는 PM 이 돌린다 — 안 돌린다.
