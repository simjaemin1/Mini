# 지시 T1226 — 직업 바꾸기를 유연하게: 사람마다 · 날마다 "바꿔서 얻는 것 > 바꾸는 비용"일 때만 (★재민 11-08)

**세션:** S12 · **베이스:** main · **가지:** `batch/job-switch-1108` · 커밋 `[승인 대기 · T1226]` · econ · 서버 손 · 랩 · 판정 0

## 왜(★재민 11-08)
지금은 전환일 7날마다 마을이 다시 고르고(`allocRealCandidates` — 실현 산출 × 시세) · 바꾼 사람은 30날 잠금(`JOB_SWITCH_COOLDOWN`) · 마을당 하루 한 명. 재민: "필요할 때 바꾸고 진동이 심할 땐 견디는 로직". 어장이 마르거나 흉년이면 너무 느리고, 시세가 출렁이면 몰려서 바꿨다 되돌아온다.

## 규칙(PM 제안 · 재민 "괜찮을 듯")
1. **날마다 · 사람마다 엇갈려**(pid 해시로 그 사람이 보는 날) — 마을이 한날에 몰리지 않게.
2. **얻는 것** = (가장 나은 다른 직업의 값 − 지금 직업의 값) × 그 차이가 이어질 기간. 값은 **한 사람이 더 들어가면(빠지면) 늘어나는(줄어드는) 몫**(한계 값 — 실현 산출 EMA · 시세 · 수요에서).
3. **바꾸는 비용** = 쌓은 숙련을 잃는 몫(새 직업은 마을 장인 숙련 45% 에서 — `MASTER_INHERIT_RATE`) + 몸이 짐 · 도구를 바꾸고 새 일터까지 가는 시간.
4. **급할 때**는 행복(굶주림 · 식량 빚)에서 식량 직업 값이 뛰어 저절로 빨라진다 — 따로 "급함 규칙"을 두지 않는다.
5. **출렁일 때** — 30날 잠금 대신 최근에 바꾼 사람일수록 다시 바꾸는 문턱이 높고 시간이 지나며 낮아진다 · 값이 오르내리기만 하면 "이어질 기간"이 짧게 잡혀 비용을 못 넘는다.
6. 새 튜닝 수 0 에 가깝게 — 숙련 이어받기 45% · 행복 반감기 30날 · 시세 등 있는 수에서 유도. 손잡이 `T1226_JOB_FLEX`(끔 기본으로 시작 · `=0` = 종전 바이트).
