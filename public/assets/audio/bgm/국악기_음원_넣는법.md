# 진짜 국악기 음원으로 바꾸기

지금 BGM의 악기 소리는 전부 **합성음**입니다. 실제 국악기 녹음으로 바꾸려면
음원 파일만 폴더에 넣으면 됩니다. 작곡·장단·믹스 코드는 한 줄도 고치지 않습니다.

---

## 1. 어디서 받나

**국립국악원 국악기 디지털 음원** — <https://www.gugak.go.kr/digitaleum>

- **공공누리 제1유형**: 출처만 표시하면 **상업적 이용과 변형까지 자유**롭습니다. 게임에 넣어도 됩니다.
- 단음 407개(악기 52종), 악구 2,226개(19종+성악) 등 무료 공개.
- 파일은 wave 로 제공됩니다.

받을 것은 **「단음」 하나면 충분**합니다. 악구·확장은 이미 만들어진 연주라 이 구조에는 안 맞습니다.

> 게임 크레딧에 출처를 넣어야 합니다. 예: `국악기 음원 제공 — 국립국악원 (공공누리 제1유형)`

### 필요한 악기와 최소 개수

| 악기 | 최소 | 있으면 좋은 음역 | 없으면 |
|---|---|---|---|
| 가야금 | 6음 | D3 ~ A5 | 합성음 사용 |
| 거문고 | 5음 | C2 ~ C4 | 합성음 사용 |
| 대금 | 6음 | D4 ~ D6 | 합성음 사용 |
| 단소(또는 소금) | 4음 | A4 ~ A6 | 합성음 사용 |
| 피리 | 4음 | A3 ~ A5 | 합성음 사용 |
| 장구 궁편 | 3~4타 | — | 합성음 사용 |
| 장구 채편 | 3~4타 | — | 합성음 사용 |
| 북 · 징 · 꽹과리 | 각 2~3타 | — | 합성음 사용 |

음이 띄엄띄엄해도 됩니다. **사이 음은 샘플러가 리샘플링으로 만듭니다**
(대역 음원으로 시험한 결과 59음 전부 오차 12센트 이내 — 사람 귀로는 구별되지 않는 수준).
같은 음을 여러 번 받아두면 타점마다 돌아가며 써서 기계처럼 반복되는 느낌이 줄어듭니다.

## 2. 어디에 넣나

```
durango-mini/public/assets/audio/bgm/samples/
```

**폴더 구조는 아무래도 괜찮습니다.** 경로(폴더명이든 파일명이든) 어딘가에 악기 이름만
들어 있으면 알아서 분류합니다. 한글·로마자 둘 다 인식합니다.

```
samples/
  가야금/  … .wav          ← 이렇게 해도 되고
  대금_D4.wav               ← 이렇게 한 폴더에 다 넣어도 됩니다
  janggu_gung_01.wav        ← 로마자도 됩니다
```

인식하는 낱말: `가야금/gayageum` `거문고/geomungo` `대금/daegeum` `단소·소금/danso`
`피리·태평소/piri` `해금/haegeum` `아쟁/ajaeng` `궁편/gung` `채편/chae` `장구/janggu`
`북/buk` `징/jing` `꽹과리/kkwaenggwari`

- 파일명에 `A3` `C#4` 같은 음이름이 있으면 그대로 씁니다.
- 없으면 **음정을 자동으로 알아냅니다.**
- 장구를 궁편/채편 구분 없이 `장구` 로만 넣으면 소리의 밝기로 자동으로 갈라줍니다.

---

## 3. 넣고 나서 할 일 (명령 두 줄)

```bash
cd durango-mini/public/assets/audio/bgm
python3 sampler.py scan samples/       # 색인 만들기 + 무엇이 들어왔는지 표로 확인
python3 render_samples.py samples/     # 12곡 다시 렌더링 → out_samples/
```

`scan` 이 이런 표를 찍습니다. **여기서 음역이 이상하면 그 파일만 빼거나 이름에 음이름을 적어주세요.**

```
악기               개수                  음역  판별
--------------------------------------------------------------
gayageum          8             D3 ~ C5  자동검출8
daegeum           7             D4 ~ A5  자동검출7
janggu_gung       4                (타악)  타악4
```

`⚠신뢰도낮음` 이 뜨면 그 파일은 음정 판별이 애매했다는 뜻입니다
(잔향이 길거나 여러 음이 섞인 파일). 파일명에 음이름을 적어주면 그걸 우선합니다.

---

## 4. 섞어 쓸 수 있습니다

**있는 악기만 진짜 소리로 바뀌고 나머지는 합성음이 그대로 쓰입니다.**
가야금만 넣으면 가야금 자리만 바뀝니다. 전부 다 모을 때까지 기다릴 필요가 없습니다.

렌더링할 때 어느 악기가 어느 쪽인지 찍어줍니다.

```
  ● gayageum       샘플
  ○ piri           합성
```

---

## 5. 브라우저 실시간 엔진은?

`bgm.js`(파일 없이 실시간 합성)는 아직 합성음만 씁니다.
샘플을 쓰려면 실시간 엔진도 샘플러로 바꿔야 하는데, 그건 음원이 확정된 뒤에 하는 게 맞습니다.
당분간은 **렌더된 파일(`bgm-loops.js`)** 쪽을 쓰시면 됩니다.
