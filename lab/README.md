* **배율의 자리**는 T172 가 고쳤다(`보고/T172_2026-09-11.md`). 사냥·벌목 주입 문이 `baseAmt` 를 통째로 덮어써서 `skillMul·toolBoost·inputMult` 가 세계에서 지워져 있었다(숙련 10과 초보가 같은 고기). 이제 문은 **양과 배율을 따로** 넘기고(`fn(v,npc,baseAmt,_mul)` · `npc._t172mul`), 배율은 **실체가 나는 곳**(`L_CHOP`·`huntTake`)에 걸린다 — 잘하는 사람이 더 베고 더 잡고, 소득은 그 장부를 따른다. 문 뒤에 다시 곱하면 이중이다. **재측정: 사냥꾼 46→160·인구 938→1,029 · 나무꾼 159→96·숲 중앙 80.1→81.5%** — 재민 값 판정의 바른 자료는 T172 표다.
